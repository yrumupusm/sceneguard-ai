# SceneGuard

**CCTV 녹화 영상에서 침입 의심 상황을 찾고, 판단 근거를 검토하는 로컬 분석 도구**

**현재 단계: 1차 MVP**

사람의 위치·이동 방향과 문·담장 주변의 관측 변화를 이용한 침입 감지. 같은 상황의 반복 검출을 사건별로 정리하고, 웹에서 원본 영상과 검출 박스를 함께 확인하는 검수 환경.

## 주요 기능

- **감시 범위 설정** — 카메라별 문·담장 영역과 경계선 지정
- **침입 의심·침입 검출** — 사람 검출·추적에 이동 방향, 경계 통과, 검출 소실 근거를 결합
- **사건 관리** — 같은 상황의 후속 근거를 모으고 상태·알림 이력 관리
- **웹 검수** — 원본 영상·박스 이미지 확인, 사건·누락 검토, 답변·수정 이력 저장

`침입 검출`은 시스템 규칙에 따른 판단. 사용자의 검수 결과와 별도로 관리하며, 출입 권한이나 법적 무단침입을 판정하는 기능은 아님.

## 동작 방식

```text
녹화 영상 + 감시 영역
    ↓
사람 검출·추적
    ↓
이동 방향·경계 통과·소실 판단
    ↓
침입 의심 / 침입 검출 / 의심 해제
    ↓
사건별 근거 정리 → 웹 검수
```

사람이 문을 넘는 모든 순간을 연속 추적하기 어려운 장면에서, 문 주변의 전후 관측을 활용하는 방식. 동일 영상·검출 설정의 결과를 저장해 후속 규칙 비교에 재사용.

## 1차 MVP 평가

AI Hub 지능형 관제 서비스 CCTV 영상 데이터의 침입 범주 **45개 영상 전구간 분석**. 시간 구간을 해석할 수 있는 **공식 사건 52건**을 기준으로 포착 여부 평가.

| 평가 단계 | 침입 의심 | 침입 검출 | 구분 |
| --- | ---: | ---: | --- |
| 초기 전체 평가 | 46/52 · 88.46% | 24/52 · 46.15% | 초기 기준 결과 |
| 경계 통과 보완 선택안 | 51/52 · 98.08% | 39/52 · 75.00% | 기본 선택안의 전체 평가 |
| 오확인 억제 보완 실험 | 51/52 · 98.08% | 37/52 · 71.15% | 비교 후보 · 기본 적용 보류 |

**초기 평가 대비 보완 실험의 침입 검출 24→37건, 13건 증가.** 다만 직전 실험안에서 잡던 일부 사건도 놓쳐, 보완안을 기본 구성으로 일괄 적용하지 않은 상태.

위 비율은 실제 사건 중 포착한 비율인 **재현율**. 미검수 경보가 남아 전체 정확도·정밀도·F1은 미확정. 개발에 사용한 카메라를 포함한 평가로, 새로운 환경의 성능과 구분.

[초기 전체 평가](docs/MVP_FULL_EVALUATION.md) · [경계 통과 보완](docs/GATE_OBSERVATION_REVIEW.md) · [최신 보완 실험](docs/experiments/EXP-0062-results.md)

### 대표 개선

같은 카메라의 **6개 영상·공식 사건 7건**에서 문 옆 기둥·담장 경로까지 감시 범위 보완. 모델·판정 규칙을 유지한 비교에서 침입 의심 **2→7건**, 침입 검출 **0→6건** 포착.

## 사용 기술

| 역할 | 기술 |
| --- | --- |
| 사람 검출 | PyTorch · TorchVision · FCOS |
| 추적·이동 분석 | ByteTrack · OpenCV · Lucas–Kanade Optical Flow |
| 결과·검수 화면 | Python · HTML · CSS · JavaScript |
| 별도 비교 실험 | SSDLite · RF-DETR · YOLO 검출·포즈 · BoT-SORT + ReID · Qwen VLM |

VLM 2B·4B·8B 및 양자화 구성, ONNX Runtime 기반 ReID는 별도 비교 실험. 기본 침입 판단은 CV 관측과 규칙 기반 처리.

## 실행 안내

**로컬 녹화 영상 분석용 구성.** 원본 영상·모델 가중치·카메라 설정·검수 DB는 별도 준비. 저장소만 내려받아 동일 CCTV 결과를 바로 재생하는 구성은 아님.
