# SceneGuard

**CCTV 침입 의심 구간을 찾고, 출입구별 사건 카드와 근거 영상으로 검토하는 로컬 프로토타입.**

사람별 경보가 반복되는 대신 같은 출입구의 짧은 알림을 한 카드로 묶습니다. 침입 의심은 검토 대상이며, 영상만으로 실제 출입 권한이나 모든 침입을 확정하는 제품은 아닙니다.

## 현재 동작하는 흐름

```text
저장된 검출·추적 관측
  → 경계 변화 / 문 주변 소실로 침입 의심 생성
  → 같은 출입구의 반복 알림을 사건 카드로 통합
  → 첫 알림 표시 / 이후 무음 갱신
  → 원본 근거 영상 확인
```

현 단계의 최신 검증은 **저장된007·030 관측을 이용한 오프라인 분석과 기존 웹 재생**입니다. 원본 영상 파일을 선택해 최종 구성 전체를 한 번에 실행하는 경로와 수동 검토 저장 UI는 아래 마무리 작업에서 연결할 대상이며, 아직 완료로 표시하지 않습니다.

## 구현과 확인 범위

| 항목 | 상태 |
|---|---|
| 침입 의심 생성 | 기존 모델 관측을 이용한 CPU 규칙 적용 완료. 정상 접근 오탐이 남아 있음 |
| 사건 카드 | 같은 세션·카메라·출입구, 알림 간3초/첫 알림부터최대10초 묶음 |
| 알림 표시 | 첫 알림 즉시 표시, 후속 무음 갱신, 중복 수신 기록 유지 |
| 근거 영상 | 원본 PTS에 맞춘 재생·되감기·근거 시점 이동 |
| VLM | 외형/영상 검토 실험 기록 보존. 현재 자동 침입 확정에 사용하지 않음 |
| 추적 단절 오탐 후처리 | EXP-0037 핵심 코드·합성 시험 준비. 실제 영상 효과 미검증 |
| 검토 결과 저장 | 별도 SQLite 저장 모듈·합성 시험 준비. 기존 웹 연결 미완료 |
| 단일 영상 분석 진입점 | 최종 연결 작업 예정. 범용/실시간 분석 완료로 주장하지 않음 |

## 확인된 결과

EXP-0036에서 기존007·030 알림 **18행을 사건 카드5개로 표시**했습니다. 기존 웹 재생에서 최초 토스트5회, 무음 갱신13회를 확인했습니다. 원래 알림/관련 ID/시간은 보존됩니다. **카드 감소는 오탐 감소나 침입 정확도 향상이 아닙니다.**

[사건 카드 결과](docs/experiments/EXP-0036-results.md) · [실제 화면·게시 확인](docs/experiments/EXP-0036-delivery.md) · [침입 의심 조건 완화 결과](docs/experiments/EXP-0035-results.md)

## 로컬 확인

이미 구성된 개발 환경에서는 기존 결과 화면의 **담당3 → EXP-0036 → 사건 카드 재생**에서 확인합니다. 원본 영상·설정·관측 캐시·결과 JSON·모델 가중치·알림 영수증은 Git에 포함하지 않습니다. 저장소만 내려받으면 실제 CCTV 데모가 자동 실행되는 구성은 아닙니다.

완료한 녹화 세션을 재생하면 영수증에 따라 팝업은 반복하지 않지만 사건 카드는 표시됩니다. 이는 사용자의 알림 수신을 영구적으로 보장하는 exactly-once 시스템과 다릅니다.

현재 서비스 관리/복구와 실제 자료 위치는 [전달 문서](docs/experiments/EXP-0036-delivery.md)에 있습니다. 기존 파일을 지우거나 영수증을 초기화해서 결과를 다시 만들지 않습니다.

합성 테스트만 실행하려면 저장소 루트에서 다음 명령을 사용합니다. 이 테스트에는 실제 CCTV·모델이 필요하지 않습니다.

```bash
python -m unittest discover -s tests -p test_mvp_finish.py -v
```

최신 로컬 구현·실행 계약: **[MVP 마무리 지침](docs/CODEX_MVP_FINISH.md)**.

## 구조

- `sceneguard/`: 사전학습 FCOS 입력, ByteTrack 관측, 경계·소실 규칙, 사건 카드, 검토 저장.
- `mvp/`: Qwen VLM의 제한된 검토 실험 및 입력/출력 진단.
- `orchestration/`, `webapp/`: 기존 실행 관리, 결과 조회·영상·카드 UI.
- `tests/`, `tests_mvp/`, `tests_orca/`: 규칙·어댑터·저장·화면 계약 테스트.
- `docs/experiments/`: 실행 조건, 성과, 실패, 검증 범위를 구분한 실험 기록.

## 한계

소수 개발 영상/수동 카메라 설정에 의존합니다. 검출 누락, ID 단절·혼합, 가림에 따른 오탐이 남아 있습니다. VLM 출력은 확인된 사실이나 동일인 정답이 아니며, 추가 학습·ReID·VLM 비교가 모두 성능 개선으로 이어지지는 않았습니다. 일반 CCTV의 정확도/F1, 시간당 오탐률, 운영 실시간 성능은 입증하지 않았습니다.

알림과 영상은 사람이 확인하기 위한 근거입니다. **침입 의심 / 침입 확인 / 침입 아님 / 판단 불가**를 구분하고, 자동 상태와 검토자가 남긴 확인을 혼동하지 않습니다.
