# SceneGuard

**고정 CCTV 녹화 영상에서 침입 의심·자동 확인과 근거 구간을 사건 카드로 검토하는 로컬 MVP입니다.** 출입 권한이나 법적 무단침입, 개인별 신원·인원수를 판단하지 않습니다.

## 기본 흐름

```text
원본 영상 + 명시적 C3/C6 카메라·분석 범위
 → 입력과 일치하는 FCOS 캐시 또는 기존 큐의 같은 검출기
 → ByteTrack · 원본의 CPU 특징 경로
 → 문 주변 의심 · 방향과 소실에 따른 자동 확인/연결된 의심 해제
 → 현재 실제 문 관측으로 사건 유지 · 관찰 종료
 → 원본 근거 영상 · 시간순 카드 · 별도 수동 검토
```

검출 캐시만 재사용해도 추적·영상 특징·최신 판정은 현재 입력에서 계산합니다. 과거 EXP 결과를 새 분석인 것처럼 재생하지 않습니다. 같은 요청의 완료 단계를 검증 후 재사용하는 기능은 별도입니다. VLM·새 모델·파인튜닝은 기본 흐름에 없습니다.

## 실행과 기본 화면

기존 로컬 저장소에서 성공한 명령입니다. 같은 명령은 완료 단계를 재사용하며, 입력·설정·버전이 달라지면 새 출력 폴더와 등록 ID를 사용합니다.

```bash
.venv-cv-batch02/bin/python -m sceneguard.mvp_pipeline \
  --video data/TS_침입/E01_007.mp4 --camera C3 \
  --scene runtime/region-revisions/007-inside-20261101-v1/scene007.json \
  --portal runtime/portal-regions/exp0046/C3.json \
  --cache outputs/exp0029/cache007 --start 48 --end 105 \
  --output outputs/mvp-v1/007-acceptance-v2 \
  --register-config /home/jhc7484/dev/sceneguard-orca-lab/runtime/orca-lab/local_config.json \
  --registration-id mvp-v1-007-acceptance \
  --registration-python /home/jhc7484/dev/sceneguard-orca-lab/.venv-orca-lab/bin/python
```

**http://127.0.0.1:8765/ → 영상 분석**에서 기본 결과를 선택합니다. 실험 번호를 찾을 필요가 없습니다. 이전 자료는 **이전 실험 및 비교 이력**에 보존합니다. 신규 영상 입력은 CLI로 지정하며 웹은 완료 결과 재생·검토를 담당합니다. 카메라 설정·원본·모델·캐시는 로컬 전용이므로 공개 저장소만으로 실제 CCTV가 자동 제공되지는 않습니다.

## 실제 입력 검증

| 구간 | 최신 결과 |
|---|---|
|007 48–105초|사건 1개. 첫 의심 55.633초, 확인 72.133초, 관찰 종료 74.567초|
|030 84–100초|사건 1개. 확인 92.733초, 97초대 후속 관측도 같은 카드, 구간 끝에서 관찰 진행 중|
|007 84–104초 일반 통행|600프레임, 후보·카드·알림 0건 정상 완료|
|007 45–48초 추가 기술 구간|90프레임, 후보·카드·알림 0건 정상 완료; 이전에 사용한 자료|

007/030은 기존 개발 회귀 자료이며 독립 평가가 아닙니다. 원본에서 새 추적·CPU 특징을 계산하고 최신 결과와 근거 영상을 생성했습니다. 동일 요청 재실행은 추가 검출·추적·특징 계산 없이 완료 단계를 재사용했고, 변경된 입력은 거부했습니다. 실제 화면과 게시 확인 범위는 릴리스 문서에 따로 기록합니다.

정기 자동 폴링을 통과하는 연속 재생은 Chromium 절전 오류로 아직 미검증입니다. 짧은 재생·상태 전환·되감기·새로고침 확인과 구분합니다.

## 상태와 한계

- **침입 의심 / 침입 확인 · 자동 / 의심 해제**는 고정 규칙의 자동 상태입니다. 수동 검토·메모와 별도로 저장합니다.
- **문 주변 관찰 종료**는 의심 해제·현장 안전·모든 사람의 퇴장을 뜻하지 않습니다. 3초간 실제 문 관측이 없으면 관찰만 닫고 확인 이력은 유지합니다.
- 사건별 첫 의심·첫 확인은 각각 한 번이며 후속 미결 근거가 같은 확인 사건을 다시 의심으로 내리지 않습니다. 개별 미결 근거는 그대로 남습니다.
- 실제 바깥 이탈에 따른 의심 해제는 **실영상 미검증인 실험적 자동 판정**입니다. 정상 통행 무경보를 해제 성공으로 세지 않습니다.

지원 범위는 고정 C3/C6·native30fps·로컬 비실시간 분석입니다. 정상 접근 의심, 가림·부분 신체·검출 누락·박스/ID 혼합의 한계가 남습니다. 정확도/F1·시간당 오탐률·다른 카메라 일반화·실시간 운영·외부 경보 전달은 검증하지 않았습니다. 새로운 모델이나 조건 탐색 없이 통합한 1차 MVP입니다.
