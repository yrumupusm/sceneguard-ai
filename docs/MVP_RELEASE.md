# SceneGuard 1차 MVP 릴리스

**고정 C3/C6·native30fps·로컬 비실시간 분석의 1차 기능 통합을 완료했다.** 실제 바깥 이탈 해제와 독립 일반화 성능은 미검증이며, 브라우저 절전으로 정기 폴링 중 연속 재생 확인 한 항목이 남는다. 전체 UI 체크리스트/성능 보증 완료를 주장하지 않는다.

최신 main `e603288`과 사용자 첨부 [CODEX_MVP_FINALIZE.md](CODEX_MVP_FINALIZE.md)를 기준으로 진행했다. 초기 로컬은 변경 없는 `00dd16a`였고 fast-forward했다. 기존 실험/원본/영역/검토DB/영수증을 보존했다. 이번 새 실행 태그MVP-0002는 기존 코드의 계약 식별자이며 과거 EXP13의 동명 계획/검토를 대체하지 않는다.

## 채택과 실제 실행

기존 FCOS·ByteTrack·CPU 특징 경로·문 이력/방향/소실·연결된 근거의 후속 상태와EXP49 사건 관리를 기본 흐름에 연결했다. 기존 영상+검증된검출에서 새 결과를 계산하며 과거 판정 파일은 회귀 비교에만 사용한다. 새 검출법·모델·학습·VLM·영역/임계값 탐색은 없다.

실제 실행 명령은 [README](../README.md)와 [MVP_QUICKSTART](MVP_QUICKSTART.md)에 있다. 기본 화면은 **http://127.0.0.1:8765/ → 영상 분석**이며 실험 번호 선택 없이007 최신 결과가 열린다. 새 영상은 단일 CLI로 분석·등록하고 웹에서 완료 결과를 검토한다. 별도 업로드 서버를 만들지 않았다.

## 변경·복귀와 한계

주요 변경은 `mvp_pipeline.py`의 현재실행 계보·측정·캐시검증·등록옵션, `webapp/mvp_registration.py`의 안전한등록, 기존웹의MVP 기본보기·미디어허용·빈결과·시각별상태, 완료절차의MVP 식별자/제한된오프라인채택표시와 회귀시험이다. 원래 방향·소실/문영역/사건유예는 바꾸지 않았다.

이전결과는 **이전 실험 및 비교 이력**에 그대로 있다. 기본 지정은 별도config키로 유지하고 snapshot을 보존했다. 복귀 방법은 실행 안내를 따르며 DB초기화/강제reset/원본덮어쓰기는 하지 않는다. 기존 README는 [이력](README.before-MVP-V1.md)으로 보존했다.

침입 검출은 정한규칙의 결과이며 법적판정이나 개인식별보증이 아니다. 정상접근 의심·박스/ID혼합·가림/검출공백의 한계는 남는다. 실제해제0건으로 **의심해제는 실영상 미검증인 실험적 자동판정**이다. 독립미사용자료·다른카메라·실시간·외부경보전달을 검증하지 않았다. 사례를 찾으려고 새데이터/모델실험을 추가하지 않고 이번통합을 종료한다.

## 게시와 독립 검토

[독립 검토](reviews/MVP-V1-independent-review.md)는 새출력·원본계보·시각별근거·공개지표와 실제웹영수증을 대조한다. 코드·문서·공개집계만 게시하며 원본영상/이미지/좌표/관측/가중치/DB/인증정보는 로컬전용이다. 게시 커밋과 실제 서비스 버전은 최종 전달 기록에 별도로 덧붙인다.

게시 전 공개 검사에서 보고서/검토의 머신 절대 경로가 거부돼 표기만 정규화하고 별도 Astra 검토로 새 해시를 결속했다. 문서 편집 종료 전에 등록한 임시 신규 항목은 로컬에 보존하고, 완료된 검토 해시로 해당 신규 항목만 다시 등록했다. 기존 실험 항목·미디어·DB는 바꾸지 않았다.

실행·구현·문서 게시 커밋은 `6b4081ec01ec222029e7af7b7e22b86c212dfad7`이다. GitHub `origin/main`과 보고서·지표·독립 검토·결속 파일의 정확한 SHA256 일치를 별도 전달 검증으로 확인했다. GitHub 검증의 성공은 브라우저 연속 재생 미검증을 해소하지 않는다. 실제 서비스 코드 대조는 별도 영수증으로 남긴다.

실제 서비스도 같은 `6b4081e` 체크아웃에서 기존 관리 명령으로 재시작했다. HTTP가 제공하는HTML/JS/CSS의 바이트가 커밋과 같고 백엔드 소스·기본007·네등록·영상Range206 및 등록된 보고서/지표/검토/binding 해시를 대조했다. 원격 게시와 실제 서비스 버전은 별도로 확인했으며, 기존 브라우저 시연 결과와 정기폴링 미검증 상태는 그대로다. 후속 전달 문서 커밋은 이 코드·결과를 바꾸지 않는다.
