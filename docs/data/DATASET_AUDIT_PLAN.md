# 데이터 감사 계획 — Safe and Unsafe Behaviours

- 상태: 실제 영상 검수 **미착수** (2026-10-26)
- 데이터 후보: https://huggingface.co/datasets/Voxel51/Safe_and_Unsafe_Behaviours
- 원본: https://data.mendeley.com/datasets/xjmtb22pff/1

## 먼저 확인할 이유
영상 단위 위험 행동 라벨만으로 객체 박스, 추적 ID, 이벤트 발생 시점의 정답까지 갖췄다고 가정하면 안 된다. 설비 패널의 열린 상태와 지정 통로 이탈처럼 문제별로 필요한 시각 정보가 다르다.

## 검사 절차
1. 원 연구 및 배포본의 클래스·라벨·영상 수·분할·라이선스·재배포 조건 대조.
2. 전체 다운로드 전 정상 약 3~5개, 위험 약 3~5개를 선정한다. 이 표본은 탐색용이며 정량적 대표성을 주장하지 않는다.
3. 실제 재생, FPS, 해상도, 길이, 카메라 구도, 객체 크기, 가림, 발생 구간 확인.
4. 영상 ID ↔ 공식 라벨 매핑 검증. 파일 이름으로 정답 임의 추정 금지.
5. 통로/패널 등 행동 판단의 근거가 보이는지, 단일 프레임인지 연속 프레임이 필요한지 분류.
6. 사용자 검수로 모델이 해석할 위험 판단과 실제 관찰 내용이 일치하는지 확인.
7. 카메라/같은 사건의 유사 영상이 평가셋에 중복돼 성능이 부풀려질 위험, 라이선스 문제 기록.
8. 실물 영상·가중치는 Git에 추가하지 않고 출처 링크·로컬 파일 ID·조건만 기록.

## Gate G1 합격 조건
- [ ] 실제 확보·재생 가능한 영상
- [ ] 공식 라벨과 파일 ID 연결
- [ ] 영상에서 관찰 가능한 최소 한 사건 정의
- [ ] 사용 조건/라이선스 확인
- [ ] 평가 가능 범위 설명 (영상/이벤트 구간/객체 단위)

미달이라면 Go가 아니라 **Conditional Go 또는 No-Go**를 제안하고 데이터/문제 재선정을 검토한다.
