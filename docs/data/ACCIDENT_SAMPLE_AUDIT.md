공식 [프로젝트](https://accidentbench.github.io/) → [코드 저장소](https://github.com/accidentbench/ACCIDENT) → [Kaggle dataset picekl/accident](https://www.kaggle.com/datasets/picekl/accident) 연결을 확인했다.

[Kaggle 공식 CLI 문서](https://github.com/Kaggle/kaggle-cli/blob/main/docs/datasets.md)는 `datasets download ... -f <file>` 개별 파일 선택을 지원한다. 이번에는 표준 라이브러리 urllib로 공개 API의 파일별 URL에 요청했고 **인증 없이 성공**했다. 토큰·자격증명 파일을 읽지 않았으며 로그인 절차를 우회한 것이 아니다. 향후 서버가 인증을 요구하면 사용자가 로컬에서 처리해야 한다.

요청 형식: `/api/v1/datasets/download/picekl/accident/<URL-encoded filename>?datasetVersionNumber=9`. 버전 9를 지정하고 현재 버전도 검사한다. HTTP 200만으로 성공 판정하지 않고 HTML 여부·응답 크기·CSV 구조·영상 디코딩까지 확인했다. 서명된 리다이렉트 URL은 기록하지 않는다.

공식 `dataset/download_dataset.sh`는 전체 ZIP을 받으므로 **실행하지 않았다**. 처음 `pageSize=1000` 요청도 서버가 200개만 반환함을 확인해 페이지 토큰을 끝까지 순회하도록 구현했다. 첫 페이지만 전체 목록으로 오인하지 않는다.

### 대회 정답과 dataset 공개 주석의 차이

기존 조사에는 [ACCIDENT 대회](https://www.kaggle.com/competitions/accident)의 실제 영상 학습 라벨 미제공 안내가 있다. 이번에는 별도 **dataset v9의 실제 CSV 2,027행에 사고 시점·영역·유형 값이 존재**함을 확인했다. 이를 근거로 대회의 hidden test 정답이 공개되었다거나 대회 학습에 사용할 수 있다고 주장하지 않는다. 대회 참가/다운로드/제출은 하지 않았다. 웹 도구로 대회 본문을 재확인하려 했으나 렌더링된 본문을 얻지 못했다.

## 2. 이용 조건과 남은 권리 확인

- **Kaggle API 실측:** 배포 라이선스 표시는 **CC BY-NC-SA 4.0**.
- **논문 보고:** [arXiv 본문 부록 B](https://arxiv.org/html/2604.09819v1#A2)는 연구 용도·재식별 금지, 원 출처별 재배포 허용 영상 사용, 주석/메타데이터 CC BY 4.0을 설명한다. 플랫폼 전체 표시와 자산별 설명을 같은 라이선스로 단정하지 않는다.
- **로컬 확인:** 받은 실제 CSV에 canonical source URL·개별 원본 라이선스 필드가 없다. 논문이 설명한 출처 정보가 이 CSV에는 포함되지 않아 개별 권리 증빙은 완료하지 못했다. 파일명으로 YouTube URL을 추정해 권리 확인을 대신하지 않는다.
- 이번 범위는 비상업 연구용 로컬 소량 감사. 영상·추출 이미지·주석 원본은 Git 제외. 공개 데모 미디어·재배포·상업 이용의 허가는 미확인이다.
- CVF 보충자료 URL은 웹 도구에서 403이어서 공식 arXiv 부록을 확인했다. arXiv 논문 자체의 라이선스를 데이터 라이선스로 전환하지 않는다.

## 3. 공개 정답 구조와 무결성

`metadata-real.csv`: **2,027행, 22컬럼**, path 중복 없음. 파일 목록의 실제 MP4 2,027개와 집합이 정확히 일치한다. 빈 필드 0개. 사고 시간이 CSV duration 범위 밖인 행 0개, bbox 좌표 범위/순서 위반 0개. 이는 구조 검사이며 2,027개 영상의 의미 검수는 아니다.

| 필드 | 실제 제공 범위 / 사용 한계 |
| --- | --- |
| `path` | 실제 영상 파일과 연결하는 키 |

| `accident_time`, `accident_frame` | 사고 기준 시점 1개. 사건 시작·종료 구간 정답과 다름 |
| `center_x`, `center_y`, `x1,y1,x2,y2` | 정규화된 사고 중심·영역. 객체별 bbox/추적 시퀀스와 다름 |

유형별 행: single 680, t-bone 657, rear-end 328, sideswipe 245, head-on 117. 이번 실제 CSV에는 정상/비사고 유형이 없다. 이 자료만으로 정상 CCTV의 오탐률·사고 발생 여부 이진 성능·실시간 경보 효용을 검증할 수 없다.

IID 분할은 train 507/test 1,520, geographic 분할은 train 454/test 1,573. 이 CSV에는 validation 값이 없다. 자유 서술 정답, 사고 원인/책임, 원 출처 URL, 고유 camera/session ID, 사건 종료 구간 필드도 없다. 합성 주석에 있을 수 있는 객체 정보가 실제 영상에도 있다고 가정하지 않는다.

### 발견하고 수정한 검사 오류: 자동 FPS 보정

초기 imageio-ffmpeg 기본 raw 출력은 가변 PTS를 일정 간격으로 맞추면서 프레임을 복제했다. 처음 156/87/231/50/79개로 집계됐으나 **`-fps_mode passthrough`를 명시한 뒤 78/86/141/50/65개**로 수정됐다. FFmpeg `showinfo`의 전체 원본 PTS 개수와 독립 대조해 일치했다. 처음 결과는 `initial_cfr_manifest.json`에 오류 이력으로 남기고 최종 수치에서 제외했다.

5개 모두 CSV `no_frames`는 실제 개수보다 1 작고 CSV duration은 마지막 프레임 PTS에 가깝다. **0부터 세는 마지막 인덱스를 저장했을 가능성**이 있으나 생성 코드를 확인하지 않아 원인을 확정하지 않는다. `accident_frame`를 0-based로 조회한 PTS는 각각 3.233333/2.692308/4.000000/2.166667/3.500000초이며 CSV 사고 시간과 오차 0.001초 미만이다. 모든 영상에서 프레임 간격이 일정하지 않으므로 `frame_index / 평균 FPS`로 사건 시간을 대신하지 않는다.

공통적으로 원거리 고정 도로 카메라 구도가 보이고, 관찰한 프레임에는 다른 카메라로의 장면 전환은 없었다. 이는 5개 표본에 한정한 관찰이다. 시간·지명·로고 오버레이는 원본에 남아 있다.

## 5. 출처·분할 누수와 평가 설계

파일명 앞 11자를 원 출처 후보로 묶으면 1,789그룹, 그중 92그룹에 복수 클립이 있다. 이 규칙은 이름 기반 가설이며 실제 원본 URL/같은 사건/같은 카메라를 확인한 것은 아니다.

- IID train/test 양쪽에 걸치는 원 출처 후보 3개: `OehnhIPFm4Q`, `kd7QwQqeJZQ`, `YueG1zLkV8o`.
- Geographic train/test 양쪽에 걸치는 후보 1개: `BLq2n48HYZc`.
- 이 네 후보에 속한 행은 총 13개. 같은 원본 편집물의 다른 사건일 수 있으므로 확정된 사건 누수라고 단정하지 않지만, 독립 평가 전에 직접 대조해야 한다.
- 선택한 5개 파일의 SHA256은 서로 다르다. 전체 데이터의 동일 영상·유사 장면 중복 여부는 검사하지 않았다.
- 이번 표본에는 공식 test 클립도 포함된다. 이미 라벨·영상을 검토했으므로 향후 미관측 최종 평가 세트로 재사용하지 않고 개발/감사 표본으로 명시한다.

## 6. 재현·검증과 로컬 산출물

- FFmpeg 7.0.2, imageio-ffmpeg 0.6.0, Pillow 12.3.0. GPU/모델/가중치/학습/추론 서버 미사용. 모델 정확도·속도·VRAM·업무 효용 미측정.
- `data/accident_audit/`: dataset.json, listing 33페이지, metadata-real.csv, annotation_classes.yaml, real_videos 5개, previews, manifest.json, annotation_report.json, request_log.json. **전부 Git 제외**.
- 최초 실제 HTTP 200 다운로드 기록은 `initial_request_log.json`, 재실행은 캐시 사용 여부를 구분해 기록한다. API에 원본 SHA256 필드가 없어 로컬 SHA256은 재현용이며 배포자 해시와 일치했다고 주장하지 않는다.
- 영상별 목록 bytes 일치, 1:1 주석 연결, 전체 디코딩, 독립 PTS 개수, 사고 프레임 인덱스/시간 대조를 수행했다. 문법 검사·`git diff --check`도 실행했다.
- 다운로드 수는 코드의 고정 5개 ID로 제한되고 개별 파일 크기 제한을 둔다. 전체 ZIP 엔드포인트를 호출하지 않는다. 재실행은 metadata를 갱신하고 동일 크기 영상 캐시를 재사용하므로 기존 파일의 변경 여부는 보존된 SHA256과 별도 대조해야 한다.

## 7. 활용 판단과 다음 사용자 검수

**Conditional Go:** 실제 고정형 도로 CCTV, 사고 전후 변화, 공개 기준 시점·영역·유형을 확보했다. 선택된 사고 클립에서 “어느 시점·어느 위치에 어떤 차량 움직임이 보이는가”를 사람이 확인·수정하는 연구는 가능하다. 접근 불가가 아니므로 CMA 대체 다운로드 조사로 전환하지 않았다.

다음 조건이 남는다.

1. 사용자가 A1 전복 여부, A2 `single`의 정의, A3/A4 최초 접촉을 전체 연속 재생으로 검수한다. 원 정답과 사람 보정본을 분리한다.
2. 사고 시작·종료/후속 조치 및 설명 사실 일치 기준은 추가 사람 라벨이 필요하다. 제공된 사고 시점 한 점을 전체 사건 구간 정답으로 바꾸지 않는다.
3. 파일명 출처 후보를 실제 원본/사건과 대조하고 개발·평가 분할을 정한다. 5개 감사 표본은 평가 오염 범위를 표시한다.
4. 산업안전과 교통 CCTV 중 제품 영역을 사용자가 결정한다. 도로 CCTV 결과를 산업현장 안전 성능으로 보고하지 않는다.
5. 원 출처별 권리·재게시 조건을 확인하기 전 공개 미디어 데모를 만들지 않는다. 비사고/연속 영상이 없어 실시간 사고 탐지·오탐률 평가를 주장하지 않는다.

위 조건을 보완한 뒤에만 G1D 최종 판단 및 G2 모델 후보 비교로 이동한다. 이번 감사는 데이터·모델의 최종 선정이 아니다.
