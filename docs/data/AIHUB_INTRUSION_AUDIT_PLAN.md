## Codex 소량 검증
- 원본 데이터가 사용자의 로컬에 이미 있다면 우선 재사용. 원격 로그인·승인·대량 파일 다운로드를 시도하지 않음.
- 가능하다면 **6~10개 이내**를 골라 반복 철제 출입구·다른 각도·정상 행동·줄 넘기·공원 울타리 사례를 포함. 특수 사례가 단 1개라면 전반 성능 일반화의 근거로 사용하지 않음.
- 파일 접근 불가 시 관련 링크, UI/인증 단계, 사용자가 해야 할 동작을 문서화하고 다운로드 성공을 꾸미지 않음.
- ffprobe/FFmpeg 등의 재현 가능한 방법으로 길이·FPS·실제 디코딩 및 주석 이벤트 PTS 연결을 확인.
- 모델 입력과 정답 JSON의 분리를 지키고, 불확실한 '정상' 라벨을 자동 생성하지 않음.
