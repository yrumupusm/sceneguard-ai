# WEB-0001 — 실험 중심 결과 화면

2026-11-02. 사용자 승인으로 기존 총괄·담당별 탐색을 실험 중심으로 바꿨다. 이전 UI 기능 동결은 이번 화면 수정 범위에서 해제됐다. 모델·판정·큐·원본 실험 결과는 바꾸지 않았다.

## 구현

- 총괄·담당 카드와 세팅 작업자 목록을 제거했다. 전체 등록 실험과 미등록 배정을 같은 크기의 최신순 카드로 표시하고 제목/ID 검색과 결과 등록 상태 필터를 추가했다.
- 상세는 목적, 이전 문제와 변경, 결론, 측정값, 대표 근거, 한계, 다음 단계, 참고 자료 순서다. 내부 JSON과 SHA 표 및 과거 총괄 검토 원문은 본문에서 제외했다. 출처 변경·검토 오래됨 경고는 유지한다.
- 원문에서 보수적으로 발췌한다. 없는 설명이나 정답을 생성하지 않는다. 참고 링크의 명시된 문맥만 표시하고 적용 맥락을 추출하지 못하면 그렇게 알린다. 원본 문서와 API의 기존 필드는 보존한다.
- EXP-0049에는 원문 해시에 연결된 편집 설명과 007/030 각각 사건 카드 2→1의 전후 그래프를 추가했다. 원문이 달라지면 해당 편집본은 적용하지 않는다. 카드 감소를 정확도 개선으로 부르지 않는다.
- 다른 실험은 개별 범위가 명시된 측정값을 최대 네 개 먼저 표시하고 전체 값은 펼쳐 본다. 서로 다른 실험의 지표를 임의의 정확도 추이로 연결하지 않는다.
- 실패·비교라고 등록된 근거를 먼저, 최대 네 개 표시한다. 나머지 근거와 입력 검수 시트는 접어 두었다. 미디어 라벨에 근거한 정렬이며 장면의 의미를 새로 판정한 것이 아니다.
- 기존 기본 MVP 영상 분석, 사건 재생, 수동 검토 및 이력 기능은 유지했다.

## 실제 확인

기존 http://127.0.0.1:8765 서비스에 적용하고 재시작했다. 실제 제공 app.js/style.css 바이트가 현재 작업 파일과 일치한다. Orca 브라우저에서 전체 53개(등록52·미등록1) 카드, 검색, 미등록 필터, 총괄/담당 제거, 동일 카드 크기(확인한 첫8개 279×173.625), 가로 넘침 없음, JSON pre 없음, EXP-0049 편집 목적과 2→1 그래프 두 개를 확인했다. EXP-0007 입력 시트는 기본 접힘 상태였다.

EXP-0049 근거 영상의 readyState4, 실제 재생 시각 증가(3.209993초)와 1초 되감기를 확인했다. 첫 재생 시도는 브라우저의 화면 밖 영상 절전 정지로 중단됐고, 화면 안으로 이동한 뒤 실제 재생을 확인했다. 이번 확인은 대표 영상의 재생이며 모든 등록 영상의 전수 재생 검증은 아니다. 사건 상태 전환·폴링·중복 방지·검토 이력 회귀는 기존 자동 시험으로 확인했으며 전체 시나리오를 브라우저에서 재검수했다고 주장하지 않는다.

독립 검토의 47개 Python 시험과 8개 Node suite가 통과했다. 담당자의 관련 API/등록 58개 시험과 통합 후 집중20개 시험도 통과했으며 서로 중복된 시험이므로 합산하지 않는다. 광범위 171개 discovery는 환경의 numpy 부재, GPU 가시성 사전조건, 과거 큐 수 고정 기대값 때문에 실패2·오류6·skip2가 있어 전체 저장소 통과로 보고하지 않는다. [독립 검토](../reviews/WEB-0001-independent-review.md).

로컬 보존 스냅샷에서 카탈로그·배정·서비스 설정·검토 DB·알림 영수증·GPU 큐와 기존 DB 스냅샷 20파일의 SHA가 동일했다. 독립 검토에서도 기존 보고서/기록/검토326파일의 HEAD 일치를 확인했다. 원본·이미지·영상·로그·DB는 커밋하지 않는다.

## 한계와 남은 작업

이번 변경은 화면 구조와 기존 기록의 읽기 쉬운 투영이다. 모든 과거 보고서를 사람이 새로 편집한 것은 아니며 일부 목적·변경 항목은 추출 불가 또는 원문 도입부로 남는다. 모든 실험의 비교 그래프나 실패 장면 설명이 새로 작성된 것은 아니다. 상세 편집과 비교 그래프의 검증된 예시는 EXP-0049다. 향후 각 실험의 공식 기록에 명확한 목적·변경·비교 수치를 남겨 같은 표시 구조로 확장할 수 있다.

MVP-0006 결과는 GitHub에 게시됐지만 로컬 완료 등록은 아직 미완료라 미등록 카드로 유지한다. 이번 UI 변경으로 등록 완료를 가장하지 않는다. 원래 남아 있던 MVP-0006 비교 미디어·서비스 등록 작업은 별도 잔여 작업이다.
