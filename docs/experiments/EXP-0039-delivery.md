- 코드 커밋 `409221637702704a288e11ddc7771d6d87834a9b`에서 기존 Run과 canonical GPU 큐를 사용했다. Sol high 실행 담당의 같은 활성 Task/Dispatch를 CPU와 조건부 ROI에 사용해 담당3 등록 이력과 실제 실행 주체가 일치한다.
- CPU 소실 진단14건, ROI2구간86프레임, 모델 적재1회·워밍업10회·GPU1job/1attempt를 완료했다. 새 모델·학습·VLM·기존 추적 재실행은 없다.
- 보호1629파일 및 과거49jobs/49attempts 행을 보존했다. 기존18알림/5카드, 모델·사용자 영역·의심·카드 규칙·검토DB는 유지한다.
- 원본·영상·이미지·좌표·원시 검출/특징 경로·가중치·로그·runtime DB는 Git 제외다. 공개 산출물은 코드·문서·비식별 집계다.

## 독립 검토와 결과 등록

Astra high는 CPU 전체14건/420대기프레임, 제안 알림·카드, ROI86프레임의 좌표/PTS/입력/실행/보존을 별도로 감사했다. 최종 보고서·32측정항목의 정확한 해시와 결론은 [독립 검토](../reviews/EXP-0039-independent-review.md)에 결속한다. 원본 영상 의미·동일인 정답을 자동 인증하지 않는다.

최종 독립 검토 `accepted_for_comparison`을 확인한 뒤 기존 `orchestration.complete` 절차로 담당3에 등록했고 로컬 package/artifacts는 `runtime/EXP-0039/delivery/`에 둔다. 등록 대상은18영상(14특징 비교+2원본+2ROI 비교)·20이미지(14판단시각+6ROI 정지 비교)다. 등록 성공과 실제 브라우저 표시를 구분한다.
