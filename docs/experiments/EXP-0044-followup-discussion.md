# EXP-0044 후속 대화 — 마지막 박스와 경계 안쪽 새 관측

2026-11-01. EXP-0044 결과를 본 뒤 사용자가 지적한 문제와 후속 방향을 정리한 대화 요약이다. 원문 전체의 축어록은 아니다. 사용자 관찰, 저장 자료로 확인한 사실, 아직 검증하지 않은 제안을 구분한다. 기존 결과 보고서와 독립 검토는 당시 실행 기록으로 보존한다.

## 1. 사용자가 제기한 문제

사용자는 007에서 사람이 파란 바깥 영역에서 보라 선 안쪽으로 이동해 사라졌는데도 왜 ‘침입 의심’으로 끝났는지 물었다. 이어 사람이 담장 부근에 있고 긴 노란 박스가 보라 선과 겹친 캡처를 제시하며, 이를 선에서 멀다고 설명하는 것은 맞지 않는다고 지적했다.

Codex는 처음에 마지막 박스가 근접 기준 밖이었다는 수치만으로 설명했다. 이때 **사용자가 보여 준 이전의 긴 박스와 실제 마지막 판정에 쓰인 작은 박스를 구분하지 않은 설명은 잘못이었다.** 화면의 사람이 문에서 멀리 떨어져 있었다는 의미로 읽히게 설명해서는 안 된다.

## 2. 저장 결과로 확인한 원인

EXP-0044는 앞선 전체 이동 경과만으로 확인하지 않고, 마지막 실제 박스의 중심이 선 가까이에 있는지도 다시 요구한다. 근접 반경은 최근 1초 박스 높이 중앙값의 0.8배와 최소 12픽셀로 정한다.

사용자는 이후 안쪽의 작은 박스와 이동 화살표가 보이는 두 번째 캡처를 제시했다. 캡처에는 원본 PTS가 없어 캡처 자체의 정확한 프레임/ID 대응을 새 정답으로 확정하지 않았다. 그림의 노란 `INWARD`는 설정된 입구 안쪽 방향이고, 붉은색 계열 이동 화살표는 저장 점에서 계산한 이동을 표시한 것이다. 고정 방향 화살표를 사람 이동의 측정값으로 해석하지 않는다.

## 3. 마지막 작은 박스도 연결 근거로 사용하자는 제안

사용자는 앞선 박스 중심이 이미 선 안쪽으로 넘어간 상태였고, 뒤의 작은 박스도 안쪽으로 향하므로 앞선 관측과 연결할 수 있지 않느냐고 제안했다. 먼 곳에서 무관하게 나타난 박스와 경계 부근의 소실 직후 안쪽에서 나타난 박스를 구분하자는 취지다.

사용자가 명확히 한 목표는 **몇 명이 침입했는지 세는 것이 아니라 침입이 발생했는지 판단하는 것**이다. 따라서 정확한 개인 ID 복원을 사건 판단의 필수 전제로 두지 않는다. 여러 사람이 섞여도 같은 출입구의 관측 흐름을 사건 하나의 근거로 모으는 방향이다. 다만 ‘정확한 동일인 연결을 요구하지 않음’이 ‘아무 박스나 연결해도 됨’을 뜻하지는 않는다.

Codex는 마지막 작은 박스가 선에서 멀다는 이유로 버리기보다 앞선 경계 이동의 후속 근거로 사용할 수 있다고 답했다. 시간·위치·방향의 연속성이 실제로 유효한지는 아직 비교 실행하지 않았다. 현재 두 캡처만으로 동일인 연결 성공이나 침입 완료를 확정하지 않는다.

## 4. 더 중요한 근거: 경계 바로 안쪽에서 관측이 시작됐는가

사용자는 이어 안쪽 이동 연결보다 **선 근처 안쪽에서 갑자기 박스가 생겼는지**가 더 중요하다고 강조했다. “보행자가 선에서부터 나타나지는 않을 것”이라는 카메라 배경 가정에 기반한 제안이다. 앞선 관측과 완벽히 같은 사람인지 확인하는 것보다 관측의 발생 위치와 직전 경과를 보자는 뜻이다.

향후 검토할 관점은 다음과 같다. 아직 수치나 필수 조건으로 고정된 알고리즘이 아니다.

- 경계 안쪽에서 처음 생긴 실제 관측인지 확인한다. 단순히 track ID가 새로 바뀐 것과 구분한다.
- 직전에 안쪽 통로에서 해당 위치로 걸어오던 관측이 있었는지 살펴본다.
- 경계 부근의 앞선 사람 관측·소실이 있다면 사건 근거를 보강한다.
- 후속 안쪽 이동이나 관측 지속도 보강 근거로 활용할 수 있다.

마지막 두 항목을 모두 필수로 요구해서 최초 출현 근거를 다시 차단하는 것으로 이 대화를 해석하지 않는다. 반대로 안쪽 박스 하나만으로 자동 확인한다는 합의도 아니다. 기존 사람의 검출 누락 후 재검출, 배경 오검출, 정상 통로의 가림 해제로도 새 박스가 생길 수 있다는 구별 과제는 남는다. 정밀 동일인 정답이나 수동 박스를 다시 요구하는 방향으로 확대하지 않는다.
