# BATCH-0006 — C6 640 대 960 비교 종료

2026-10-29. 동일 YOLO26m-Pose·C6 고정 ROI에서 입력 해상도만 바꾼 신규 세 예측을 완료했다. **94초의 문 위 사람은 사용자 검수상 새로 포착했고 품질도 괜찮지만, 90초 누락은 해결하지 못했다. 기본 적용은 보류한다.** 기술 실행과 일부 사람 관측 개선은 확인했으며 행동 구분 성능은 평가하지 않았다.

## 결과와 사용자 검수

| E01_030 시점 | 640 cached 박스 / 관절 추정 | 960 new 박스 / 관절 추정 | 사용자 관찰과 판단 |
| --- | ---: | ---: | --- |
| 84초 | 3 / 38 | 3 / 37 | 새 960도 잘 된다는 정성 검수. 기존 세 사람의 양호한 관측을 유지한다는 제한된 근거이며 관절별 정밀 GT는 아님 |
| 90초 | 1 / 12 | 0 / 0 | 사용자는 이전 실험과 동일한 수준으로 평가. 640의 오른쪽 한 사람 관절도 어긋났고 960은 새 출력 자체가 없어 유용한 관절 확보 실패가 지속됨 |
| 94초 | 0 / 0 | 1 / 11 | 사용자가 새 박스를 문 위 사람으로 확인하고 생각보다 잘 잡혔다고 평가. 이미 넘어가 있는 사람은 여전히 누락 |

관절 수는 confidence/unknown 규칙을 통과한 추정치 수이며 정확한 관절 수가 아니다. 90초의 정성적 ‘동일 수준’을 출력 개수 동등성으로 해석하지 않는다. 94초는 개수 증가뿐 아니라 사용자 인물 대응 확인이 있어 **문 위 한 사람의 제한된 관측 개선**을 말할 수 있다. 다만 손목·골반·무릎·발목 각각의 오차, 가림/중복/ROI 절단, 연속 시간 안정성은 확인하지 않았다. 이전 EXP-0024 관찰·공식 라벨을 변경하지 않는다. 에이전트는 로컬 CCTV를 클라우드로 전송하거나 픽셀을 직접 검수하지 않았다.

## 고정 조건과 비용

[EXP-0025](EXP-0025-c6-pose-960.md), [ADR-0023](../decisions/ADR-0023-c6-pose-960.md), [독립 검토](../reviews/EXP-0025-independent-review.md)를 따른다. 같은 84/90/94초 native PTS와 RGB, C6 x537:1440/y216:864, FP32·conf0.25·nmsFalse·max_det300 등 공식 kwargs22개 중 imgsz만640→960이다. 실측 tensor는 세 장 모두 CUDA0 FP32 1×3×960×960이다. 기존640 Results3개는 읽기 전용 재사용했고 새640추론은0회다. 960은 단일 큐 job/attempt1개, 모델 로드1회, sample3회, 별도 warmup1회, 오류/OOM/retry0이다.

| 시점 | 640 과거 inference ms | 960 신규 inference ms | 640 과거 public wall ms | 960 신규 public wall ms |
| --- | ---: | ---: | ---: | ---: |
| 84초 | 10.286 | 18.909 | 24.386 | 54.531 |
| 90초 | 30.990 | 24.237 | 903.369 | 898.043 |
| 94초 | 17.817 | 20.905 | 28.063 | 38.730 |

공식 Results.speed와 public 호출 wall은 계측·동기화·tensor 저장 영향이 다르다. 90초는 각 run의 첫 호출로 setup/fuse/warmup을 포함한다. 과거와 새 단회 측정이므로 FPS나 일반적 속도 향상으로 비교하지 않는다. 신규 constructor0.244초, setup0.382초, warmup0.424초, run-entry11.342초, queue attempt17.478초이며 중첩 구간을 합산하지 않는다.

새 PyTorch allocator peak allocated/reserved는 **294.27/370MiB**다. 과거 EXP-0023 전체5호출의195.36/218MiB와는 호출 수·범위가 다르다. 새 실행 직전 여유8172MiB로 기존6144MiB gate를 통과했고 장치 전체14샘플 최대사용2538MiB는 다른 프로세스까지 포함한다.

## 총괄 결정과 종료

- **구현·실행:** 신규 CPU 계약11개와 기존 큐 회귀14개 통과, 독립 합성6개는 중복 계약 검증. 실제960 세 장 성공과640무재추론 확인.
- **사람·관절 품질:** 84초 정성적 양호 유지,94초 문 위 한 사람 개선,90초 미해결 및94초 다른 사람 누락. 세 개발 프레임의 제한된 결과이며 정밀 관절 정확도·독립 성능은 없음.
- **행동 성능:** 시도/진행/완료 구분을 실행하지 않았고 accuracy/F1/FPR 등은 미평가. 기본 모델·설정 자동 교체 없음.
- **전달:** 세 원본/640/960 비교 이미지와 원시 결과는 로컬 전용. 기존 웹의 실제 렌더링과 GitHub 원격 byte 검증은 [전달 기록](BATCH-0006-delivery.md)에서 별도 확인한다.

이번 비교는 종료한다. 다음 한 의사결정은 **90초 넘기 자세의 관절 근거가 없는 상황에서 pose 기반 행동 판단을 확대할 수 있는가**이며 현재 답은 보류다. 새로운 해상도·threshold·ROI·모델·학습·추적·규칙·후속 GPU 작업을 실행하거나 예약하지 않는다.
