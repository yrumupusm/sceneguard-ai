# EXP-0005 — 고정 35프레임 및 연속 장면 검수 초안

2026-10-28 / Codex 시각 검수 초안, 사용자 확정 추적 정답 아님. [실험 보고서](EXP-0005-bytetrack-cache-comparison.md).

공통 기준: 원본의 실제 사람 위치/보이는 신체와 대조해 동일 인물 연결, 누락, 옆 사람·배경으로의 잘못된 연결 의심, 중복 track, 배경 track, 예측만 유지한 상태를 구분했다. 가림·겹침·작은 크기는 유보한다. 모델 ID를 정답으로 쓰지 않았다. A/B/C의 같은 숫자 ID가 같은 사람이라는 의미는 없다.

로컬 `outputs/cv_phase2e/review{ID}/continuous_ABC.mp4`에 원본과 A/B/C를 네 패널로 생성했다. 녹색 H=confirmed high 관측, 청록 L=confirmed low 관측, 주황 U=미확인 관측, 자홍 점선 P=실제 검출 없이 예측만 유지. 흰색 경계/노란 ROI는 기존 설정이다. 아래 수치는 confirmed 관측 수와 예측 상태 수이며 실제 사람 수가 아니다. 주황 U는 별도 로컬 states에 보존하며 경계 입력에서 제외했다.

35개 고정 프레임 모두 검사했다. 후보 탐색용 추가 검수는 030 89.600~90.500의 28개 연속 프레임, 007 55.900~57.000의 34개 연속 프레임(원본 프레임을 누락 없이 나열한 event_sequence 카드)을 확인했다. 영상 전체의 사람별 정체를 모든 프레임에서 수동 정답화한 것은 아니다. 비교 영상은 네 구간 모든 원본 프레임/시간 간격을 보존한다. 크롭 카드는 표시용이며 추적/검출 입력은 항상 원본 좌표 캐시다.

## 연속 후보 검수

- **030 89.600~90.500, 28프레임:** 실제 세 사람이 문을 넘는 장면. B의 관측이 끊기는 동안 C #3(앞쪽 어두운 옷), #4(중앙 인물 부근)는 high/low를 번갈아 연결한다. 왼쪽 #1은 예측만 유지하다 재관측하므로 전원 연속 관측 복원은 아니다. #3의 bbox가 전신에서 상체 일부로 급격히 작아지는 장면이 있다. C의 90.300초 두 후보는 실제 넘기와 시간적으로 겹치지만, 두 사람의 정확한 선 통과/완료 정답으로 확정하지 않는다. #4가 가려진 옆 사람을 포함하는 문제와 몸 일부 박스의 바닥점 이동을 따로 검수해야 한다.
- **007 55.900~57.000, 34프레임:** 사람들은 문 밖에서 접근·서기/방향 전환을 하며 이 짧은 구간의 실제 넘기는 확인되지 않는다. C #2가 상체 부분 검출을 low로 계속 연결한 뒤 전신/다른 사람까지 겹친 큰 박스로 바뀐다. 56.633초 bbox bottom y=.2605에서 56.667초 .3667로 변화한다. 양방향 후보 2개는 부분 신체 bbox의 하단 위치 변화와 겹침에 민감한 경계 판단의 실패 의심 사례다. 정체가 옆 인물로 옮겨 갔는지 부분 박스만 바뀐 것인지는 수동 객체 정답 없이 확정하지 않는다. B도 중복·가림·ID 변경이 남는다.

명확히 보이는 007 50→52초의 두 개별 인물 위치 유지와 030 후보 직전/직후 연결은 긍정적인 국소 근거다. 하지만 불확실한 가림 구간을 연결 성공으로 세거나, 배경 track의 지속 시간을 개선으로 계산하지 않는다. 다음은 이 초안의 대상별 정체/신체 범위를 사용자가 확정하는 작업이다.
