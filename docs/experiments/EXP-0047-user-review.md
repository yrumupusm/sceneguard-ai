# EXP-0047 새 연결 구간 사용자 관찰

2026-11-01. 동결 보고서·지표·독립 검토 이후 받은 사용자 답변이다. 기존 결과를 재실행하거나 동결 파일을 수정하지 않았다.

## 직접 받은 관찰

007 새 연결 묶음의 59.2초·62.767초·69.567초 주변에 대해 사용자는 두 사람이 겹쳐 있고 녹색·노란색 박스가 두 사람 사이에서 오가지만, 주로 사람에게 붙어 있다고 설명했다. 지점별 동일인 확정 답변은 아니므로 세 연결을 각각 정확한 동일인 연결로 표시하지 않는다. 문·배경만을 따라갔다고 판정하지도 않는다.

사용자는 사람 한 명씩 구분하는 것이 아니라 입구에서 침입이 발생했는지를 확인하는 목적임을 재강조했다. 이 목적에서는 겹친 사람 사이의 박스 전환만으로 입구 사건 근거 전체를 무효화하지 않는다. 정밀 신원·인원수 판정은 요구하지 않는다.

## 해석과 남은 한계

- 사용자 관찰은 사람 주변의 관측 지속을 뒷받침한다. 개인별 동일성이나 모든 후속 방향의 정답을 확정하는 근거는 아니다.
- 사건 수준 근거와 대상 수준 해제의 범위를 구분한다. 한 사람의 바깥 이탈로 다른 사람의 미결 의심까지 해제해서는 안 된다. 이번 실제 해제는0건이므로 그 오류가 실제 발생했다고 주장하지 않는다.
- 007의 후속 관측 하나가72.133333초에 과거 두 사건 카드를 함께 확인한 결과는 남아 있다. 같은 입구에서 사람들이 겹친다는 관찰만으로 앞선 별도 사건까지 확인해도 된다고 확정하지 않는다. 두 확인 알림을 침입2건·사람2명으로 세지 않는다.
- 기존 접근·대기/침입 진행 검수는 그대로 재사용한다. 새 사용자 답변을 근거로 임계값·연결·영역·사건 묶음을 변경하지 않았다.

현재 결론은 **사람 단위 정확한 연결은 미확정이나 사건 검토 근거로 사용할 수 있음 / 잘못된 사건 간 상태 전파 방지는 미해결 / 기본 적용 보류**다. 추가로 같은 영상의 정밀ID 검수를 요구하지 않는다.
