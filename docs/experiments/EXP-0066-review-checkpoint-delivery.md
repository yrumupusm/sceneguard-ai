# EXP-0066 중간 기록과 추가 학습 라벨 검수 전달

2026-11-08. 전체 모델 비교가 끝나기 전에 사람이 확인할 새 라벨 표본6개를 기존 웹에 등록했다. 이 기록은 전달 검증이며 학습 라벨의 의미 검수 완료나 검출 모델의 추가 학습 완료를 뜻하지 않는다.

## 사용자가 확인할 내용

[EXP-0066 영상 검수](http://127.0.0.1:8765/#video-review?experiment=EXP-0066)에서 왼쪽 원본과 오른쪽 라벨을 보고 **화면에 보이는데 박스가 아예 없는 사람이 있는지** 답한다. 누락이 있으면 화면의 원본 시각과 위치를 메모한다. 약간의 박스 어긋남과 구별하고, 가림이나 화질 때문에 판단하기 어렵다는 답변도 가능하다. 각 영상은 약8.3초이며 총50초다.

기존 검수8원본과 앞서 제공한 오판15원본은 선정에서 제외했다.6개 답변을 전체797라벨의 완전성으로 확대하지 않는다. 검수한 구간의 실제 누락을 보완하거나 제외하는 근거로만 사용하며, 보호한 학교45개와 EXP-0064 시험 자료는 추가 학습/임계값 선택에 넣지 않는다.

## 등록과 실제 화면 확인

등록된 원문은 `EXP-0066-review-checkpoint.md`, `review-checkpoint-metrics.json`, `EXP-0066-review-checkpoint-review.md`, `EXP-0066.binding.json`이다. 실행 상태는 `inconclusive`, 검토는 `accepted_for_comparison`, 채택은 보류다. 중간 상태16측정값 중 학교 의미 성능·학습 효과 관련4개는 미측정이며0으로 대체하지 않았다.

실제 서비스 API에서 네 원문의 SHA256이 등록 명세와 같음을 확인했다. 등록 전68개 카탈로그 행·18개 검수 요청·499개 미디어 항목을 보존하고 카탈로그1개·검수 요청6개·미디어6개만 추가했다. 재등록은 `already_registered`로 중복 생성하지 않았다. 기존 설정의 다른 필드도 보존했다.

별도의 로컬 Chromium에서 GPU를 사용하지 않고6영상의 실제 재생·2초 탐색·되감기,1920×600 해상도와8.333333초 길이,6질문의 해당 영상 연결,15초 자동 갱신 중 재생 유지까지 확인했다. 자동화는 답변을 제출하지 않았고 화면 이미지를 외부에 전송하지 않았다. 첫 확인 스크립트는 API 해시 키를 잘못 가정해 중단됐으며, 실제 파일 경로 키에 맞춘 두 번째 확인이 통과했다. 실패 기록도 보존했다. 애플리케이션 코드를 바꾼 것은 아니다.

로컬 근거는 `runtime/model-comparison/exp0066/review-checkpoint-delivery-v1/`의 `question-registration.json`, `preservation-and-api.json`, `registration-idempotency-receipt.json`, `browser-receipt-v1.json`, `browser-receipt-v2.json`이다. 원본 영상과 검수 답변 DB는 로컬 전용이다.
