# EXP-0066 모델 비교 중간 기록 · 추가 학습 라벨 검수

2026-11-08 고정 스냅샷이다. 기존8개 구성의 원본45개 처리는 완료했고 보조 분류기는3개를 학습했다. YOLO26 세 크기의 학습 전 출력과 검출 모델의 추가 학습 전후 비교는 이 기록 시점에 미완료다. 사용자가 직접 확인할 수 있도록 새 라벨 검수6영상을 먼저 전달한다. 전체 실험 종료나 학교 성능 개선 완료를 뜻하지 않는다.

처리한 창 수나 박스 후보 수를 고유 사람 수·누락 복구·침입 사건 성공 수로 바꾸지 않는다. 현재 비교는 고정 시점의 출력이며 원본의 모든 native프레임에 검출기를 적용한 실험과 다르다. 학교 정밀도·재현율·학습 효과는 미측정이다. 기존 EXP-0062 AFTER의37/52 참조 대응과 EXP-0064 선택 가중치/0.5를 보존한다.

## YOLO 실행 오류와 수정

첫 시험은 공식 가중치의 초기 모드 값을 너무 일찍 검사한 코드 오류였다. 실제 세 체크포인트는 필요한 native 검출 분기를 갖고 있고, 공식 예측 초기화 때 실행 모드가 선택된다. native 분기 존재 확인 후 공식 setter로 의도한 모드를 선택하도록 수정했다. 실제 체크포인트의 CPU 초기화 확인과13개 회귀 시험을 통과했으나, 이를 GPU 추론 완료라고 세지 않는다. 두 번째 시도는 기존6GiB GPU 여유 기준 미달로 자식 프로세스를 시작하지 못했다. 두 실패와 기존 큐 행은 모두 보존한다.

[실행 조건](EXP-0066-yolo-baseline-protocol.md) · [초기 검사 수정](EXP-0066-yolo-baseline-correction.md) · [진행 실행 기록](EXP-0066-yolo-baseline-execution.md). 이 스냅샷 이후의 실행은 후속 기록과 실제 영수증으로 구분한다.

## 이번에 확인할 라벨

사람 검출기를 학습할 때 화면에 보이는 사람이 라벨에서 빠져 있으면 그 사람을 배경으로 학습할 수 있다. 기존 공식 라벨의 좌표·시간·파일 검사는 했지만 모든 가시 사람의 주석 완전성은 아직 확인하지 못했다. 원본의 다른 시점에 등장하는 actor가 현재 라벨에 없다는 사실만으로 누락을 확정하지 않는다.

학습 후보의 넘기·보행·서 있기·앉기, 검증 후보의 넘기·앉기에서 하나씩 새 원본을 선택했다. 기존8표본 검수와 앞서 제공한 오판 보기15원본은 제외했다. 각 영상은 왼쪽 원본, 오른쪽 라벨 파일의 사람 박스다. 새 모델이 예측한 박스가 아니다.

질문은 **“화면에 보이는데 박스가 아예 없는 사람이 있나요?”**다. 박스가 약간 어긋나는 문제와 구분하고, 누락이 있으면 원본 시각과 위치를 메모한다. 가림 때문에 판단하기 어려운 답변도 가능하다. 이번에는 프레임 번호 시작 방식과 행동 구간의 타당성을 한 선택지에 묶지 않는다.1번 시작 표시를 사용하되 모든 원본에서 시간 대응이 확정됐다고 주장하지 않는다.

답변은 확인한 구간에만 적용한다.6개 표본으로 전체797라벨이나 모든 촬영의 정답을 확정하지 않으며, 모델 예측만으로 빠진 정답을 채우지 않는다. 사람 없는 구간이나 행동 라벨 없는 구간을 자동 정상으로 처리하지 않는다. 보호45개 학교 영상과 EXP-0064 시험 자료를 추가 학습/선택에 넣지 않는다.

검수 영상의 생성과 재생 확인은 사람의 의미 검수와 다르다. 실제 질문 등록·답변 상태·웹 전달 검증은 별도 전달 기록으로 남긴다. 상세 선정과 재현은 [라벨 검수 준비](EXP-0066-detector-label-review-preparation.md), 저장 집계는 [고정 스냅샷](../../records/EXP-0066/review-checkpoint.json)을 따른다.

## 다음 학습에 반영할 조건

검수된 사람 박스의 누락/다른 사람 혼동부터 보완하거나 해당 구간을 제외한다. 검증 정상 자료가 앉기에 치우친 한계는 남으므로 보행·대기·접근 후 돌아가기 자료와 촬영 그룹 분리를 보강한다. 그 뒤 같은 모델의 초기 가중치·입력·후처리를 맞춘 학습 전후 쌍을 평가한다. 이미 완료한 보조 분류기 학습만으로 박스 검출 개선을 입증했다고 보고하지 않는다.
