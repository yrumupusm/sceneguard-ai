# EXP-0039 사용자 검수 추가 기록

2026-10-31. [기존 결과 보고서](EXP-0039-results.md)의 동결 이후 받은 사용자 관찰이다. 기존 보고서·지표·독립 검토·웹 등록 binding은 변경하지 않는다. 이번 기록은 새로운 추론이나 독립 검토 결과가 아니다.

## 확인된 영상과 검수 범위

사용자가 처음 사용한 표기 “004”는 추가 질문으로 **E01_030 92.0–93.4초, s0003, 첫 번째 ROI 비교 영상**임을 확인했다. E01_004 또는 s0004에 연결하지 않는다.

사용자는 원본에 총 세 사람이 있으며, 이번 평가는 **오른쪽에서 먼저 넘는 두 사람**에 관한 것이라고 명시했다. 세 번째 사람은 이 답변에 포함되지 않는다. 후기 s0008(97.833–99.233초)은 아래의 후속 답변으로 별도 기록한다.

|사용자가 관찰한 장면|가운데: 저장된 전체화면 추론|오른쪽: 기존 고정ROI 입력 재추론|
|---|---|---|
|문을 넘은 직후, 사람과 문이 겹치는 아주 짧은 때|상대적으로 더 잘 잡음. 대부분 노란 박스|가운데보다 상대적으로 불리함|
|문에서 조금 벗어나 사라지기 전, 상반신이 잘 보이는 때|상대적으로 덜 잘 잡음|상대적으로 더 잘 잡음. 녹색 박스도 꽤 보임|

노랑은0.25이상0.5미만, 녹색은0.5이상의 모델 점수 표시다. 사용자 관찰은 실제 대상에 대한 상대적인 검출 품질 평가이며, 녹색이라는 이유만으로 박스의 정확성·전신 검출·동일인 연결·침입 확인을 확정하지 않는다. 정확한 전환PTS, 각 프레임의 대상별 박스 대응, 중복/배경 오검출 여부에 대한 추가 판정은 제공되지 않았다.

## 후기 s0008 사용자 검수

후속 답변의 대상은 **E01_030 97.833–99.233초, s0008, 두 번째 ROI 비교 영상**이다.

|항목|가운데: 저장된 전체화면 추론|오른쪽: 기존 고정ROI 입력 재추론|
|---|---|---|
|대체적인 사람 검출|대체로 잘 잡음|대체로 잘 잡음|
|사람과 문이 겹칠 때의 박스 범위|문까지 포함하는 듯 박스가 실제 사람 키보다 길어지는 경우가 있음|사용자가 본 구간에서는 그런 경향이 보이지 않음|

이는 사용자가 관찰한 **박스 범위의 차이**다. 모델이 사람과 문을 내부적으로 합쳤다는 원인 진단이나 분할 결과는 아니다. ROI가 대상을 새로 찾았다기보다 두 방식 모두 검출하는 상황에서 박스가 과도하게 길어지는 현상이 덜 관찰됐다는 근거로 기록한다. 모든 ROI 박스가 정확하다는 보장이나 전 구간의 오검출 감소로 확대하지 않는다. 정확한 발생PTS·대상별 프레임 라벨·박스 오차 수치는 제공되지 않았다.

박스 범위 변화는 하단 중심점이나 연결에 영향을 줄 가능성이 있으나, 이번 답변만으로 실제 하단점 안정성·추적 연결·알림 개선을 확인한 것은 아니다. 이번에는 저장 비교 영상에 대한 검수만 반영하고 새 추론/추적 실험을 수행하지 않는다.

## 해석과 남은 범위

s0003의 사용자 관찰상 **입력 방식의 우세가 가림 상태에 따라 달라진다.** 문과 겹친 짧은 구간에서는 기존 전체화면 결과가 우세하고, 문에서 벗어나 상반신이 보이는 구간에서는 ROI 결과에 국소적인 이점이 있다. 따라서 ROI가 모든 구간에서 더 낫다는 결론도, 도움이 전혀 없다는 결론도 내리지 않는다.

이 관찰은 기존 진단 집계와 구분한다. 마지막 박스 주변의 고정 검색 범위에서 박스 부재가15→17프레임이었다는 수치는 그대로지만, 이는 이동한 실제 대상별 검출 품질을 평가한 정답 기반 지표가 아니다. 고정 검색 범위의 부재 통계만으로 사용자가 확인한 국소적인 ROI 이점을 부정하지 않는다. 반대로 이 두 사람의 짧은 국소 개선을 전체 관측 공백·추적 연결·알림 오탐 개선으로 확대하지 않는다.

두 비교영상에 대한 사용자 정성 검수를 받았다. s0003의 세 번째 사람 및 두 구간의 프레임별 정밀 박스·동일인 정답은 아직 없다. s0008은 양쪽 모두 대체로 검출하면서 ROI에서 박스의 과도한 길어짐이 덜 관찰됐다는 범위로 해석한다. 원래 가시성 답변(부분 가림·곧 소실)은 그대로 유지한다. 기본 적용 보류 및 원본18알림/5카드 보존 결정을 바꾸지 않는다. 새 모델·추론·추적·설정 변경·추가 실험은 수행하지 않았다.
