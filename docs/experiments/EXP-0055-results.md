## 실행·실패 이력과 검증

직전 EXP-0054의 정식 after 9결과를 해시로 연결해 대조로 재사용했다. 대조 재생 0회, 후보 9개 각각 한 번 성공, 분석 실패·분석 재시도 0회다. 첫 코드 사본 준비는 중첩 `sceneguard` 디렉터리를 빠뜨린 경로 때문에 복사·분석 전에 assertion으로 실패했다. 실패 영수증을 보존하고 같은 manifest의 정확한 소스 하위 경로만 고친 뒤 실행했다. 준비 오류 1회를 분석 실패나 결과에 맞춘 규칙 재시도로 숨기지 않는다.

관련 349개(기존 333+새 16) 시험과 독립 94개 고정 소스 검사가 통과했다. 개발 중 기존 333개에서 새 근거 삽입 순서로 한 기대값이 실패한 이력은 보존했고, 기존 근거 순서를 보존하도록 수정한 뒤 기존 시험 수정 없이 통과했다. 새 16개 시험의 초기 fixture/assertion 3실패와 출력 키 1오류도 보존했다. 최종 고정 후 실제 분석은 반복하지 않았다. 이전 dual 전용 실패 이력을 포함해 전체 저장소 모든 시험이 통과했다고 주장하지 않는다.

후보 분석 호출 경과시간 합 154.164452초·CPU 합 146.450572초다. 최대 두 CPU 작업의 호출 합계이며 배치 전체 경과시간이나 실시간 추론 속도가 아니다. 독립 검토는 정식 입력·소스·결과·공식 재집계를 읽기 전용으로 대조했으며 실제 9영상 파이프라인을 재실행하지 않았다.

## 실행 경로와 근거

기존 Run `run_3d23462a014a`의 실제 평가 Task `task_5b9c8d6cb468` / Dispatch `ctx_21fe654b9aee`에 연결한다. 소급 문서 작성 배정으로 실행 이력을 바꾸지 않는다. native 기록에서 요청 모델은 설정 기본값이며 실효 모델·reasoning effort는 null이므로 이름을 추정하지 않는다.
