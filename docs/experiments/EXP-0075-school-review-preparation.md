## 학습 전후 비교에 연결하는 방식

1. 이번 검수의 사람 박스·전체 사람 완전성·빈 프레임 확인을 정확한 revision으로 고정한다. 불확실 프레임은 분모에서 별도 보류하고 보류 수를 공개한다. 일부 승인으로 전체 영상 검수를 완료시키지 않는다.
2. 학교 전용 평가 manifest를 만들되 **AI-Hub 학습122·개발78 목록에 합치지 않는다.** 현재 출력은 검수 패키지이며 학습용 YOLO 파일·일반 개발 manifest를 만들지 않았다.
3. 저장 EXP66 출력은 이번 선정·참고용이다. EXP74의 정확한 person head와 CPU 전처리·top300 조건을 A/B/C 모두에 맞추어 평가한다. 기존80종 공식 예측 경로/GPU 저장 출력이 새 person-only/CPU 경로와 완전히 같다고 가정하지 않는다. 필요한 A 재평가는 확정된 학교 프레임에서 같은 평가기로 한다.
4. 동일 `(frame_id, gt_id)`의 기존 검출 유지·회복·새 누락·계속 누락을 비교하고 FP를 별도로 센다. confidence0.5/IoU0.5·주 checkpoint epoch5 등 EXP74 계획을 유지한다. 사건/영상별 분모를 함께 보이고 다른 사람의 박스를 해당 사람의 성공으로 세지 않는다.
5. 학교 결과로 임계값·학습량·가중치를 고르지 않는다. 결과를 보고 후속 설정을 바꾸면 이 자료는 진단 이력이 있는 회귀 자료로 남기고, 독립 성능 확인에는 새로운 사건을 확보한다.

현재는 검수 대기이므로 학교 정밀도·재현율·누락 회복률·B/C 성능은 미측정이다. 기존 학교가 이미 여러 실험에서 쓰인 점도 보존하며 독립 시험으로 부르지 않는다.
