# EXP-0073 사용자 검수에 따른 사람 박스 보완

2026-11-09. EXP72 세 영상에 받은 검수 내용을 재사용해 **배경 오검출17개를 제거한 별도 초안**과 **다섯 장면의 한 사람 박스 수정안**을 만들었다. 야간23.333초는 사람 여부를 판단할 수 없어 프레임 전체를 학습·평가 편입 보류로 남겼다. 새 수정 좌표는 미확인이며 재학습·새 모델 추론은0이다.

## 사용자 관찰의 적용 범위

EXP72 R01/R02/R03의 웹 answer_version1, 연결 영상 바인딩과 로컬 사용자 관찰 기록을 실제 읽고 연결했다. 세 답변은 앞선 대화에서 이미 관찰 기록으로 반영됐으므로 재답변/재확인 처리를 반복하지 않았다. 당시 ‘반영 완료’는 관찰을 기록했다는 뜻이며 수정 좌표의 사람 승인은 아니었다.

| 대상 | 받은 관찰 | 이번 처리 |
|---|---|---|
| 주간 R01 원본20초 | 한 사람에게 순간적으로3박스 | 한 사람 전체를 감싸는 좌표 수정안1개 생성, 확인 필요 |
| 야간 R02 23.333초 | 오른쪽 끝 작은 박스는 무엇인지 판단 어려움 | 사람/배경 모두 미확정. 한 프레임 전체 보류 |
| 야간 R02 23.667·24·24.333·25초 | 오른쪽 한 사람이 여러 박스로 나뉨 | 해당 인물에만 한 박스씩 제안, 총4장 확인 필요 |
| 개발 R03 화면 위 먼 길 | 첨부 사진의6번은 사람이 아닌 곳. 번호는 바뀜 | 같은 화면 위치의 작은 후보17개/13프레임만 제거 |

지적한 문제의 의미를 다시 묻지 않는다. 새 질문은 주간1장·야간4장의 **새 좌표가 적절한지**에 한정한다. 야간24.667초 등 언급하지 않은 시각과 다른 인물의 박스는 그대로 보존하며, 이를 새 확정 정답으로 자동 승격하지 않는다. R03의 왼쪽 위 다른 작은 보행인 후보도 제거하지 않았다.

## 위치 대응과 수정 방법

원본은3FPS다. 사용자가 말한20/23.333/23.667/24/24.333/25초는 원본 decoded index60/70/71/72/73/75와 대응하며 native PTS와 RGB 해시를 대조했다. 화면에 쓰인 박스 번호는 프레임별 번호여서 인물의 고정 ID로 사용하지 않는다.

R03은 사용자가 지목한 첨부 화면의 고정 배경 위치를 원본 해상도에 대응시킨 작은 선택 영역 안에 **완전히 들어오는 기존 후보만** 제거했다. 적용은 기존 검수24프레임 안의 실제 후보17개에 한정한다. 해당 영역 전체·다른 시간·다른 영상을 빈 배경 정답으로 지정하지 않았다. 운영 검출기의 영역 필터나 임계값을 바꾼 것도 아니다.

R01의 세 모델 박스는 사람의 몸 일부만 포함해 단순히 최고 점수 하나를 남기면 머리와 뻗은 다리가 빠질 수 있다. 원래 actor 주석과 모델 박스의 바깥 경계를 참고해 수정안을 만들었다. 원래 actor의0/1번 시작 해석을 인증하거나 정답으로 자동 채택하지 않았고 사용자에게 그 기술적 선택을 요구하지 않는다. 새 한 박스가 실제 보이는 몸을 적절히 감싸는지를 확인받는다.

R02는 사용자가 같은 사람이라고 확인한 오른쪽 박스들의 바깥 경계를 사용해 한 박스를 제안했다. 동일인이라는 관찰은 좌표 경계의 정확성까지 보장하지 않으므로 미확인 상태로 남긴다. 왼쪽 인물의 기존 박스는 바이트 값 그대로 유지했다. 전역 NMS·점수 임계값 변경·추적·다른 사람 박스 자동 병합은 없다.

## 실제 산출물

- 입력72프레임·196개 후보를 불변으로 보존하고 별도 수정 초안72프레임·169개 박스를 저장했다.169는 확정 정답 수가 아니다.
- 배경17개 제거, 주간3→1개, 야간 오른쪽4→1·3→1·2→1·3→1의 변화만 적용했다.
- 보완 좌표 확인용5원본 PNG, 기존/수정안 비교이미지5개, 비교영상2개와 선택적 편집 패키지를 생성했다. 새5개 좌표에는 사람이 확인하지 않았다는 출처를 명시했다.
- 주간 비교영상은20초 정지화면 한 장을3초 표시한다. 야간은23.667·24·24.333·25초의 비연속 정지화면4장을 각1초 표시한다. 원래 시간 간격이나 연속 행동 영상으로 해석하지 않는다.
- 23.333초의 기존 후보는 진단 자료로 남기되, 해당 프레임 전체의 편입을 보류했다. 애매한 작은 후보만 지우고 나머지를 완전한 사람 정답으로 내보내지 않았다.

기존197검수 프레임과 EXP72 질문·바인딩·원본·초안은 변경하지 않았다. 학습 예약19/개발 예약01, 학교45, EXP64 시험296 및 같은 보호 그룹, 사용자 제외를 유지한다. 새 정답 내보내기·자동 학습 release는 없다.

사용자는 새5개 좌표만 두 묶음으로 확인하면 된다. 수정이 더 필요하면 해당 원본 시간과 박스가 넓거나 좁은 방향을 메모한다. 세 원본 전체의 문제점을 다시 찾는 검수가 아니다. 별도 정상 개발 자료와 독립 월담 시험 부족은 그대로이며 이번 보완을 성능 개선이나 학습 준비 전체 완료로 표시하지 않는다. 실제 웹 등록·재생·GitHub 확인은 별도 전달 기록을 따른다.
