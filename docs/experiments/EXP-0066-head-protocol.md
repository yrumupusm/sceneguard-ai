## Automatic joint supervision

For each target, a query must have a valid original-source-coordinate box and IoU >=0.5 with **both** annotation-origin boxes at its anchor. Its ranking is highest minimum IoU, with lowest query index breaking exact ties. All qualifying targets participate in conflict detection, including targets whose best match is elsewhere. Conflicting binary labels make the query unknown. Unambiguous same-label collisions coalesce into a single query sample, preserving all assigned target provenance; multiple actors sharing that query are not distinct observations. Exact duplicate targets do not add weight. Unmatched targets and queries stay unknown and never create normal examples. Geometric association is not human same-actor verification or independent detector recovery. Each record includes matched count, unknown count, unmatched targets, conflicts, and provenance.

Per-split coverage retains target total, matched and unmatched targets, ambiguous targets (a subset of unmatched/uncertain targets, not an extra disjoint denominator), query total, matched and unknown queries, and conflicting query IDs. Matching deliberately uses all valid learned queries, including low native person scores; each retained sample logs its person score. Original native person thresholds are EVAD 0.7 and STMixer 0.6, distinct from the new head threshold. `matched_native_person_operating_point_verified=false` makes clear that matching all valid queries does not evaluate those native person operating points. Joint validation precision/recall is conditional on matched automatic queries and is not end-to-end person-plus-action recall. Encoder labels are scene-level weak references, not actor-specific predictions.

Encoders produce one full-scene weak-reference sample per window. Their input never depends on label boxes. Joint inputs also remain full-frame: annotation boxes are used only after inference for supervision of automatic predictions.

## Fixed head fitting and threshold

CPU binary linear heads use seed 66; train-only population mean/std with zero std replaced by one; Adam learning rate 0.01, weight decay 0.0001; 100 epochs; batch 128; balanced class weights N/(2*Nclass) from actual matched training samples. Training loss is class-weighted binary cross entropy; selection is minimum **unweighted** validation cross entropy, earliest epoch on an exact tie. There is no hyperparameter search or class-dependent geometry tuning. Missing complete-window features, nonfinite representations/losses, or zero/one-class actual train or validation samples reject fitting.

The threshold is selected exclusively from validation negatives. With N negatives, at most floor(N/20) false positives are allowed; sort their scores descending and take float64 `nextafter(score[floor(N/20)], +infinity)`. A candidate requires score >= threshold. This strictly excludes the boundary and all its ties, giving official-reference validation FPR <=0.05. Exact counts, boundary, ties policy, validation scores/labels, selected epoch, history, balanced weights, sample keys, and source/config hashes are saved. Official-reference validation precision/recall are reported with the weak-label and sitting bias; human precision/recall remain null. Test/school scores never select the epoch, model, threshold, or protocol.

If the boundary is exactly 1.0, its float64 nextafter is greater than 1.0 and correctly rejects all probabilities, including 1.0. CPU fitting streams per-epoch history so failure preserves the completed epochs alongside failed status and traceback. Advisory scoring leaves `intrusion_completed=null`, because an action-only result cannot determine completed-intrusion presence or absence.

Saved CPU heads can subsequently score frozen school representations. `score_features` emits only advisory `climbing_action_candidate` and score fields. It cannot promote intrusion completion or change baseline event state/first notice/confirmation/release. Actual school scoring is a later root-owned stage.

Every threshold/selection/scoring result explicitly sets `threshold_status=provisional_official_reference_not_human_calibrated` and `matched_false_positive_operating_point_verified=false`. Sitting-only weak-reference validation cannot establish the ZIP's separately reviewed matched false-positive operating point, or equal FPR across eight models. Reviewed walking/waiting/turnback negative calibration remains insufficient and is reported separately; school45 never fills that calibration role.
