## 검증과 재현

신규 합성/관측 결속30테스트는 모두 통과했다. 지원 관측2개, AND 대신OR, 방향/출발 영역 미정 허용, 미래 정보/분석창 종료, 같은 쪽 정상 이탈 순서, 예측·변조·중복 거부와 이전 결과 불변을 포함한다. 실제 두 출력의 segment/행/박스/PTS/후보/원래 경보/설정 및 기존 event를 원본과 정확 대조했다.

전체 저장소의 기본 CV 환경 일괄 테스트는 통과하지 않았다. 기존 분리 환경에 있는 cv2/transformers/yaml/ultralytics/fastapi의 누락 import와 기존 EXP-0029 고정 이력 fixture의46 대44 불일치가 발생했다. 실패 로그를 보존하고 새 설치나 무관한 테스트 변경은 하지 않았다. 관련 CPU 회귀는 기존77+신규30=107개 모두 통과했다. 기존 분리 환경의 data34/MVP167/VLM8도 통과했다. 추가 환경 검사에서도 lap/scipy/fastapi 누락과 과거 고정 큐 이력43/44 대46 불일치는 남았다. 전체 테스트 통과라고 보고하지 않는다.
