2026-11-08. 사용자가 새 비교 영상1·3·5번 모두 “전체25프레임의 주황색 박스와 보이는 사람을 확인했고 수정할 곳 없음”으로 답했다. 세 답변은 각각 answer_version1이고 추가 메모가 없다. 정확한 표시 집합을 읽고 기존 질문/영상 바인딩을 재검증하여 **75프레임·182개 사람 박스 행**을 별도 확정 라벨로 내보냈다. 모델 출력만으로 만든 정답이 아니라, 표시된 위치와 보이는 사람의 완전성에 대한 명시적인 사람 검수를 근거로 한다.

|---|---|---:|---:|

182는 반복 프레임의 박스 행 수이며 고유 사람 수가 아니다. Train2촬영그룹/validation1그룹이고 원래 분할을 유지한다. 낮은 점수로 숨겼던35개 초안, 원래79개 주석과의 합집합, 표시하지 않은 프레임은 반영하지 않았다. 원래2·4·6번75프레임/100주석 준비 자료도 그대로 보존하며 이 새 답변의 확인 범위에 합치지 않는다.

## 실제 반영

새 출력은 `outputs/model-comparison/exp0067/confirmed-person-v1/`이다. `manifest.json` SHA `1bda84cc3421bcfc1b528bfb4e4092c02e9ec22d4a09c41907ff46211381ad18`에 각 원본 프레임/RGB/PTS·촬영 그룹/분할·표시된 proposal ID/좌표·질문 ID/answer version/영상 바인딩을 기록했다. `images/train`, `images/validation`과 `labels/train`, `labels/validation`에 YOLO person단일클래스 라벨을 만들고 `train.coco.json`/`validation.coco.json`에 같은 원본 좌표의 공통 형식도 저장했다. `dataset.yaml`은 해당 분할만 가리킨다. 학습151박스/검증31박스다.

검수된 사람 위치와 완전성은 true로 기록했다. 행동 종류·시작/종료·사람 신원은 확정하지 않으며 단순한 person라벨을 월담/정상 행동 라벨로 바꾸지 않는다. 특히5번의 뒤따르는 사람은 person로 포함되지만 이후 월담 여부는 여전히 미확정이다. 3번의 원래 주석 종료/중복actor0도 원본 파일을 수정하지 않고 별도 사람 라벨로 보완한다.

원래 모델 초안/영상/보고서/지표/웹 바인딩과 편집 DB는 보존했다. 편집 화면의75pending은 이전 초안 패키지의 수동 편집 상태다. 이번 웹의 구간 검수를 대신 수동 저장한 것으로 가장하지 않으며, 확정 상태의 근거는 이 별도 manifest와 웹 처리 이력이다. 새 모델/GPU 작업0, 실제 추가 학습0회다.
