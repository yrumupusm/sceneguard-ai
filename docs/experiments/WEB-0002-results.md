# WEB-0002 — 실험 이력과 영상 검수 분리

2026-11-02. 사용자가 승인한 화면 개편을 기존 로컬 서비스에 적용했다. 실험 목록과 영상 검수를 상단 메뉴로 분리하고, 저장된 실제 관측 이미지를 보며 사건·박스·누락을 검수할 수 있도록 연결했다. 새 검출·추적·특징 분석·VLM 추론은 실행하지 않았다.

## 화면 사용

- `http://127.0.0.1:8765/#history`: 실험 이력. 한 줄에 실험 하나, 높이 320px 목록 안에서 스크롤한다. 기존 검색·결과 필터·실험 상세는 유지한다.
- `http://127.0.0.1:8765/#video-review`: 영상 검수. 영상과 저장 결과를 선택하고 첫 의심·확인 버튼으로 원본 시각에 이동한다. 페이지 이동 시 영상 선택·재생 위치·입력 중 검수는 유지하며 숨겨진 영상은 정지한다.
- 사건에는 판단 시점 이미지와, 근거가 있는 경우 판단 전 마지막 실제 관측 이미지를 별도 시각으로 표시한다. 박스가 없는 판정 순간에 과거 박스를 얹지 않는다.
- 사건 판단(미검수/올바른 사건/오경보/판단 불가)과 박스 품질을 각각 단일 선택한다. 영상 전체 누락 여부는 별도 항목이며 사건 없는 영상에도 표시한다. 모순되는 중복 선택을 막기 위해 체크박스 대신 라디오 선택을 사용한다.
- 검토자·메모·버전·수정 시각·이력을 로컬에 저장한다. 기존 수동 검토는 별도 접힌 항목으로 보존한다. 사건 카드에는 사람이 읽는 사건 번호·시각을 쓰고 내부 저장 키는 표시하지 않는다.

브라우저 첫 탭이 이미지 디코딩 검사 중 응답하지 않아 Orca 명령 timeout이 발생했다. 새 탭에서는 네 이미지가 모두 정상 표시됐다. 첫 재생 요청은 브라우저의 백그라운드 절전으로 거절됐고, 활성 탭에서 영상 표시 후 한 번 재시도해 실제 진행·되감기를 확인했다. 이를 모델/API 실패나 행동 성능 검증으로 세지 않는다.

기능 확인 메모는 `WEB-0002 저장 기능 확인 · 사람 검수 아님 · 판단은 미검수 유지`로 기록했다. 사람 정답을 대신 입력하지 않았으며 기존 검토 DB를 변경하지 않았다. 새 검수 DB와 이미지·상세 검증 기록은 로컬에만 둔다.

## 구현·검토

기존 Run의 Sol high가 저장 근거/검수 API, Terra high가 화면을 담당했고 Astra high가 독립 검토했다. 총괄이 지연 GET 중 메모를 편집할 때 미편집 선택값이 초기화되는 문제를 수정하고 실제 서비스 통합을 확인했다. 정상 app 진입으로 가려졌던 순환 import, 확인 시각 null, 박스 부재 표시도 검토 중 수정했다.

독립 최종 검증은 **Python 59개, Node 10개 스위트 통과**다. 저장 충돌/이력/이전 DB 보존, 실제 CPU 합성 영상에서 정확한 프레임·박스 렌더링, 미래/무관 관측 제외, 라우팅/재생 상태/초기값/지연 GET 등을 포함한다. 총괄도 라우팅·검수·MVP 상태 Node 세 스위트를 재확인했다. 중복 실행 수를 고유 시험 수에 더하지 않았다. [독립 검토](../reviews/WEB-0002-independent-review.md)

## 적용 범위와 한계

현재 서비스의 76개 사건 보기 등록 중 새 박스 이미지 연결은 **MVP 13개 결과**에 적용된다. 저장 결과 감사에서 의심 22시점 중 현재 박스 17개·이전 박스 21개, 확인 8시점 중 현재 박스 0개·이전 박스 8개를 확인했다. 확인이 없는 의심 14개는 자동 확인 없음으로 표시한다. 이것은 이미지 연결 건수이며 검출 정확도가 아니다. 과거 EXP 등록 63개는 새 이미지 매핑이 없어 기존 영상·근거 보기를 유지한다. 전체 45개 분석 출력이 새 개별 검수 화면에 모두 등록됐다는 뜻이 아니다.

실제 박스가 있어도 대상 일치·사건 정답은 보장되지 않는다. 공식 라벨과 미검수 구간을 구분하며 누락 질문을 없애거나 미검수를 정상으로 바꾸지 않는다. 새 선택은 자동 판정/알림/정답 파일을 수정하지 않으며 정확도 집계에 자동 편입하지 않는다.

원본·카드·프레임 매핑 해시는 검사한다. 구형 manifest는 decision stage 자체의 해시를 직접 고정하지 않아, 해당 stage를 거친 관측 연결은 로컬 일관성 검증이지 완전한 암호학적 보증이 아니다. 이전 시각의 이미지는 저장된 명시적 근거 참조가 있을 때만 제공한다. 선택 영상/결과 변경은 패널을 다시 만들므로 미저장 검수는 먼저 저장해야 한다.

기능 구현·실제 화면 동작 확인과 행동 성능 개선은 별개다. 이번에는 판정 성능 실험을 수행하지 않았고 기존 MVP-0006의 미완료 전달을 완료로 바꾸지 않았다. 게시 대상은 코드·시험·비식별 문서이며 원본/이미지/DB는 게시하지 않는다.

## 후속 화면 수정 — WEB-0003

2026-11-02 사용자 브라우저의 이전 스타일 잔류를 확인했다. 메뉴를 헤더 내부 탭으로 옮기고 CSS/JS 버전 주소 및 no-cache 응답으로 갱신을 보완했다. 위 최초 sticky 메뉴는 이 헤더 탭으로 대체됐다. 실제 새로고침 후 한 줄 목록(높이320px, 첫 세 행47px)과 탭의 선택 스타일을 확인했다. 웹 API8시험·라우팅 Node스위트 통과.
