# EXP-0072 촬영 다양성 보강과 사람 박스 검수 준비

2026-11-09. 기존 학습 자료와 다른 촬영 예약의 주·야간 월담 원본2개, 별도 개발 예약의 원본1개에서 **3구간72프레임·196개 사람 후보 박스**를 생성했다. 모두 미검수 초안이다. 재학습·성능 평가·새 독립 시험 확보는 수행하지 않았다.

## 기존 검수와 보호

작업 시작 시 웹의 신규/수정/확인 후 미처리 답변은0이었다. EXP67의75프레임과 EXP71의122프레임, 총197프레임 검수와 좌표를 재사용 가능한 기존 자료로 보존했다. 이번72프레임과 중복은0이며 이전 장면을 다시 질문하지 않는다. EXP71 라벨1/2의 완료 상태와 가림 메모도 보존한다.

학교45와 EXP64 시험296/연관327, 사용자 제외 시나리오, 기존 시험·학습·개발 예약을 유지했다. 모델 제안이나 원래 actor 주석을 자동 정답으로 채택하지 않았고 무박스 구간을 정상/빈 배경으로 확정하지 않았다.

두 학습 원본은 기존 학습 예약14/15와 다른 예약19지만, 서로 같은 배경·촬영일로 묶여 있다. 두 원본을 두 독립 사건으로 세지 않는다. 개발 P01은 같은 촬영 배경의 Training P19까지 개발 예약01로 묶어 학습 편입을 막은 기존 결정을 유지한다. 예약 충돌이 없다는 것은 실제 촬영 독립성 인증과 다르며, 독립 사건 수는 미확정이다.

검수는 **화면에 보이는 모든 사람의 박스**를 대상으로 한다. 넘는 사람만 선택하는 작업이 아니다. 사람 이외의 박스·중복·합쳐진 박스·작은 사람 누락을 확인하며 완전히 가려진 사람의 박스를 추측해서 그리지 않는다. 행동 시작·종료나 인물 신원은 이번 질문의 정답 범위가 아니다.

각 영상은 왼쪽 원본, 오른쪽 주황색 사람 후보와 점수를 표시한다. 화면 위 시계는 원본 시간이다. 기존 actor/0·1번 시작 선택은 묻지 않는다. 각 원본의 대표 전체 해상도 이미지와 박스 표시 이미지도 함께 제공한다. 영상 재생 시간8초와 원본 시각을 구분한다.

세 영상 모두 매 프레임에 후보가 있지만, 이는 사람이 빠짐없이 검출됐다는 뜻이 아니다. 특히 개발 영상129박스는 낮은 점수 후보를 포함한 프레임별 누적 개수로, 인원수나 검출 성공 수가 아니다. 문제가 있는 시간·위치만 메모로 받고 필요한 좌표 보완을 별도로 준비한다.

## 실제 실행과 재현

기존 YOLO26x 사전학습 가중치와 Ultralytics8.4.192를 재사용했다. 원본3FPS의 연속24프레임씩, 전체 화면640 입력·FP32·사람 후보0.05·CPU 배치1을 고정했다. 0.05는 검수용 제안을 남기는 기준이며 기존 모델 평가 임계값0.5를 변경하지 않는다. GPU와 학습 큐를 실행하지 않았다.

```bash
.venv-pose-batch03/bin/python scripts/prepare_person_review_drafts.py \
  --profile exp0072 \
  --output outputs/model-comparison/exp0072/person-drafts-v1
```

출력 경로는 새로 생성하며 기존 출력에 덮어쓰지 않는다. `selection-before-inference.json`에 추론 전 분할 예약·기존 검수 겹침 확인을 저장하고, 원본/라벨 SHA·native PTS·프레임 RGB·실제 후보·원래 actor 참고 주석을 초안JSON에 보존했다. 비교 영상3개를 다시 디코딩해 각각24프레임임을 확인했다. 기존 EXP71 기본 선택은 유지하며 새 명시적 프로필만 추가했다. 두 프로필의 실제 분할 사전검사도 통과했다.

기존 보호 입력과 두 검수 manifest를 합친9개 고유 입력의 해시, 가중치 해시, 생성 영상 해시 및 후보 좌표 유효성의 저장 검증을 완료했다. 이는 데이터 출처와 실행 일관성 확인이며 완전한 사람 정답의 의미 검수와 다르다. 원본·영상·좌표·DB·가중치는 로컬에만 보존한다.

## 정상 보행·대기 개발 자료와 남은 일

보유 정상행위432쌍의 실제 원천·라벨을 모두 확인했고 파일 부재는0이다. 이 중 보행·서 있기 계열324쌍은 학습 예약173, 같은 학습 예약의 격리4, 보호 시험과 같은 촬영 그룹147로 나뉜다. 나머지108쌍의 내용 유사성 보류는 앉기 계열이므로 이를 해결해도 보행·대기 개발 자료의 공백을 채우지 못한다. 현재 제약 아래 바로 개발용으로 채택할 정상행위 후보는0이다.

[개발 자료 감사](EXP-0072-development-source-audit.md)의 실제 목록과 제한을 따른다. 기존 보호 목록327개 외에 같은 보호 그룹에 속한2개도 계속 보류한다. 기존 학습용 정상행위를 프레임 단위로 개발용에 나눠 넣거나, 보호 시험을 학습·개발로 가져오지 않는다. P01에 함께 보이는 주변 인물은 정상 보행·대기 검출의 보조 자료가 될 수 있지만, 전 구간이 정상인 별도 개발 영상이나 정확한 행동 라벨을 확보했다는 뜻은 아니다.

다음은 새3구간의 모든 사람 박스 검수와 필요한 좌표 보완이다. 개발용 정상 보행·대기·접근 후 돌아가기의 독립 촬영 자료, 보호 자료와 겹치지 않는 새 월담 시험은 여전히 보강 대상이다. 이번 검수만으로 학습 준비가 모두 끝나거나 성능 개선이 입증된 것으로 표시하지 않는다. 자료 준비 후에도 사전학습 원본 A와 BN 통계를 고정한 추가학습 C의 실행 조건을 별도로 고정한다.

별도 정상 개발 자료를 확보할 때는 학습 예약14/15/19 및 보호 시험과 촬영 사건·멀티카메라 연결이 없는 연속 원본, 촬영일·장소·카메라 관계, 실제 FPS/PTS, 작은 사람·가림·보행·대기의 모든 보이는 사람 박스가 필요하다. 빈 배경은 사람 없음의 명시적 검수를 요구한다. 접근 후 돌아가기는 원래 라벨이나 사람이 확인한 실제 구간이 필요하며 파일명이나 모델 예측으로 지정하지 않는다.
