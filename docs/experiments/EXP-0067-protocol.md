# EXP-0067 — 추가 학습용 사람 박스 보완 초안

2026-11-08 사용자 승인: 누락 박스 보완 자료 제작부터 추가 학습/전후 비교까지 Codex가 진행하고, 판단하기 어려운 새 내용만 사용자에게 요청한다. 이 실험은 EXP-0066의 검수 결과를 재사용해 **실제 누락 박스를 보완할 수 있는 초안**을 만드는 단계다. 과거 YOLO 사전학습 비교 종료 뒤의 추가 실행 금지는 이번 별도 승인 범위를 막지 않는다.

## 실행 전 고정 범위

- 기존 학습 라벨 검수1·3·5번, 각25프레임·3FPS, 총75프레임만 사용한다. train50/validation25와 원래 원본/촬영 그룹을 유지한다. 사례 선택은 새 모델 점수를 보기 전에 받은 검수의 누락/경계 문제를 따른다.
- 기존2·4·6번의75프레임 준비 자료는 재검수/재추론하지 않는다. 학교45개와 EXP-0064 시험 자료, 제외한4-19–35/4-69–70은 추가 학습·선택에 넣지 않는다.
- 기존 YOLO26x 공식 사전학습 가중치 하나와 EXP-0066의 고정 공식 호출 조건을 사용한다. 전체화면640, FP32, 배치1, person 반환0.05, 기본 표시0.5다. 임계값 탐색이나 다른 모델 비교를 추가하지 않는다.
- 실제 native 프레임/PTS/RGB SHA와 원본·라벨 해시를 표시 자료와 대조한다. 원래0/1 시작 해석 좌표를 둘 다 보존하고 origin1을 표시한다. 사건 경계 밖으로 라벨을 연장하거나 actor0 중복을 자동으로 합치지 않는다.
- 모델 결과는 별도 초안이며 기존 주석을 덮어쓰거나 정답과 자동 병합하지 않는다. 낮은 점수/무검출도 보존하고, 무검출을 사람이 없는 프레임으로 해석하지 않는다. 모델 출력 개수는 복원 성공 수가 아니다.

## 실행과 검토

기존 Run의 Sol 담당과 Astra 독립 검토를 사용한다. 새로운 단일 `person-label-repair` 작업을 기존 canonical GPU 큐에 등록한다. 새 명령의 소스·입력·설정·가중치·환경·현재 배정·자원·상속 reservation을 검증하고 코드 고정 및 독립 검토 후 실행한다. 실행 상한은75개 scored 출력, 한 작업/1800초이며 자동 재시도는 없다. 실제 모델 warmup은75개 출력과 별도로 해석한다. 기존143개 jobs/attempts와 실패 이력을 보존한다.

예전 검수나 일반적인 긍정 답변만으로 모델 초안을 정답으로 승격하지 않는다. 새25프레임 영상에 대해 **표시된 주황 박스가 전부 실제 사람 위치와 맞고, 중복·배경 박스·빠진 사람이 없음**을 사용자가 명시 확인한 경우에만 해당25프레임과 표시된 박스 ID/좌표/해시, 정확한 답변 버전에 한정해 후속 반영할 수 있다. 표시하지 않은0.5미만 초안이나 기존 라벨과의 자동 합집합, 다른 시각, 행동 종류까지 승인한 것으로 확장하지 않는다. 이번 단계에서 답변을 대신 제출하거나 정답으로 반영하지 않는다.

오류나 불확실성이 있으면 해당 시각만 보완한다. 로컬 박스 보완 화면에서는 원래 주석·모델 초안·사용자가 채택/수정한 박스를 구분하고, 사람 추가·박스 수정·삭제 및 **현재 프레임**의 완전성/불확실성을 저장한다. 미확인 프레임은 미확인으로 남기며 저장은 학습을 자동 실행하지 않는다. 원본/모델 초안은 불변이고 사용자 수정은 별도 버전 이력으로 남긴다.

검수 질문이 이미 답한 “사람이 빠져 있는가”의 반복이 되지 않도록 새 초안의 실제 위치만 묻는다. 새 자료는 EXP-0067에 등록해 답변이 연결된 EXP-0066 원래 보고서/미디어/바인딩을 보존한다. 영상과 좌표·DB는 로컬 전용이다. 브라우저 자동 시험은 별도 합성 패키지에만 답변을 쓰고 실제 사용자 정답을 대신 제출하지 않는다.

## 학습으로 넘어가는 조건

검수된 정확한 프레임/좌표만 학습 후보에 반영한다. 전체 사람 주석이 불완전한 프레임은 일반 검출기의 배경 손실에 넣지 않는다. 현재 검증 정상의 앉기 편중, 소량/장소 편중과 미확정 프레임 번호 대응은 별도로 남긴다. 이75프레임의 초안 생성 성공은 전체797라벨의 보완 완료나 모델 추가 학습 완료가 아니다.

정답 보완 뒤 여섯 검출 모델의 데이터/선택 규칙/학습 예산을 고정하고 소량 학습·검증을 거쳐 본 학습으로 진행한다. EXP-0062 AFTER와 EXP-0064 선택 가중치/0.5, 기존 사전학습 비교 출력은 유지한다. 행동 점수와 사람 검출·침입 완료를 구분하며 학습 전후 개선은 실제 동일 평가 후에만 보고한다.
