# EXP-0065 — 학교 CCTV 행동 후보 진단과 다음 학습 자료

2026-11-07. **기존 기준이 놓친 공식 사건 15개 중 7개에 시간대가 겹치는 행동 후보가 있다. 같은 사람·같은 문에 대한 후보인지는 미검수이므로 성능 개선은 아직 입증하지 못했다.** 45개 영상의 저장 점수 진단과 대표 검수 영상 25개 생성을 완료했다. 새 추론·학습·임계값 변경은 없으며 운영 기본은 유지한다.

비교 기준은 EXP-0062 AFTER(그 안의 EXP-0061 보완 포함), 행동 모델은 EXP-0064의 선택 epoch 6 가중치, 임계값은 0.5다. 45개는 회귀·진단 전용이며 새 학습·검증·임계값 선택에 사용하지 않는다. 이미 본 EXP-0064 시험 자료도 학습으로 옮기지 않는다.

## 실제 저장 결과 대조

3,573개 입력 창과 467개 후보 창을 원래 추론 영수증의 파일 해시까지 대조했다. 공식 시간 참조 52개와 EXP-0062의 확인 대응 37개·누락 15개를 사건별로 연결했다. 시간 겹침은 입력의 실제 샘플 시점이 공식 반열린 구간 안에 있는지로 계산하며 사람·문 대응의 성공 판정이 아니다. 분류 범위는 고정된 3 FPS 입력 계획이다. 원본의 모든 프레임에서 대상이 관측됐는지는 별도 대조가 필요하다.

| 사건 시간대의 입력 상태 | 전체 52개 | 기존 확인 대응 37개 | 기존 확인 누락 15개 |
|---|---:|---:|---:|
| 점수 0.5 이상 후보 있음 | 33 | 26 | 7 |
| 입력은 있으나 모두 0.5 미만 | 13 | 8 | 5 |
| 실제 일부 관측만 있어 8시점 입력 부족 | 5 | 2 | 3 |
| 시간대 안의 실제 관측 입력 없음 | 1 | 1 | 0 |

기존 누락 중 후보가 있는 영상은 **015·021·026·028·034·039·043**이다. 가장 높은 시간 겹침 창을 검수 대상으로 골랐으며, 해당 창이 다른 사람을 보고 있을 가능성은 남는다. 대표 창의 답변을 같은 사건의 다른 후보 창 전체로 확대하지 않는다. 026·034의 기존 이른 확인 수용/보류 같은 과거 검수도 보존한다. 공식 구간 내 매칭 누락을 사용자가 보기에 침입을 전혀 감지하지 못한 것과 동일하게 해석하지 않는다.

입력이 있는 낮은 점수 5건은 011·013·035의 두 번째 참조·036의 두 번째 참조·045의 두 번째 참조다. 부분 입력 3건은 035의 첫 참조·042·044다. 낮은 점수를 행동 오판으로, 입력 부족을 사람 검출 FN으로 확정하려면 먼저 대상과 실제 행동 구간을 확인해야 한다.

020의 두 번째 참조는 예정된 입력 시점만 시간대에 걸쳐 있고 실제 관측은 밖에 있었다. PR 준비 코드의 부분 관측 집계를 수정해 이 1건을 별도 분류했다. 기존 검출·추적이나 정답을 고쳐 집계를 맞춘 것이 아니다. 사건별 52행, 정상 구간 11개의 완전 포함/경계 입력, 후보 검수 묶음 193개는 [상세 진단](EXP-0065-coverage-results.md)에 기록했다. 묶음은 인원수·침입 사건 수가 아니며 공식 사건 밖의 후보를 정상 오판으로 세지 않는다.

006의 시간 미확정 공식 참조 1개는 52개와 별도로 유지한다. 008의 행동 의미 보류도 유지한다. 사람 기준 정밀도·재현율·F1, 침입 완료 정확도, 실시간 알림 개선은 **미측정(null)**이다. 오프라인 창 점수와 batch 처리 시각을 실제 경보 시각으로 바꾸지 않았다.

## 검수 자료와 기존 답변 재사용

학교 CCTV 23개 구간과 별도 장소 정상 라벨 오판 2개를 렌더링했다. 학교 자료는 기존 누락 15개 전체와 카메라·진단 유형별 대표를 포함해 8개 카메라를 모두 다룬다. 선정·미선정 이유는 전체 52행에 남겼다. 원본 장면, 선택 대상의 실제 박스, 다른 실제 관측 박스, 모델의 문맥 ROI, 원래 8시점 입력과 창 점수를 함께 표시한다.

25개 영상은 총 647표시 프레임·215.667초다. 원본 PTS를 표시하고 3 FPS로 재생한다. 결측 박스를 보간하지 않으며 입력이 없으면 ROI나 점수를 만들지 않는다. 부분 창은 8개 예정 시점과 실제 관측 유무를 표시한다. 독립 검토에서 모든 생성 MP4를 로컬 디코딩해 크기·FPS·프레임 수·해시를 확인했고, 원시 CCTV를 외부 이미지 도구로 전송하지 않았다.

| 별도 장소 오판 | 실제 입력 시각 | 점수 | 확인한 범위 |
|---|---|---:|---|
| 4-61, actor 0, 공식 stand | 16.667–19.000초 | 0.999995 | 8개 입력 RGB가 평가 NPY와 동일 |
| 4-62, actor 1, 공식 stand | 85.667–88.000초 | 0.999738 | 8개 입력 RGB가 평가 NPY와 동일 |

두 장면 모두 0/1 시작 해석 각각에서 대상의 stand 박스가 8시점에 있다. 해당 시점에 ROI와 겹치는 **다른 actor의 annotation**은 없다. 이는 라벨이 없는 다른 사람이 없다는 뜻이 아니다. 대상의 실제 행동, 라벨 시각의 의미, 입력 영역에 다른 넘는 인물이 있는지는 새 검수로 남긴다. 높은 점수를 근거로 라벨을 양성으로 바꾸지 않았다.

작업 시작·재개 시 웹 미처리 답변 조회는 성공했고 새 답변은 없었다. 기존 EXP-0063의 여덟 답변 중 두 오판과 관련된 박스 정렬 답변을 재사용했다. 이 답변을 행동 의미나 정밀 시작·끝 정답으로 승격하지 않았다. 새 질문은 **누락 사건의 후보 7개에 대한 모델 대상 대응과 오판 2개의 행동·ROI 의미**, 총 9개로 제한한다. 등록·답변 수신 상태는 [전달 기록](EXP-0065-delivery.md)에 별도로 남긴다.

## 보유 데이터 조사와 보강 준비

Training·Validation의 실제 행동 라벨 JSON 6,534개와 대응 원천 ZIP 멤버를 조사했다. 10개 공원에서 촬영됐으며, 별도의 객체 이미지 라벨 51,841개는 행동 음성으로 사용하지 않았다. 사람이 명시적으로 moving/stand/sit로 라벨된 구간만 정상 후보로 다루며, 불법행위 폴더 전체나 미주석 구간을 정상으로 확정하지 않는다.

기존 자료에서 보지 않은 6개 장소 중 태종대에서 stand 10구간·6원본·2시나리오를 찾았다. 다른 새 장소에서는 명시적 보행·대기·월담 라벨을 확보하지 못했다. 전체 moving 1,413개 공식 구간은 시민공원에만 있다. 따라서 현재 자료만으로 새로운 장소의 넘기와 여러 정상 유형이 모두 있는 독립 평가 세트를 완성할 수 없다.

원본·기존 촬영 묶음·같은 장소/시나리오·겹치는 촬영 시간을 연결해 211개 보수적 그룹으로 분할 목록을 만들었다. 기존 시험 296원본과 연결되는 다운로드 멤버 327개를 보호했고, 사용자가 제외한 월담 시나리오 362멤버를 제외했다. 기존 v3 분할 파일은 변경하지 않았다. 프레임을 디코딩하기 전에 장소 예약과 신규 후보 96원본·35그룹을 고정했다.

보호 자료 341개(기존 시험 296+학교 45) 전체와 후보 96개를 원본당 다섯 시점의 CPU 내용 지문으로 대조했다. 후보 96개의 실제 원천 ZIP 멤버 SHA256도 계산했다. 완전 동일 해시는 없었지만 내용 유사 의심 7개에서 양쪽 대상과 촬영 그룹으로 보류를 전파해 **29원본을 보류하고 67원본·24그룹을 의미 검수 후보로 남겼다.** 비슷한 배경을 같은 사건이라고 확정하지 않았다. 다섯 시점 지문만으로 재인코딩·크롭·시간 이동 중복이 전혀 없다고 보증하지 않는다. 기존 학습/검증 자료와는 해시·메타데이터를 대조했으며 전체 내용 지문 대조 범위에 포함하지 않았다.

| 후보의 예정 용도 | 점검 전 원본 | 제한된 점검 통과 원본 |
|---|---:|---:|
| 기존 학습 촬영 묶음에 연결된 추가 원본 | 70 | 51 |
| 기존 검증 촬영 묶음에 연결된 추가 원본 | 13 | 3 |
| 새 학습 보강 묶음 | 4 | 4 |
| 새 검증 보강 묶음 | 4 | 4 |
| 새 평가 촬영 묶음 | 5 | 5 |
| 합계 | 96 | 67 |

태종대 stand 후보는 학습 보강 2원본·3구간과 검증 보강 4원본·7구간으로 서로 다른 촬영/시나리오 그룹에 배정했다. 같은 장소이므로 장소 독립 평가라고 부르지 않는다. 검증에 대기를 보강할 근거는 확보했지만 보행·접근 후 돌아가기 부족은 해결되지 않았다. 새 평가 후보 5원본 중 4개는 이미 EXP-0064 시험에서 본 어린이대공원의 별도 촬영 묶음이고, 1개는 시민공원이다. 새 촬영과 새로운 장소를 구분한다. 다른 미사용 5개 장소는 평가용으로 예약했으나 필요한 명시적 행동 라벨이 없어 준비 완료로 세지 않았다.

학교 계열의 다른 로컬 자료 269개 원천·라벨 대응도 조사했지만, 공식 사건 분류만으로 보행·대기·돌아가기의 사람별 정상 구간을 만들지 않았다. 추가 제조업 자료의 정지 이미지와 읽지 못한 분할 ZIP도 행동 영상 확보로 세지 않았다. 검수로 확인된 접근 후 돌아가기·문을 만지고 넘지 않기는 각각 0개다. 출처·actor·공식 시작/끝·박스·입력 후보 영역·보류 이유를 포함한 목록과 세부 한계는 [자료 보강 보고서](EXP-0065-augmentation-results.md)에 남긴다. 모든 보강 후보의 학습 허용 상태는 false이며 실제 학습용 이진 정답이나 새 학습 클립을 생성하지 않았다.

## 다음 학습에서 바꿀 제안

1. **데이터 구성을 먼저 보완한다.** 장소별 보행·서 있기·접근 후 돌아가기·문을 만지고 넘지 않기를 확보하고 사람별 행동 구간을 검수한다. 기존 검증 음성이 앉기에만 치우친 문제를 해결하기 전에는 그 검증 점수만으로 다음 모델을 선택하지 않는다. 새 평가 장소에는 양성과 여러 음성을 함께 확보한다.
2. **두 정상 라벨 오판의 의미 검수에 따라 입력 변경 축을 고정한다.** 다른 사람이 ROI에 섞인 경우에만 대상 박스/마스크와 문맥을 구별하는 입력을 비교한다. 현재 자료만으로 ROI 혼입, 라벨 오류, 배경 학습 중 하나를 원인으로 단정하지 않는다.
3. **입력 부족과 행동 분류를 따로 개선한다.** 5개 부분 관측·1개 무관측 참조는 모델 재학습만으로 해결되는지 알 수 없다. 실제 대상의 관측 공백, 3 FPS 샘플링과 짧은 행동의 대응을 먼저 검토한다. 이번에는 검출·추적·보간·입력 길이를 바꾸지 않았다.
4. **확인된 후보를 다음 침입 판단 실험에만 연결한다.** 새 의미 검수 뒤 7개 후보의 대상·문 대응을 확인하고, 행동 점수와 침입 완료 상태를 분리한 별도 비교를 설계한다. 기존 45개나 열어 본 시험에 맞춰 임계값을 선택하지 않는다.

## 재현과 검증 범위

[실행 명령과 산출물 목록](EXP-0065-reproduction.md)에 같은 자료를 읽는 CPU 진단·미디어·보강 단계의 재현 방법을 정리했다.

기준 잠금 SHA `3799ae3e…`, 입력 계획 `f8bea6c8…`, 실제 추론 결과 `b465170e…`, 선택 가중치 `8b4e2eb7…`를 유지한다. 전체 해시는 [사건 진단 보고서](EXP-0065-coverage-results.md)와 [독립 검토](../reviews/EXP-0065-independent-review.md)에 있다. 기존 EXP-0064 등록 원문·시험·점수와 EXP-0062 판단 출력을 수정하지 않는다.

로컬 실제 산출물은 `outputs/action-recognition/exp0065/coverage-v1/`, `review-media-v2/`, 보강 자료 디렉터리에 보존한다. 첫 미디어 v1은 독립 검토의 입력 해시 고정 요구를 반영하기 전 예비 결과여서 등록하지 않는다. 최종 v2는 독립 검토한 summary/per-video 바이트를 명시하고 입력·코드가 실행 중 바뀌면 거절한다.

진단 31시험·표시 7시험·자료 보강 20시험을 통과했고, 별도 구현의 52행 재계산 및 25개 실제 미디어 대조를 통과했다. 이는 실제 실행·출처·표시 계약의 검증이다. 의미 검수와 학교 CCTV 성능 개선 완료를 뜻하지 않는다. GitHub·웹 등록·재생 확인은 전달 기록에서 실제 수행한 항목만 완료로 표시한다.
