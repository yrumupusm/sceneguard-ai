## 실제 ReID 입력의 재현 범위

기존 `representatives` JPEG는 관측 박스 범위만 자른 자료다. 이를 그대로 실제 네트워크 입력이라고 표시하지 않았다. 원본 native PTS와 저장 박스를 사용해 설치된 공식 ReID의 **전처리 함수만 CPU에서 호출**했다.

- 기존 center-xywh 좌표 계약을 유지하고, 공식 crop의 gain 1.02·pad 10·원본 경계 clipping을 적용했다.
- BGR→RGB, FP32 /255, bilinear 448×448, `align_corners=False`의 기존 전처리를 재현했다.
- 공식 crop 반환값과 계산한 원본 crop 범위의 픽셀이 일치하는지 확인했다. 원본 디코딩의 정수 native PTS와 time base도 대조했다.
- 표시 PNG는 재현한 float 입력을 8비트로 표현한 이미지다. 재현 tensor의 shape·SHA는 로컬 manifest에 별도 기록했다.

이는 **당시 저장한 입력 tensor 덤프가 아니라 동일 전처리의 사후 재현**이다. 모든 비교판과 HTML에 이 차이를 표시했다. 기존 대표 JPEG도 별도 참고 이미지로 제공한다. 모델 생성·가중치 로딩·forward·GPU 초기화·새 embedding 생성은 모두 0이며, 연결/추적/영역 판단을 다시 실행하지 않았다.
