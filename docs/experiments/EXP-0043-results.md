# EXP-0043 — 경로 참조 변경 실제 비교: 개선 미확인·기본 적용 보류

2026-11-01. **단일 수정 구현과 두 전체 구간 A/B 실행은 완료했지만, 유용한 침입 의심 개선은 확인하지 못했다.** 사용자는 누락 구간에서도 사람을 따라가는 점이 많고 문 잔상이 섞인다고 확인했다. 이를 근거로 공간 변화의 참조를 최근 약0.5초에서 기존 창의 시작점으로 바꾸는 한 가지 가설을 실제 비교했다. 접근·대기 후보가 늘었고 필요한 초기 장면의 유효한 조기 근거는 확인되지 않아 기존 MVP를 유지한다. 추가 튜닝은 하지 않는다.

이전 진단 완료·사용자 답변 대기 상태는 [진단 체크포인트](EXP-0043-diagnostic-checkpoint.md)에 그대로 보존했다. [사용자 관찰](EXP-0043-user-review.md)은 클립 수준이며 모든 점의 동일인 대응이나 정확한 침입 시작 프레임의 정답이 아니다. 화면의 표현은 침입 의심이며 법적 출입 권한이나 침입 확정을 판정하지 않는다.

## 확인한 원인과 한 가지 수정

EXP42의 전체2190프레임·12046신호를 재현했다. 원래00764–74초의2928신호와65–66초의265신호는 모두0.55미만이었다. 최고점이 아닌 경로까지 확인했으므로, 이미 양성인 경로를 최고창 선택에서 버린 산술 오류는 아니었다. 대표65.066667초 점수0.427550의 국소 경로는 근접도×위쪽 이동 상한부터0.480128이었다. 이는 기존 방식의 진단이며 수정 후 모든 신호도 미달이라는 뜻은 아니다.

새 사용자 관찰은 ‘필요한 움직임이 전혀 없었다’는 설명에 맞지 않는다. 저장된 같은 영구 점들을 살펴보면65–66초의 충분히 오래된195신호에서 최근/시작점 참조의 위쪽 변위 중앙값은4.66/9.93px, 국소 변형은5.35/11.75px였다. 최근 참조가 점진적인 공간 변화를 작게 평가하는지 시험할 근거가 있었다. 하지만 접근 장면의 위쪽 변위도19.40→87.69px로 커져, 개선을 미리 가정하지 않았다. 이 수치는 영상 속 신체나 행동을 인식한 값이 아니다.

실행 전 [고정 비교 조건](EXP-0043-comparison-protocol.md)을 작성하고 `seed_geometry_recent_dynamics_v1` 한 조건만 실행했다.

- 공간 성분(선 통과·위쪽 이동·국소 변형·경계 법선 진행·방향 일관성)만 같은 생존 점의 창 시작→현재 위치로 계산한다. 창 수명 최대2.5초는 그대로다.
- 현재 근접도·점 품질·카메라 보정·시작 박스 높이·수식과 가중치·기준0.55·지지 시간·쿨다운·시작창·영역은 유지한다.
- 속도와 속도 변화는 저장된 최근 참조 값을 그대로 사용한다. 시작점 기준으로 가속도를 다시 계산해 부풀리지 않는다. 공간 참조 시각과 최근 동역학 참조 시각을 별도로 저장한다.
- 기존/시작점 점수 중 큰 것을 선택하지 않는다. 반전·정지·드리프트·대기 누적의 부작용을 시험하고, 장면별 예외나 결과 뒤 재조정은 추가하지 않는다.
