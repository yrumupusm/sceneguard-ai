## 고정한 방법

## 실제 배경으로 정한 영역과 한계

총괄이 두 원본의 native PTS0 배경을 직접 확인한 뒤 **결과를 보기 전에** polygon을 한 번 고정했다.030은 전경 횡단보도/보도 쪽을 outside, 문 뒤 학교 도로 쪽을 inside로 구분했다.007은 왼쪽 도로를 outside, 접이식 울타리 뒤 좁은 길을 inside로 구분했다. 문·울타리·기둥과 불명확한 전이 띠는 제외했다. 예시 좌표를 복사하지 않았으며, local JSON은 source SHA와1920×1080에 결속했다. 좌표·표시 이미지는 로컬 전용이다.

이는 영상평면의 안전 영역 초안이다. bbox 높이65%의 내부 세 점을 투표하므로 실제 발이나 지면 좌표가 아니다. 부분 박스·가림·원근 때문에 반대편 배경으로 점이 투영되거나, 실제 넘어간 사람도 안전 영역에 들어오지 않을 수 있다. 출력에 맞춰 polygon이나 임계값을 조정하지 않았다.

같은 polygon·영역 규칙을 **연결 전 tracklet**과 **연결 후 chain**에 모두 적용한다. EXP-0028 선 통과 후보와 새 polygon 후보는 규칙이 다르므로 후보 수 차이를 tracklet 효과로 부르지 않는다.

## 사후 분석 시각과 표시

전체 구간의 뒤쪽 관측을 이용하므로 실시간 ID 복원이나 경보가 아니다. `confirmed_at`은 영상상의 관측 시각, `available_after_pts`는 입력 마지막 시각(03099.966667초,007104.966667초)이다. 실제 계산 시간은 별도다. 앞쪽 프레임에도 최종 연결 ID가 표시되지만 그 시점에 이미 알았다고 해석하지 않는다.

원본/기존 raw ID/사후 연결 ID를 나란히 표시하고 원본 PTS·영역·동일 영역 규칙의 후보 수·사후 가용 시각을 넣었다. 검출 없는 공백에 박스를 만들어 그리지 않는다. 표시 확대는 원본 관찰을 돕기 위한 것이며 추론 crop 변경이 아니다. 확대판은 고정 polygon 외접범위+3%만 표시하므로007 기둥 오른쪽 후기 인물 등은 잘릴 수 있다. 이 경우 전체화면 비교판을 사용하며, 위 시각 대조는 확대판 밖 원본도 확인했다. 기존 온라인 후보와 비교할 때 이 지연을 포함해야 한다.
