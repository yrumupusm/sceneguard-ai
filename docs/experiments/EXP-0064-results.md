# EXP-0064 첫 이진 행동 인식 학습과 별도 파이프라인 비교

2026-11-07. **10 epoch 학습과 새 시험 1,431개 평가, 기존 45개 전구간의 별도 행동 점수 비교를 완료했다. 공식 라벨 대조 참고치는 정밀도 99.658%·재현율 100%지만, 별도 장소의 정상 라벨 2개를 모두 넘기로 분류했다. 실사용 일반화 성능은 입증하지 못했다.** 45개에서는 3,573개 입력의 점수를 계산해 넘기 후보 467개를 얻었으며, 이를 침입 사건 수나 성능 개선으로 해석하지 않는다. EXP-0063의 데이터 감사와 사용자 표본 검수를 바탕으로, 사람 주변의 문·담장을 함께 보는 `넘기 / 넘기 아님` 모델 하나를 학습했다. 기존 EXP-0062 운영 판단은 보존한다.

## 현재 확인된 결과

- 원본·라벨 2,162개 파일의 해시 검증과 5,741개 클립 준비를 완료했다. 모든 클립의 ID·NPY 해시·`8×112×112×3 uint8` 형식을 독립 확인했다.
- 먼저 만든 2,033개 클립과 별도 소량 점검용 36개 클립이 최종 입력과 바이트·배열·형식까지 일치한다.
- RTX 3080에서 실제 학습 32개·검증 4개의 소량 점검을 통과했다. 배치 4의 8개 미니배치, 누적 4, 실제 AdamW 갱신 2회이며 시험 자료를 사용하지 않았다. 최대 PyTorch 할당 메모리는 888,636,928바이트였다. 이 작은 점검의 검증 수치는 모델 성능으로 보고하지 않는다.
- 수정 버전의 소량 점검 attempt `e880e2d07ff1406793fd762fb7582416`도 성공했다. 갱신 시도 2·실제 갱신 2·건너뜀 0, AMP scale 65,536, 모델 텐서 102개와 최적화 상태 텐서 186개의 유한성을 확인했다. 저장된 Adam 상태 62개의 step 값은 모두 2다. 원래 소량 점검과 학습·검증 손실이 같으며, 본 학습과 성능 검증 완료를 뜻하지 않는다.
- 본 학습은 원래 사전학습 가중치에서 시작하는 10 epoch 단일 구성이다. 소량 점검의 학습된 가중치를 초기값으로 사용하지 않는다.
- 첫 전체 학습 attempt `058639f80f394a71b345eb4eae5ceacb`는 첫 epoch에서 `clip_grad_norm_(..., max_norm=inf, error_if_nonfinite=True)`의 비유한 기울기 노름 오류로 exit 1 종료했다. 완료 epoch·선택 가중치·시험 결과는 없다. 실제 실패 전 갱신 횟수와 최대 메모리를 확인하지 못했으므로 0으로 확정하지 않는다. 실패 로그와 실행 기록은 보존하며, 정확한 원인을 단순 traceback만으로 특정하지 않는다. 표준 GradScaler의 건너뛰기·스케일 조정과 실제 갱신 횟수 기록을 보완한 별도 실행 버전을 사용한다.
- 수정한 본 학습 attempt `67e95fc8cf204de7be9627e81f524931`는 exit 0 성공했다. 10 epoch·갱신 시도 2,250·실제 갱신 2,248·AMP 건너뜀 2회이며 매 epoch 모델·최적화 상태가 유한했다. 건너뜀은 1회차와 10회차의 마지막 1개 표본 갱신에서 발생했다. 이 기록으로 원래 실패 실행의 정확한 배치·원인을 소급 확정하지 않는다.
- 검증 손실이 가장 낮은 6회차 모델을 선택한 뒤 시험 추론을 한 번 수행했다. 최대 PyTorch 할당 메모리는 889,882,112바이트(약 848.66 MiB)다. GPU 전체 사용량이나 순수 GPU 연산 시간을 뜻하지 않는다. 저장된 점수·선택 기준·모델 상태와 실행 기록을 독립 확인했다.
- 새 시험의 공식 라벨 대조와 대표 불일치 2개 영상을 저장했다. 사람 검수 기준 성능과 침입 완료 정확도는 미측정이며, 45개 회귀의 실제 결과는 별도로 기록한다.

수정 실행 `amp-overflow-v2`는 무한대 임계값의 기울기 노름 계산을 제거하고, 표준 GradScaler가 유효하지 않은 기울기의 갱신을 건너뛰고 스케일을 조정하도록 했다. 실제 AdamW 호출을 별도로 세어 갱신 시도·실제 갱신·건너뛴 갱신을 기록한다. 비유한 손실과 모델·최적화 상태는 계속 실패로 처리하며, 실제 갱신이 없는 epoch를 완료로 인정하지 않는다. 설정·데이터·사전학습 가중치는 그대로다. [PyTorch 2.5.1 구현](https://github.com/pytorch/pytorch/blob/v2.5.1/torch/amp/grad_scaler.py)의 동작을 확인했고, 관련 CPU 검사 100개와 별도 수치 반례 검증을 독립 통과했다. 이는 수정 코드 검증이며 학습·성능 완료를 뜻하지 않는다.

기존 전처리 생산 코드의 SHA와 새 학습 코드의 SHA는 구분해 보존했다. 전처리 함수·의존성·모델 초기화까지의 코드가 동일함을 확인해 기존 입력 5,741개를 재사용한다. 원래 실패한 작업을 초기화하거나 재시도한 것이 아니라 별도 버전의 작업으로 실행하며, 변경된 학습 코드에는 새 소량 점검을 요구한다.

## 별도 파이프라인 연결의 해석

학습 모델 자체의 시험 평가를 확인한 후 기존 45개 원본의 전체 native PTS와 저장된 검출·추적을 사용해 별도 행동 점수를 계산한다. 기존 침입 사건·카드·첫 알림·확인 시각은 보존한다. 행동 점수가 0.5 이상이어도 표시 의미는 **넘기 행동 후보**이며 침입 완료·확인·해제를 뜻하지 않는다.

같은 추적 대상의 실제 관측이 8개 샘플 시점에 모두 있는 경우만 입력을 만든다. 예측 박스로 누락을 채우지 않는다. 원본 PTS에 가장 가까운 3 FPS 시점을 선택하고 같은 거리이면 앞 프레임을 사용한다. 8개 시점의 입력을 1초 간격으로 생성하며 기존 검출·추적의 ID와 박스를 그대로 사용한다.
