- 유일한 모델은 공식 `yolo26m-pose.pt`다. 공식 release와 정확한 패키지·가중치·설정·입력 해시는 ADR/manifest 및 실행 허가에 고정한다. 기존 환경과 기본 CV/VLM은 유지한다.

## 관절 품질과 행동을 구분하는 판정

모델이 반환한 17개 COCO 관절의 순서·confidence·원본 좌표·실제 입력 크기를 기록한다. 관절 confidence **0.5 이상**은 이번 진단의 보존 기준일 뿐 관절 정확성이나 가시성의 정답이 아니다. 그보다 낮거나 누락·비정상인 관절은 unknown으로 처리하고, (0,0)을 정상 신체 위치로 해석하지 않는다. 낮은 confidence도 원시 결과에 보존하며 표시 여부와 검출 결과를 구분한다.

원본/pose overlay에서 사람별 박스 대응, 부분 신체, 좌우 관절 혼동, 울타리·다른 사람에 붙은 관절, 작은 대상 누락, 중복과 배경 의심을 별도로 기록한다. 아직 사람 검수가 없는 항목은 미확정이다. 박스·관절 개수 또는 confidence만으로 실제 사람 복원, 관절 정확도, 관절별 recall을 만들지 않는다.

연속창의 박스 인덱스는 사람 ID가 아니다. 같은 사람이라는 근거가 없는 관절끼리 변화량이나 ID 연속성을 계산하지 않는다. 관측/누락의 프레임별 진단은 가능하지만 사람별 지속 관측을 자동 보장하지 않는다. 예측·보간 관절은 이번 실제 관측을 대신하지 않는다.

규칙 단계는 아래 조건을 모두 만족할 때만 별도 사전 등록·검토 후 진행할 수 있다. 출력 결과에 맞춘 수치 반복 조정은 없다.

1. 시도·접근 구간의 실제 사람과 필요한 손목/엉덩이/무릎/발목 대응이 확인되고, 가림과 다른 사람의 관절을 구분할 수 있다.
2. 시간에 따른 같은 사람의 대응이 충분히 안정적이며, 필요한 관측이 누락된 구간을 정상으로 처리하지 않는다.
3. 기존 고정 카메라 설정이 규칙에서 요구하는 물리적 경계 관계를 뒷받침한다. 가상 통과선을 울타리 상단/반대편으로 임의 해석하거나 새 경계를 정답 장면에 맞춰 그리지 않는다.

조건 미충족이면 `pose evidence insufficient` 또는 `boundary geometry unvalidated`로 규칙을 실행하지 않는다. 이는 정상 행동 판정이나 모델의 확정적 실패율이 아니다. 추정 좌표의 실제 정확성이 미확정이면 그 상태를 분명히 보고한다. 현재 승인으로 추적기·경계 보정을 자동 추가하지 않는다.

## 관찰·공개·완료

기존 사용자 관찰은 평가용으로만 쓴다. 030 약90초의 올라탐, q04의 문 잡기/발 올림과 구간 내 완료 미관찰, q02/q05의 접근-only, v01의 줄 넘기 후 반대편 서기를 구분한다. 줄 넘기를 울타리 넘기의 주 양성으로 합치지 않는다. 031의 종료 관찰을 030에 전이하지 않는다.

원시 관절·프레임·영상·가중치·환경·DB·로그·receipt는 로컬 전용이다. 공개물은 재현 코드·비식별 집계·해석·독립 리뷰다. 로딩/준비/추론/결과 저장 비용과 GPU allocator 메모리 범위를 분리하고 CPU/공식 벤치마크를 이번 GPU 실측으로 쓰지 않는다. accuracy/F1/FPR·완료율은 산출하지 않는다.

최종 판정은 기술 실행, 사람/관절 품질, 행동 구분, 독립 검토, 웹/GitHub 전달의 다섯 항목으로 나눈다. 기본 적용은 자동 변경하지 않으며 배치 종료 뒤 후속 GPU 작업은 예약하지 않는다.
