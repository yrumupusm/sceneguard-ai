# EXP-0007 — 짧은 원본 CCTV 클립의 독립 로컬 VLM 행동 분석

2026-10-28 / Codex 개발 실험. 기반 HEAD `d13c1308f2edbf9b18972a474e6eb7479175d6f2`. [선정 ADR-0012](../decisions/ADR-0012-local-vlm-clip-analysis.md). 기존 EXP-0005 CV/추적/경계 코드와 EXP-0006 기본 적용 보류를 유지했다. **VLM을 기본 파이프라인에 연결하지 않았다.**

## 결과와 판단

Qwen3-VL-2B-Instruct 하나를 RTX 3080에서 로컬 실행했다. 여섯 클립 모두 생성은 완료했지만 **행동을 안정적으로 구분하는 효용은 확인하지 못했다**. 접근을 이동/대기로 설명하는 부분적 부합은 있었으나, 실제 넘기 장면을 문 열기/단순 이동으로 설명하거나 근거 없는 동작·목적을 추가했다. 030은 행동 목록에 넘기를 적었지만 근거가 문 열림에 의한 통행이고 반복으로 출력이 잘려 올바른 넘기 이해로 세지 않았다. 가림이 큰 031도 적절한 판단 유보 대신 걷기를 반복했다.

이는 사람이 미리 선택한 5초 개발 클립 6개의 사후 분석이다. 연속 CCTV에서 사건을 발견한 실험이 아니며 정확도·F1·오탐률·범용/실시간 관제 성능을 산출하지 않았다. CV의 기하학적 통과 후보와 VLM의 언어 행동 설명을 같은 정확도로 직접 비교하지 않는다. 기본 도입/자동 사건 판정 채택은 보류한다.

## 실제 영상 입력 감사

각5초 구간에서 start+k×.5초(k=0..9) 이상 첫 원본 프레임 선택. **모두10프레임, 전체60프레임**. 원본1920×1080을 processor가 전체 화면 **448×768**로 한 번 resize했다. aspect ratio가32배수 반올림 때문에 약간 달라지며 사람 위치 크롭은 없다. processor do_sample_frames=False; 추가 샘플링0, 원본·resize 프레임 중복0, temporal padding0. 추가 시도/OOM에 따른 예산 변경 없음.

video_grid_thw=[5,28,48], temporal patch2로10프레임→5시간패치. 공간 merge2×2 후 **1,680 영상 토큰**을 실제 input_ids에서 확인했다. 영상으로 처리한10장이지 한 장 이미지 분석이 아니다. timestamp는 각 두 프레임 평균을 소수1자리로 표시한다. 보통 `<0.2 seconds>…<4.2 seconds>`이며 006의 실제 .5005초 간격에서는 `<0.3>…<4.3>`이다. 이 반올림된 모델 timestamp를 정밀 사건 시각으로 쓰면 안 된다.

## 구조화 출력과 실패 보존

완료 run02의 **6응답 모두 코드 펜스(````json`)로 시작해 엄격한 JSON 파서 실패**. 01/03/04/05/06은 사람이 읽을 수 있는 JSON형 본문, 02는 문장 반복·토큰 한도 때문에 본문도 미완결이다. 파서를 묵시적으로 고쳐 성공률을 부풀리거나 원응답을 다시 쓰지 않았다. 의미 평가는 원문을 읽어 작성한 초안이며 파싱 성공과 별개다. 모든 원응답/생성 token IDs/parse_error/hit_token_limit 보존. 다시 질문하거나 특정 클립에 맞춰 프롬프트/길이를 변경하지 않았다.

최초 run01은 모델 로딩과 clip01 생성 후 `Path.write_text`에서 ASCII UnicodeEncodeError가 났고 오류 JSON 저장도 실패했다. **그 시도의 응답 본문은 보존하지 못했다**(빈 파일/traceback/로딩 정보/메모리 로그 보존). 원인 범위는 생성 후 기본 텍스트 인코딩에 의존한 저장 경로이며 런타임 locale 변경 주체는 미확정이다. 명시적 UTF-8 I/O, PYTHONUTF8=1, 텍스트보다 생성 token IDs 선저장을 적용해 run02에서 같은6개 조건을 실행했다. 첫 응답의 의미를 확인하기 전 실패했으며 응답별 프롬프트 수정은 없었다. 모델 변경/추가 다운로드/OOM 재시도 아님. 실제 생성 시도는 실패한 첫1회+완료6회다.

`torch_dtype` deprecated 경고와 greedy에서 기존 generation_config의 sampling 옵션이 무시된다는 경고도 console 로그에 보존했다. 고정 do_sample=False가 적용됐고 이를 sampling 실행이라고 보고하지 않는다.

새 환경에서 실행하는 순서다. 이미 있는 준비/실행 폴더 덮어쓰기 거부; 재실행에는 새 ROOT/run 이름을 사용하고 audit에도 맞춘다. 기존 CV환경에 lock을 설치하지 않는다. full lock은 실제 설치된 버전이고 torch CUDA wheel은 첫 명령으로 공급한다.

- 가중치 공식 LFS hash 일치, config/tokenizer 포함 파일별 해시 기록.
- 원본60프레임 픽셀·순서·PTS/샘플 간격·중복0 확인. processor 실제 resize/grid/1680토큰/추가 sampling0/padding0 감사 통과.
- 익명 프롬프트6개에 원본 ID·침입 경로·CV event key/보고서 단서 미포함, 각 user1개 독립 대화 확인. 원본 metadata/선정 근거는 실행 입력 텍스트에서 분리.
- 응답 계약 테스트4개: 정상 Unicode JSON, 펜스 실패, 잘린 JSON 실패, 잘못된 완료 상태 거부. 기존 CV코드는 수정하지 않았고 `.venv` 설치 전후 freeze 동일.
- `outputs/vlm_exp0007/clip*/rgb.npy,input.json,review_input.jpg`: 원본 표본/PTS. `run02/clip*/processor_resized_rgb.npy,actual_input_review.jpg`: 실제 모델 resize 입력과 검수 시트. 원시 expanded_prompt/token IDs/response/result 및 메모리 로그 모두 로컬 전용.
- 기존 출력·캐시·공식 JSON·설정 530파일의 보존 해시와 실행 전 manifest/prompt/ADR 해시 동일 확인.
- 모델 불러오기/각실행 코드 SHA는 loading.json에, 선정/manifest/prompt 해시는 preregistered.json에 보존. 사용자·공식 정답 라벨과 기존 보고서/출력 변경 없음.

## 다음 판단

이번 조건은 실행 가능하지만 행동 분류의 안정성과 구조화 응답 모두 부족하다. 작은 영상 속 사람 정보 손실, 생성 반복, 근거 없는 문 열기 설명을 실패 사례로 유지한다. **현재 모델/조건의 기본 연동을 하지 않는다.** 다음에는 이번60개 실제 입력 프레임에서 보이는 동작과 모델 설명의 불일치를 사용자와 검수해 평가 기준부터 확정한다. 이후 별도 범위에서 입력 정보 손실과 모델 추론 오류를 분리할 한 가지 대조를 설계할 수 있으나 이번에 크롭/해상도 재탐색·새 모델·재학습·자동 CV 연결은 하지 않았다.
