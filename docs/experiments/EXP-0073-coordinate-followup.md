2026-11-09. 주간20초의 청록색 박스 밑변을 신발 쪽으로 조금 올려 달라는 사용자 요청을 반영했다. 위쪽·양옆은 그대로 두고 밑변만 올린 새 수정안과 수정 전후 이미지를 `outputs/model-comparison/exp0073/day-bottom-v2/`에 별도로 저장했다. 새 경계의 최종 승인은 아직 없으며 기존 등록 영상·질문 바인딩은 변경하지 않았다. 수정본은 로컬 `http://127.0.0.1:8771/`에서 볼 수 있고, 주간 검수 메모에도 링크를 남겼다.

동시에 받은 야간 새 좌표4개의 ‘위치·크기가 맞음’ 답변(answer_version1)을 실제 읽고 연결 자료를 검증했다. 원본23.667·24·24.333·25초에 표시된 청록색 대체 박스4개만 승인 기록으로 보존했다. 주황색 기존 박스나 전체 프레임 완전성 승인으로 확대하지 않았다. 야간23.333초 한 프레임의 전체 보류는 유지했다.

정확한 승인 좌표·답변 버전·원본 SHA/PTS·편집 패키지 SHA는 로컬 `runtime/model-comparison/exp0073/day-bottom-v2/night-four-box-approval.json`에 있다. 주간 수정은 `scripts/refine_exp0073_day_box.py --output NEW_OUTPUT`으로 기존 디코딩 환경에서 재현한다. 원본 이미지 해시, 위·양옆 동일성 및 실제 HTTP 제공 이미지 해시를 대조했다. 새로운 모델 추론·학습·운영 규칙 변경은 없다.

검수 화면의 반영 완료는 요청을 반영했다는 뜻이며 주간 새 좌표 최종 승인이나 전체 학습 자료 완성을 뜻하지 않는다. 기존 질문의 자료는 이전 수정안 그대로 보존하며 새 수정본과 혼동하지 않는다.
