## 문 구역과 사용자 범위 수정

총괄은 사용자가 명시적으로 제공한 두 이미지의 윤곽을 확인해 각각 5개 꼭짓점으로 근사 옮겼다. 문 본체 높이에 맞춰 축소했으며 먼 안쪽 통로와 옆 보행로를 포함하도록 확대하지 않았다. 정확한 좌표까지 사용자 확정이라고 주장하지 않는다. 첫 실행 전에 수정·고정했으며 검출 박스·사건 시각·실험 결과로 영역을 역산하거나 탐색하지 않았다. 처음 초안과 미리보기는 별도로 보존한다. 최초 초안으로 실험한 결과는 없다.

## 역할과 전달

기존 Run의 Sol high가 CPU 실행·표시, Astra high가 독립 검토, Terra high가 최소 웹 연결을 맡는다. 총괄이 등록과 게시를 담당한다. 새 서버·큐·화면 기능은 만들지 않는다. 새 판정 중 의미가 애매한 사례만 짧은 영상으로 확인하며 기존 장면 검수는 재사용한다. 기본 MVP·수동 검토 DB·알림 영수증은 보존한다.
