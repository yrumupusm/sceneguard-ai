# WEB-0004 — 전체 이력의 측정값 표시 정리

2026-11-02. 사용자 요청에 따라 등록된 전체 실험 이력의 측정값 표시를 공통으로 변경했다. 원본 보고서·측정 JSON·평가 결과는 수정하지 않았다.

## 변경

- 단일 값마다 그리던 막대그래프를 제거하고 최대 네 개의 주요 기록을 숫자로 요약한다. 명시적으로 비교 조건이 등록된 전후 그래프만 유지한다.
- 상세 측정값은 **항목 / 측정값 / 표본 수** 표로 표시한다. 같은 원문 측정 조건끼리만 묶고 조건은 각 표 위에 한 번 설명한다. 단위가 같다는 이유로 서로 다른 조건을 합치지 않는다.
- 전체 이력의 서로 다른 측정 조건 285종 중 영어 문장 215종을 한국어로 옮겼다. 한국어 조건은 보존한다. 새로운 미등록 문구는 임의로 번역·요약하지 않고 원문을 유지한다.
- 영상·프레임·초 등 단위를 한국어로 표시하고 공식 사건 TP/FP/FN은 잡은 사건·잘못 잡은 사건·놓친 사건으로 풀어 쓴다. 조건에 남은 조기 오경보 제외와 개발 자료 한계를 함께 읽어야 한다.
- 천 단위 구분과 소수점 최대 세 자리 반올림을 적용한다. 0이 아닌 0.001 미만 값은 지수로 표시해 0으로 오해하지 않게 한다. 0과 미측정은 구분하며 비율을 임의의 정확도나 백분율로 바꾸지 않는다.
- 영어 문장의 반복을 줄이면서 미확정 예측, 정답 부족, 처리 시간의 포함·제외 범위, 관찰 종료와 의심 해제의 차이는 보존한다.

## 검증

실제 서비스의 **등록 결과 52개, 측정값 1,332개**를 조회해 모두 새 표시 자료에 연결됨을 확인했다. 결과별 조건 묶음은 합계 292개다. 미등록 배정에는 측정값을 만들어 넣지 않는다.

| 실제 브라우저 확인 | 결과 |
|---|---|
| MVP-0004 | 단일 값 그래프 0개, 측정 표 27행. 전체45/실행2/미지원43/실패0을 요약. 공식 사건 평가의 조기 오경보 제외 조건 유지 |
| MVP-0005 | 단일 값 그래프 0개, 측정 표 19행. 전체45/실행45/실패0/184,300프레임을 요약 |
| EXP-0049 | 명시된 007·030 사건 카드 전후 비교 그래프 2개 유지. 상세 측정 표 40행. 카드 수가 정확도가 아니라는 조건 유지 |

Python 13개 시험(전체 카탈로그 범위·값·원문 보존, 중요 평가 조건, 서로 다른 범위의 분리, 기존 웹 API·비교 편집)과 Node 측정표·실험 목록 2개 스위트가 통과했다. 모든 기존 기록 JSON 69개의 작업 전후 SHA256이 일치했다. API 조회는 전체 52개를 확인했고 실제 브라우저 표시는 위 세 결과를 대표로 확인했다. 모든 이력을 사람이 새로 검수했다는 뜻은 아니다.

로컬 서비스에 적용하고 자산 주소를 `web0004`로 갱신했다. 원본 영어 조건·정밀 수치는 기존 기록 및 API 원본 필드에 그대로 남는다. 한국어 설명과 단위는 화면 표시용 필드다. 모델·판정·영역·검수 DB·알림 영수증·큐를 변경하거나 새 추론을 실행하지 않았다. 행동 성능 개선이나 과거 실험의 미완료 항목 완료를 주장하지 않는다.
