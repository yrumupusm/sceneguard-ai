# EXP-0051 — 모호함 일괄 거절 제거와 실제 통과 우선 비교

2026-11-04. EXP-0050의 확인39/52→0/52 실패와 연결 거절 원인을 설명한 뒤, 사용자가 “보수적으로 잡으면 안돼”라고 수정 방향을 명시했다. 이번 지시는 이전의 같은 관측 계보 거절 유지 및 추가 분석 보류를 대체한다. 새 추론 없이 코드 수정과 저장 측정값 비교를 이어간다.

## 판정 방향

- 목적은 출입구 통과 사건 검출이다. 사람 신원이나 박스 연결의 완전한 유일성을 확인의 필수 조건으로 요구하지 않는다.
- 근처에 연결 가능한 박스가 여러 개 있다는 사실만으로 이미 관측되는 일관된 통과 경로를 막지 않는다. 원시 박스 경쟁은 진단 정보로 남길 수 있지만 모든 후보에 영구 거절로 전파하지 않는다.
- 실제 출발·문 구간·반대편의 이동 경로를 우선 사용한다. 여러 관측 가설 중 통과 근거가 있는 경로가 있으면 사건 확인에 사용할 수 있으며, 신원 확인으로 표현하지 않는다.
- 잘못된 경로를 실제 관측처럼 만들거나 미래 좌표·예측 박스로 통과를 만들지는 않는다. 끊김 구간은 저장된 대상 이동점과 실제 박스 근거를 사용하고, 확인할 수 없는 연결 하나가 이후 새 근거 전체를 막지 않게 한다.
- 잠시 연결이 모호해도 출발 이력을 일괄 삭제하지 않는다. 새로 독립된 사건의 근거가 충분하면 다시 판단하며, 그 근거를 오래된 관련 없는 후보에 소급 적용하지 않는다.
- 새 안쪽선·기존 바깥선·양방향 기준을 유지한다. 문 옆 정지·안쪽 가장자리 지속 관측만으로 확인하지 않고, 실제 통과 또는 문 소실의 위치·방향·진입 근거를 본다. 이미 확인한 안→밖 통과는 복귀로 취소하지 않는다.
- 연결·시간·박스·특징점의 수치 기준은 영상 정답 시각에 맞춰 탐색하지 않는다. 새 점수 선택이 필요하면 자료 결과를 보기 전에 정의와 한계를 명시한다.

실측 전에 추가로 정한 사건 연결 원칙: 충분한 실제 통과 근거가 있지만 현재 관측 구간에 속하는 기존 후보가 없으면, 통과 완료 시점에 실제 근거를 참조하는 현재 통과 후보를 별도로 만든다. 옛 후보를 대신 확정하지 않으며 원래 후보 내용은 그대로 보존한다. 같은 통과 근거로 반복 후보를 만들지 않는다. 저장된 이동점과 실제 박스가 지지하는 복수 연결은 설명 가능한 순위로 선택하고 대안과 신원 미확인을 함께 기록한다. 이 원칙은 기존 후보 부재가 다시 통과 일괄 누락으로 이어지지 않도록 실제 결과를 보기 전에 확정했다.

## 시험과 비교

이전 합성 시험 중 '후보가 여러 개면 무조건 의심' 및 '같은 계보는 계속 거절'은 사용자가 거부한 정책이다. 이 기대값을 그대로 새 구현의 합격 기준으로 강제하지 않는다. 대신 중복/근접 박스가 있어도 관측되는 통과를 잡는 사례, 일부 연결의 불확실성이 끝난 뒤 새 통과 회복, 출발 이력 보존, 실제 경로 없는 대상 교체·선 끝점 우회·정지·미래 근거·오래된 후보 소급 확인을 구분해 시험한다. 실측 전 독립 검토에서 정책 충돌을 확인한다.

실행 전 소스·경계·입력·평가 정의를 고정하고 전체45개를 재생한다. 원래 기준은39/52 확인·51/52 의심·이른 최초 확인8건이며, 실패한EXP-0050의0/52도 별도 보존한다. 확인 매칭 이득/손실·전체 누락·최초 확인 시각·미검수 알림·의심 알림 변화를 함께 보고한다. 안→밖 우선9영상과010 사용자 등반 약63초를 별도로 비교하고006 미확정·008 보류를 유지한다. 전체 정확도나 새 모델 추론 결과로 부르지 않는다.

기존 평가기를 재사용하며 새 출력 폴더만 만든다. 명백한 구현/실행 오류는 고쳐 새 revision과 출력으로 재검증하되, 결과를 높이기 위한 영상별 예외나 임계값 반복 탐색은 하지 않는다. 운영 채택 여부는 실제 결과와 회귀를 함께 보고 결정한다. EXP-0050의 등록 자료·원본·정답·검수DB·영수증은 수정하지 않는다.

첫 고정 실행 중 재현한 구현 누락: 원래 관측 조각이 정지한 중복 박스에 남아 있으면, 실제로 출발→문→반대편을 통과하는 분기 관측에 출발 이력이 전달되지 않는다. 독립 합성 시험은 같은 수치 기준·실제 박스·저장 이동점의 완전한 경로에서 양방향으로 이를 재현했다. '출발 조각이 사라져야만 다음 경로로 연결'하는 구현이 선언한 실제 경로 우선 정책을 충분히 구현하지 못한 경우다. 첫 `passage-first-001` 실행은 변경 없이 끝내고 보존하며, 이 재현 가능한 처리 누락만 수정한 새 소스를 고정해 별도 `passage-first-002`에서 다시 비교한다. 이는 첫 결과를 보고 시작한 수정임을 밝히며, 실행 전 전체 설계가 완전했다고 주장하지 않는다. 영상별 시간·경계·수치 조건은 변경하지 않는다.

구현은Sol high, 독립 검토는Astra high로 기존Orca Run을 재사용한다. 총괄이 통합·실제 재생·결과 등록·게시를 맡는다. 브라우저 전달은 기존 시간 초과를 보존하고 가능한 범위만 실제 검증한다.
