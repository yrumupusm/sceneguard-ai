# EXP-0074 전달 확인

2026-11-09. 라벨 보완·CPU 사전학습 기준선·B/C 실행 준비를 완료했다. 실제 재학습, GPU 작업 등록, 운영 모델 교체는 하지 않았다. 결과와 평가 범위는 [결과 보고서](EXP-0074-results.md), 실행 조건은 [프로토콜](EXP-0074-protocol.md)을 따른다.

## 웹과 검수

기존 서비스의 EXP-0074에 집계14개와 영상4개를 등록했다. 개발 기준선 영상3개는 원본·정답·실제 예측을 보여 주며, 나머지1개는 P01 원본56.000·58.333·61.667초의 비연속 세 프레임이다. 작은 대상·겹친 박스·누락에 대한 질문1개만 추가했고 기존 승인5좌표와 제거한 배경 위치를 다시 묻지 않았다. 답변은 대화로 직접 받아도 출처와 범위를 기록해 반영한다.

별도 편집기 `http://127.0.0.1:8772/`는 이 세 프레임만 제공한다. 좌표 초안과 미확정 상태를 유지하며 에이전트가 완료 답변을 대신 제출하지 않았다. 세 프레임 승인도 다른 미확정 프레임의 완료로 확대하지 않는다. 현재 추가 검수는 대기이며 학습·개발 정답에 편입하지 않았다.

로컬 headless Chromium에서 실험 API의 보고서·지표·검토 해시, 영상4개의 재생·seek·되감기, 15초 자동 갱신을 지난 재생 유지, 질문 영상 재생을 확인했다. 편집기에서는 세 원본 이미지 해시와 시각, 앞뒤 이동, 낮은 점수 초안 표시, 기존 실험으로 돌아가는 링크를 확인했다. 영상 이미지는 외부 도구에 업로드하지 않았다. 이 검사는 별도 로컬 브라우저이며 Orca 내장 브라우저 검증으로 표현하지 않는다.

첫 브라우저 검사는 편집기 이미지 로드 중 비활성화된 표시 체크박스를 너무 일찍 눌러 실패했다. 검증 스크립트만 이미지 준비까지 기다리도록 수정한 두 번째 검사가 통과했다. 제품 코드·원본·박스·답변은 변경하지 않았으며 첫 실패도 보존했다. 증거는 로컬 `runtime/model-comparison/exp0074/delivery/browser.json`과 `browser-v2.json`에 있다.

## 보존과 독립 검토

기존 등록74개는 동일하고 EXP-0074만 추가됐다. 기존 검수 요청37개/이력149행을 그대로 보존하고 새 질문으로38개/150행이 됐다. 기존 알림10행, 평가1행/이력1행, 사건 검수2행/이력5행도 행 해시가 같다. canonical GPU queue는145 jobs/145 attempts 그대로이며 새 작업·마이그레이션이 없다. 근거는 로컬 `delivery/preservation.json`이다.

학교45와 EXP-0064 시험 보호 자료는 이번 학습·개발 자료에 들어가지 않았다. 학습122프레임/333박스와 개발75프레임/56박스를 고정했다. 개발 A 결과56TP/0FP/0FN은 제한된 개발 진단이고 누락 회복 분모는0이다. 성능 개선·독립 일반화·B/C 학습 완료를 뜻하지 않는다.

기존 Orca Run의 데이터 담당 `task_41f1ae16bb43`, B/C 담당 `task_1c18aa91eb7f`, 독립 검토 `task_e8f02059df11`이 각 결과를 제출했다. 독립 검토의 서로 다른66개 시험이 통과했고 지적3개를 수정한 뒤 차단 지적0개로 준비 범위만 승인됐다. 실제 BN forward는 통계 고정 검증이고 optimizer step은0이다. 세 작업자는 종료·해제했으며 이 Run의 회수 가능한 미정리 작업자는0개다. 다른 기존 작업자는 변경하지 않았다.

## GitHub 게시 범위

공개 코드는 라벨 보완·평가·표시·B/C 실행 준비와 관련 시험, 집계·보고서·등록 자료다. 원본 영상·좌표·가중치·DB·로컬 검수 패키지는 게시하지 않는다. 무관한 로컬 변경도 포함하지 않는다. 게시 커밋과 원격 보고서·지표·검토·binding 네 파일의 실제 대조 결과는 로컬 `delivery/github.json`에 별도 저장한다. 웹 재생 증거와 GitHub 게시 증거는 서로 대체하지 않는다.

실제 결과 커밋 `f6412709d320c34299d34019c64dbc9399476f27`을 origin/main에 게시했고 원격 커밋과 위 네 파일의 SHA256 일치를 확인했다. 이 전달 확인을 덧붙이는 문서 변경은 등록된 결과·지표·검토·binding 바이트를 바꾸지 않는다. 재학습은 계속 미실행이며 새 검수 답변도 아직 없다.
