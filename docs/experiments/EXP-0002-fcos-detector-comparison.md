- 날짜/담당: 2026-10-27 / Codex 로컬 실행·시각 검토. 사용자 최종 의미 검수는 별도.

- 선택 근거: [ADR-0008](../decisions/ADR-0008-fcos-detector-comparison.md). 기존 [EXP-0001](EXP-0001-phase2a-cv-baseline.md)과 출력 보존.

- 가설: 큰 입력과 FPN을 쓰는 FCOS가 기존에 놓친 실제 사람을 더 잘 관측할 수 있다. **모델·가중치·입력 크기를 함께 바꾸므로 해상도만의 효과를 분리하는 실험이 아니다.**

### 비사람 오검출 의심 사례를 별도로 확인

031 왼쪽 흰 차량 뒤 상점 입구의 작은 영역은 FCOS에서 person score 약 0.504(32초), 0.506(42초), 0.509(44초)로 검출된다. 원본 30/32/42/44초를 crop 확대해 비교하면 같은 위치에 고정된 의자·흰 물체처럼 보이며 실제 보행자 신체로 확인되지 않는다. **비사람 배경 오검출 의심**으로 기록한다. 원본에서도 작고 정체가 불분명하므로 물체 종류나 비사람 여부의 최종 확정은 사용자 검수에 남긴다. 정지해 있다는 이유만으로 사람을 배제한 것은 아니다.

이 영역의 좌표로 사후 검색하면 178 bbox, 30.866667~45.966667초 사이에 간헐적으로 나타나고 score 범위 0.500025~0.536025다. 이는 **탐색적 영역 출력 집계**이며 178개의 확정 FP 정답이 아니다. 공식 라벨 수정·모델 점수를 정답으로 전환하지 않았다. 근거: 로컬 review031/native_background.jpg, suspected_background.jpg 및 pair_32/42/44 이미지. 이 영역은 감시 ROI 밖이므로 후보 0과 배경 오검출 여부는 별개다.

즉, 추가 검출 중에는 실제 사람 복원뿐 아니라 중복·오검출 의심이 섞여 있다. 검수 범위에서 발견하지 못한 오류가 없다고 주장하지 않는다.

## 검증·오류 해결·보존

- 인공 경계 회귀 11개 + 모델 spec/공식 FrozenBN 구조 검사 2개, 총 **13개 테스트 통과**.
- FCOS의 pretrained 구조는 FrozenBatchNorm2d인데 weights=None 생성 시 일반 BN이 된다. 53개 BN을 공식 FrozenBN 구조로 맞춘 뒤 strict 로드했다. 별도 backbone 다운로드나 학습 없이 공식 COCO 구조/32,269,600 parameters 확인.
- 네 실행의 모든 2,060 PTS가 기존 SSD와 정확히 일치. 독립 감사 manifest와의 최대 차이 약 3.34e-7초로 반올림 수준. 영상 SHA·config SHA·추적 코드 SHA 동일.
- 이전 출력 전체 파일+공식 JSON 45개+config 3개 총 117파일의 전후 SHA 동일. 영상 4개 해시도 독립 감사와 일치. EXP-0001/ADR-0007 원문 보존.
- 일반 git push는 로컬 HTTPS 인증 정보가 없어 실패. 연결된 GitHub API로 같은 tree의 커밋을 생성하고 expected parent 검증 후 main에 반영, fetch/rebase로 로컬과 원격 일치 확인. 인증정보 저장/우회 없음.

## 판단과 다음 작업

**FCOS는 실제 사람의 일부 누락을 줄이는 유망한 대안이지만 안정적인 넘기 검토 지원 모델로 확정할 근거는 부족하다.** 특히 030 넘기 자세, 031 가림, 006 원거리 시점별 누락과 007 중복·연결 모호성이 남았다. 모델/입력/백본/점수 등이 동시에 변한 결과를 해상도만의 효과로 주장하지 않는다.

다음은 새 모델 설치보다 다음 검수·진단을 우선한다.

1. 위 35개 paired frame과 031 고정 물체 crop을 사용자와 검수해 실제 사람/중복/비사람/판정 유보를 별도 기록한다. 모델 bbox를 정답으로 자동 채택하지 않는다.
2. 030/031의 가림·변형 자세 누락과 007의 모호 연결을 구분한다. 검출 정답·사람별 관측 가능성부터 소량 확정하고, 범위 변경 없이 현재 실패 사례를 검토한다.
3. 006 감시 범위/음성 구간, 001/007/030 첫 등장≠넘기 시작, 031 접촉≠공식 시작·미완료 종료, 카메라 그룹/평가 manifest/G1E를 확정한다. 같은 카메라 영상은 분할을 넘지 않게 한다.
4. 속도 우위를 판단해야 한다면 CPU 렌더링 없는 같은 부하에서 모델 순서를 교차해 반복 측정한다. 현재 기록은 단일 실행 비용이다.
5. 별도 실험을 설계한다면 같은 FCOS에서 입력 크기만 바꾸는 조건으로 해상도 효과를 분리할 수 있다. 이번에는 실행하지 않았다. 재학습·고급 tracker·VLM·UI는 추가하지 않았다.
