# EXP-0067 — 추가 학습용 사람 박스 보완 초안 생성

2026-11-08. EXP-0066에서 사용자가 누락/경계 문제를 확인한 학습 라벨1·3·5번의 **원본75프레임에 실제 YOLO26x 추론을 완료했다.** 원래 주석과 분리한 박스 초안, 원본/기존 주석/새 초안의 비교 영상3개, 프레임별 박스 수정·이력 저장 화면을 만들었다. **정답 보완 완료나 검출 모델 추가 학습 완료는 아니다.** 새 초안의 사람 대응은 사용자 확인 전이다.

## 검수와 보완 방법

기존 웹의 **EXP-0067 실험 → 영상 검수로 이동**에서 세 비교 영상을 본다. 왼쪽은 원본, 가운데 청록색은 원래 라벨, 오른쪽 주황색은 새 모델 초안이다. 번호는 각 프레임의 박스 번호이며 사람 추적 ID가 아니다. 원본 시각을 표시하고 낮은 점수 초안은 기본 영상에서 숨긴다.

새 질문은 기존의 “사람이 빠져 있는가”를 반복하지 않는다. **새 영상25프레임 전체의 주황 박스가 실제 사람 위치에 맞고, 중복·사람 아닌 박스·빠진 사람이 없는지** 확인한다. 이 명시적인 확인을 받은 경우에도 표시된182개 박스 중 해당 구간의 정확한 프레임/박스/영상 해시·답변 버전에만 적용할 수 있다. 숨긴0.5미만35개 초안이나 원래 라벨을 자동으로 합쳐 정답으로 만들지 않는다.

오류가 있으면 시각·위치를 메모하면 된다. 직접 고칠 때는 로컬 `http://127.0.0.1:8769/`의 **사람 박스 보완** 화면에서 기존/자동 초안을 채택하거나 박스를 새로 그리기·좌표 수정·삭제한 뒤 현재 프레임을 저장한다. 가려서 보이지 않는 사람의 위치를 추측하지 않으며, 판단이 어려운 프레임은 불확실로 남긴다. 해당 화면은 검수자와 프레임별 완료/누락/불확실 상태를 별도 DB에 저장한다. 저장이 학습을 자동 실행하지 않는다.

이전 답변 다섯 건과5번 채팅 관찰을 재사용했다. 3번의 약60초 주석 종료와 중복 actor0,5번 뒤따르는 사람의 이후 월담 여부 미확정은 그대로 보존한다. 새 사람 박스 확인이 행동 종류/시작·종료나 모든 원본의 프레임 번호 해석을 인증하는 것은 아니다.

## 확인한 기능과 남은 작업

소스/입력/큐 계약10개, 실행자 거절·자원 대기·재시도 금지3개, 편집 저장11개, 이전 검수 범위9개 시험을 통과했다. 별도 합성 자료의 실제 Chromium에서 채택/저장/이동·수정 시 완료 해제·저장/새로읽기 중 경합 방지·실패 후 수정 보존·이전 버전 저장 거절을 확인했다. 실제 사용자 정답을 대신 저장하지 않았다.

초기 시험은 잘못 선택한 system Python의 PIL/numpy 부재와 임시 큐 초기화 누락으로 실패했고 올바른 기존 환경/fixture로 수정했다. 새 화면 담당 시작은 업데이트 안내에서 멈춰 작업 전 해제했으며 화면은 총괄이 구현하고 독립 검토했다. 브라우저 라이브러리는 작업 폴더에만 받아 풀었고 전역 설치나 기존 모델 환경 변경은 없다. 실제 전달·재생 확인은 별도 전달 기록에 남긴다.

남은 것은 새 초안의 실제 사람 대응 확인과 오류 좌표 보완이다. 확보한 소량 자료만으로 전체797라벨의 완전성, 다른 장소 일반화나 검증 정상의 앉기 편중 해결을 주장하지 않는다. 검수된 프레임만 다음 학습 후보에 반영하고, 정상 보행·대기·접근 후 돌아가기 검증 자료도 보완해야 한다.

YOLO26m/l/x·EVAD-B/L·STMixer의 **실제 추가 학습과 같은 학교 영상의 전후 비교는 아직 미실행**이다. 기존 사전학습 출력, EXP-0062 AFTER, EXP-0064 선택 가중치/0.5를 유지한다. 사람 정밀도·재현율과 학교 성능 개선은 미측정이며 박스 행 증가로 대신하지 않는다.
