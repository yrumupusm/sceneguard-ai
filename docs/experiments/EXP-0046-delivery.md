## 실패 기록

미리보기 준비 때 기본 python에 PIL이 없어 메타데이터 조회가 실패했다. 기존 CV 환경의 수정 스크립트는 첫 실행에 저장소 import 경로가 없어 쓰기 전에 실패했으며 PYTHONPATH를 추가한 한 번의 수정 실행으로 완료했다. 실제 판정 실행이나 새 환경 설치를 재시도한 것이 아니다.

웹 합성 fixture의 최초 잘못된 이벤트 ID는 유효한 해시 형식으로 한 번 수정해 통과했다. 이 실패는 실제 사건/판정 결과를 바꾼 것이 아니다. 원본 오류와 수정 영수증은 runtime에 보존한다.

사건 보기 등록 보조 스크립트도 최초 import 경로가 없어 변경 전에 실패했다. PYTHONPATH를 지정한 한 번의 수정 실행으로 완료했고 기존 39등록을 보존했다. 완료 등록 자체와 실제 CPU/미디어 작업은 최초 실행에 성공했다.

웹 서비스의 첫 detached 시작은 종료돼 동일 서비스의 지속 세션 방식으로 한 번 복구했다. 브라우저 CLI의 지원하지 않는 timeout 옵션은 실행 전에 거부돼 제거했고, 실제 첫 브라우저 검사는 지연 로딩 이미지 대기에서 멈춰 eager load를 적용한 한 번의 재검증으로 통과했다. 030의 추가 상태 경계 검사는 video mount 전 접근을 한 번 수정해 통과했다. JavaScript 첫 요청의 잘못된 `/app.js`는404였고 실제 `/assets/app.js`로 한 번 바로잡아 게시 해시를 확인했다. 판정·모델·구역 변경이나 CPU 실험 재실행으로 해결한 것이 아니다.
