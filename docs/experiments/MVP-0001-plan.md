# MVP-0001 — 원본 CCTV 전체 처리의 제한된 통합 계획

2026-10-28, 실행 전 계획. 기존 BATCH-0001의 종료와 모든 EXP1~10 결과는 보존한다. 새 범위는 사건 시각을 사람이 지정하지 않은 원본 입력에서 행동 후보와 근거를 남기는 로컬 CLI다. 법적 무단침입·권한 판단, 실시간 관제 성공, 자동 채택을 주장하지 않는다. 웹 기능 개발은 하지 않는다.

## 재사용·실패·비교 한도

| 구성 | 재사용 / 비교 역할 | 현재 실패와 새 실행 범위 |
|---|---|---|
| A: FCOS + ByteTrack C + 기존 경계 | EXP5 캐시·ID·후보·설정 그대로 보존 | 부분/긴 박스 변화가 하단점 통과를 만들고 누락·중복이 남음. 기존 네 구간2,060프레임 결과를 재사용하며 새 검출/추적 실행 없음. 행동 분류기와 같은 정답으로 평가하지 않음 |
| B: Qwen 전체 화면 | EXP8 기준 및 EXP10 큰 입력 결과, 기존 가중치/환경/질문/파싱 재사용 | 작은 사람의 넘기 누락·근거 없는 완료. 기존6클립 결과를 재사용. 전체 영상의 동일 시간창 기준 결과만 새로 생성 가능; 새 설정 탐색 아님. 큰 입력 대조를 이미 사용한 개선으로 세고 추가 개선 없음 |
| C: 같은 Qwen + 카메라별 고정 감시 영역 | 기존 PTS0 정적 배경에서 정한 CV 감시 ROI를 영상 입력 영역으로 사용 | 사람·경계 관계가 더 크게 보이면 설명이 나아지는지 한 대조. 사람 위치/정답 시각별 crop 없음. 질문·프레임·생성 조건은 B와 같음. 기준 실패 후 총괄이 전역 개선 최대1개만 별도 동결 가능; 자동 sweep 없음 |

후보 구성은 이3개로 닫는다. 새 가중치0개를 계획하며 최대2 허용량을 채울 의무는 없다. Smol은 이전 근거 모순/선택지 반복에 직접적인 개선 기전이 없어 이번 후보에서 제외한다. Qwen이 필수라는 제품 결정이 아니라 이미 확보한 모델로 입력 가설을 가장 작게 비교하는 선택이다. 후보가 모두 부족하면 기능 구현과 성능 미달을 함께 보고한다.

## 개발·검증 자료와 입력 분리

- 개발 비교는 EXP7/8과 같은6클립. 기존 사용자 관찰, Codex 초안, 미확정을 별도 manifest에 기록한다. C3의006/007은 같은 그룹이고006 후기 보행은 기존 감시 ROI 밖이다. 그 구간의 무경보를 영역 안 정상 구분 성공으로 세지 않는다.
- 원본 전체 실행은 **E01_007, E01_030, E01_013의3개**를 예정한다. 007/030은 개발,013은 이번 설정 선택에 쓰지 않는 C4 진단 검증용이다. 013/039/045는 같은 그룹으로 함께 예약하고 이번에는013만 실행한다. 과거 감사에서013 장면/공식 구간을 본 이력이 있어 완전 blind test나 독립 장소 검증이 아니다. 카메라 그룹의 독립 장소 여부도 미확정이다.
- C3/C6/C7의 영역은 기존 PTS0 배경 설정을 그대로 가져온다. C1/미설정 C4는 **전체 화면 fallback**임을 명시한다. 사람 위치로 새 영역을 짐작하지 않는다. C4에서는 영역 확대의 일반화 이점을 검증했다고 주장할 수 없다. 기존 배경 설정이 없는 카메라의 실제 감시 영역 확정은 후속 적용 제약으로 남긴다.
- 추론용 sources/cameras에는 파일 ID·경로·해시·고정 ROI만 허용한다. 평가 manifest의 사건 시각·관찰·공식 JSON·캡션·기존 답변은 analyzer로 전달하지 않는다. 원본 비식별화·native PTS를 유지하고 픽셀은 로컬에만 둔다.

## 하나의 실행 흐름

고정 초기 설정: 전체 소스 PTS 순서로 디코딩, **5초 시간창 / 2.5초 간격 / 약2fps 표본**, batch1. 실제 프레임/PTS/resize/token 수를 기록한다. EOF 잔여 창은 실제 확보 프레임만 쓰고, 부족하면 근거 부족으로 남긴다. 전처리기의 마지막 프레임 반복이 필요하면 그 수와 실제 마지막 PTS를 따로 기록하며 미래 관측으로 만들지 않는다.

CV 후보 유무와 관계없이 시간창을 분석한다. 따라서 CV가 누락한 사건을 선제 배제하지 않는다. 계산 비용과 고정 표본 사이 짧은 동작 누락 가능성을 함께 보고한다. 익명 window ID와 동일 중립 질문만 전달한다. 출력은 passage_or_waiting/contact/climbing_attempt_or_in_progress/stepping_over_boundary/indeterminate의 복수 행동 및 근거·완료 관찰·불확실성이다. 완료 문장만으로 행동 후보를 생성하지 않는다.

모든 창 원문/파싱/측정 결과를 보존한다. 넘기/줄 넘기는 행동 후보, 접촉은 접촉 검토, 판단 불가·파싱 실패는 별도 검토 상태다. 미관측과 판단 불가를 정상으로 바꾸지 않는다. 같은 카메라의 시간상 겹치는 같은 행동 후보를 하나의 검토 묶음으로 정리하되 원래 창들을 삭제하지 않는다. 최종 규칙은 구현 전에 코드 계약에 고정하고 사건별 예외를 금지한다. 각 후보의 원본 구간과 앞뒤 맥락을 로컬 MP4로 저장한다.

사건 추정 범위(시간창), 마지막 입력 PTS, 후보를 계산할 수 있게 된 원본 시각, 최초 결과 저장의 실제 UTC/경과시간, 후속 병합·근거 저장 시각을 각각 기록한다. 뒤 프레임/EOF를 사용한 결과를 과거 시각에 감지했다고 소급하지 않는다. 파일 처리 wall clock과 실시간 재생 기준 대기량을 혼합하지 않는다.

## 역할과 단계

1. Sol high 방법 담당: 공식 지원/이용 조건 재확인, 고정 ROI adapter·기존 큐 최소 명령 등록·CPU 회귀, 개발 비교/실측/개선 제안. 소유: `mvp/method.py`, `mvp/compare.py`, `orchestration/mvp_command.py`, queue 등록 변경, 해당 테스트/ADR/EXP11 보고서. GPU는 총괄의 code/data/자원 검토 후 같은 큐에서만 실행.
2. Sol high 통합 담당: 모델과 분리된 시간창·결과/중복 상태·근거 저장·CLI, 합성 end-to-end 및 EOF/PTS/지연 테스트. 소유: `mvp/windows.py`, `mvp/events.py`, `mvp/evidence.py`, `mvp/pipeline.py`, `mvp/cli.py`, 해당 테스트/실행 문서. adapter는 코디네이터가 확정한 작은 callable 계약으로 연결한다. 웹·기존 CV 수정 금지.
3. Astra high 독립 평가: 개발/검증 구분과 누수/정답 수준 manifest, 코드·실측·실패 검토. 소유: 평가 manifest/문서와 독립 검토만. 새로운 추론·픽셀 클라우드 전송·공식 라벨 수정 금지.
4. 총괄: 계약·camera 설정·배정·비교/개선 선택·통합·전체3영상 실행 승인·공개 보고서/등록/게시. 기존 Run/단일 GPU 큐, active worker 최대3. GPU 자원이 다른 작업에 점유됐으면 그 프로세스를 임의 종료하거나 큐를 우회하지 않는다.

## 완료와 종료 기준

- **자동 테스트:** 입력/공식 정답 분리, 시간창/원본 PTS/EOF, 미래 프레임 미사용, 접촉/판단 불가 상태, 중복 보존, 지연 필드, 근거 경로·큐 소유권·회귀를 검사한다. 통과를 행동 성능으로 간주하지 않는다.
- **기능 통합:** 사건 시각 인수 없이 원본3개 EOF까지 처리, 창별 출력·후보 목록·근거 파일·실측·재현 CLI·예제 camera config 생성. 실행 실패면 부분 결과와 실제 중단 지점을 남긴다.
- **행동 성능:** 동일 개발 관찰에서 일반 접근을 넘기로 부풀리지 않으면서 명확한 몸 상승을 더 잘 구분하는 근거가 있는지, 접촉/가림 유보와 완료 과장을 평가한다. 개선이 없거나 판단 불가로만 회피하면 미충족. 정밀 GT가 없어 최종 accuracy/F1/오탐률은 산출하지 않는다. 전체 영상의 미검수 구간은 미확정이며 라벨 밖 음성 가정 금지.
- **전달:** 새 EXP별 담당 배정→보고서/실측→독립/총괄 검토→기존 complete 등록→GitHub 및 실제 서비스 파일/화면 확인. README/최종 요약에 기능 완료/미완료와 성능 장애를 분리한다.
- **예산:** 구성당 기준1+개선 최대1, 실제 job 오류 retry최대1. CPU 개발 테스트와 모델 실행 재시도를 구분한다. 정한 비교/전체3영상 실행이 끝나거나 제한/자원 차단이 해소되지 않으면 종합 결과를 보고하고 멈춘다. 자동 후보 확장·재학습·다음 배치 없음.
