# EXP-0063 명시적 정상행위 음성 정책 v2

2026-11-06, 실제 학습·학습 프레임 추출·모델 결과 조회 전 결정이다. 사용자의 정상행위 데이터 포함 승인은 보행/대기 폴더에만 한정되지 않았다. 첫 구현의 moving/stand-only 제한 때문에 고정v3 검증 분할의 정상40원본(선언 sit_down_bench183, sit_down_floor184사건)이 모두 제외된 사실을 확인했다. 이 상태에서는 검증 양쪽 클래스 조건을 충족하지 않는다.

v2는 공식 JSON의 **wall_over=넘기**, **moving/stand/sit_down_bench/sit_down_floor=넘기 아님**으로 정의한다. 파일명·모델 예측·무주석 구간으로 정답을 만들지 않는다. smoking·모호한 종류는 이번 첫 조건에서 제외한다. 앉기 구간도 명시된 해당 actor-event와 실제 박스/시간 내부만 사용하며 영상 전체 음성으로 확장하지 않는다.

같은 actor의 다른 행동/다른 object_id 중첩, 다른 사람의 넘기 사건과 음성 구간의 중첩, 0/1해석에 필요한 박스 누락·중복·모순, 짧은 공통 내부 구간을 거절하는 조건은 유지한다. 최종v3 원본/촬영그룹 분할·기존45제외·사용자 시나리오 제외를 변경하지 않는다. v1 계획과 오류/제외 집계는 보존하고 v2는 새 출력 경로에 쓴다.

검수8답변의 의미는 [별도 반영 기록](EXP-0063-user-review-followup.md) 그대로다. 이 문서는 그 답변을 앉기나 전체 데이터의 인간 정답으로 확대하지 않는다. 앉기의 정답 출처는 공식 사람별 annotation이고 검수는 표본 정렬 관찰이다.

검증 음성이 앉기 위주이므로 validation CE로 선택한 checkpoint가 보행·대기 구분에 최적이라는 주장을 하지 않는다. 첫 실험은 넘기와 명시적 정상행위의 공식 라벨 참조 분류다. 학습/검증/시험 모두 음성 세부 행동 종류별 개수와 제외 이유를 기록하고, 시험의 보행·대기·앉기별 오판을 구분한다. 원래 목표인 CCTV 보행/접근/대기 대비 일반화나 정밀 침입 판단의 달성 여부는 별도 검증이 필요하다. 모호한 의미 정답의 지표를 측정 완료로 표시하지 않는다.

독립 검토는 이 변경이 사용자 승인 정상 자료 안의 명시적 라벨 추가이며, 고정분할 보존·범위 공개 조건에서 첫 참조 실험을 진행할 수 있다고 판단했다. 실제 전처리·GPU smoke·학습 GO는 최종 코드와 입력 해시에 대한 별도 검토를 따른다.
