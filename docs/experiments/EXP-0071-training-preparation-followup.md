# EXP-0071 후속 — 월담·정상행위 준비와 사용자 검수 반영

2026-11-09. 사용자의 시작 요청에 따라 보유한 월담·정상행위 자료로 준비를 진행했다. **불법행위1·3·4 ZIP의 복구는 현재 작업의 선행 조건이 아니다.** 이전 획득 보고서의 미발견 파일 목록은 조사 이력으로 보존하지만 필수 다운로드 목록으로 사용하지 않는다.

## 실제 준비 결과

월담1,188쌍과 정상행위432쌍, 총1,620쌍의 현재 원천 파일 존재 또는 ZIP member 크기/CRC와 라벨 바이트 해시를 다시 대조했다. 라벨 해시 변경은0이다. 전체 영상의 전수 디코딩이나 사람 정답 완성 검사는 아니다.

EXP70/71의 제외·보호·내용 유사성 보류와 촬영 예약을 함께 적용했다. 학습 원본을 개발 예약으로 옮기지 않고 충돌 자료를 보류했다.

| 상태 | 월담 원본 | 정상행위 원본 | 의미 |
|---|---:|---:|---|
| 학습 검수 후보 | 350 | 173 | 알려진 분할 예약 충돌이 없는 후보이며 학습 release 아님 |
| 개발 검수 후보 | 18 | 0 | 월담 한 예약 묶음. 정상 보행·대기 개발 자료의 공백이 남음 |
| 제외·보호·보류 | 820 | 259 | 사용자 제외, 보호 시험, 기존 격리/유사성 보류, 다른 분할 예약 포함 |

학습 후보는10예약, 개발 후보는1예약이다. 정상행위173개는 모두 하나의 보수적 예약에 속하므로173개의 독립 사건으로 세지 않는다. 촬영 독립성이 인증된 수는 아직 null이다. 학교45와 EXP64 시험296/연관327, 기존 제외 시나리오와75프레임 검수는 보존했다. 새 독립 시험 월담을 확보했다고 보고하지 않는다.

`scripts/prepare_wall_normal_training_review.py`가 현재 목록·분할 예약·검수 상태를 연결한다. 로컬 `outputs/model-comparison/exp0071/wall-normal-preparation-v1/`은 답변 수신 전, `wall-normal-preparation-v2/`는 답변 반영 후 스냅샷이다. 이전 버전은 덮어쓰지 않았다. 각 원본의 실제 경로·라벨 해시·보류 이유는 로컬에만 남긴다.

## 받은 다섯 검수의 적용

웹 답변 다섯 건의 answer_version=1을 실제로 읽고 정확한 버전으로 확인했다. 이전 질문과 연결 영상·보고서·지표는 수정하지 않는다.

| 검수 | 사용자의 관찰 | 적용 |
|---|---|---|
| R01 작은 보행인 | 표시된 모든 사람 박스가 맞음 | 표시 박스의 영상 수준 확인을 재사용. 후보가0개인 원본24.667초 한 프레임은 별도 정밀 확인 대상으로 남김 |
| R02 월담자·동행자 | 사람은 두 명인데 겹침·울타리 가림 때문에 박스가 합쳐지거나 중복됨 | 24프레임을 그대로 정답으로 사용하지 않고 박스 보완 대상으로 분리 |
| R03 이동하는 사람 | 표시된 모든 사람 박스가 맞음 | 사람 박스 관찰을 보존. 원래 다른 행동 계열의 개발 자료이므로 이번 월담·정상행위 학습 원본 목록에는 추가하지 않음 |
| R04 서 있는 사람 | 표시된 모든 사람 박스가 맞음 | 해당19.333–27초의 표시 박스 관찰을 재사용. 이미 검수된53–61초는 다시 묻지 않음 |
| R05 빈 배경 | 전 구간에 보이는 사람이 없음 | 해당 원본0–8초의25프레임에 한정한 사람 없음 관찰로 반영. 다른 시간·원본으로 확대하지 않음 |

좌표 보완 대상으로 분리한25프레임을 제외한97프레임에는 기존 관찰을 재사용한다. 이 수는 새 정밀 좌표 정답97프레임을 내보냈다는 뜻이 아니다. 질문 자체가 정밀 좌표 수정·학습 release와 구분되어 있으므로 단순 답변 수신으로 데이터셋을 자동 확정하지 않는다. 모델 점수0.05는 제안 보존용이며 기존 평가 임계값을 바꾸지 않는다.

R01의24.667초에는 모델 제안이0개인데 원래 actor 참고 annotation은 있다. actor annotation의 시간/박스가 맞다는 보장은 없으므로 누락이라고 단정하지도, 일반적인 구간 승인만으로 빈 배경이라고 확정하지도 않는다. 나머지 R01 전체를 다시 질문하지 않고 이 한 프레임만 확인한다.

R02의 두 사람이라는 관찰은 구간의 사람 수에 관한 것이다. 모든 프레임에서 강제로 두 박스를 선택하는 규칙으로 만들지 않는다. 합쳐진 박스·중복 박스를 점수순으로 두 개 남겨 정답 처리하지 않으며, 완전히 가려진 사람의 위치를 추측하지 않는다. 원래 actor 라벨 역시 구간마다 한 명만 있거나 비어 있어 전체 사람 정답을 대신할 수 없다.

## 필요한 좌표 보완 자료

기존 사람 박스 편집기를 재사용해 **R02 24프레임＋R01 24.667초 한 프레임**의 별도 패키지를 만들었다. 원본 PTS와 RGB 해시가 EXP71 초안과 같은25개의 원본 PNG, 모델 제안과 원래 actor 참고를 연결했다. 저장할 박스는 자동 채택하지 않는다. 기존75프레임 편집기·DB를 덮어쓰지 않고 새 로컬 포트8770과 별도 DB를 사용한다.

편집 화면은 `http://127.0.0.1:8770/`이다. **라벨2**가 R02, **라벨1**이 R01의 한 프레임이다. 필요한 경우 낮은 점수 초안 표시를 켜고, 쓸 박스를 채택하거나 드래그해 추가·좌표 수정·삭제한 뒤 프레임별로 저장한다. 가림 때문에 판단이 어려우면 그 상태를 저장하며 확정 박스를 강요하지 않는다. 기존 영상 검수 화면에서 같은 의미 질문에 다시 답할 필요는 없다.

공통 편집기의 돌아가기 링크만 패키지의 유효한 실험 번호에 맞추도록 보완했다. 기존 EXP67 패키지는 기존 주소를 유지한다. 기존 저장/수정이력/빈 프레임 명시 확인 보호의11개 시험을 통과했다. 실제 새 편집기의 읽기·프레임 이동 검증과 저장 DB 상태는 로컬 실행 증거로 남긴다. 실제 사용자 좌표 입력 대신 테스트 정답을 저장하지 않는다.

실제 로컬 Chromium에서25프레임 패키지·1920×1080 원본 표시·두 사례 선택·처음/끝/이전 프레임 이동·낮은 점수 후보 표시·EXP71 돌아가기 링크를 확인했다. 이미지25개는 제공된 바이트 해시가 원본 PNG와 같으며, 검사 종료 시 저장된 좌표 revision은0개다. 기존8769 편집기의75프레임과 EXP67 링크도 유지된다. 원본 픽셀을 클라우드 도구로 보내지 않았다. 근거는 `runtime/model-comparison/exp0071/review-application-v1/editor-browser.json`이다.

## 다음 비교의 범위

먼저 월담 인물의 놓침을 줄이면서 원래 보행인 검출을 유지하는 데이터 구성을 준비한다. 정상행위는 양을 채우기 위해 모두 넣지 않고 작은 사람·가림·보행·서 있기 대표 조건을 보존용으로 선택한다. 개발 자료는 기존 앉기 사례에만 의존하지 않도록 보강해야 한다.

첫 실행 우선순위는 사전학습 원본 A와, 확정 자료로 BN 누적통계를 고정하여 추가학습하는 C의 비교다. 원래 A–D의 B(전체 학습·BN 갱신), D(마지막 분류/박스 예측층만 학습·나머지/BN 고정) 정의는 보존하며 이번에 임의로 바꾸지 않았다. 정상행위 소량 혼합의 효용을 따로 비교할 때는 같은 초기값·학습 step·BN 처리·평가 자료를 고정해 데이터 구성만 바꾼다. 시험 자료로 조건이나 epoch를 고르지 않는다.

단순히 이번72프레임을 기존75프레임에 더하는 것만으로 여러 사건의 학습/개발/시험 문제가 해결되지 않는다. 다음 월담 보강은 별도 학습 예약인 P26/P28의 주·야간 난간 가림을 우선 검토하되 같은 촬영 묶음은 한 표본 집단으로 취급한다. 개발 정상행위의 촬영 연결 보류도 해소해야 한다.

현재 실제 실행은 자료 목록 재대조, 답변 반영,25프레임 좌표 보완 패키지 생성까지다. 새 모델 추론·GPU·재학습은0이며 모델 성능은 미측정이다. 학습 착수 전에 좌표 보완과 촬영/분할 확인이 남는다.
