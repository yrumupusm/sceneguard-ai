# EXP-0013 — 로컬 MVP의 전체 영상 비교 실행

2026-10-28. **실행·기능 통합은 완료, 행동 성능 검증과 채택은 보류.** 이 결과는 기존 EXP-0011/0012의 GPU 차단 결과를 덮어쓰지 않는 새 비교 실험이다. 하나의 실제 Orca Task/Dispatch가 아래 세 순차 큐 작업을 실행했다. 표의 EXP-0013/14/15 문자열은 worker의 큐 작업 키 구분이며, 공개 결과·담당 연결은 이 통합 비교인 **EXP-0013 한 건**이다.

## 비교 조건과 담당

실험 모델은 이미 설치된 로컬 `Qwen3-VL-2B-Instruct`, 기존 pinned 가중치와 `.venv-vlm`이다. 입력·질문·생성 조건을 바꾸지 않았고 배치 1, `cuda:0`, bfloat16, SDPA, greedy, max 384 tokens를 사용했다. 전체화면 Qwen과 고정 카메라 영역 Qwen을 같은 5초 창·2.5초 stride의 원본 PTS 순서로 실행했다. 사람·사건 위치에 따른 crop, 공식 라벨·정답·기존 답변 제공, CV 후보 게이트는 없었다. 현 결과 웹, 실행 등록 및 큐는 기존 것만 재사용했다.

C4/E01_013은 새 ROI 성능 표본이 아니다. 전체 조건의 낮은 wall time은 fallback 재사용이 포함돼 직접 속도 향상으로 비교할 수 없다. 저장된 토큰은 모델 출력 길이이며 검출 인원·사건 수가 아니다.

각 작업은 담당자 실행 설정상 5초 창, 2.5초 간격, 원본 PTS 기준 명목 2fps였다. 공개 metrics에는 전체 구성의 processor 관측 프레임 범위 3–10만 기록되어 있고, 전체화면/ROI별 범위는 분리돼 있지 않다. ROI 신규 생성 4–10은 담당자 기록이지만 공개 자료로 독립 재현되지 않았다. 상세 입력 시각·resize·visual token 정보도 포함되지 않아 전처리기의 실제 프레임별 샘플링·변형은 이 자료로 확인할 수 없다. 모든 창에 정확히 10프레임이 들어갔다고 표현하지 않는다. 원본 030의 EOF 인접 창은 담당자 보고상 실제 관측 1개로 모델 호출을 건너뛰고 `insufficient_data`로 남겼다.

## 검증과 판단

- **자동 테스트:** 담당자 실행 기록상 기존 MVP suite 47개 통과(6.494초), 기존 Orca·등록·viewer suite 75개 통과, 조건부 skip 1개(8.551초). 독립 검토자는 테스트를 재실행하지 않았다. 테스트는 합성/계약 검증이며 행동 정답이 아니다.
- **기능 통합:** 담당자 실행 기록과 공개 요약상 기존 canonical GPU 큐에서 3개 job이 순차적으로 attempt 1 성공했다. 세 연속 원본의 EOF·기능 상태, 창 상태와 로컬 근거 MP4 생성도 담당자 보고다. 독립 검토는 raw 실행 로그·미디어를 열지 않았으므로 이 세부를 독립 재현하지 않았다. 새 CV 미사용, 시간 단위 실행에서는 CV 후보 게이트도 사용하지 않았다.
- **행동 판단 성능:** 미확정. 화면 근거와 출력 의미를 사람 검수하기 전에는 통행/접촉/넘기 정밀도, 완료 정확도 또는 감지 성공률을 계산하지 않는다. 독립 장소 검증도 아니다. 최종 accuracy/F1/FPR/시간당 오탐률은 산출하지 않았다.
- **채택:** 기본 자동 판정이나 법적 무단침입 판단으로 채택하지 않는다. 본 MVP는 검토용 event candidate와 근거를 생성하는 기능이 동작했으나, 신뢰할 행동 분별과 실제 운영 적합성이 입증되지 않았다.

### 다음 결정과 로컬 근거

사용자 확인은 두 쟁점에 모은다: (1) 007의 52.5–57.5초 후보가 실제 경계 넘기 행동을 설명하는지 여부. 이 구간의 사람 행동은 완전 검수되지 않았으며 앞선 Codex 접근·대기 설명만으로 정상 정답이라 할 수 없다. 사용자가 확인한 것은 56.633→56.667초 박스 범위 변화와 영상에서 이에 대응하는 순간 수직 이동이 보이지 않았다는 점이다. (2) 030의 약 90초 넘기 장면 및 EOF 부근의 불완전 후보. 각 설정의 비교 영상은 결과 페이지와 로컬 `outputs/mvp0001/EXP-0012/<attempt>/.../evidence/`에 있다. E01_013은 prior exposure와 카메라 그룹 한계를 그대로 유지한다. 사람 검수 이후에도 성능 기준은 별도 결정하며, 독립 카메라/세션 표본 없이 일반화를 주장하지 않는다.

세 job의 정확한 queue ID·attempt·GPU sample·source hash와 재현성 검사는 Git 제외 `runtime/mvp-0001/executions/ctx_0da6354a652f/`에 보존한다. 로컬 결과 파일·이미지·원본 영상·가중치·raw 응답·runtime DB·로그는 Git에 올리지 않았다. 모델 답변을 웹 UI에 표시하는 기능은 추가하지 않았다.

### 독립 검토 범위와 측정 포인터

독립 검토는 보고서, 공개 metrics, 세 개의 비식별 수치 요약만 열어 숫자·해시를 대조했다. 보고서의 런타임/환경 확인, 테스트 통과, EOF, 근거 영상 생성, 개별 장면의 세부 시각·상태는 담당자와 로컬 실행 기록에서 옮긴 **담당자 보고**이며 이 독립 검토에서 원시 결과나 영상을 재확인하지 않았다. 39개 수치와 세 요약 파일 해시는 맞았지만, 이 결과는 수치 요약의 무결성 확인이지 모델 입력·가중치·큐/시스템 전 구간의 독립 재현 인증이 아니다.

Metrics의 마지막 네 장면별 수치는 `source_pointer`에서 `sources` 배열 안의 고유 `source_id` 행을 먼저 찾은 뒤 남은 키를 읽는 로컬 선택 규칙을 사용한다. 이것은 표준 JSON Pointer 배열 인덱스 표기가 아니므로 소비자는 해당 선택을 명시해야 한다. 독립 검토에서 일반 객체 키 순회로 해결된 값은 35/39, 고유 source ID 선택을 적용한 값은 39/39였다.
