# EXP-0006 — 박스 범위 일관성에 따른 후보 검토

2026-10-28 / Codex 구현·개발 비교. 기반 HEAD `c55e6cfc5759c8a575466c52fca540ac320710ab`. [ADR-0011 실행 전 고정 조건](../decisions/ADR-0011-candidate-box-consistency.md), [EXP-0005](EXP-0005-bytetrack-cache-comparison.md), [두 구간 검수 초안](EXP-0005-candidate-focus-review.md).

**결과: 검사 통과 0, 판단 유보 2, 근거 부족 2. 기본 적용 보류.** 원래 네 후보는 삭제하거나 시각을 바꾸지 않았다. 박스 불안정을 드러내는 검토 정보는 얻었지만 실제 넘기 장면의 후보까지 유보한다. 알림 앞에 두면 이번 표본에서 모든 후보의 즉시 전달을 막고 .2초를 기다리게 된다. 이를 오탐 해결/침입 성능 향상이라고 보고하지 않는다.

## 관찰의 출처와 범위

이번 사용자 메시지는 **대화에서 ChatGPT가 확인한 007 관련 프레임**의 관찰을 전달했다. 56.633→56.667초 박스 하단 급변에 대응하는 사람의 순간 수직 이동이 보이지 않았다는 국소 관찰이다. 사용자가 전 구간 ID·발·정밀 사건 정답을 확정했다는 뜻으로 기록하지 않는다. 030은 실제 넘기와 박스 변화가 함께 보인다는 Codex 초안을 유지하며 두 후보를 성공 2건으로 세지 않는다.

네 영상 EXP-0005 C의 저장된 `frames.jsonl`(030 480 / 006 500 / 007 600 / 031 480, 총 2,060프레임), `events.jsonl`만 비교 입력으로 사용했다. confirmed 실제 관측 bbox/ID/점수/원본 PTS를 그대로 읽었다. 검출·추적 실험 재실행, 가중치 다운로드, 경계 후보 재생성 없음. 모델/점수/NMS/ByteTrack/ROI/선/기존 통과 규칙 및 공식 라벨 변경 없음. 테스트의 합성 입력 검사는 실제 영상 재추론·재추적과 구분한다.

## 방법과 사전 선택

실행 전에 ADR-0011 및 로컬 `outputs/cv_phase2g/preregistered.json`에 시각/문서 SHA256을 저장했다. 이전 두 사례를 이미 본 상태에서 고른 개발 기준이며 독립 검증이나 맹검은 아니다. 실행 후 수치를 조정하거나 특정 영상/ID/시각 예외를 넣지 않았다.

- emission 전 .2초에서 후 .2초까지의 동일 ID 실제 관측을 검사한다. 시작은 창 시작 이하의 가장 최근 프레임으로 최대 .1초까지만 확장한다. 결정은 emission+.2초 이상에 도달한 첫 원본 PTS. 이번 네 후보에서는 양자화 추가분 없이 .2초다.
- 그 안에서 시간 간격 ≤.2초인 모든 관측 쌍을 비교한다. `H=max(h1,h2)/min(h1,h2)`, `W=max(w1,w2)/min(w1,w2)`, `T=Δtop/min(h1,h2)`, `D=Δbottom/min(h1,h2)`.
- 이상 조건: **(H≥1.5 AND |D−T|≥.3) OR W≥1.5**. 작은 흔들림보다 큰 50% 크기 변화를 보는 한 세트다. |D−T|는 상·하단이 같은 만큼 움직였는지 설명하지만 H 조건과 수학적으로 중복될 수 있다. 신체 부위를 식별한 추가 독립 증거가 아니다. .2초·1.5·.3 모두 최적값 주장 없음.
- 원본 프레임 하나라도 같은 ID 관측이 없거나 PTS gap>.1초/과거 범위 부족/기한 전 EOF이면 **근거 부족 우선**. 이상이 있어도 증거 수치를 남기고 최종 상태는 근거 부족이다. 충분하면 이상 유무에 따라 유보/통과. 안정적 부분 신체 박스는 통과할 수 있다.
- `CandidateReview.step`은 현재 도착한 프레임과 현재 emission 후보만 받는다. 미래 emission 입력을 거부한다. pending→최종 전이를 별도 저장하고 미래 프레임은 기존 결정을 바꾸지 않는다. 예측/미확인 관측은 입력에서 제외한다. 관측이 없는 프레임도 순서대로 처리한다.
- 과거/현재 실제 bbox를 시간 순서로 보관하는 오프라인 소규모 구현이며 장시간 운영용 메모리 최적화는 하지 않았다. 검사 결과는 후보 뒤의 독립 부가 정보다. 기본 CV 실행 경로에는 연결하지 않았다.

상태 의미: `pending` 검토 대기, `passed` 이번 규칙에서 이상 미발견(침입/넘기 완료 확정 아님), `deferred` 박스 변화로 통과 판단 유보(정상 아님), `insufficient` 관측 근거 부족. disabled는 원래 후보를 필드 추가 없이 그대로 반환한다.

네 후보를 모두 유지하면서 검토 상태를 부가했다. 크기 변화가 큰 순간을 설명 가능한 수치로 드러냈지만, **검사 통과 후보는 0**이다. 030의 실제 넘기까지 유보했고 007은 연속 관측 요건을 충족하지 못했다. 따라서 오탐 제거 효과나 좋은 필터라고 결론 내릴 수 없다. 기본 적용은 보류하고 사람의 검토 보조 정보로만 평가한다. 006/031은 새 판별 기회 자체가 없으므로 탐지 개선/정상 판별 성공으로 세지 않는다. 006 ROI 밖 한계 유지.

안정적인 부분 신체 박스/안정적인 잘못된 ID는 이 규칙을 통과할 수 있다. 실제 이동·원근 변화·가림도 크기를 바꾸므로 과도 유보 가능. 하단 중심점을 발이라고 부르지 않으며 신체 부위를 분류하지 않았다. 정밀 정답 없는 개발 표본으로 정확도/F1/오탐률/IDF1/HOTA 미산출. 카메라 그룹 누수 방지·공식 라벨·G1E 미확정 제한 유지.

새 출력이 있으면 덮어쓰기를 거부한다. 비교는 `--output`으로 새 루트 사용 가능하며 표시 ROOT도 맞춘다. 실험 기준/실행 코드 SHA256은 comparison/summary.json에 기록한다. 이번 실행은 한 조건 한 번이며 수치 재탐색 없음.

- 35테스트 통과(기존 24+신규 11): 박스만 급변, 안정 이동, 실제 이동+크기 변화, 관측 공백, EOF, 미래 emission 거부/조기 결정 금지/뒤 프레임이 기존 결정을 못 바꿈, 예측 제외, disabled·입력 불변, 안정 부분 박스 한계, 폭 변화, PTS gap/과거 부족.
- 2,060 입력 프레임의 ID/박스/점수/native PTS/time_base 포함 객체 불변, 네 원래 후보 불변, disabled 결과 정확 일치. 원래 events 바이트 복사본도 보존. 모든 최종 사용 관측 ≤결정 PTS 검증.
- 기존 출력/캐시/공식 JSON/설정 530파일 SHA256 보존 및 실행 전 ADR 해시 불변 확인.
- 실제 데이터 재추론/재추적/기존 경계 재실행 없음. 별도 검토 모듈만 추가했고 baseline 코드 호출 경로/기본 설정은 불변.
- 영상 재디코딩으로 007 94원본→470표시, 030 88원본→440표시 프레임과 출력 PTS 간격 1/30초 확인. 느린 구간은 원본 프레임 4회 표시. 캐시 검토·표시 속도를 모델 추론 FPS로 보고하지 않는다.

다음 작업은 두 영상의 **유보/근거 부족이 검토 업무에 유용한지** 확인하고, 안정적 부분 박스의 누락과 실제 동작 과도 유보를 포함할 평가 기준을 정의하는 것이다. 이 결과만으로 기준 완화/대기 변경을 자동 수행하지 않는다. 기존 후보 삭제와 기본 설정 교체는 하지 않았다.

표시 초안에서 pending의 대기 시간이 상태 생성 당시 0으로 고정되어 보이는 문제를 발견했다. 표시 현재 PTS−emission으로 고쳤으며 최종 상태의 확정 대기시간은 유지했다. 초안은 preview 디렉토리에 보존하고 표시 영상만 다시 생성했다. 비교 코드/기준/결과는 재실행·변경하지 않았다.
