# EXP-0071 사람 박스 보완 검수 반영

2026-11-09. 라벨1과 라벨2의 사용자 검수를 반영했다. 두 사례의 좌표 검수는 완료이며 같은 장면을 다시 질문하지 않는다. 학습·개발 자료의 촬영 다양성 확보와 새 독립 시험 확보는 별도 미완료다. 재학습은 실행하지 않았다.

## 완료 선언과 저장본

라벨1은 원본24.667초 한 프레임의2박스, 라벨2는24프레임의46박스다. 사용자 저장본25프레임/48박스와 수정 이력을 보존했다. 라벨2의99.667초와100초에는 한 사람이 완전히 가려졌다는 메모와 보이는 사람의 한 박스만 유지한다. 보이지 않는 사람의 위치를 추정하거나 구간 전체를 두 박스로 강제하지 않았다.

사용자가 라벨2 완료를 명시했고, ‘모든 사람 확인’과 ‘확인 완료’가 별개인 화면 상태를 설명한 뒤 라벨1의 한 프레임을 확인하고 최종 완료를 선언했다. 이 현재 선언을 정확한 저장 버전에 연결했다. 기존 완료1프레임은 그대로 두고, 수정 중으로 남아 있던24프레임에 상태만 완료로 정리한 새 revision을 추가했다. 박스 좌표는 전부 동일하며 기존 revision을 삭제하지 않았다. 상태 정리의 근거와 AI 처리임을 메모에 남겼다. 화면의 이중 확인 UI 자체를 수정한 것은 아니다.

로컬 근거는 `runtime/model-comparison/exp0071/coordinate-completion-v1/`의 `before.json`, `completion-scope.json`, `after.json`, `audit.json`이다. 기존 actor와0/1번 시작 주석은 참고로 보존하며 사용자가 선택하지 않았다는 이유로 검수 미완료로 돌리지 않는다. 이 작업은 실제 보이는 모든 사람의 위치 검수이며 행동·동일인·원래 actor 시각의 정답 확정은 아니다.

## 검수 반영 내보내기

기존 웹 답변5건의 정확한 answer_version1과 영상 바인딩을 다시 확인했다. 좌표 보완25프레임에는 사용자 저장 좌표를 사용하고, 나머지97프레임에는 이미 받은 표시 박스/사람 없음 관찰을 재사용했다. 모델 제안만으로 승인하지 않았고 미주석 프레임을 빈 배경으로 처리하지 않았다.

| 용도 | 프레임 | 사람 박스 | 범위 |
|---|---:|---:|---|
| 학습 후보 | 72 | 182 | 작은 보행인·서 있는 사람·월담자/동행자, 기존과 같은 촬영 예약14/15 |
| 개발 보조 진단 | 50 | 25 | 이동하는 사람25프레임 및 명시적으로 사람 없음을 확인한25프레임, 예약05 |
| 합계 | 122 | 207 | 기존75프레임과 중복0 |

`outputs/model-comparison/exp0071/confirmed-person-v1/`에 원본 PNG, YOLO 사람 좌표, 프레임별 출처·검수 버전·가림 메모·파일 해시를 저장했다. 기존 EXP67의75프레임/182박스를 덮어쓰거나 자동 병합하지 않았다. 이번207박스는 프레임별 주석 수이며207명의 독립 인원이 아니다. 웹에서 확인한 박스의 경계 정밀도가 별도의 전문 이중 검수를 통과했다는 뜻도 아니다.

실행 명령:

```bash
.venv-pose-batch03/bin/python scripts/export_exp0071_reviewed_people.py \
  --output outputs/model-comparison/exp0071/confirmed-person-v1
```

재실행 시 새 출력 경로를 사용한다. 기존 디코딩 환경과 웹 서비스 환경을 각각 사용하며 의존성을 설치하거나 변경하지 않는다. 실제 원본의 SHA·PTS·RGB, 저장 PNG의 RGB, 좌표 경계 및 YOLO 좌표 왕복을 대조했다. 학습/개발 사이 원본과 촬영 예약의 겹침0, 기존 보호 입력8개의 해시 보존, 기존75프레임 겹침0을 확인했다. 실제 편집기 API에서도25프레임 완료를 확인했다. 검증은 저장과 출처의 일관성 확인이며 모델 성능 측정이 아니다.

## 남은 준비

이번 학습 후보72프레임은 이전 소량 학습과 같은 두 촬영 묶음이다. 이를 추가해도 독립 사건 다양성 문제가 해결되지는 않는다. 별도 학습 예약19의 P26/P28 주·야간 월담 후보와 개발 예약01의 P01을 다음 검수 후보로 유지한다. P26/P28은 같은 묶음이므로 두 독립 사건으로 세지 않는다. 이 후보들의 새 초안 생성·검수는 이번 완료 범위가 아니다.

개발 보조 P05는 원래 다른 행동 계열이어서 월담·정상행위 학습 목록에 자동 편입하지 않는다. 별도 촬영의 정상 보행·대기 개발 자료와 새 독립 시험 월담은 계속 부족하다. 기존 학교45와 EXP64시험296/연관327, 사용자 제외 시나리오를 계속 보호한다.

`training_release=false`는 검수 미완료를 뜻하지 않는다. 촬영 다양성·분할과 다음 비교 프로토콜을 아직 확정하지 않았다는 뜻이다. 이번 실행의 새 추론·GPU·재학습은 모두0이며 성능 개선은 미측정이다. 이전 질문이 참조하는 보고서·지표·미디어는 수정하지 않았다.
