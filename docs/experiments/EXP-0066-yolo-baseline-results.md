## 실제 결과와 해석

같은 원본·동일 입력 목록의8번 프레임 하나를 사용했다. 전체 화면640입력·FP32·배치1·공식 native end-to-end 출력이며, 표시 기준0.5를 고정했다. 저장 조건0.05와 표시 조건0.5를 구분한다. 원본의 모든 프레임마다 추론한 실험은 아니다.

이 표는 저장 출력의 집계다. 박스가 있는 입력에는 다른 사람·중복·오검출이 포함될 수 있으므로 관심 사람의 검출 성공률이나 정확도 순위가 아니다. x의 출력이 더 많은 것만으로 더 정확하다고 결론 내리지 않는다. 같은0.5도 모델 사이의 동일 오경보율을 뜻하지 않는다.

정규 입력의 박스 행은 m2,693/l3,073/x3,816개, 추가 진단은15/16/25개다. 이 수도 고유 사람 수가 아니다. 처리 시간에는 디코딩·초기화·공식 워밍업·무결성 확인이 포함되며 실시간 검출 FPS나 경보 지연으로 바꾸지 않는다. 워밍업의 추가 forward를6,219개 저장 출력에 포함했다고 가정하지 않는다.
