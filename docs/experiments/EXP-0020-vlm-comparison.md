# EXP-0020 — frozen Qwen4B comparison

Preparation in progress; **generation has not started and adoption remains on hold**. This experiment compares the existing 16 original-prompt Qwen3-VL-2B BF16 answers with one official Qwen3-VL-4B checkpoint using NF4 language weights and BF16 vision/compute. Capacity and quantization change together; their effects cannot be separated. This is a selected development/diagnostic comparison, with no final accuracy/F1/FPR or independent camera/site generalization claim.
