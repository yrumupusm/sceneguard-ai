# EXP-0063 — 2차 MVP 첫 행동 학습 실험

2026-11-06 사용자 요청. 목표는 고정형 CCTV의 사람별 넘기 행동과 보행·접근·대기를 구분하는 것이다. 이 문서는 학습 결과가 아니라 실행 전 계약이다. 기존 학습 금지는 과거 실험의 범위이며 이번 사용자의 미세조정 요청을 막지 않는다.

## 데이터와 정답

사용자가 제공한 AI-Hub 173 Training의 월담 원본·JSON을 읽기 전용으로 사용한다. 4-19–4-35, 4-69–4-70은 목록과 제외 이유만 남기며 학습·검증·시험에 넣지 않는다. 파일명은 짝 찾기와 제외에만 사용하며 행동 정답을 생성하지 않는다. 원문 event의 actor_id/object_id와 annotation을 연결하고 실제 PTS, 라벨의 정수 초, 프레임 번호를 따로 보존한다. 0/1 시작 번호와 박스 대응을 확인하지 않고 임의의 매핑으로 고정하지 않는다.

라벨 밖 구간은 미표기이며 자동 음성이 아니다. 다른 사람이 넘는 화면 안의 stand 라벨도 전체 화면의 음성이 아니다. 음성은 명시적 사람 행동 라벨 또는 정확한 구간의 사람 검수 근거가 있어야 한다. 접근 후 돌아가기 등 어려운 음성은 해당 장면을 실제 검수한 뒤 추가한다. 미확정 구간·중복 박스·범위 밖 좌표는 검수 목록에 남긴다. 원본·박스·검수 샘플은 로컬에만 저장한다.

AI-Hub 공식 설명은 이 자료가 연출 수집된 3FPS 영상이며 이벤트와 사람별 박스를 제공한다고 명시한다. 현장 연속 CCTV의 일반화 성능으로 확대하지 않는다. [공식 데이터 설명](https://www.aihub.or.kr/aihubdata/data/view.do?currMenu=115&dataSetSn=477&topMenu=100).

## 분할

프레임 추출 전 source SHA와 원본 단위 분할을 저장한다. 월담-only 첫 제안은 같은 촬영일 전체를 연결했다. 사용자가 정상행위 자료를 추가 승인한 뒤, 모든 정상 자료가 같은 장소·하루에 촬영된 것을 확인했다. 통합 v3는 같은 장소·행동군·시나리오의 여러 날짜/카메라, 촬영 시간이 겹치거나 닿는 원본 및 동일 바이트 파일을 연결한다. 날짜가 같다는 이유만으로 별도 촬영까지 합치지는 않는다. 시각 중첩만 묶었던 v2는 카메라 시계 차이에 취약해 사용하지 않는다. v1/v2 산출물은 보존하며 어느 분할에서도 학습하지 않았다. 파일명은 행동 정답 생성에 쓰지 않고 보수적 촬영 그룹 식별에만 사용한다. 장소 정보 충돌·라벨 오류는 격리한다. 묶음을 실제 사건 정답 수라고 부르지 않는다.

통합 v3는 학습671·검증153·시험296·제외313·오류격리7개다. 별도 장소 children-grand-park96개는 시험에만 들어가고 나머지 시험200개는 같은 장소의 별도 촬영 자료다. 정상 자료는 학습207·검증40·시험130·격리7개로 분리됐다. 시험 장소의 정상 자료가 부족하므로 두 시험 층의 지표를 합쳐 장소 일반화 성능이라고 부르지 않는다. 정확한 목록은 `outputs/action-recognition/exp0063/combined-split-v3/split-manifest.json`이며 SHA256 `bfb0f9fcd570794036cc6d2eaad46f988679b612996e21282a34821203ad5499`다. 촬영 메타데이터의 독립 검증과 라벨 의미 검수는 별도 남아 있다.

장소가 분리된 시험을 우선한다. 분할은 모델 결과를 보기 전에 고정하고 별도 장소의 음성 부족은 숨기지 않는다. 학습/검증은 양쪽 클래스의 명시적 자료가 모두 있어야 시작한다. 시험에 음성이 없으면 전체 정밀도/F1/오경보 성능은 null이다. 검수로 학습 구간이 추가돼도 원본 분할을 이동하지 않는다.

## 비교 기준

EXP-0062의 **후보 적용 후** 출력을 기준으로 한다. EXP-0061 보완 85모듈 manifest는 `3927ce310da74aa8d6d3eb69e488c2ba35d625cee81b2589648205dbcde1d823`다. 새40개와 기존5개 재사용의 최종45개 출처를 유지한다. EXP-0060 대조42/52 또는 현재 운영 코드와 섞지 않는다. 이 기준의 공식 확인은37/52이며 행동 모델 성능은 아니다.

`scripts/freeze_action_baseline.py`는 실제 코드/어댑터, 기하, 검출 캐시, FCOS 가중치와 라이브러리 버전, PTS 입력 및 기존 결과를 묶는다. 45개 원본 SHA를 학습·검증·임계값 선택 금지 목록으로 만든다. 원본 공식52시간참조와006미확정1건,008검토보류는 그대로다. 학습 후 같은 입력·규칙·평가로 회귀를 비교한다. 새 시험 자료와 표를 분리한다.

## 모델과 전처리

첫 모델 한 개는 `torchvision.models.video.r3d_18`, `R3D_18_Weights.KINETICS400_V1`다. 기존 torch2.5.1+cu124 / torchvision0.20.1+cu124 / av16.0.1을 사용하며 기존 검출·추적은 수정하지 않는다. 공식 가중치 URL은 `https://download.pytorch.org/models/r3d_18-b3b3357e.pth`이며 다운로드 시 전체 SHA를 기록한다. 현재 다운로드·GPU 학습을 완료했다는 뜻은 아니다. [공식 모델 API](https://docs.pytorch.org/vision/main/models/generated/torchvision.models.video.r3d_18.html).

설정은 실제3FPS 연속8프레임(첫–마지막2.333333초),112×112, 사람과 문·담장이 포함된 검수 ROI의 비율 보존 letterbox다. 최초 준비안16프레임(5초)은 라벨 길이 감사에서3012넘기 구간 중1288개만 충족해, 학습·결과를 보기 전에8프레임으로 결정했다.8프레임은2881개가 길이만 충족한다. 이 수는 구간 검수·학습 승인을 뜻하지 않는다. 공식 모델의16프레임 평가 조건과 다른 입력 길이이며 단일 모델·단일 첫 학습 조건을 유지한다.

정규화는 해당 공식 가중치의 평균/표준편차를 쓴다. 공식 중앙 crop과 달리 문·담장 맥락을 보존하는 선택이며 실험 설정에 기록한다. 전부 명시적 행동 구간 안에 있어야 하고 짧은 행동은 보류 집계한다. 프레임 반복·시계 늘리기·합성 프레임은 사용하지 않는다. 모든 박스를 검출 박스처럼 평가하지 않으며 정답 ROI 사용의 행동 분류와 실제 검출 ROI 사용의 통합 평가를 분리한다.

RTX3080 10GB, 조회 당시1899MiB사용을 확인했다. AMP FP16 microbatch4,4회 누적,seed6301,AdamW lr1e-4/weight_decay1e-4,10epochs를 첫 조건으로 둔다. 실제 메모리 smoke 전이므로 배치 적합성은 미검증이다. 메모리 부족만으로 배치를 줄일 수 있고 결과를 보고 여러 모델·임계값을 탐색하지 않는다. 기존 canonical GPU 큐,6144MiB 여유 조건과 정확한 작업 출처를 유지한다. 이 학습기의 GPU 실행에는 큐 어댑터 연결·검토가 추가로 필요하며 단독 우회 실행하지 않는다.

## 실행과 평가

1. 검수 근거 및 원본/사건 누수·45개 제외 검사를 통과한 clip manifest를 만든다.
2. 소량 실제 자료의 전처리, forward/backward, 검증을 확인하고 별도 smoke 결과를 남긴다. CPU 합성 시험을 실제 학습 smoke라고 부르지 않는다.
3. 한 조건으로 학습하며 검증 cross-entropy가 가장 낮은 checkpoint를 선택한다. 시험은 선택 완료 뒤 한 번 평가한다. 초기 행동 점수 기준0.5는 고정하며45개 회귀 자료로 선택하지 않는다.
4. 검수된 사람 클립의 precision/recall/TP/FP/FN/TN과 원본·사건별 분모, 장소별 결과, 짧아서 제외된 사건을 보고한다. 실패 영상은 원본 PTS·라벨·예측 점수·실패 종류와 함께 저장한다.
5. 분리된 실험 구성에서 기존 사람 검출·추적 뒤 행동 점수를 연결한다. 점수만으로 침입 완료를 생성하지 않는다. 통합 전 점수를 어떤 사건 상태에 사용할지 고정하고 별도 검토한다. 검출 누락/행동 오판/사건 판정 오류를 구분할 정답이 없으면 그 지표는 미측정이다.

기본 MVP, 기존45결과, 정답, DB, 큐의 기존 행은 보존한다. 가중치, optimizer/scaler/RNG, 실제 명령·환경·입력/전처리 해시, epoch로그, 검증·시험 점수 및 실패 자료를 새 경로에 저장한다. 구현·데이터 감사·검수자료 생성·실제 학습·실제 비교의 완료 상태를 각각 기록한다. 검수 답변 후에는 이미 승인된 이 범위를 이어가며 학습 승인을 반복 요청하지 않는다.
