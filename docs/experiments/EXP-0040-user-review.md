# EXP-0040 통지 제외 사례 사용자 검수

2026-10-31. [기존 결과 보고서](EXP-0040-results.md)와 [독립 검토](../reviews/EXP-0040-independent-review.md)를 동결·등록한 뒤 받은 사용자 답변이다. 기존 수치/보고서/review binding을 소급 변경하지 않고 이 추가 기록으로 최신 관찰을 남긴다.

## 검수 대상과 답변

기본0.70에서 통지 제외된 전체 사례는007s0007/raw9, 원래59.666667초의1행이다. 사용자에게58.4–60.166667초의 원본 및 원본/저장 박스/특징 경로 비교 영상을 함께 제시했다.

사용자 관찰:

- 사람은 두 명이며 박스가 사람 수에 비해 여러 개 보인다.
- 문으로 접근하는 중이 아니라, 이미 문 앞에 서서 침입 행동 전에 가만히 기다리는 장면이다.
- 사람을 감싸는 녹색 박스는 계속 잘 표시된다.

이번 EXP0040 비교영상의 녹색은 **기존 confirmed track에 연결된 실제 저장 검출**을 뜻한다. 다른 저장 검출은 주황으로 표시했다. 앞선 EXP0039 ROI 비교영상의 녹색 점수≥0.5 범례와 다르며, 이번 사용자 답변으로 점수가0.5이상이라고 역산하지 않는다. 녹색 역시 정확한 박스/동일인 정답을 보증하지 않는다.

## 반영과 제한

이 한 건을 통지에서 제외한 판단은 사용자가 확인한 **문 앞 대기·사람 검출 지속**이라는 장면 관찰과 부합한다. 따라서 “모든 제외 사례가 미검수”인 상태에서, 유일 제외 사례의 장면에 대한 사용자 근거가 추가됐다. 다만 사용자 답변은 박스에 대한 관찰이므로, 개별 특징점이 같은 사람·문·다른 사람 중 무엇을 따라갔는지 또는 raw9와 endpoint 검출이 정확히 같은 사람인지를 확정한 것으로 확대하지 않는다. 박스가 많은 이유도 중복 검출이라고 모두 확정하지 않는다.

기존52.5–58초의 알려진 정상 접근 오탐3건과 이번59.666667초 대기 사례는 다른 행이다. 이번 관찰로 기존3건이 줄었다고 다시 계산하지 않는다. 제안은 여전히 전체18→17알림·5→6카드이며,56초 첫 오탐을 남기고62.5초에 추가 카드를 만든다. **국소적으로 장면에 맞는 제외1건이 있더라도 전체 통지/카드 부담 개선 목표는 미충족**이다. 기본MVP 교체 및 점수 기준 변경은 하지 않는다.

새 추론·추적·모델·학습·영역 변경은 없다. 원본/경로/원시 결과는 로컬만 보관한다. 기존 웹의 동결 보고서에 남은 “답변 대기”는 등록 당시 상태이며, 이 문서는 그 후의 사용자 검수 추가 기록이다. 웹 보고서를 몰래 수정하거나 독립 검토가 이 답변까지 인증했다고 표현하지 않는다.
