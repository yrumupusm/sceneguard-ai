# 전체 원본 MVP 평가 — 실행 전 고정 계약

2026-11-01. 사용자 승인과 `CODEX_MVP_EVALUATE_ALL.md`에 따른다. 분석 기준은 `548ff7098045f9efc5bd2edfd5ce61431a5e210e`, 현재 체크아웃은 평가 집계기를 추가한 `f05d430`이다. 이번 작업에서 모델·판정·영역·임계값을 변경하지 않는다. 전체 목록과 실제 실행 결과는 `docs/MVP_FULL_EVALUATION.md`에 별도로 보고한다.

- 원본마다 한 행을 유지한다. 동일 바이트 사본, 추출 클립, 비교 영상은 추가 독립 원본으로 세지 않는다. 실패·미지원·미실행도 전체 분모에 남긴다.
- 현재 실행기의 카메라 및 native PTS 제약을 그대로 적용한다. C3는 사용자 수정 inside와 EXP46 최종 문 구역, C6는 기존 scene과 EXP46 최종 문 구역이다. 검증된 카메라 연결 없이 다른 영상을 C3/C6으로 지정하지 않는다.
- 지원 원본은 `mvp_pipeline --whole`로 상태를 유지하며 처음부터 끝까지 처리한다. 동일 FCOS 전체 캐시가 없으면 기존 canonical GPU 큐를 사용한다. 여유 GPU 메모리 조건을 충족하지 못하면 우회 실행하지 않는다.
- 전체 실행 판정은 기존 실행기의 성공 플래그만 믿지 않는다. 디코딩한 전체 native PTS 열과 실제 검출 캐시·현재 관측의 개수/PTS 열을 대조하고 첫 프레임 누락도 실패로 기록한다. GPU 자원 확인은 새 검출이 필요한 행에만 적용한다. 사건 알림 의도와 평가 manifest 알림 목록의 누락 없는 대응도 검사한다.
- 공식 정답의 겹치는 구간만 같은 출입구 사건으로 합치며, 예측을 보고 정답을 합치지 않는다. 실제 디코딩 인덱스와 native PTS를 연결한다. 0/1-based 해석이 미확정이면 두 공식 참조를 분리한다. 프레임 수가 불일치하면 정밀 참조를 미확정으로 남긴다.
- 공식 참조와 사용자 검수는 별도 manifest/점수다. 미검수 시간은 음성으로 만들지 않는다. 기존 사용·감사 이력을 조사하며 미확인 이력을 독립 테스트로 부르지 않는다.
- 사건 단위 의심/자동 확인을 별도 평가한다. 일대일 최대 매칭, 반개구간 `[start,end)`, 추가 허용폭 0초를 고정한다. 카드 유지 시간 대신 새 후보 decision PTS와 개별 근거의 첫 자동 확인 PTS만 사용한다.
- 사건이 나중에 TP가 되어도 앞선 검수 정상 시간의 첫 알림은 따로 집계한다. 정상 시간과 경보 원시 수를 먼저 보고한다. 정밀 행동 시작이 없는 참조 시각 차이는 실제 탐지 지연으로 부르지 않는다.
- 전체 실행 coverage와 실행 완료 자료의 성능을 분리한다. 미검수 예측이 있으면 전체 정밀도/F1은 미확정이며 평가 가능한 부분과 범위를 함께 보고한다. 관찰 종료와 처음부터 무경보는 의심 해제 성공이 아니다.
- 로컬 원본·정답·캐시·원시 결과·DB는 공개하지 않는다. 새 전체 평가 등록은 기존 기본 시연과 검토/알림 저장을 덮어쓰지 않는다.

실행은 Sol high, 독립 검토는 Astra high로 기존 Orca Run에서 수행한다. 평가 어댑터와 실행 래퍼는 `scripts/`에 두어 동결한 분석 모듈을 바꾸지 않는다. 분석 실행 후 규칙 수정이나 같은 평가 자료를 이용한 튜닝은 이번 범위에 포함하지 않는다.
