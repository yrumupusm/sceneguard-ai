## 먼저 필요한 검수

1. **분할/촬영 확인:** P06/P08/P12의 실제 장소와 촬영 대응 확인, P19/P22의 보류 유지 여부, 나머지 후보의 멀티카메라·시간 이동 복제 확인. 파일명 suffix는 검증된 카메라 ID가 아니다. 불확실하면 같은 예약으로 묶거나 보류하며 독립 사건으로 세지 않는다.
2. **라벨 정렬과 모든 사람 박스:** 원본 PTS와 0/1 시작 대응을 확인한 뒤, 선택한 native 프레임마다 보이는 모든 사람을 추가/수정한다. 작은 배경 인물·동행자·서 있는 사람·앉은 사람·일부 잘린 사람을 포함한다. 완전히 보이지 않는 몸의 위치는 추측하지 않고 ignore 정책을 정한다. 표시 초안은 origin1 가정이며 미확정이라고 명시했다.
3. **정상행위 공백 보완:** 학습 P16/P17의 보행과 P18의 서 있는 문맥, 개발 P05의60–62초 이후 보행과 P01의뒤쪽 정지 인물, 시험 P07/P09/P10/P11의 보행/서 있는 사람을 우선 검수한다. 원래 개발 라벨에는 명시적인 moving/stand가 없으므로 이 사람별 구간은 새 주석이 필요하다. “서 있음”과 “문 앞 대기”, “접근 후 돌아가기”는 서로 다르며 마지막 두 조건은 아직 확인된 자료가 없다.

## A–D 실행 가능 여부

**현재: 확대 데이터의 학습 실행 준비 미완료.** 후보 원본·실제 디코딩·분할 예약·검수 범위는 확보했다. 학습12/개발5/시험7을 완전한 사람 데이터셋으로 바로 내보내면 안 된다.

검수와 분할 확인 뒤 같은 초기 YOLO26m 사람 가중치·확정 데이터·학습 순서/횟수·입력640·무증강 조건으로 다음을 비교할 수 있다.

| 조건 | 학습 | BN 누적 통계 |
|---|---|---|
| A | 없음 | 사전학습 상태 |
| B | 전체 가중치 | 갱신 |
| C | 전체 가중치 | 고정; affine 계수의 학습 여부 명시 |
| D | 마지막 사람 분류·박스 예측층만 | 고정; 나머지 특징/BN 계수도 고정 |

현재 학습기는 전체 가중치 학습 경로다. C/D 조건의 정확한 파라미터/BN 고정 확인과 epoch별 저장은 후속 구현/실행 항목이며 이번에는 변경하지 않았다. A/B/C/D가 모두 같은 확정 사람 정답을 쓰게 하고, 사후 통계 교체를 C의 재학습으로 대신하지 않는다.

새 시험 후보에는 현재 월담 자세 구간이 없다. 검수 후 다른 촬영의 일반 사람 검출 유지·작은 사람/가림·오검출은 비교할 수 있지만, **새 촬영의 월담 인물 검출 개선까지 검증할 자료는 부족**하다. 보호된 EXP64 시험/학교45를 학습·개발로 당겨 채우지 않는다. 기존 보호 자료를 추후 회귀로 평가하더라도 새 독립 시험과 구분하고, 사건 시간만으로 사람 박스 성공을 세지 않는다. 학교 CCTV에서의 독립 일반화는 여전히 미측정이다.

최소 평가에는 기존 미검출 회복, 기존 검출 유지, 새 누락, FP/평가100프레임 및 사건별 결과를 함께 남긴다. 임계값0.5·IoU0.5의 동일 프레임 일대일 대응을 유지한다. 시험 자료는 학습 조건·epoch·임계값 선택에 사용하지 않는다. 시험에서 학습 전 누락이0이면 회복률을 억지로 계산하지 않는다.
