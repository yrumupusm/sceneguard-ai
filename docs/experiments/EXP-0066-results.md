# EXP-0066 — FCOS 누락 장면의 여덟 모델 비교

**후속 상태:** YOLO26m/l/x도 각각 학교45개·6,219입력 처리를 완료해 총11개 구성의 저장 출력이 확보됐다. 보조 분류기는3개 완료/나머지 대기이며 검출 모델의 추가 학습은 아직0회다. 최신 [YOLO 결과와 비교 화면](EXP-0066-yolo-baseline-results.md), [학습 라벨 검수6건 전달](EXP-0066-review-checkpoint-delivery.md)을 따른다. 아래 두 분류기 중심 수치는 이전 진행 시점의 기록으로 보존한다.

2026-11-08 게시용 진행 기록이다. 여덟 모델의 학교 45영상 처리와 독립 출력 검증을 완료했다. 일곱 고정 모델 분류기 중 VideoMAE와 V-JEPA2 두 개의 학습 및 저장된 학교 입력 각 6,219개의 CPU 점수 계산을 완료했다. 나머지 분류기 학습, 최종 비교 자료와 웹 전달은 진행 중이다. 실제 인물 대응과 행동 의미 검수가 끝나지 않아 사람 복구율·학교 행동 정밀도/재현율·침입 성능 개선은 미측정이다.

사용자 보완에 따라 기존 8개와 YOLO26m/l/x를 포함한 총 11개 후보를 유지한다. [학습 전후 평가 계획](EXP-0066-paired-box-evaluation.md)과 [YOLO26 추가 범위](EXP-0066-yolo26-addendum.md)를 적용한다. 현재 고정 모델의 분류기 학습은 기준 조건이며, 검출 모델/영상 모델 자체를 추가 미세조정한 효과의 전후 비교는 아직 실행하지 않았다.

## 고정한 비교 조건

FCOS 박스나 알림의 존재를 새 모델 실행 조건으로 사용하지 않았다. 모든 모델이 같은 45개 원본 전체 시간 범위를 읽고, 모델마다 184,300 native 프레임에서 정규 1초 간격 6,177창과 사전 고정 진단 42창을 처리했다. 모델마다 총 6,219창이며 매 native 프레임마다 추론한 실험은 아니다. 진단 42창은 정규 관측 집계와 분리한다.

전체 화면·배치 1·16개 입력 칸·4/30초 간격을 사용했다. 가장 가까운 실제 PTS를 선택하며 동률은 앞 프레임, 영상 경계는 명시적인 끝 프레임 반복이다. 마지막 입력이 도착하기 전에 점수를 사용할 수 없으며 중심 시점을 경보 시각으로 세지 않는다. 모델별 기본 해상도·정밀도 차이는 유지했고, 유효 사람 픽셀 크기를 통제한 별도 실험은 미실행이다.

기준선은 EXP-0062 AFTER의 공식 참조 52개 중 확인 37개이며 그대로 보존했다. R3D18은 EXP-0064 선택 epoch6와 임계값 0.5를 유지한다. 이번 전체 화면 16프레임 입력은 이전 사람 주변 8프레임/3FPS 입력과 별도 조건이다. 새 후보가 늘어도 침입 완료로 자동 연결하지 않는다.

## 전용 분류기와 보호 자료

분류기 실행 코드는 동일 내용 파일 경로 검증을 보완한 `36d14d4e01987d34eba066fb10313d2f98c21a3f`으로 고정했다. 원본 모델의 가중치를 고정하고 별도 학습/검증 자료로 선형 분류기를 학습한다. 네 인코더는 전체 장면 특징, 세 joint 모델은 실제 예측 박스와 해당 사람 라벨이 양쪽 프레임 번호 해석에서 모두 IoU 0.5 이상 대응한 후보의 80개 AVA logit을 사용한다. 사람을 수동으로 잘라 넣거나 FCOS 박스를 proposal로 사용하지 않는다. R3D를 다시 학습하지 않는다.

분할은 기존 보호 목록을 재사용한다. 학습 양성 1,571/음성 1,711, 검증 양성 411/음성 291의 총 3,984개 고유 입력이다. 원본/라벨 출처와 동일 촬영 그룹을 유지하고 학교 45개·EXP-0064 시험 자료를 학습·임계값 선택에서 제외한다. 792개 원본 해시, 797개 원본 경로·라벨과 선택된 실제 RGB 24,616프레임을 확인했다. 3FPS 자료의 16개 입력 칸은 실제 7프레임과 9개 반복이며 관측량을 늘려 세지 않는다.

정상 라벨은 검수된 전체 장면 부재 정답이 아닌 제한된 공식 참조다. 이미 확인된 라벨 충돌과 보호 자료는 제외했지만, 검증 음성이 앉기에만 치우친 한계는 남는다. 따라서 검증 참조 음성 비율 5% 이하 조건을 선택해도 실제 보행·대기·접근 후 돌아가기의 동일 오경보율을 맞췄다는 뜻이 아니다. 선택된 후보에 조건부로 측정한 joint 분류 성능과 검출기 전체 재현율도 구분한다. [분류기 고정 지침](EXP-0066-head-protocol.md)을 따른다.

## 기존 검수의 재사용

EXP-0065 답변 9개의 정확한 답변 버전을 재사용했다. 028의 회색/빨간 박스는 동일 인물의 추적 단절이며, 034의 기존 선택 입력은 서 있기다. 015·039·043의 박스 단절과 행동 시각, 021의 문 옆 경로 관찰도 기존 범위로 유지한다. 별도 장소 오판 1의 라벨 충돌, 오판 2의 85초 빈 박스와 약 89초 후속 월담을 과거 시험 정답의 소급 수정이나 새 모델 성공으로 확대하지 않는다.

## 남은 실행·검수와 해석 제한

- 완료한 두 분류기 외 나머지 학습과 점수 계산은 진행 중이며, 실제 완료 결과로 후속 기록을 갱신한다.
- 검출 모델 여섯 구성의 학습 전후 박스 비교와 영상 특징 모델 네 구성의 고정/미세조정 비교는 별도 학습 명세·라벨 감사가 필요하다. 현재 분류기 학습 결과로 그 효과를 대신 주장하지 않는다.
- 공식 사건의 시간대 안에 후보가 있어도 관심 인물·문 대응 확인 전에는 TP로 세지 않는다.
- encoder 전체 장면 점수에는 사람 검출 재현율을 부여하지 않는다. joint 후보 번호는 해당 시점의 번호이며 연속 추적 ID가 아니다.
- 전체 45개에서 보이는 사람별 누락 정답 목록은 완성되지 않았다. 알려진 실패 장면의 결과를 전체 사람 복구 정확도로 확대하지 않는다.
- 사람별 의미 검수·독립 일반화 성능·동일 오경보율·공간 해상도 통제·실시간 경보 지연은 별도 미측정이다.
- 기본 서비스·기존 검출/추적·침입 규칙은 교체하지 않는다.

초기 EVAD 좌표 중복 변환과 STMixer 한글 메타데이터 오류는 수정된 새 실행으로 검증했고, 이전 실패·잘못된 좌표 출력은 이력으로 보존했다. [수정 근거](EXP-0066-execution-corrections.md)를 참조한다.
