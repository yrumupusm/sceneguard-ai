## 구현·검증과 남은 실행

단일 R3D-18 Kinetics400 미세조정 설정과 실제 native PTS 전처리·학습/검증·checkpoint 저장 코드를 별도 준비했다. 8연속프레임·112입력·AMP·microbatch4/누적4·10epoch·고정0.5이며 GPU 메모리 적합성은 실제 smoke 전이다. 16프레임보다 짧은 사건을 포함하기 위한8프레임 선택은 라벨 길이 조사에 따른 학습 전 결정이다. 사람과 문·담장의 맥락이 보이는 ROI를 검수한 후 사용한다. 기존 검출·추적을 바꾸지 않는다.

감사/분할/학습계약38개 시험이 통과했다. 여기에는 합성 H264 실제 encode/decode, PTS 불일치 거절, 같은 사건/동일파일 누수,45회귀 금지, 미주석 음성 거절, 구간 밖 양성 거절이 포함된다. 기준 고정의 기존 출력 경로 재실행도 오류로 거절하고 파일 바이트를 보존했다. 이 검증은 실제 자료 학습 smoke나 행동 성능 검증이 아니다.

현재 사전학습 가중치 다운로드·실제 전처리/forward/backward·미세조정·성능 평가·실패 사례 평가·45회귀 비교는 수행하지 않았다. 검수 답변의 정확한 버전을 읽고 반영 이력을 남긴 뒤 시간/박스/음성 정책과 clip manifest를 고정해야 한다. GPU canonical 큐 어댑터, 검수 영수증과 학습 manifest의 불변 연결, 독립 검토도 추가로 필요하다. 원본 라벨이나 단순한 reviewed 문자열만으로 실행을 승인하지 않는다. 준비된 학습 명령 템플릿은 큐 연결 전 실행 지시가 아니다.

행동 단독 평가 이후 별도 통합 구성에서 기존 검출·추적의 ROI를 사용한다. 행동 점수를 침입 완료로 바꾸지 않으며, 사건 상태에 적용할 규칙은 통합 전에 별도 고정한다. 검출 누락·행동 오판·사건 판단 오류를 구분하고 정답 부족 지표는null이다. 현재 새 시험 precision/recall/F1과45회귀 변화는 모두 미측정이다.
