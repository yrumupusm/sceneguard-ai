2026-11-08 사용자가 `SceneGuard_FCOS_miss_comparison (1).zip`을 추가했다. ZIP SHA256은 `d8329fa91aa1016851f12aa70ff91d4b0251836f4bde79f7ab0734eef95b49d2`다. 원문 5개 파일과 파일별 해시를 로컬 `runtime/model-comparison/exp0066/handoff-yolo26-added-v1/`에 별도 보존했다. 기존 ZIP·8개 모델 실행 결과·고정된 실행 소스는 변경하지 않았다.

## 추가 범위

YOLO26m/l/x Detection 세 구성을 추가하여 기존 8개와 합계 11개 모델 구성을 기록한다. 각 YOLO 크기에는 사전학습 사람 검출과 검수된 사람 박스·월담 상태를 이용한 추가 학습의 두 조건이 있으므로, 추가 실행 조건은 6개다. 이는 모델 6개를 추가한다는 뜻이 아니다. 기계 판독 목록은 [추가 명세](../../records/EXP-0066/yolo26-scope-addendum.json)에 저장했다.

사전학습 가중치 이름은 `yolo26m.pt`, `yolo26l.pt`, `yolo26x.pt`다. 공식 Detection 지원은 [Ultralytics 문서](https://docs.ultralytics.com/models/yolo26/)에서 확인했다. 실제 실행 전 세 가중치 해시, 라이브러리 버전, 출력 분기/NMS, 해상도, 임계값과 원본 시점을 고정한다. 현재 설치된 버전의 동작을 확인하며 최신 문서의 기본값을 과거 환경에 자동 적용하지 않는다.

## 실행 순서와 기존 작업

추가 ZIP은 YOLO26을 1차 비교로 두고 EVAD/STMixer는 추가 학습 후 남는 실패를 본 뒤 검토하며, 영상 인코더는 이력으로 보존하도록 적혀 있다. 이후 사용자가 ‘yolo만 할건 아니지않아?’라고 전체 비교 범위 유지를 명확히 했고 ‘깃헙 업데이트할거 하고 진행하자’고 요청했다. 최신 직접 지시에 따라 11개 후보를 유지하고, 진행 중인 고정 모델 분류기 결과는 기준 조건으로 보존한다. 검출 모델의 학습 전후 및 영상 모델의 고정/미세조정 비교는 [보완 평가 계획](EXP-0066-paired-box-evaluation.md)에 별도로 정의한다. 기존 실행을 강제 종료하거나 산출물을 덮어쓰지 않았다.

## 평가 및 학습 조건

- FCOS 검출 유무와 무관하게 같은 원본 범위·시점에서 처리한다. 기존 45개 전구간 및 고정 진단 시점을 재사용하는 실행 명세를 준비하고, 1초 관측과 native 매 프레임 추론을 구분한다.
- 사전학습/추가 학습의 공통 비교는 같은 사람의 검출 회복·누락·배경 오검출·박스 품질이다. 다른 사람의 박스나 박스 개수 증가를 복구 성공으로 세지 않는다.
- 사전학습 COCO 모델에는 직접 월담 출력이 없으므로 해당 행동 지표는 ‘해당 없음’이다. person 점수를 월담 확률로 바꾸지 않는다.
- 월담 추가 학습은 검수된 대상 박스와 행동 상태가 필요하다. 기존 클립의 약한 장면 라벨을 사람별 검출 정답으로 자동 변환하지 않는다. 박스가 없는 프레임도 자동 배경/정상 정답으로 만들지 않는다.
- 세 크기에 같은 촬영·멀티카메라 그룹 분할과 선택 기준을 사용한다. 학교 45개와 동일 촬영 그룹, EXP-0064 시험 자료는 학습·검증·임계값 선택에서 제외한다. 정상 보행·대기·접근 자료의 부족을 먼저 점검한다.
- EXP-0026의 사람 박스 추가 학습과 7프레임 결과는 과거 이력이다. 새 월담 학습이나 전구간 평가 완료로 세지 않는다.
- 기존 EXP-0062 AFTER와 운영 검출·추적·침입 규칙을 보존한다. 새 행동 점수는 침입 완료와 별개다. 실제 실행은 기존 단일 GPU 큐를 사용한다.
