## 갱신된 판단과 다음 확인 대상

사용자 관찰은 **넘기 때 박스 불안정·동일 인물의 ID 단절·한 인물 주변 중복**이 남았다는 근거를 보강한다. 그러나 같은 사람에게 새 번호가 생기는 단절과, 살아 있는 ID가 다른 사람으로 이동하는 오연결은 다른 문제다. 이번 답변만으로 모든 번호 변경을 오연결로 분류하거나 프레임별 ID switch 정답을 만들지 않는다.

기본 교체 보류를 유지한다. 007은 접근 후보 억제뿐 아니라 실제 넘기 시작 이후의 미출력도 함께 해결해야 한다. 다음 분석 대상으로는 이미 저장된 관측/예측 상태와 검출 행을 사용자 지칭 인물에 대응해, 박스 자체의 누락·중복과 추적 재배정의 영향을 구분하는 것이 적절하다. 이는 후속 제안이며 이번에 새 실행이나 매개변수 탐색을 시작하지 않았다. Roboflow 검수나 파인튜닝을 진행 조건으로 되돌리지 않는다.

기존 웹의 EXP-0028 결과는 최초 독립 검토 시점의 고정 자료다. 이 사용자 답변을 그 당시 검토자가 확인했다고 소급 표시하지 않으며, 본 보충 기록의 GitHub 게시와 기존 웹 등록 상태를 구분한다.
