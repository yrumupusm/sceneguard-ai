# EXP-0043 누락 구간 사용자 관찰

2026-11-01. 새00764–74초의 로컬 비교 영상에서, 특히65초대에 움직이는 인물에도 현재 점이 붙어 따라가는지 질문한 데 대한 답변이다. 사용자는 ‘놀랍게도 꽤 잘 따라가’라고 답했고, 이어 **문에 잔상이 남기는 하지만 사람에 붙은 점들도 꽤 많이 따라가는 편**이라고 보충했다.

이는 필요한 구간에서도 사람 움직임을 담는 점이 상당수 남아 있다는 장면 수준의 관찰이다. 배경과 문에 남는 경로가 함께 있다는 한계도 유지한다. 특정 시작창69/70/71이나 모든48창·모든 점의 정확한 동일인 대응, 침입 시작의 정확한 프레임을 확정한 답변은 아니다. 선의 과거 이력과 현재 배경점의 오추적도 전부 구분된 정답은 아니다.

기존 계산 재현에서는00764–74초의 모든2928신호가 기준 미달이고,65–66초265신호도 미달이었다. 이 관찰을 함께 보면 ‘사람의 움직임을 전혀 얻지 못해서만 누락됐다’는 설명은 충분하지 않다. 확보된 움직임을 기하·참조·점수에서 어떻게 처리하는지 검토하는 B 방향의 제한된 비교를 진행할 근거로 삼는다. 특정 점수 항 하나가 유일한 원인이라는 증명은 아니므로, 수정은 개발 가설 한 가지로 고정해 전체 두 구간에서 득실을 확인한다.

이 답변으로 새 누락 구간의 관찰 대기는 해소됐다. 기존 접근·대기/030 검수도 그대로 재사용하며 정확한 점·ID 정답이나 수동 박스를 다시 요구하지 않는다. 사용자 관찰을 생성기의 침입 정답이나 정확도/F1으로 변환하지 않는다. 관찰 수신 자체가 수정 구현·A/B 성공·최종 채택을 뜻하지 않는다.
