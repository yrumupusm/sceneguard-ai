# EXP-0065 실제 실행과 전달

2026-11-07. PR #2의 준비 코드를 실행 PC의 실제 자료에 연결했다. [결과 보고서](EXP-0065-results.md), [사건별 진단](EXP-0065-coverage-results.md), [자료 보강](EXP-0065-augmentation-results.md), [재현 명령](EXP-0065-reproduction.md)을 분리해 보존한다. 실제 행동 의미 검수와 성능 개선은 계산·전달 완료와 구분한다.

## 실행 근거

기존 Run `run_3d23462a014a`를 재사용했다. 저장 점수 진단은 `task_7f2aba8173dc` / `ctx_f6bdafb3cc3f`, 자료 보강은 `task_a777315f49b5` / `ctx_e4443f9bfd56`, 독립 검토는 `task_154d5300bb52` / `ctx_e06cbb52bb70`이다. 실제 세션의 Sol high 두 담당과 Astra high 검토를 확인했다. 초기 새 터미널 시작은 업데이트 안내에서 실패했고 해당 소유 자원만 해제했다. 기존 세션의 긴 입력은 제출되지 않은 초안이어서 지운 뒤 저장한 지침을 읽는 짧은 명령으로 전달했다. 실제 새 작업 transcript와 완료 메시지로 실행 여부를 확인하며 입력 수락만으로 실행됐다고 세지 않았다.

45개 저장 점수 3,573개와 공식 참조 52개를 실제 대조했다. 원래 점수 영수증과 기준 해시를 확인했고 새 GPU·모델·학습 실행은 없다. 원본 박스/입력 범위 영상은 최종 `review-media-v2`의 25개이며 독립 로컬 디코딩에서 647프레임·1280×680·3 FPS를 확인했다. v1은 입력 해시 연결 보완 전 예비 결과라 등록하지 않는다.

## 검수·보존

시작 및 작업 중 웹 미처리 답변 조회는 성공했고 새 답변은 없었다. 과거 정렬 답변을 재사용했다. 새 질문 명세 9개는 실제 미디어와 연결해 별도 검토했다. 내용은 후보 7개의 대상 대응과 정상 라벨 오판 2개의 행동/ROI 의미이며 정렬을 반복해서 묻지 않는다.

운영 코드 91개·잠긴 AFTER JSON 471개와 EXP-0064 등록 원문 네 파일의 바이트가 동일하다. GPU 큐는 확인 시점에 기존 100작업·100시도이며 이번 작업이 새 행을 만들지 않는다. 시작 시 있던 `sg-passage-first-impl/`, `sg-passage-first-review/` 로컬 디렉터리는 건드리지 않았다. 등록 후 기존 카탈로그 67행·검수 요청 9행·이력 33행의 내용을 대조해 동일함을 확인했다. EXP-0065 결과 1행, 새 질문 9행·생성 이력 9행, 미디어 26개만 추가했다. GPU 큐 100작업·100시도 행 해시와 기존 EXP-0064 등록 네 파일도 동일하다.

## 전달 상태

실제 최종 보고서·지표·독립 검토를 기존 담당3에 등록했다. 결과는 실행 성공·비교용 검토 통과·운영 채택 보류이며 의미 성능 5지표는 null이다. 새 질문 9개는 모두 검수 대기이고 과거 질문에 답변을 덧쓰지 않았다.

기존 웹에서 33개 지표의 원문/한국어 표시·미측정 표시, 요약 그래프 디코딩, 25개 MP4 모두의 실제 재생·2초 이동·0초 되감기를 확인했다. 16.5초 폴링 동안 영상 노드가 유지됐고 48프레임 추가 디코딩·62회 시간 갱신으로 재생 지속을 확인했다. 검수 화면의 9개 질문 제목/ID/미응답 상태를 API와 대조하고 각각 ‘요청 구간 보기’를 눌러 해당 1280×680 영상을 로드했다. 답변 입력·제출은 하지 않았다. 사용자 작업 중인 다른 브라우저 탭은 변경하지 않았다.

[새 검수 화면](http://127.0.0.1:8765/#video-review?experiment=EXP-0065). 화면·디코딩 확인은 사람이 실제 행동 의미를 판정한 검수와 다르다. 의미 답변은 아직 없고 학교 행동·침입 성능 개선은 미측정이다.
