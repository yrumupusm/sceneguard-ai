현재 실행 계획은 실행 당시HEAD와 모든 분석/큐/입력 바이트를 고정한다. 게시 후에는HEAD가 달라지므로 현재 계획을 억지로 재사용하지 않는다. 아래처럼 기존 상태를 보존하는 새 작업 폴더에서 준비하고, 새 실제 Orca 배정 정보를 사용한다. 환경변수는 임의 ID가 아니라 실행을 담당하는 활성 배정의 값이다. 분석/큐 모듈이 고정 버전과 달라졌으면 실행을 거부하며 몰래 새 규칙의 점수를 합치지 않는다.
