# EXP-0066 검출 학습용 라벨 확인 준비

2026-11-08 사용자는 자동으로 확인하기 어려운 학습 라벨은 직접 검수 요청해 달라고 했다. 파일·해시·좌표·원본 시각 검사는 자동 진행하고, 실제로 보이는 사람의 누락과 가림처럼 영상 의미 확인이 필요한 경우만 구체적인 장면을 제시한다. 이 확인은 학습 전 사전학습 검출 모델 실행의 선행 조건이 아니다.

## 확인한 내용

기존 학습/검증 계획3,984개 입력의 주석을 읽었다. 그중1,346개는 같은 원본의 다른 시점에 라벨이 있는 인물이 현재 시점에는 라벨이 없는 경우다. 이는 검수 후보를 고르는 신호이며 실제 사람 누락1,346건을 뜻하지 않는다. 해당 인물이 그 시점에는 화면 밖에 있을 수 있다.1번 시작 해석에서 둘 이상의 actor가 현재 라벨에 있는 입력은1,584개다. 이 수도 실제 사람 수나 완전한 주석 인증이 아니다.

학습 후보의 넘기·보행·서 있기·앉기, 검증 후보의 넘기·앉기에서 각각 새로운 원본 하나를 골랐다. 기존 EXP-0063의8표본 검수 원본과 이미 제공한 정상 라벨 오판 보기의15원본을 제외했다. 동일한 원본은 두 번 선택하지 않았다. 같은 원본에 기록된 다른 인물의 현재 박스 부재, 전체 actor 수, 원본 식별자와 시각의 고정 순서로 골랐으며 새 모델 예측은 사용하지 않았다.

원본 왼쪽/주석 오른쪽의6개 영상을 만들었다. 각25연속프레임, 실제3FPS로 총150프레임·50초다. 원본 PTS와 모든 해당 시점의 주석 박스를 저장했고, 실제 MP4 디코딩·크기1920×600·시각 연속성·파일 해시를 확인했다. 표시에는 기존 표본 검수에서 주로 선호된1번 시작 해석을 사용하지만 모든 원본의 시간 정답으로 확정하지 않았다.0/1 양쪽 좌표는 로컬 메타데이터에 남겼다. 영상 생성은 학습 데이터 수정이나 사람 검수 완료가 아니다.

## 요청할 확인과 적용 범위

질문은 “화면에 보이는데 박스가 아예 없는 사람이 있나요?” 하나다. 약간 어긋난 박스와 사람 전체의 주석 누락을 구분한다. 누락이 있으면 화면 위 원본 시각과 위치를 메모할 수 있게 하고, 가림/화질로 판단하기 어려운 선택지도 제공한다. 넘기 시작·끝과 프레임 번호 해석을 한 선택지에 섞어 확정하도록 묻지 않는다.

현재 질문6개의 초안과 연결 영상은 준비됐으며 기존 웹에는 아직 등록하지 않았다. 따라서 사용자 답변 대기 또는 검수 요청 완료로 보고하지 않는다. EXP-0066의 실제 비교 결과를 등록할 때 같은 실험의 검수 자료로 연결한다. 이6표본의 답변만으로 전체797라벨이나 모든 촬영의 주석 완전성을 인증하지 않는다. 누락이 확인되면 해당 구간의 보완/제외와 추가 확인 범위를 별도로 정하고, 기존 모델 예측을 정답으로 임의 확정하지 않는다.

보호45개 학교 원본과 EXP-0064 시험 자료는 이 후보 선정과 라벨 준비에 사용하지 않았다. 새로운 검출 모델 추가 학습은 아직0회이고, 자동 학습 허가 상태로 전환하지 않았다. 검증 음성이 앉기에 치우친 문제는 이번 검수6개를 만든 것으로 해소되지 않는다.
