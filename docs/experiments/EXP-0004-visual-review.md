# EXP-0004 — 고정 35프레임 시각 검수 초안

2026-10-28 / Codex 초안. [실험 보고서](EXP-0004-fcos-score-threshold-comparison.md).

EXP-0002에서 미리 정한 같은 35 PTS를 네 조건 모두 검사했다. 원본 영상 위에 최종 기준을 통과한 박스·점수·임시 ID를 표시한 4분할 이미지를 사용했다. 사용자 최종 판정 또는 객체 정답 bbox가 아니며, 모델 출력을 정답으로 삼지 않았다.

공통 기준: (1) 원본에서 실제 보이는 사람이 새로 복원되는지, (2) 보이는 신체를 적절히 감싸는지/일부만 감싸는지, (3) 같은 사람의 중복, (4) 사람이 아닌 영역의 박스, (5) 가림·작은 크기 때문에 유보할 대상을 구분했다. 추가 박스가 없는 조건은 이전 조건과 같은 관측이다. 명시되지 않은 대상의 존재/부재를 확정하지 않는다. ‘의심’과 차량 유리 내부 등 ‘유보’는 확정 오탐 수에 포함할 수 없다. 정밀 적합성 IoU 정답은 작성하지 않았다.

이미지는 로컬 `outputs/cv_phase2d/review{ID}/compare_{PTS:.6f}.jpg`; 좌상 0.5 / 우상 0.4 / 좌하 0.3 / 우하 0.25. 모든 박스는 해당 조건의 **실제 최종 검출**이며 EXP-0003의 내부 raw 진단 후보와 다르다. PTS는 아래 표에서 소수 6자리로 표시하고 원본 정밀값은 manifest에 보존했다. 개수는 사람 수가 아니다.
