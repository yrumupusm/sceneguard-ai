# EXP-0066 YOLO26 학습 전 검출 비교 고정 조건

사용자의 학습 전후 비교 요청에 따라 YOLO26m/l/x 사전학습 출력을 먼저 저장한다. 추가 학습용 라벨 점검은 이 추론을 차단하지 않는다. 기존 8개 후보와 세 YOLO 모델을 모두 유지한다. 보조 분류기 후속 실행은 11단계 완료 지점에서 보존·대기하며, 실행 중인 프로세스가 없음을 담당자와 독립 검토자가 확인했다.

## 입력과 출력

기존 고정45 원본과 native PTS, 6,177개 정규 시점 및 42개 보충 시점의 계획을 그대로 사용한다. 각16칸 창에서 인덱스8의 실제 원본 프레임 하나만 검출기에 넣는다. YOLO가16프레임 행동을 분석했다고 표현하지 않는다. 창의 마지막 입력 시각은 기존 저장 형식에 남지만 검출 박스의 실제 대응 시각은 `sample_pts[8]`, 원본 프레임 번호는 `sample_frame_indices[8]`이다. 전체184,300프레임은 원본 시간 검증을 위해 디코딩하며, 검출은 모델당6,219회다. 동일 원본 시점이 정규/보충 창에 중복될 수 있으므로 이를 독립 사건으로 세지 않는다.

각 모델에서 일곱 고정 입력의 실제 smoke를 먼저 통과한 뒤45개 전체를 실행한다. 모든 실행은 기존 단일 GPU 큐 `model-compare`를 사용한다. smoke와 전체 실행 사이에 소스·체크포인트·환경·입력 조건을 바꾸지 않는다. 실패는 보존하고 검토 없이 자동 재시도하지 않는다.

공식 사전학습 COCO person(class0), Ultralytics8.4.192, FP32, 배치1, 전체 화면640×640 letterbox, RGB 원본을 연속 BGR로 변환해 공식 `YOLO.predict`에 넣는다. 모델의 원래 end-to-end 출력을 사용하며 추가 NMS·FCOS 후보 제한·추적은 적용하지 않는다. `rect=False`, `quantize=None`, `nms=False`, `max_det=300`, `conf=0.05`로 반환된 사람 박스와 점수를 보존하고, 사전에 정한 표시/요약 기준은0.5다. 0.05 미만 및 원래 모델 내부 top-k에서 제외된 후보는 저장되지 않는다. 서로 다른 모델의0.5가 같은 오탐 수준을 뜻하지 않는다. 학교 결과를 보고 임계값을 선택하지 않는다.

공식 Results의 `xyxy`는 이미 원본 픽셀 좌표이므로 다시 확대하지 않는다. 좌표·점수·크기·class0을 검사하고 박스 면적 유효성을 별도로 저장한다. 사람 점수를 넘기 행동이나 침입 완료 점수로 바꾸지 않는다. 모든 체크포인트, 사용 환경과 Ultralytics Python/config 파일 해시를 실행 명세에 고정하고 네트워크·자동 설치를 막는다. 기존 환경 패키지는 변경하지 않는다.

## 평가 및 학습 라벨

이번 실행은 학습 전 출력 확보다. 같은 사람의 복구 성공, 정밀도/재현율, 학습 효과는 정답 대응과 학습 후 실행 전까지 미측정으로 둔다. 기존 EVAD/STMixer의 서로 다른 입력 크기는 보존하고 조건 차이를 명시한다. 전후 비교에서는 모델별 동일 입력·후처리를 유지한다. 이후 핵심 실패 구간의 촘촘한 평가와 정상 대조 자료는 현재1초 간격 출력과 별도로 구분한다.

2026-11-08 사용자는 자동으로 확인할 수 없는 추가 학습 라벨은 직접 검수 요청해 달라고 했다. 파일/해시/좌표/시간 검사는 자동 진행한다. 모든 가시 사람의 라벨 누락, 다른 사람과의 혼동, 가림 중 행동처럼 의미가 불확실한 새 장면만 원본 시각과 질문을 붙여 기존 웹 검수에 등록한다. 기존 답변은 정확한 버전과 적용 범위로 재사용하며, 새 질문을 등록하지 않은 상태를 사용자 답변 대기로 표현하지 않는다. 검출 모델 예측만으로 누락 박스나 행동 정답을 확정하지 않는다. 보호45개와 EXP-0064 시험 자료를 학습·선택에 넣지 않는다.
