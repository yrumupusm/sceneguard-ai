# EXP-0069 — 학습 장면 편중과 BatchNorm 통계 영향 실제 진단

2026-11-08. **과적합과 양립하는 학습·검증 격차가 실제로 나타났다.** 학습 자료에서는 TP148→150, FP6→2로 개선됐지만, 다른 촬영 사건의 검증에서는 TP31→6으로 급락했다. 또한 BatchNorm(BN) 통계만 바꾸는 통제 실험에서 검증 검출이 크게 달라졌다. 단순히 모델 전체가 학습에 실패했다고 보기보다, 소수 촬영 장면에 치우친 적응과 BN 통계/가중치의 상호작용을 우선 점검해야 한다.

이 결과는 **원인 하나를 확정하거나 전체 AI-Hub 추가학습의 실패를 뜻하지 않는다.** 학습2사건·검증1사건뿐이고 학습 중간 체크포인트가 없어 과적합이 시작된 epoch, 광범위한 일반화, 원인별 기여율은 측정하지 못했다.

## 실행 전에 고정한 비교

[프로토콜](EXP-0069-protocol.md)을 코드와 함께 `d0eace5`에 고정한 뒤 실제 평가했다. EXP68 초기/최종 가중치를 사용해 학습50프레임/151박스와 검증25프레임/31박스에 아래 네 조건을 각각 적용했다. 총300 CPU 프레임 추론, FP32·640입력·4스레드·eval/inference_mode·무증강이다. 기존과 같은 신뢰도0.5 및 IoU0.5에서 프레임별 최대 일대일 매칭을 사용했다. 상위300 후보·보존0.05·추가NMS없음도 유지했다. 새 학습·GPU 실행·임계값 조정·최적 모델 선택은 없다.

| 조건 | 학습되는 파라미터 출처 | BN 내부 통계 출처 |
|---|---|---|
| A 학습 전 | 초기 | 초기 |
| B 학습 후 | 마지막5epoch | 마지막5epoch |
| C 통계 복원 진단 | 마지막5epoch | 초기 |
| D 통계 변경 진단 | 초기 | 마지막5epoch |

124개 BN의 running_mean/running_var/num_batches_tracked, 총372개 buffer만 교환했다. BN의 학습되는 weight/bias와 다른 파라미터는 가중치 조건 그대로다. 조건별 전체 state 해시를 재구성해 대조했고 각75회 추론 전후 모델 상태가 동일함을 확인했다. C/D는 메모리에서만 만든 진단 조합이며 저장·채택한 모델이 아니다. 통계를 교환하면 파라미터와 통계의 불일치도 생길 수 있으므로 'BN을 고정해 학습한 모델'의 결과로 해석하지 않는다.

## 실제 수치

TP/FP/FN은 프레임마다 반복된 박스 행이다. 사람 수·행동 성공 수·독립 사건 수가 아니다.

| 조건 | 학습 TP/FP/FN (정답151) | 학습 재현율 | 검증 TP/FP/FN (정답31) | 검증 재현율 |
|---|---:|---:|---:|---:|
| A 학습 전 |148 / 6 / 3|98.01%|31 / 0 / 0|100.00%|
| B 학습 후 |150 / 2 / 1|99.34%|6 / 0 / 25|19.35%|
| C 학습 후 + 초기 통계 |147 / 2 / 4|97.35%|14 / 1 / 17|45.16%|
| D 학습 전 + 학습 후 통계 |143 / 2 / 8|94.70%|2 / 0 / 29|6.45%|

학습 F1은 A0.970492→B0.990099, 검증 F1은 A1.0→B0.324324다. 학습1번의 TP/FP/FN은75/1/2→77/0/0, 학습3번은73/5/1→73/2/1이다. 전체 개선은 익힌 두 장면에 한정되고 검증5번으로 전이되지 않았다.

**첫째, 과적합/촬영 장면 편중 가설을 지지하는 패턴이다.** 초기보다 학습 장면의 검출과 오검출이 좋아졌고 다른 사건에서는 크게 악화됐다. '50장이 부족할 것이다'라는 추측을 넘어 실제 학습·검증 성능 차이를 확인했다. 다만 두 시점/한 검증 사건으로 통계적으로 일반적인 과적합의 단독 인과를 입증한 것은 아니다.

**둘째, BN 통계 변화가 이 검증 장면에 큰 영향을 준다.** B→C에서 다른 파라미터를 그대로 두고 통계만 초기값으로 바꾸면 TP6→14로 일부 회복된다. 반대로 A→D에서 학습되는 파라미터를 초기값으로 유지하고 통계만 최종값으로 바꾸면 TP31→2로 급락한다. BN 통계 변화는 유력한 기여 요인이다. 그러나 C도31개를 회복하지 못하고 FP1이 생기며 학습 검출은 감소한다. 가중치와 통계가 함께 적응한 상호작용이 있으므로 원인의 몇 퍼센트가 BN인지 나누지 않는다. C를 해결 모델로 채택하지 않는다.

**셋째, 기존 GPU 결과의 평가 오류나 CPU 전환 차이로 이 격차를 설명할 수 없다.** A/B의 검증25프레임 각각 TP/FP/FN이 기존 EXP68 GPU 저장 결과와 모두 같다. 원시8400후보의 CPU/GPU 최대 점수 차이는 A0.000005633/B0.000005931, 최대 좌표 차이는 A0.03745/B0.06244픽셀이다. bitwise 동일하지 않지만 고정 기준의 실제 매칭 수는 동일하다. 이것만으로 학습 구현의 모든 잠재 오류가 배제되는 것은 아니다.

## 데이터와 한계

학습은 사용자 박스 검수가 끝난1번33–41초/25프레임/77박스 및3번53–61초/25프레임/74박스, 검증은5번13.333–21.333초/25프레임/31박스다. 기존 사건 분할과 답변을 재사용했다. 작업 시작의 웹 미처리 답변 조회는 성공·0건이며 새 질문이나 답변 제출은 없다. 현재 답변 바인딩과 입력 이미지/라벨 해시도 검사했다.

학습/검증 모두 YOLO26x 제안을 사용자가 확인한 사람 박스다. 제안 기원 편향과 연속 프레임의 상관이 남는다. 검증5번은 이미 반복 관찰한 진단 자료이며 독립 최종 시험이 아니다. 행동·신원 라벨을 만들지 않았고 학교45·EXP64시험은 사용하지 않았다. EXP62 AFTER 및 EXP64 선택 모델/0.5도 변경하지 않았다.

epoch별 학습 loss는 두 검출 헤드의 가중 비중이 달라진 값이라 과적합 판단에 사용하지 않았다. 중간 모델이 없어 처음부터 일반화가 저하됐는지, 특정 epoch 이후 떨어졌는지 미측정이다. 이번 진단으로 곧바로 최적 epoch/학습률/임계값을 선택하지 않는다.

## 다음 학습에서 검증할 변경

가장 먼저 비교할 조건은 **원래 사전학습 상태에서 시작해 BN의 누적 통계를 유지하는 학습**이다. 이번 C는 학습이 끝난 뒤 통계를 교환한 것이므로 이를 직접 대신하지 않는다. 다음 실험에서는 한 조건만 바꿔 BN 통계를 유지한 채 학습하고 epoch별 학습/검증 출력을 남겨, 언제 격차가 생기는지 확인해야 한다. 가중치 동결·학습률·워밍업을 동시에 바꾸면 원인이 섞이므로 별도 비교로 둔다.

본격적인 성능 개선 실험에는 다른 장소·사람·자세·가림의 사건과 완전한 사람 박스를 보강해야 한다. 같은 영상의 프레임 수만 늘리는 것으로 다양성이 확보됐다고 보지 않는다. 현재 세 사건은 진단/개발로 유지하고 별도 평가 사건을 확보한다. 이번 테스트는 사전 고정4조건으로 종료했고 재학습·새 모델 채택을 자동 수행하지 않았다. 메인6모델 추가학습/학교 비교 범위는 유지된다.
