# EXP-0072 — 보유 정상행위 개발 자료와 촬영 독립성 감사

2026-11-09. **현재 보유한 정상행위 432쌍에서 안전하게 개발용으로 추가할 후보는 0개다.** 파일 부족이 아니라 기존 학습 예약·보호 시험·격리 및 내용 유사성 보류가 이유다. 촬영 독립 사건 수는 `null`이며 독립성이 없다고 입증한 수치도 아니다. 이 감사는 분할·보류·정답·학습 release를 변경하지 않는다.

## 실제 확인한 범위

EXP70 `source-inventory.jsonl`·`split-proposal.json`·`group-closures.json`, EXP71 `wall-normal-preparation-v2/source-reservations.json`, EXP63 고정 분할, EXP65 내용검사·보호 지문과 관련 준비 코드를 연결했다. EXP70의 기존 입력 바인딩과 읽은 입력의 감사 전후 SHA256이 일치했다. WEB pending은 기존 서버 Python으로 `pending --include-acknowledged`를 읽었고 `{"requests": []}`였다. 답변 확인·처리 DB 쓰기는 하지 않았다.

정상행위 432쌍과 P01/P26/P28의 원본 435개·라벨 435개를 현재 파일 또는 ZIP member의 전체 바이트로 SHA256 검사했다. 정상 원본 411개는 기존 SHA와 일치하고, 21개는 과거 SHA가 없어 현재 해시만 새로 기록했다. P01/P26/P28 원본 3개와 라벨 435개는 모두 기존 해시와 일치했다. 현재 라벨의 장소·촬영 시각·선언 프레임 수·FPS도 목록과 일치했다. 과거 해시가 없는 21개에 대해 ‘기존 바이트 불변’을 인증하지 않는다.

영상 디코딩·픽셀 열람·외부 업로드·모델 추론·GPU·학습은 이 작업에서 각각 0회다. 원본 경로와 개별 목록은 로컬 출력에만 남겼다. 보호 시험/학교 원본은 다시 읽지 않았으며 고정된 해시와 기존 지문만 비교했다.

EXP65의 `C_30_4 … 16-53-00_a … DF4` 원본 하나가 `C_30_3 … 16-23-00_a … DF2` 원본을 `suspected_content_overlap`으로 가리킨다. 이는 train 앉기 그룹60개와 validation 앉기 그룹48개의 연결이다. 기존 5시점 소형 지문 검사에서 나온 유사성 의심이며 실제 동일 사건·중복 촬영 확정은 아니다. 반대로 확정 중복이 아니라는 이유로 보류를 풀 수도 없다. EXP65 `quarantine_results`가 의심한 원본과 상대 원본의 그룹 전체를 보류했고, EXP70이 그 그룹에 속한 모든 member에 `prior_content_hold`를 적용했다. 이 두 그룹에서 EXP65가 검사한 12개는 모두 `quarantine_suspected_overlap_or_group`이며 의심 목록이 비어 있는 sibling도 보류가 유지된다.

학습 예약14의 격리4개는 이동 계열32의 시나리오9 두 원본, 10 한 원본, 11 한 원본이다. 네 원본 모두 `event_frame_out_of_range`, `event_reversed`, `event_time_out_of_range`, `event_without_declared_actor_boxes`가 남아 있다. 원본 ID·경로·라벨 해시·과거 배정은 로컬 `normal-source-audit.jsonl`과 `candidate-hold-list.json`에 전수 기록했다.

촬영 그룹은 기존 원본 그룹, 전역 동일 SHA, 같은 장소·계열·시나리오, 장소별 촬영 시간의 양 끝 포함 겹침을 합친 보수적 closure다. 같은 카메라 코드만 골라 sibling을 분리하지 않는다. 카메라 식별과 실제 촬영 시각은 독립 검증되지 않았으므로 다른 그룹 ID 자체를 독립성 증명으로 사용하지 않는다. 특히 정상행위 전부가 같은 명목 장소와 2021-09-11에 속하며, 그룹을 나눴다는 사실만으로 촬영 세션 독립성을 인증하지 않는다.
