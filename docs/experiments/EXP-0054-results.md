- 기록 작성일: 2026-11-04. 게시일은 실제 GitHub 게시 확인 시 별도로 기록하며 실행일로 대체하지 않는다.

## 목적과 변경 범위

이른 확인 보완은 미루고, 출발 영역과 유한 경계 근처 소실 이력이 있으나 최근 방향이 불명확할 때 반대편의 새 실제 출현으로 확인을 보완했다. 운영 모듈 변경은 `legacy_directional.py` 하나다. 기존 명확한 방향·소실 및 실제 관측 통과 확인을 유지하며 반대편 출현을 모든 확인의 필수 조건으로 만들지 않았다.

불명확은 기존 3px 기준 사이의 최근 경계 법선 변위다. 방향 자료 부족을 곧바로 정지·반대 이동으로 단정하지 않는다. 계속 보이는 정지 관측은 소실이 아니지만, 작은 변위 또는 정지 뒤 실제 소실과 유효한 반대편 새 출현이 있으면 보조 근거가 될 수 있다. 분명한 반대 방향 이동, 이미 반대편에 있던 관측, 영상 단절·끝은 새 확인 근거로 대체하지 않는다. 전후 ID·동일 특징점 연결로 사람의 신원이나 가려진 이동 경로를 복원했다고 주장하지 않는다.

같은 출현에 보조 확인이 먼저, 기존 명확한 확인이 나중에 완성되는 좁은 경우에는 두 시점의 근거를 보존한다. 하나의 출현이 두 인과 근거를 뒷받침할 수 있으며 전역적으로 한 출현·한 원천 소유를 보장하지 않는다. 합성 사례의 첫 확인 알림은 한 번이고 나중 근거로 과거 시계를 소급 변경하지 않는다. 사건 묶음·개별 해제·중복 정리와 수치·영역·기존 하단 중앙점은 그대로다.

## 실제 변화와 실패·정정 이력

9영상의 원시 반환 5종씩 45개와 추출 예측이 전후 원문 동일하다. 새 보조 확인 근거 0건이고 013의 65.566667초 확인을 포함한 기존 근거를 보존했다. 당시 사용자는 이 013 출현이 앞서 문에 접근하다 가려진 사람이 바깥으로 나온 장면이라고 확인했지만 다른 관측의 동일인 정답으로 확대하지 않는다. 이 확인은 이전 EXP-0053에서 새 출현 검사 계약을 바로잡아 얻은 별도 소실·출현 경로이며 이번 불명확 방향 추가의 새 성공이 아니다. 하단점상 문 방향 변위와 기존 특징점상 unknown은 구분한다. 기존 68.2초 개별 해제의 영상 적절성도 미검증이다.

최초 배정에서 021을 옛 `mvp-all-v3`로 지정한 입력 오류가 있었다. 옛 021 대조와 최초 집계는 비정식 이력으로 보존하고 정식 021만 최신 C5로 다시 준비했다. 다른 8개 대조를 재사용하고 후보는 정식 입력으로 한 번씩 실행했다. 총 대조 호출 10회(정식 9+비정식 1), 후보 9회이며 분석 실패·기술 재시도·규칙 튜닝은 0이다. 옛 021을 정식 성능 분모에 섞지 않는다.

## 실행 경로와 근거

기존 Run `run_3d23462a014a`의 실제 평가 Task `task_a36ce0781a7b` / Dispatch `ctx_2ef6d006f846`에 연결한다. 소급 문서 작성 배정으로 실행 이력을 바꾸지 않는다. native 기록에서 요청 모델은 설정 기본값이며 실효 모델·reasoning effort는 null이므로 이름을 추정하지 않는다.
