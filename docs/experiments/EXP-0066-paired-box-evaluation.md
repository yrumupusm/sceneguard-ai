# EXP-0066 — 사용자 보완: 같은 대상의 학습 전후 박스 비교

2026-11-08 사용자는 추가 학습 효과를 보려면 학습 전후를 비교해야 하며, 정답 구간에서 박스 검출 품질을 비교하자고 명확히 했다. 우선 질문은 ‘같은 모델의 추가 학습이 실제 관심 사람의 검출을 개선했는가’다. 서로 다른 모델의 후보 수 비교나 학습 후 검증 점수만으로 이 질문에 답하지 않는다.

## 비교 단위

학습 전/후에 같은 평가 원본·native 시점·입력 영역·해상도·후처리 조건을 사용한다. 평가 영상을 이용한 임계값 탐색은 하지 않는다. 같은 임계값 조건의 결과와 별도 개발자료로 정한 오탐 수준의 결과는 서로 구분한다. 실제 사용한 조건과 가중치 해시를 기록한다.

공식 행동 시간 구간은 평가할 시점의 범위를 정한다. 그 안에서 실제 관심 사람과 예측 박스를 대응시켜야 한다. 다른 사람의 박스, 합쳐진 두 사람, 배경 박스를 관심 사람 복구 성공으로 세지 않는다. 대상 박스 정답이 있으면 사전 고정 IoU로 검출/누락/위치 품질을 계산한다. 시간 정답만 있고 사람별 위치 정답이 없는 학교 장면은 기존 검수를 재사용하고, 미확정 대상 대응만 추가 검수한다. 시간 정답을 박스 정답으로 대체하지 않는다.

같은 대상·시점별로 ‘전후 모두 검출 / 학습 후 복구 / 학습 후 새 누락 / 전후 모두 누락’을 기록하고, 부분·합쳐진·중복 박스와 미확정 가림을 별도로 남긴다. 프레임 수를 독립 사람/사건 수로 부풀리지 않는다. 정상 보행·대기·접근과 배경의 오검출도 함께 보며, 양성 구간의 출력 증가만으로 전체 개선을 주장하지 않는다.

## 현재 실행과의 차이

현재 7개 모델의 고정 특징 기반 선형 분류기 학습은 사람 박스 좌표를 만드는 모델을 수정하지 않는다. EVAD/STMixer의 원래 박스와 사람 점수는 보존되므로 이 학습으로 검출기 박스 회복이 개선됐다고 주장할 수 없다. 새 행동 점수로 걸러진 박스 목록이 달라지는 것은 행동 후보 선택 변화이며 원래 검출 회복과 별도다. VideoMAE/V-JEPA/InternVideo의 현재 전체 장면 출력에는 박스가 없어 박스 검출 전후 비교 대상이 아니다.

YOLO26m/l/x는 크기별 동일 사전학습 가중치에서 시작하는 검출 모델 추가 학습 전후를 비교한다. 검수된 사람별 박스·행동 상태, 정상 사례, 촬영 그룹 분할을 먼저 확보한다. 사전학습 person 박스와 학습 후 행동 상태별 박스는 공통 사람 객체로 대응시켜 검출 효과를 평가하고, 월담 행동 지표는 별도다. 기존 보호45 및 EXP-0064 시험 자료는 학습·선택에서 제외한다.

이 문서는 평가 목적과 요구를 보완한 기록이다. 기존 진행 중인 작업·소스·결과를 변경하거나 검출 모델 추가 학습을 실행한 기록이 아니다. 기존 분류기 결과는 행동 분류 실험으로 보존하며 박스 개선 증거로 사용하지 않는다. 실제 박스 전후 평가, 검출 학습과 학교 성능 개선은 아직 미완료다.

## 사용자 후속 정정 — 전체 후보 유지

사용자는 ‘yolo만 할건 아니지않아?’라고 범위를 재확인했다. YOLO만 남기거나 기존 후보를 취소하지 않는다. 기존 8개와 YOLO26 세 개, 총 11개 구성을 유지한다. 직전 조정 설명의 YOLO 우선 표현을 후보 범위 축소로 적용하지 않는다. 진행 중인 단계의 강제 종료나 후속 중지 명령은 실행하지 않았다.

평가 설계는 다음과 같이 나눈다. 아래 추가 미세조정은 설계 요구이며 현재 실행 완료 또는 실행 설정 고정을 뜻하지 않는다.

| 비교군 | 기준 조건 | 추가 학습 조건 | 공통 평가 |
|---|---|---|---|
| YOLO26m/l/x, EVAD-B/L, STMixer | 각 모델의 고정 사전학습 검출 출력 | 같은 모델에서 검출 관련 가중치까지 추가 학습한 출력 | 동일 관심 사람·시점의 검출/누락/오검출/박스 품질. 행동은 별도 |
| VideoMAEv2, V-JEPA2, V-JEPA2.1, InternVideo | 사전학습 영상 모델 고정 + 학습한 공통 형식의 행동 분류기 | 같은 초기 영상 모델의 일부/전체를 미세조정 + 같은 형식의 행동 분류기 | 동일 평가 자료의 넘기 정밀도/재현율 및 정상 행동 오판. 박스 검출 지표 없음 |
| 기존 R3D18 EXP-0064 | 선택 가중치와 0.5 유지 | 현재 재학습 조건 없음 | 기존 행동 기준선. 새 미세조정 효과의 전후 쌍으로 가장하지 않음 |

영상 특징 모델의 두 조건은 모두 학습된 행동 분류기를 가져야 한다. 무작위 초기 분류기를 의미 있는 사전학습 행동 기준으로 사용하지 않는다. 이 쌍이 측정하는 효과는 영상 모델 가중치의 추가 미세조정 효과이며, 분류기 학습 자체의 유무와 구분한다. 현재 고정 모델 분류기 실행은 이 기준 조건을 제공하지만, 검수 부족·앉기 편중을 해결하기 전 해당 수치를 검증된 일반화 성능으로 승격하지 않는다.

검출 모델 여섯 구성의 새로운 미세조정에는 대상 박스·가림·정상 행동 라벨 감사가 선행되어야 한다. 기존 weak scene 학습 자료를 검출 정답으로 자동 승격하지 않는다. 조건별 데이터, 가중치 초기값, 학습 범위/예산, 입력, 선택 규칙과 검증/시험 분리를 실제 실행 전에 별도 동결하고, 현재 고정된 실행을 소급 변경하지 않는다.

## 실제 준비 점검

`scripts/audit_comparison_detector_labels.py`로 기존 선택 구간의 라벨 797개 해시와 대상 메타데이터를 확인했다. 3,984개 입력에 대상 주석 출현 4,309개, 중복을 합친 source/frame/actor/object 후보 4,298개가 있다. train 27촬영그룹/652원본 해시, validation 6그룹/140원본 해시로 교차 중복은 0이다. 선택된 대상의 양쪽 프레임 번호 해석 박스는 모두 양의 면적을 갖는다. 이 수치는 사람 수나 검수된 정답 수가 아니다.

정상 대상 주석은 학습에 moving 568·stand 893·앉기 552회, 검증에 앉기 314회가 있다. 이는 대상 주석 출현 횟수이며 고유 클립 수와 다르다. 검증 정상에는 보행·서 있기·접근 후 돌아가기의 구분 평가가 부족하다. 0/1 시작 해석에 따라 좌표가 다른 대상 주석 출현은 4,162개지만, 좌표 차이만으로 오주석이나 잘못된 시간 대응이라고 단정하지 않는다. 기존 검수의 적용 범위 밖 장면을 자동 확정하지 않는다.

화면 내 모든 가시 사람이 주석됐는지, 각 프레임의 대상 행동이 검수됐는지는 아직 보장되지 않는다. 이 목록을 검출 학습 데이터로 즉시 내보내지 않는다. 미주석 사람을 배경으로 학습시키지 않도록 전체 사람 라벨 완전성 또는 검증된 ignore 처리 방법을 먼저 정한다. [준비 점검 결과](../../records/EXP-0066/paired-data-readiness.json)는 `training_release=false`이고 검출 모델 추가 학습 횟수는 0이다.

재현 명령(새 출력 파일 사용):

```bash
python3 scripts/audit_comparison_detector_labels.py \
  --plan outputs/model-comparison/exp0066/head-plan-v2/manifest.json \
  --output runtime/model-comparison/exp0066/paired-preparation-v1/audit-v2.json
```

이 감사는 선택된 학습/검증 라벨만 읽었으며 보호 학교/시험 라벨과 영상 픽셀은 읽지 않았다.
