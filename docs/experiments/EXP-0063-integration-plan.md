# 첫 행동 모델 통합 비교의 고정 범위

사용자 요청의 행동 단독 평가를 먼저 수행한 뒤, 별도 구성으로 EXP-0062 AFTER에 행동 점수 관측층을 연결한다. 이 문서는 결과가 나오기 전에 고정하는 통합 계약이며 실행/성능 완료를 뜻하지 않는다. 학습 기준/임계값 선택에 기존45영상을 쓰지 않는다.

## 입력과 표본 시각

`baseline/attempt-002/baseline-lock.json`에 묶인45원본, 기존 FCOS 검출·추적 프레임과 EXP-0062 결과를 읽기 전용으로 사용한다. 새 사람 검출이나 추적기 교체, 기존 영역·사건 규칙 변경은 하지 않는다. 원래 tracking frames의 observed=true 실제 박스만 사용하며 소실 구간을 예측 박스로 채우지 않는다.

원본 PTS0에서 시작하는3FPS 목표 격자에 가장 가까운 native 프레임을 선택하되, 그 시각을 이용 가능한 시각으로 기록한다.29.97/30FPS 원본의 실제 선택 PTS를 보존한다. 선택한 시각마다 같은 track_id의 실제 박스가 있어야8프레임 행동 창을 구성한다. 첫8프레임 이후3프레임마다(약1초) 같은 방식으로 이동한다. 영상/트랙별 시각 예외는 없고 누락 창은 별도 집계한다. 창의 첫/마지막 관측 밖 시간을 참조하지 않는다.

ROI는 해당8관측의 실제 사람 박스 합집합을 학습 데이터와 동일한 주변 확장 정책으로 만든다. 학습의 공식 annotation ROI 분류와 이 검출 ROI 적용의 차이를 명시한다. 이미지 전처리·정규화·최종 validation-selected checkpoint·점수0.5 기준은 학습 실험에서 고정한 것을 그대로 사용한다.

## 출력 의미와 비교

행동 점수0.5 이상은 `climbing_action_candidate`로 표시한다. 이것은 대상 사람의 넘기 동작 후보이며 침입 완료·방향·출입 금지 여부·사람 동일성의 정답이 아니다. 첫 통합에서 행동 점수만으로 기존 침입 확인이나 해제 상태를 바꾸지 않는다. EXP-0062 원래 사건 상태·최초 통지·확인 시각은 별도 보존하고 행동 후보를 함께 표시한다.

45개 회귀 보고서는 원래 침입 판단의 동일성, 실제 행동 모델 실행 범위, 트랙/박스 불충분으로 실행하지 못한 창, 행동 후보 수·시각·기존 사건과의 관측상 관계를 구분한다. 침입 지표가 같다는 것은 이 구성의 보존 성질이며 학습 모델의 성능 개선을 뜻하지 않는다. 기존 공식52시간참조와006미확정·008보류를 유지한다. 실제 동작 정답이 부족한 후보의 정밀도/재현율은null로 남긴다.

새 시험 자료에서는 먼저 공식 actor-event 라벨 기준 분류 지표를 같은 장소 별도 촬영/별도 장소로 나눈다. 그 지표를 사람 검출 성능·실제 침입 완료 성능으로 부르지 않는다. 실패는 가능한 근거에 따라 검출/추적 관측 부족, 행동 분류 참조라벨 불일치, 기존 사건 판정 오류로 나누며 사람 정답이 부족한 원인은 미확정으로 남긴다. 대표 실패 영상은 원본 시각·예측·라벨 출처와 함께 로컬에만 저장한다.

## 실행 전 조건

공식 라벨 참조 학습의 실제 smoke와 첫 학습·단독 시험을 완료한 다음 통합을 실행한다. 학습 데이터/임계값을45결과로 수정하지 않는다. 새 GPU 행동 추론도 동일 canonical 큐와 독립 검토를 거친 별도 작업으로 기록한다. 기존 결과/기본 시연은 보존한다.
