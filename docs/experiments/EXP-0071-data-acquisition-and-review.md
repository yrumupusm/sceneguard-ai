# EXP-0071 — 자료 확보 재조사와 모든 사람 박스 검수 준비

2026-11-09. **누락 ZIP 6개와 그 안의 원본·라벨은 검색한 위치에서 회수하지 못했다. 새 독립 시험용 월담 영상도 아직 확정하지 못했다.** 대신 기존 보유 자료의 짧은 5구간, 122프레임에 모든 사람 검출 후보를 표시한 검수 초안을 만들었다. 기존에 확인한 75프레임은 다시 묻지 않는다. 이번 작업은 자료 확보 감사와 검수 준비이며, 재학습·성능 비교·모델 채택은 없다.

## 누락 ZIP 검색과 복구 경로

C·D·E·F 드라이브의 접근 가능한 경로, 사용자 홈과 임시 폴더에서 파일명·분할 압축 파일·공원 원본/라벨 추출본을 검색했다. 과거 목록 6,534쌍의 member 이름과 검색 결과를 대조했다. Windows 최근 항목의 원천 ZIP1/3/4 바로가기는 발견했지만 실제 ZIP 또는 추출본으로 세지 않았다. 사용자 다운로드의 `SceneGuard_FCOS_miss_comparison` ZIP 두 개는 비교 명세 JSON/README이며 영상 공급원이 아니다.

검색 로그에는 접근 거절 등이 남아 있다. 읽을 수 없는 시스템/휴지통 영역이나 연결되지 않은 외장·네트워크 저장소까지 없다고 단정하지 않는다. 파일이 다른 이름으로 재인코딩되었거나 임의 이름의 다른 압축 파일 안에 든 경우도 이 파일명 중심 조사만으로 배제하지 못한다. 검색 원문·오류·member 대조와 해시는 로컬 감사 자료에 보존했다.

재다운로드는 [AI-Hub 공원 주요시설 및 불법행위 감시 CCTV 영상 데이터](https://www.aihub.or.kr/aihubdata/data/view.do?currMenu=115&dataSetSn=477&topMenu=100)의 다운로드/파일 목록에서 다음 여섯 항목을 선택한다. 사이트의 데이터셋 ID는 477이며, 로컬 폴더 앞의 173과 구분한다.

## 새 시험 월담 조사

AI-Hub07의 보유 269개 사건 라벨 중 학교45 밖의 침입 원본 E01_051–055를 추가 조사했다. 다섯 원본의 실제 바이트와 라벨을 읽고 해시, native FPS, 길이, 사건 프레임을 확인했다. 모두 1920×1080·30 FPS이며 길이는 약 134.067–185.400초다. 이 자료는 별도의 검증 ZIP에 있지만 ZIP의 Training/Validation 구분이 우리 실험의 독립성을 보증하지 않는다.

다섯 라벨의 촬영일은 기존 학교45 중 12개와 같다. 제한된 시각 지문에서도 4원본에 기존 학교 영상과의 유사 신호가 있다. 정확한 파일 해시 일치가 없다는 사실이나 나머지 1개에 지문 신호가 없다는 사실만으로 다른 촬영 사건이라 확정하지 않는다. 같은 카메라 배경의 유사 신호도 동일 사건 확정과 다르다. 원래 사건 라벨은 사람별 완전한 박스가 아니며, 선언 행동/시작·끝을 실제 의미 정답으로 승격하지 않았다.

다섯 원본은 촬영 로그·실제 카메라·시간 대응과 기존45의 부분/시간 이동/멀티카메라 관계를 확인할 때까지 보류한다. 학습·개발로 이동시키지 않으며 새 시험 성능의 분모에도 아직 넣지 않는다. 이번에는 영상 의미 검수를 완료하지 않았다. 자세한 수치·검색 한계는 [획득 감사](EXP-0071-acquisition-audit.md)에 있다.

## 사람 박스 검수 초안과 웹 질문

EXP70의 기존 연결 묶음, 분할 예약, 보호 입력 해시와 원본 해시를 확인한 후보부터 **예약 간 알려진 충돌이 없는 초안**을 만들었다. 프레임 추출 전에 선택 목록을 저장했다. 촬영 독립성이 모두 인증되었다는 뜻은 아니므로 최종 데이터셋 release는 계속 false다. 학습 예약 P16/P18은 같은 묶음, P20/P21은 같은 묶음으로 유지하고 개발 P05는 개발 예약을 유지한다. 각 묶음의 연관 원본을 다른 분할로 나누지 않는다. 선택된 세 예약은 272개 연관 member를 포함한다. 그중 기존 격리 sibling 4개는 이번 초안에 사용하지 않았다.

| 묶음 | 검수 ID / EXP70 후보 | 예약 | 원본 시간 | 프레임 | 확인할 대상 |
|---|---|---|---|---:|---|
| 1 | R01 / P16 | 학습 | 21.000–28.667초 | 24 | 화면 위쪽 먼 보행인, 작은 사람 누락 |
| 1 | R02 / P20 | 학습 | 95.333–103.000초 | 24 | 월담자·동행자·울타리/기둥에 가려진 사람 |
| 1 | R03 / P05 | 개발 | 54.000–62.000초 | 25 | 이동하는 사람·주변 보행인; 후반 보행과 앞부분 행동은 구분 |
| 2 | R04 / P18 | 학습 | 19.333–27.000초 | 24 | 서 있는 사람도 포함한 모든 인물 |
| 2 | R05 / P05 | 개발 | 0.000–8.000초 | 25 | 먼 배경까지 실제 사람이 없는지 |

기존 EXP67 P21의33–41초, P18의53–61초, 기존 사례5의13.333–21.333초는 이번 질문에 포함하지 않았다. 기존 answer_version=1 세 답변과 이전 EXP66 범위 검수는 출처와 적용 범위를 보존한다. 신규/수정 답변 및 확인 후 미처리 답변 조회도 성공했고 작업 시작과 등록 전에는 0건이었다.

기존 로컬 YOLO26x 사전학습 가중치를 CPU에서만 실행해 모든 프레임의 사람 후보 227박스를 얻었다. 이는 227명이나 227개 확정 정답이 아니다. 입력640, person 후보 저장 기준0.05, FP32, 증강 없음이며 원본 전체 화면을 사용했다. 검수에서 작은 사람 후보도 보이게 하기 위한 초안 조건으로, 기존 비교 실험의 사람 임계값0.5나 행동 모델의0.5를 바꾼 것이 아니다. 모델 점수는 사람 검출 점수이며 넘기 행동 점수가 아니다. 원래 actor 라벨은 원점0/1의 참고 정보로 별도 JSON에 두고, 모델 후보와 합쳐 정답으로 만들지 않았다.

비교 영상은 왼쪽 원본, 오른쪽 주황색 제안 박스와 원본 PTS를 표시한다. 각 구간의 전체 해상도 원본/박스 정지화면도 로컬에 보존했다. 박스가 없는 26프레임 중 25개는 R05이고 나머지 1개는 R01이다. 어느 쪽도 자동 빈 배경으로 처리하지 않는다.

기존 웹의 EXP-0071에서 두 묶음의 다섯 질문을 등록하는 구성이다. 실제 등록·재생 확인은 별도 [전달 기록](EXP-0071-delivery.md)에 남긴다. 질문은 누락/잘못된 박스의 원본 시간과 화면 위치를 요청한다. 사용자 답변이 오면 정확한 답변 버전에 연결해 누락 인물을 추가하고, 위치·크기·가림·프레임별 완전성을 확인한다. 단순한 전체 구간 확인 답변을 정밀 좌표 인증이나 자동 학습 승인으로 확대하지 않는다.

남은 29후보 전체의 범위/보류 이유는 로컬 `all-candidate-review-queue.json`에 연결했다. 이번에 초안을 만든 것은 그중 4원본의5구간이다. 모든 후보의 박스 보완이 끝났다고 보고하지 않는다. P06/P08/P12의 장소 기록 충돌, P19/P22의 개발 배경과 겹치는 학습 보류 및 EXP70의 나머지 보호 조건을 유지한다.

## 외부에서 필요한 자료와 라벨

우선 부족한 것은 **새 촬영의 월담 양성**과 **문에 접근했다가 돌아가기/문 앞 대기**다. 정상 앉기만 늘려서는 이 공백을 채울 수 없다. 파일 수를 맞추기보다 아래 조건이 서로 다른 실제 촬영 사건에서 확보되는지 확인해야 한다.

| 촬영 조건 | 확보할 장면과 기록 |
|---|---|
| 독립성 | 기존 학교45·EXP64 시험·학습/개발과 다른 촬영 세션. 장소·카메라 고정 ID, 촬영일/시작시각, 사건 ID, 동시에 촬영한 모든 카메라와 재편집/추출 관계를 제공 |
| 월담 양성 | 충분한 높이의 문·담장, 접근→기대기/올라타기→넘기→반대편 이동의 전후 문맥. 낮은 울타리·가림 거의 없는 사용자 제외 조건으로만 채우지 않음 |
| 어려운 관측 | 먼 작은 사람, 철문/기둥/나무/다른 사람 가림, 일부 몸만 보임, 역광·저조도. 해상도뿐 아니라 원본/640입력에서의 사람 높이 분포를 기록 |
| 정상 대조 | 같은 문 주변의 보행, 실제 대기, 접근 후 돌아감, 몸 굽힘·앉기, 여러 사람이 함께 이동. 모든 정상 구간을 앉기로 대체하지 않음 |
| 빈 배경 | 사람 없는 것으로 사람이 확인한 연속 구간. 나무·현수막·차량/그림자 등 오검출 원인과 조명 변화를 포함하고 먼 배경도 확인 |
| 영상 보존 | 원본 FPS·PTS·해상도와 타임베이스, 누락 프레임/편집 이력. 가능한 원본 연속 영상과 충분한 앞뒤 문맥, 합법적으로 사용할 수 있는 이용 조건 |

검출 정답은 평가할 **모든 프레임의 모든 보이는 사람**을 포함해야 한다. 원본 decoded index·PTS와 박스 좌표계, 가림/화면 잘림, 불명확하여 평가에서 제외할 영역을 기록한다. 완전히 가려진 사람을 추측한 박스로 채우지 않는다. 시간에 따른 대상 연결과 행동 구간은 별도 필드로 두며, 사람 검출 성공·넘기 행동·침입 완료를 분리한다. 행동 시작·끝의 정의와 불확실 구간도 남긴다. 월담자만 표시된 라벨이나 아무 라벨 없는 프레임을 완전한 정답으로 받아들이지 않는다.

같은 사건의 모든 카메라·후속 클립은 한 분할에 넣는다. 출처가 불명확하면 큰 촬영 묶음 전체를 보류하며, 시험 후보를 보고 학습 조건·임계값을 선택하지 않는다. 기존 보호 자료는 계속 회귀/보호 시험으로 남기고 부족한 학습·개발을 채우는 데 사용하지 않는다.
