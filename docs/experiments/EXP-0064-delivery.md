## 실제 등록과 브라우저 확인

최초 등록은 package 제목이 기존 배정 제목과 달라 검증 단계에서 거절됐다. 배정 원문은 바꾸지 않고 package 제목을 원래 제목과 맞췄으며, 원래 실패 receipt와 새 성공 receipt를 모두 보존했다. 성공 이후 동일 입력 재호출은 중복을 만들지 않았다. EXP-0063의 등록 원문·측정값·검토·binding 네 파일과 이전 카탈로그 66행은 동일하다.

첫 브라우저 검사는 오래 열린 탭의 구형 JavaScript 화면에 WEB-0004 이후의 표 구조가 없어 실패했다. 실제 서버가 제공한 `webapp/app.js`는 현재 파일과 같았고, 해당 탭만 새로고침한 뒤 새 receipt로 다시 확인했다. 서버·모델·등록 값을 변경해 통과시킨 것이 아니다.

`browser-receipt-v2.json`에서 EXP-0064 선택, API 원문/검토 네 해시 일치, 실제 표시된 39개 측정값과 표본 수, 미측정 표기를 확인했다. 960×630 영상 두 개는 각각 0.215943초·0.215602초까지 실제 재생했고 1.333333초로 seek한 뒤 0초로 되감았다. 그림 두 개는 각각 1920×768, 1950×825로 디코딩됐다. 16.5초 폴링 관찰 중 muted 첫 영상의 재생과 노드를 유지했고 추가 디코딩 44프레임·timeupdate 63회를 확인했다. 영상 의미를 새로 검수한 것이 아니며 원시 픽셀을 외부 이미지 도구로 전송하지 않았다.

실제 제공된 viewer JS SHA는 `8c7efc6403525fa2693906e50295d6d605b83c8abba790dbcf4e673660c5ccef`다. 이번 browser probe에는 검토 당시 버전에 그림의 실제 디코딩 확인만 추가했으며, 현재 실행 파일과 실패·성공 receipt를 로컬에 보존했다. 세 담당 모두 실제 성공 `worker_done`을 수신했고 release 결과는 기존 외부 터미널이어서 `retained / external_terminal / processAction none`이었다. 사용자 터미널을 임의로 닫지 않았다.
