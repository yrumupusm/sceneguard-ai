# BATCH-0005 — 고정 C6 ROI 비교 실행 완료, 기본 적용 보류

2026-10-29 KST. **YOLO26m-Pose의 같은 설정에서 신규5개 조건이 모두 정상 실행됐고, 기존90초 전체화면 결과1개를 재사용했다.** C6 ROI에서는84·90초의 박스/관절 추정이 늘었지만94초는 여전히 빈 결과다. 박스 수 증가를 실제 인물·관절 복원 성공으로 해석하지 않으며 기본 구성은 유지한다.

## 구현·실행과 비용

기존 C6 `[.28,.20,.75,.80]`에서 원본 RGB의 x537:1440/y216:864,903×648만 잘랐다. 같은 Ultralytics8.4.192·공식 체크포인트·640/FP32/conf.25/nmsFalse·나머지 public kwargs를 유지했다. ROI local Results의 유효성을 먼저 판단하고 원본 표현에 (+537,+216)을 한 번만 적용한다. unknown은 그대로 unknown이며 full-frame Results에는 변환이 없다. 입력 시야·인물 크기·letterbox가 함께 달라져 이들 효과를 분리한 비교는 아니다.

기존 Run/단일 GPU 큐에서 source `62fe072bdd70f4e3eeb8c51a4984b96f221fea41`, job `7c366be9bf694ce7a476a47119419ca2`, attempt `90784d50902748b9956101771e27662b`로 실행했다. 담당 CPU 검사23개와 독립 합성 검사7개가 통과했다. one model load·새 public predict/sample forward5회·별도 warmup forward1회, 오류/OOM/retry0이다. 정상 empty는 기술 실패나 재시도 사유가 아니다. 기존40 jobs/attempts와 입력·가중치·batch04 소스를 보존했다.

## 다음 결정

**권고 한 가지: 이번 세 로컬 비교 이미지에서 새 ROI 출력의 실제 신체·관절 대응을 먼저 확정한다.** 90초의1행/12추정이 유용한 관절인지,84초의 증가가 중복 없이 맞는 사람인지,94초의 빈 결과가 어떤 가시성 한계를 남기는지를 확인하는 것이 다음 결정의 근거다. 현재는 추정 수 증가만 확인돼 기본 적용·추적·행동 규칙·CV+VLM 결합을 보류한다. 새로운 조건이나267전체 처리, 모델/ROI/임계값 변경을 자동 예약하지 않는다.
