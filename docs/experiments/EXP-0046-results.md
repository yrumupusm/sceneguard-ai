# EXP-0046 — 문 주변 고정 구역의 새 출현 비교

2026-11-01. **실제 저장 관측 비교 완료, 기본 적용 보류.** 기존 바닥 방식의 B는 두 영상 모두 0건이었고 문 구역 방식은 007 8건, 030 12건이다. 위치 조건이 막던 관측 일부를 살렸지만 알려진 접근·대기 문맥에서도 의심이 생긴다. 007의 후반 작은 박스와 030의 일부 작은 첫 박스는 여전히 제외된다. 후보 증가를 침입 판단 성능 향상으로 해석하지 않는다.

EXP-0045 방향＋소실 A의 자동 확인 3근거와 모든 원래 18후보를 보존했다. 다만 결합 보기에서는 원래 첫 통지 5개 중 4개가 앞선 카드의 갱신으로 흡수된다. 원래 보기와 A 보존 보기를 유지하고 기본 MVP는 교체하지 않는다. 등록·게시·실제 브라우저 확인은 별도 [전달 기록](EXP-0046-delivery.md)으로 구분한다.

## 조건과 실제 변경

변경 없는 60ea8b9에 main 9a228c0를 반영했다. [실행 전 조건](EXP-0046-protocol.md)에 따라 기존 Run과 환경에서 007 48–105초 1,710프레임, 030 84–100초 480프레임을 각각 한 번 CPU 처리했다. 실제 관측은 EXP-0042, 원래 알림은 EXP-0035, A 결과는 EXP-0045를 재사용했다. 검출·추적·flow·VLM 호출과 모델 다운로드·학습은 모두 0이다.

최초 정지 배경 초안을 사용자에게 보여주었고, 사용자는 두 구역이 문 높이보다 너무 크다고 지적하며 수정 윤곽을 직접 제공했다. 그 윤곽을 각각 5개 꼭짓점으로 근사 반영한 뒤 첫 실행 전에 고정했다. 처음 초안은 보존했으며 초안 조건으로 비교 실행하거나 결과에 맞춰 영역을 재조정하지 않았다. 기존 바닥선·안팎 영역·가림 주석은 바꾸지 않았다. 007은 승인 inside 수정본을 명시 사용했다.

B의 첫 실제 박스 중심이 새 다각형 안에 있거나 박스 면적의 0.5 이상이 겹치면 위치 조건을 통과한다. 기존 바닥 거리, 박스 높이 비례 반경, 선 투영, ground inside는 진단값이며 필수 조건으로 재삽입하지 않았다. 관측열 연결·중복 정리·lookback·warmup·시간 지지는 EXP-0045 그대로다. B 단독은 침입 의심이다. 새 관측열은 새 사람이나 실제 안쪽 출현의 정답이 아니다.

## 검증·근거·한계

독립 검토는 실제 전체 2,190프레임의 관측과 222첫 위치, 20새 B의 입력 참조·ID·시간 지지·기하를 판정 엔진 재실행 없이 대조했다. 옛 B가 EXP-0045를 정확히 재현하고, 옛/새 연결 상태가 매프레임 동일하며, A와 원래 이벤트 payload를 보존하는 계약을 검증했다. 합성/통합 시험은 CCTV 성능 정답이 아니다. 자세한 시험과 최종 문서 해시 결속은 [독립 검토](../reviews/EXP-0046-independent-review.md)를 따른다.

로컬 `outputs/exp0046/{007,030}-v1/`에 baseline/history/portal-only/combined 카드와 전체 첫 관측 감사, 원본 PTS를 표시한 비교 영상을 보관한다. 원본 패널은 관측 오버레이 없이 표시하고 근거 패널에는 첫/현재/과거 실제 박스와 원본 시각을 구분한다. 과거 박스는 점선이며 현재 위치나 예측으로 표현하지 않는다. 정지 범위 미리보기는 `outputs/exp0046/portal-preview/`다.

기존 사용자 관찰은 재사용한다. 새 B의 개별 동일인·첫 박스 출현 의미는 전부 사용자 확정된 것이 아니며 미확정을 남긴다. 007 65.5–69초와 030 87.2–90.5초의 두 짧은 비교 영상을 한 번에 제시해 새 출현/재검출·중복/판단 어려움의 구분만 요청했다. 이 보고서의 수치·결론을 동결할 때 답변은 대기 상태이며, 이후 답변은 별도 관찰 기록으로 남긴다. 기다린 시간을 근거로 사람 검수를 완료했다고 처리하지 않는다.

전체 2개, B 후보별 20개, A 근거 3개, 위 두 검수용과 두 위치 탈락 진단을 합해 로컬 비교 영상 29개를 생성했다. 최초 미디어 생성은 007 81.372746초, 030 58.867769초이며 판정 시간과 별개다. 4,514개 인코딩 프레임의 시각 연결을 검사했다. 이는 중복 표시 프레임을 포함한 제작량이며 새로운 평가 표본 수가 아니다.

정확도·F1·시간당 오탐률·일반화 성능은 산출하지 않는다. 구현과 실제 CPU 비교의 완료, 행동 판별 성능의 미달, 웹 전달 확인은 서로 별개다. 이번에는 후속 조건 추가나 임계값·영역 탐색 없이 종료하고 기존 MVP를 유지한다.
