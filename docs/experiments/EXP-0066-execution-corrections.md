# EXP-0066 실행 중 발견한 오류와 수정 근거

2026-11-07. 아래는 실제 실행·출력 검증에서 발견한 문제다. 기존 결과를 덮어쓰지 않으며, 실행 성공과 올바른 좌표·행동 성능을 구분한다.

## 실행 시간 상한

첫 다섯 모델의 소량 실행은 성공했다. 실제 창별 처리 시간을 전체 6,219창에 적용하면 일부 모델은 기존 3,600초 한도에 가까워질 수 있어 `model-compare`에만 14,400초 상한을 적용했다. 다른 큐 명령의 한도, GPU 잠금, 활성 배정·소스·입력 검증은 유지한다. 이는 전체 실행의 실측 완료 시간이나 속도 개선이 아니다. 수정 커밋은 `de8c22bc1df8c77269b035b3e5df51f8bf9a94ce`다.

## EVAD 박스의 중복 좌표 변환

EVAD-B의 `ff2c9a438c984f59a58b6417fbf33cfd`, EVAD-L의 `815139b6611b4eff99b5308875cf2597`은 각각 7창·24,155프레임을 처리하고 정상 종료했다. 그러나 실제 비교 화면에서 높은 사람 점수의 박스가 화면 오른쪽·아래 끝으로 잘리는 문제가 발견됐다. 따라서 이 두 결과는 올바른 사람 검출 비교에 사용할 수 없다.

공식 EVAD 코드는 detection head가 반환한 박스 텐서를 참조한 채 후처리에서 그 저장 공간을 원본 픽셀 좌표로 바꾼다. 준비 코드의 hook 역시 같은 텐서를 참조했는데, 이 값에 다시 resize 역변환을 적용했다. 512×288 입력에서 `[100, 50, 200, 150]`인 박스는 원본 1920×1080에서 `[375, 187.5, 750, 562.5]`여야 하지만, 잘못된 추가 변환과 잘림을 거쳐 `[1406.25, 703.125, 1920, 1080]`으로 저장됐다.

수정은 공식 반환값의 원본 좌표 사람 박스를 그대로 사용한다. 동시에 공식 행동 박스의 정규화 좌표에 원본 너비·높이를 곱한 값과 일치하는지, 100개 query의 순서와 batch가 같은지 검사한다. 공식 후처리 함수의 실제 저장 공간 변경을 실행하는 CPU 회귀 시험을 추가했다. 모델 가중치·입력·정밀도·사람 점수 기준을 바꾼 수정이 아니다.

처음의 유한 값·범위·독립 역변환 시험만으로는 이 텐서 공유 문제를 발견하지 못했다. 독립 검토도 초기 전체 실행 준비 통과 판단을 철회했다. 철회 기록은 로컬 `independent-joint-review/evad-readiness-revocation-v1.json`에 있으며, 원래 출력은 오류 이력으로 보존한다. 이미 잘린 좌표를 사후 계산으로 복구했다고 주장하지 않는다. 수정 소스에 대한 새 소량 실행과 좌표 대조가 필요하다.

## STMixer 실행 후 한글 메타데이터 읽기 실패

STMixer의 `4ebd7864eaec417c8e114d24fa81988e`는 7창 출력 뒤 최종 입력 무결성 검사에서 `UnicodeDecodeError`로 종료 코드 1을 반환했다. 당시 기본 텍스트 인코딩이 ASCII여서 한글이 들어간 cohort JSON을 읽지 못했다. 성공 `result.json`이 없으므로 이 시도를 소량 실행 성공으로 세거나 최대 GPU 메모리를 측정 완료로 표시하지 않는다. OOM·모델 추론 실패로 분류할 근거도 없다.

비교 명령·실행기·joint adapter의 JSON 읽기를 UTF-8로 명시했다. `LC_CTYPE=C` 상태에서도 한글 JSON을 읽는 회귀 시험을 추가했다. 기존 행동 학습 명령과 모델 환경은 수정하지 않는다. 이 수정 뒤의 새 실행은 별도 revision으로 기록하며 이전 실패 기록을 보존한다.

## 검수 자료의 제한

예비 `review-smoke-v2` 화면의 EVAD 박스는 위 오류 때문에 검수용으로 사용하지 않는다. 새 렌더러는 수정 이전 EVAD 출력을 거부한다. 결과 파일·큐의 실제 성공 기록·원본 및 계획 해시를 대조하고, 전체 결과를 순차적으로 읽되 화면에 필요한 진단 창만 메모리에 보관한다. 박스 수를 사람 수·복구 성공 수로 세지 않고 전용 행동 head가 없는 모델의 넘기 후보 수는 미측정으로 표시한다.

수정 코드 시험과 실제 모델 실행, 실제 인물 대응 검수는 각각 별도 단계다. 이 문서의 오류 수정만으로 모델 비교나 성능 개선이 완료된 것은 아니다.

## 임시 미리보기의 재생 위치 이동

수정된 8개 모델의 소량 결과를 모은 `review-smoke-v4`에서 재생·이동을 다시 확인했다. 기존 Orca 내장 브라우저 호출은 시간 초과가 반복됐으며, 별도 로컬 Chromium에서도 이동 시각이 0으로 돌아가는 현상을 재현했다. 이때 실제 재생 시작은 성공했고 실패 위치는 seek 검사였다. 영상 오류나 모델 계산 실패로 분류하지 않는다.

임시 Python 기본 HTTP 서버가 영상 byte range 요청을 지원하지 않았다. 로컬 전용 임시 서버에 구간 요청과 `206 Content-Range` 응답을 적용한 뒤, 같은 영상 바이트로 7개 샘플의 재생·중간 위치 이동·되감기 및 63개 모델 선택(8개 비교 모델과 FCOS)을 확인했다. 실제 근거는 `runtime/model-comparison/exp0066/local-headless-browser-v4-range.json`이다. 앞선 실패 로그도 보존한다. 최종 기존 웹 등록 화면이나 새 행동 head 표시 검증을 완료했다는 뜻은 아니다.

이 검사는 GPU를 끈 별도 로컬 Chromium에서 실행했다. 필요한 세 라이브러리는 실험 runtime 안에만 내려받아 풀었고, 시스템 패키지나 모델 가상환경은 수정하지 않았다. 영상·이미지를 외부 서비스로 업로드하지 않았다.

## 전용 행동 점수와 실제 query 대응

새 head 표시 초안은 점수 파일의 모델·query 좌표와 원래 모델 출력을 충분히 대조하지 않았다. 독립 합성 반례로 이 부족을 확인한 뒤, 전체 점수와 원래 출력의 같은 창을 순차 대조하도록 보완했다. 모델명, 원본/창, 박스·사람 점수, query 개수·번호, 사람과 행동의 결합 조건, 실제 성공 학습 영수증 및 점수 생성 소스 해시가 다르면 표시를 거절한다. 10개 출처·표시 시험과 독립 100-query 반례 검사를 통과했다. 실제 head 점수는 생성 뒤 별도로 확인한다.

## 원거리 인물 검수를 위한 원본 해상도 표시

960픽셀 미리보기만으로 원거리의 작은 사람을 자세히 보기 어려워, 같은 실제 anchor 프레임을 원본 해상도 JPEG로도 저장한다. 새 로컬 화면은 원본 해상도와 화면 맞춤을 전환하며 박스 표시 기준을 유지한다. 비교 이미지의 선택 사항 `--native-resolution`은 원본 JPEG 해시·크기를 검사하고 같은 좌표와 비율로 박스·문자를 표시한다. 모델 입력 크기·추론·평가 임계값을 바꾸지 않는다.

`review-smoke-v5-native`의 실제 7개 샘플에서 원본 1920픽셀 확대·복귀, 표시 기준 유지, 63개 모델 선택과 재생·위치 이동·되감기를 로컬 Chromium으로 확인했다. 근거는 `runtime/model-comparison/exp0066/local-headless-browser-v5-native.json`이다. 기존 미리보기와 그 소스 해시가 일치하는 이전 렌더러 사본은 보존했다. 이 검증은 사람 대응 정답이나 최종 8개 전체 실행·head 표시 완료가 아니다.

독립 검토에서 v4와 v5의 7개 미리보기 MP4가 바이트·디코딩 RGB까지 동일하지는 않음을 확인했다. 16개 시점의 PTS, 모델 출력·입력 창·검수 메타데이터와 작은 anchor JPEG는 같았다. 표시 영상은 손실 압축을 다시 거친 결과이며 실제 모델 입력이 바뀌었다는 뜻이 아니다. 차이의 구체적인 인코더 원인은 확정하지 않는다. 이후 생성에서는 PyAV/OpenCV·인코딩 라이브러리 버전과 압축 설정, 원본에서 선택한 각 RGB 프레임 해시를 함께 저장한다. 이전 미리보기 파일을 덮어쓰거나 동일 바이트라고 주장하지 않는다.

## 여덟 모델 점수 표와 임계값 표시

기존 웹의 정적 비교 이미지에도 네 개의 실제 박스 화면 아래 여덟 모델 점수 표를 추가했다. 사람 박스를 출력하는 세 모델은 실제 사람 표시 기준을 통과한 유효 후보 중 최고 행동 점수와 해당 시점 후보 번호를 표시한다. 전체 장면 분류기는 사람 위치를 특정하지 않는다고 명시한다. 전용 head가 아직 없으면 점수·판정은 미측정으로 남기며 0으로 바꾸지 않는다. 최고 점수의 인물이 관심 대상과 같다는 판단은 별도 검수다.

엄격한 음성 점수 경계 선택에서 임계값이 1보다 아주 조금 클 수 있다. 이를 짧게 반올림해 1로 표시하면 점수 1을 허용하는 것처럼 오해할 수 있어, 표·박스 화면 머리말·로컬 HTML 모두 이 경우 모든 점수가 제외된다고 표시한다. 계산 임계값은 바꾸지 않았다. 낮은 사람 점수·무효 박스의 높은 행동 점수를 제외하고 미생성 head를 미측정으로 유지하는 두 반례 시험을 통과했다.

독립 검토는 기존 v6 이미지 7개의 총 56개 표 행을 실제 저장 출력과 대조했다. R3D 점수와 0.5 판정, 다른 일곱 head의 미측정 표시 및 원본 해상도 이미지 출처가 일치했다. 이후 머리말의 임계값 반올림 문제를 수정한 최신 소스와 JavaScript 경계값도 별도로 확인했다. 근거는 `independent-joint-review/score-table-actual-v6-review.json` 및 `score-table-fixed-source-review.json`이다. 실제 학습 head 점수가 포함된 최종 이미지 검증은 그 점수를 생성한 뒤 진행한다.

## 학습 입력의 동일 내용 파일 경로 검증

일곱 분류기의 첫 실행 명세를 실제 입력 검사에 넣자 22개 창에서 CPU 준비 영수증의 대표 경로와 입력 계획의 별도 경로가 달라 거부됐다. 준비 단계는 동일 SHA256의 원본을 한 번 디코딩하고, 다른 이름의 다섯 파일도 별도로 해시 확인해 `source_alias_bindings`에 기록했다. 실행기는 이 정보를 사용하지 않고 모든 경로가 대표 경로와 문자 단위로 같아야 한다고 검사했다. 학습용 GPU 실행이나 큐 등록 전에 발견됐으며 원본·라벨 내용이 다르다는 판정은 아니다.

수정은 준비 영수증의 원본 SHA256·해상도·time base가 일치하고, 다른 경로는 고정된 준비 결과의 별도 경로 목록에 같은 SHA256으로 등록된 경우에만 허용한다. 실행 직전 선택한 각 원본 파일과 해당 라벨의 현재 해시를 다시 검증하는 절차는 유지한다. 임의 경로를 허용하거나 대표 파일의 라벨을 다른 파일에 빌려주지 않는다. 미등록 경로·다른 해시·다른 해상도/시계의 거부 시험과 실제 고정 계획의 22개 별도 경로 창 회귀를 추가했다. 앞선 실행 후보는 실행하지 않은 거부 이력으로 보존하며 수정 소스는 새 버전으로 검토한다.

수정 뒤 관련 시험 31개와 독립 검토의 실제 일곱 모델 소량 입력 계약 검사를 통과했다. 별도로 전체 입력 계약은 797개 원본 경로와 797개 라벨 파일의 현재 바이트 검증까지 성공했다. 로컬 근거는 `head-queue-integration/alias-preflight-v2/result.json`과 `independent-joint-review/head-alias-fixed-smoke-contracts.json`이다. 이 검사는 읽기 전용이며 큐 등록·모델 추론·학습은 없었다.
