# EXP-0074 사람 검출 기준선과 첫 A/B/C 비교 준비

2026-11-09. **사람 라벨 수정 반영과 사전학습 YOLO26m 기준선 평가는 실행했다. B/C 재학습은 실행하지 않았다.** 현재 개발 자료는 기존 검출 유지·새 누락·오검출 확인에 쓸 수 있지만, A가 놓친 정답이0개여서 누락 회복 효과를 측정할 분모가 없다. 작은 사람 조건3프레임만 추가 검수로 준비했다.

## 승인 라벨 반영과 사용 가능한 자료

사용자가 대화에서 직접 전달한 오류 관찰과 수정 승인을 재사용했다. 기존 웹 기록은 그 관찰을 연결해 보존한 이력이며 웹에서 다시 답해야 하는 조건이 아니다. 주간20초의 밑변 수정본1개와 야간23.667·24·24.333·25초의 오른쪽 사람4개, 총5개 승인 좌표를 새 보완 라벨에 실제 반영했다. 개발 P01의 지정 위치 배경 후보17개 제거도 유지했다. 박스 번호를 고정 제거하는 규칙이나 운영 검출 ROI는 만들지 않았다.

야간23.333초는 전체 프레임을 제외한다. 나머지71프레임의 보완본에는167개 박스가 있고 그중5개만 이번 좌표 승인이 명시돼 있다. 남은162개 초안을 전체 사람 정답으로 자동 승격하지 않았다. 보완본은 별도 불완전 YOLO 라벨과 승인 근거로 저장했고 표준 학습·개발 목록에는 넣지 않았다. 기존197프레임은 원래 검수된 이미지·좌표·답변 버전을 유지한다.

|---|---:|---:|---|
| 학습 | 122 | 333 | 기존50 + 보강72. 작은 보행인·서 있기·월담자와 동행자 포함 |

| 야간23.333초 | 1 | 미확정 | 전체 제외 유지, 빈 배경으로 사용하지 않음 |

P05는 전체 원본의 행동 종류와 무관하게 검수한 사람·빈 배경 프레임을 개발에 포함했다. P01도 개발 예약01로 사용할 수 있으나 남은 작은 대상·중복과 전체 사람 라벨이 미확정이다. P01을 월담 영상이라는 이유로 제외하지 않는다.

학습은 보수적 예약14/15, 개발은 P05 예약05와 기존 case5 closure다. 원본 SHA·기존 촬영 그룹·예약의 학습/개발 교차는0이다. P26/P28은 같은 예약19이며 추가 후보일 뿐 현재 학습 목록에 넣지 않았다. 메타데이터 분리는 실제 촬영 장소·사건 독립성 인증이 아니며 기존 case5의 개발 진단 한계도 유지했다. 학교45와 EXP64 시험296/관련 보호 그룹은 사용하지 않았다.

## 실제 A 기준선

고정된197프레임을 CPU FP32로 한 번 평가했다. A는 공식 YOLO26m의 person 행을 정확히 보존한 EXP68 step0 초기 checkpoint다. 공식 가중치와 초기 상태의 일치, 저장 epoch0/optimizer step0, 평가 전후 모델 상태 불변을 확인했다. 입력640 letterbox, one2one top300, 추가 NMS 없음, confidence0.5·IoU0.5의 프레임별 일대일 매칭이다. 실제 추론시간은 로컬 결과에 기록하며 GPU 속도나 전체 시스템 지연으로 해석하지 않는다.

| 자료 | TP | FP | FN | 정밀도 | 재현율 |
|---|---:|---:|---:|---:|---:|
| 개발75프레임 전체 | 56 | 0 | 0 | 100% | 100% |
| └ 기존 개발25 | 31 | 0 | 0 | 100% | 100% |
| └ P05 이동25 | 25 | 0 | 0 | 100% | 100% |
| └ P05 빈 배경25 | 0 | 0 | 0 | 해당 없음 | 해당 없음 |
| 학습122프레임 진단 | 288 | 9 | 45 | 96.97% | 86.49% |

모든 숫자는 검수된 프레임의 박스 행 기준이며56명의 고유 인원이나56개 사건을 뜻하지 않는다. 학습 자료 결과는 개발/시험 성능과 분리한다. 개발 자료100%는 한정된 쉬운 표본의 결과이며 학교 CCTV 성능 개선이나 독립 일반화 성능을 입증하지 않는다.

개발 정답은 입력640 기준 중간 크기28·큰 크기28이고 작은 사람은0이다. 여기서 작은/중간/큰 기준은 letterbox 축소 후 박스 면적의 제곱근32/96 경계이며 COCO 원본 면적 AP와 다르다. 학습 자료에는 작은 정답91개 중32개 누락, 중간242개 중13개 누락이 있다. 정밀한 가림 정도나 자세별 정답이 없으므로 이를 검수된 가림/월담 자세별 성능으로 단정하지 않는다.

학습용 명시적 빈 배경은 현재0프레임이고 새 주·야간 예약19 보강본도 미포함이다. 개발 자료의 작은 사람·다양한 가림 조건과 별도 야간 평가 역시 부족하다. 첫 비교에서 이 모든 조건을 검증했다고 하지 않는다. 이번에는 실제로 확인된 개발 누락 분모의 공백을 우선 좁혀 보완한다.

학습 출처별로 작은 보행인 P16은34TP/1FP/15FN, 기존+보강 서 있기 P18은146TP/7FP/15FN, 월담자·동행자 P20은33TP/0FP/13FN, 기존 case1은75TP/1FP/2FN이다. 같은 촬영 그룹인 P16/P18은 사건별 표에서 합쳐 계산한다. 모든 프레임과 GT ID의 성공/누락, unmatched prediction, 점수·전체 anchor를 저장해 후속 비교에 재사용한다.

## 필요한 부분만 남긴 보강

누락 회복 분모가0이므로 현재 개발75프레임만으로 B/C의 누락 개선을 입증할 수 없다. 학습에서 누락된 프레임을 개발로 옮기거나 낮은 점수를 사람 정답으로 간주하지 않았다.

P01의56.000·58.333·61.667초 세 장에 대해 원본·미확정 박스·먼 산책로 픽셀 확대를 만들었다. 배경 오검출 제거는 이미 반영돼 있다. 확인할 것은 다른 위치의 작은 대상이 실제 사람인지, 겹친 박스가 같은 사람인지, 빠진 사람이 있는지다. 이전 승인5좌표와 야간23.333초는 이 질문에 포함하지 않는다. 세 장을 확인하더라도 P01 전체24프레임 완료로 확대하지 않는다.

기존 편집기를 별도 패키지로 열어 좌표를 보완할 수 있다. 편집기의 ‘모든 사람 확인’은 해당 한 프레임의 누락까지 확인했다는 뜻이고, ‘확인 완료’는 그 결과를 완료 상태로 저장하는 선택이다. 판단하기 어려운 대상은 불확실로 남긴다. AI가 완료 revision을 대신 저장하지 않았다. 새 개발 자료로 확정되면 기존 목록을 덮어쓰지 않고 새 버전으로 고정한 뒤 A를 먼저 평가한다. 실제 누락이 확인돼야 회복 분모로 쓴다.

추가71프레임 전부를 첫 비교의 필수 검수로 묶지 않는다. 현재122학습·75개발로 BN에 따른 검출 유지 비교를 준비할 수 있다. 누락 회복 평가를 포함하려면 위 작은 사람 개발 보강이 먼저 필요하다. 새 독립 시험 확보는 별도 진행 과제이며 개발 실험 준비의 차단 조건으로 삼지 않는다.

## B/C 실행 조건과 준비 검증

[비교 계획](EXP-0074-protocol.md)과 [실행 준비](EXP-0074-bc-preparation.md)에 초기 가중치·자료 해시·순서·평가·명령을 고정한다. B/C 모두 전체 파라미터를 학습하고 C만 BN 누적 통계를 고정한다. BN affine의 weight/bias는 두 조건 모두 학습 가능하다. 현재 자료에서 동일 seed68, batch2, 640입력, AdamW lr0.0001, 5epoch×61step=305step이며 마지막 epoch5를 주 비교로 지정한다. 각 epoch checkpoint와 평가를 별도로 보존한다.

실제 YOLO26m에 합성 입력을 CPU forward해124개 BN을 검사했다. B의372개 누적 buffer는 변했고, C의 변경은0개였다. train 모드 재설정 뒤에도 유지됐고 전체 학습 가능한 파라미터396개 텐서 및 BN affine의 학습 가능성은 동일했다. 이 시험에서 optimizer step은0이며 모델 파라미터도 변하지 않았다. 합성 단위 시험으로 affine gradient와 checkpoint 저장도 확인한다. 이는 통계 고정 구현 검증이지 B/C 학습 완료나 성능 개선이 아니다.

사건별 기존 검출 유지·누락 회복·새 누락·계속 누락·FP 비교가 가능한 안정된 GT ID를 준비했다. 개발75의 누락 회복률은 분모0으로 미측정이며, B/C 결과도 재학습 전이므로 null이다. 마지막 예측층만 학습하는 조건은 후속 후보로 남긴다.
