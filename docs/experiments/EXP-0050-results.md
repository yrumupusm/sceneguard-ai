# EXP-0050 — 두 경계·출발 이력 보완과 이른 확인 비교

실행은 완료했지만 행동 개선은 실패했다. 기존 운영 설정을 유지한다.

공식 사건 확인 매칭39/52→0/52, 의심51/52→51/52, 이른 최초 확인8→0건이다. 새 확인 매칭0건과 기존 매칭 손실39건을 함께 확인했다. 확인 알림 전체가 사라져 이른 판단 보완 성공으로 볼 수 없으며, 현재 수정안은 미채택한다.

## 목적

문 바로 안쪽의 지속 관측만으로 확정하는 이른 판단을 줄이고, 문 구간에서 안쪽 출발 이력이 사라져 안→밖 통과를 놓치는 문제를 함께 확인한다. 사용자가 두 보완의 코드 반영과 시험을 승인했다.

## 변경과 고정 조건

기존 공통선과 검토한 안쪽 전용선을 사용해 출발 측→문 구간→반대편의 유한 경계 통과를 검사한다. 직접 관측 통과는 소실을 기다리지 않는다. 소실 추론은 출발·측정 진입·마지막 위치·최근 방향·기존1초 부재를 함께 요구한다. 안→밖과 밖→안에 같은 원칙을 적용하며 이미 확인된 통과는 이후 복귀로 취소하지 않는다.

실제 박스 높이65% 지점과 기존 저장 특징점을 사용한다. 가려진 발을 복원하지 않는다. 새 경계가 활성화되면 옛 확인 경로의 우회를 막는다. 0.2초·최소3회 안정 관측 및 기존 연결 기준은 유지했고 임계값 탐색은 하지 않았다. 이번 후보 경로는 자동 해제를 실행하지 않는다.

전체45개 저장 측정값을 CPU로 재생했다. 새 모델·GPU·검출·추적·flow 실행은0이다. 새 프로필 사본에만 안쪽선을 추가했고, portal 사본은 새 scene 연결 digest만 변경했다. 기존 원본·정답·운영 프로필·과거 결과·검수 DB와 영수증은 보존했다.

## 실행·보존·검증

기존 Orca Run `run_3d23462a014a`를 재사용했다. EXP-0050 배정은 구현 Task `task_7401f8b9ce5b` / Dispatch `ctx_d5a3784daaeb`이며 실제 Sol high 실행을 확인했다. 수정 Task `task_8e6e122d86ae` / Dispatch `ctx_c8cbea40bf22`도 Sol high다. 평가기는 별도 담당이 준비했고 총괄이 동결 소스로 실제 재생을 실행했다. 독립 검토 Task `task_b328e3b69b0d` / Dispatch `ctx_272dc564db6a`는 Astra high다. 작업자 완료·코드 시험 통과·비교 실행 성공·행동 개선·기본 채택을 서로 다른 상태로 기록한다.

실행 소스 `d40fe5011956acba47bd04b3a17dbf224b325f10`. 후보 규칙 바이트는 독립 검토한 `2cdfc3eb9966e69a4211035df6eea8fa21c41fcc`와 같다. 전체 경과720.872907초, 작업 CPU 시간 합2557.409184초다. 실시간 처리속도나 GPU 추론 시간으로 해석하지 않는다. 보호 원본 입력204개와 새 프로필17개, 코드 snapshot92개, 원래 geometry snapshot19개의 불변 검사가 통과했다.

구현·독립·기존 동작559개 시험과 평가기17개 시험이 통과했다. 선 끝점 우회, 연속 관측의 일대다·다대일 혼동, 단절 후 경쟁 박스, 꺾인 윤곽, 미래 관측 누설, 같은 편 복귀·확인 후 복귀 및 후보 소유권을 검사했다. 합성 시험 통과가 실제 행동 개선을 보장하지 않는다.

첫 실행 run-001은 새 scene과 원래 portal digest의 연결 불일치로45개 모두 판정 전 실패했다.33.043104초의 실패 기록과 보호 입력을 보존했다. 사본의 digest 연결만 수정하고 실제 PortalGate 회귀를 추가한 뒤 새 run-002를 실행했다. 실패 결과를 성능 집계에서 성공으로 바꾸거나 원본 설정을 덮어쓰지 않았다.

## 확인이 사라진 경로의 진단

독립 감사에서 원래 후보986개와 실제 관측에 유일하게 연결된 후보963개를 확인했다. 안→밖 우선9개 공식 구간에도 연결된 후보가 존재한다. 후보 자체가 전부 없어진 결과는 아니다. 저장된 판정 감사에서는 경쟁 연결 거절이 지배적이며, 출발 근거·관측 단절·연결 유효시간 제한도 함께 나타난다. 경쟁 가능성은 매 프레임의 실제 박스들을 비교해 계산되고, 그 거절은 같은 관측 계보의 뒤 사건에도 이어질 수 있다.

기록된 프레임 쌍 경쟁 항목128,604개, 모호함 거절 변화1,216개, 연결시간 초과 변화804개, 관측 연결58개는 진단 기록 수다. 사람 수나 독립 사건 수가 아니다. 거절 감사는 중복을 줄여 저장하므로 특정 시점의 기록 부재가 이후의 모든 경계 근거 부재를 증명하지 않는다. 연결 거절만 완화하면 올바른 확인이 회복된다고 단정하지 않으며, 영상 속 다인·차량·가림의 물리적 원인도 이 수치로 확정하지 않는다. 상세 사건별 시각은 독립 검토에 보존한다.

## 한계와 다음 단계

경쟁 연결이 있었던 관측 계보는 이후에도 의심으로 남을 수 있다. 이 거절은60초 출발 이력 제한과 별개이며 새로 안정된 출발 관측만으로 자동 해제하지 않는다. 안전한 새 사건 회복은 오래된 모호한 후보와 새 통과 근거를 분리하는 후속 설계가 필요하다. 직접 관측과 소실 추론은 서로 다른 근거이고, 신원·차량·가림의 물리적 원인은 수치만으로 확인하지 않는다.

기본 운영 프로필은 기존 선택안을 유지한다. 코드와 후보 프로필 및 결과는 재현 가능한 비교 자료로 남긴다. 등록 영상은 기존 원본 재생 자료이며 새 판정 오버레이 영상이 아니다. 새 임계값 탐색이나 GPU 추론 없이 이번 결과의 누락·시각·근거를 우선 검토한다.
