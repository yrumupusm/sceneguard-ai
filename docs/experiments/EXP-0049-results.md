2026-11-01. **실제 제한 비교 동결 — root 초안 검토 승인 및 독립 수치·미디어 검증 완료.** EXP48의 개별 근거 판정을 그대로 두고 현재 실제 문 박스로 사건을 유지한 결과, 두 영상 모두 2카드가 1카드로 합쳐졌다. 030의 97.433333초 후속 의심은 같은 확인 사건에 붙고 별도의 의심 알림을 만들지 않는다. 이는 사건 정리 결과이며 검출·침입 정확도나 해제 성능 개선 주장이 아니다. 기본 MVP 자동 적용은 보류한다.

030은 86.033333초 첫 의심, 92.733333초 첫 확인이며 A 93.033333초 및 후속 94.1초 근거도 원래 상태/시각 그대로다. 97.433333초에 EXP48의 별도 카드가 열리던 후보와 이후 후보 2개는 기존 확인 사건의 **미결 추가 근거 3개**로 붙는다. 별도 카드·반복 의심 알림은 없고 개별 확인은 전파하지 않는다. 마지막 실제 문 관측은 frame 429/cache 1, 98.3초다. 원본 끝 99.966667초는 유예 끝 101.3초보다 이르므로 open을 유지한다. 101.3초 빈 프레임을 만들거나 확인/해제를 변경하지 않는다. 두 영상 모두 실제 공백에 의한 사건 분할은 없었고 실패 공백 예시를 만들지 않았다.

007 후반 84–104초는 기존 [사용자 검수](EXP-0048-user-review.md)의 일반 통행이라는 관찰을 재사용한다. 새 의심 후보나 문 관측으로 사건이 연장되지 않는다. 이 구간의 601프레임에서 현재 문 관측과 open 사건은 모두 0이다. 이전 61개 기하 관측열을 61명 또는 독립 정답 표본으로 해석하지 않고 같은 질문을 반복하지 않는다. 앞선 의심 근거가 확인 카드 안에서 미결로 남는 문제와 후반 새 의심 없음은 별개다.
