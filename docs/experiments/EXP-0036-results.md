## 고정 동작과 보존 범위

`(녹화 세션, 카메라, 출입구)`가 같고 직전 알림부터3초 이내이면서 첫 알림부터10초 이내이면 같은 카드다. 첫 이벤트를 받는 즉시 카드와 최초 알림 의도를 만들고, 이후 이벤트는 종료 시각·관련 알림 수·ID·원래 알림 참조만 갱신한다. 3초를 모은 뒤 처음 알리는 방식이 아니다. 같은 이벤트 재전송은 수를 늘리지 않는다. 이 숫자는 표시 묶음 설정이며 검출/침입 임계값을 변경한 것이 아니다.

007은 `E01_007-original / C3 / C3_fence`,030은 `E01_030-original / C6 / C6_fence`로 고정했다. 실제 gap 행에는 boundary_id가 없어 기존 카메라의 boundary 설정과 이름을 대조했다. 좌표를 추정하거나 수정하지 않았다. 원본을 바꿔 분석하거나 새로고침할 때 session ID를 바꾸지 않는다. 다른 세션·카메라·출입구는 합치지 않는다.

EXP-0035의 `events` 중 침입 의심과 보존된 `existing_alerts`만 입력했다. 복제된 losses/review_changes를 다시 세지 않는다.007의 기존 침입 아님6행은 별도 보존하고 카드로 승격하지 않는다. 각18개 원래 알림은 정확히 한 카드에 들어갔다. ID 합병·인원 수 산출·동일인 판정·침입 확인 자동 승격은 없다. 출발 영역/방향/VLM으로 의심을 다시 거부하지 않는다.

## 기존 서비스에서 실제 확인

새 서버나 프레임워크 없이 기존8765 결과 화면의 EXP-0036에 두 영상의 사건 카드 재생 부분만 연결했다. 기존 MP4를 그대로 사용하며 영상0초는007 원본48초/030 원본84초다. JSON은 로컬 allowlist·SHA·실제 배정/등록·기존 미디어 등록을 확인한 뒤 시각별 카드 snapshot과 원래 알림 참조만 전달한다. 원본 bbox/scene·전체 source_event는 API에 싣지 않는다.

카드 DOM을 ID별로 유지해 갱신 때 펼친 원래 알림 목록이 닫히지 않는다. 원본 PTS에 도착한 버전만 표시하며 되감기에는 미래 카드·ID·알림 수를 제거한다. `근거 시점 보기`는 같은 영상에서 첫 알림3초 전(분석창 시작에 제한)으로 이동하고 일시정지하며 알림을 내지 않는다. 알림은 로컬 화면 토스트이며 외부 발송/운영 감시 시스템을 추가한 것이 아니다.
