# SceneGuard — 프로젝트 목표·범위·성공 기준

- 작성: 2026-10-26
- 상태: **출입 경계 침범 이벤트 감지·검토 1차 MVP 잠정 채택** (ADR-0004). 데이터·모델·평가 결과 미확정
- 성격: AI Software Engineer 직무 포트폴리오를 위한 독립 프로젝트. 상용 수준의 안전 인증 또는 실제 성능 확보를 주장하지 않는다.

## 해결할 문제와 사용자
고정형 CCTV에서 사람이 **설정된 출입 경계를 통과하거나 넘어가는 동작**을 감지해 사건 후보 시각·근거를 관제 담당자가 확인하도록 돕는 것이 초기 목표다. 카메라별 ROI/경계선 설정을 허용하며, 법적 무단침입·출입 권한 판단을 대체하지 않는다. 관제 담당자는 **가정한 사용자**로 실제 인터뷰·효용 검증 전이다.

현재 결정: [ADR-0004](decisions/ADR-0004-boundary-crossing-cctv-mvp.md) / [제품 업무 흐름](PRODUCT_WORKFLOW.md). 과거 사고 클립 검토 방향은 [ADR-0003](decisions/ADR-0003-incident-review-product-direction.md)에 보존. **메인 데이터·모델·평가 단위는 미선정**.

## 목표
1. 공개 영상의 라벨과 실제 장면을 확인해 첫 MVP 행동을 정의한다.
2. 선행연구 → 데이터 특성 → 후보 기술 비교 → 검증의 순서로 모델·아키텍처를 결정한다.
3. 최소 파이프라인으로 이벤트 후보와 확인 가능한 근거를 반환한다.
4. 평가 단위(영상 / 사건 구간 / 프레임 / 작업자)를 정의하고 측정 가능한 지표를 평가한다.
5. 정확도와 오탐·미탐, 설명 오류, 처리 지연과 자원 사용량을 단계별로 기록한다.
6. 결정/실험/실패/재검토 과정을 Git 기록과 문서로 보존한다.

## 이전 데이터의 이벤트 후보 (이력 / 현재 MVP 아님)
- Safe Walkway Violation: 실제 화면에 통로 경계와 작업자 이동이 식별되면 고려
- Opened Panel Cover: 패널의 열린 상태와 발생 장면이 관찰 가능할 때 고려
- Unauthorized Intervention: 작업 '권한' 데이터 없이 위반 확정 금지
- Forklift Overloading: 허용 하중·규정 없이 영상만으로 과적 확정 금지

위 목록은 이전 Safe and Unsafe Behaviours 데이터에서 검토한 이력이다. 패널 상태 분류는 메인 MVP에서 제외(ADR-0002). **현재는 AI-Hub 71850 침입 CCTV 범주의 출입 경계 통과/넘기 이벤트를 조건부 MVP 대상으로 검증한다.**

## 초기 비목표
- 법규 위반의 자동 확정/제재 또는 사람의 안전 판단 대체
- 처음부터 전체 데이터 다운로드, 모든 클래스의 높은 정확도 주장
- 대규모 24시간 CCTV 관제, 모든 출입구에서의 무설정 침입 판정, 법적 무단침입 확정, 실시간 경보 성능 주장(실측 전)
- Jetson, Kubernetes, 실시간 서버, 대시보드 등 기능을 이유 없이 선제 구현
- YOLO, BoT-SORT, ConvLSTM, VLM, ONNX, TensorRT의 의무적 도입

## 모델 선택 기준
관찰 단서(상태/시간/움직임) · 라벨 수준 · 정확도/지연 요구 · RTX 3080 자원 · 학습/검수 비용 · 라이선스 · 재현성. 
추적은 같은 개체의 이동이 필요한 경우에만 검토하고, VLM 설명은 독립적으로 검증한다. 최적화는 실측 병목 발견 후 고려한다.

## 평가 지표 후보
| 평가 | 후보 지표 | 전제 |
| --- | --- | --- |
| 사건 분류 | 클래스별 Precision/Recall/F1, FP/FN | 평가 단위와 정답 라벨 확인 |
| 사건 시간 | 시작/종료 구간 오차 | 구간 정답이 있어야 함 |
| 상황 설명 | 실제 장면과 설명의 사실 일치성 | 사람 검수 기준 |
| 추론 | FPS, p50/p95 지연, GPU 메모리 | 전처리/추론/후처리/전체 구분 |
| 운영 | 재현성, 장애 복구 및 로그 | 시스템 구축 이후 |
| CCTV 경보 | 검수된 정상 구간에서 시간당 오탐, 감지 지연, 영상별 이벤트 Precision/Recall/F1 | 정상 구간·사건 구간의 시간 정답 검증 이후 |
| 일반화 | 같은 카메라 평가 vs 처음 보는 카메라 평가 | 카메라/장소 ID와 독립 평가 표본이 있어야 함 |
| 검토 업무 | 사람의 분석 기록 작성 시간, 모델 수정률, 검색 소요 | 사용 시나리오와 비교 조건을 직접 검증할 수 있는 경우 |

## 위험과 품질 원칙
유사한 학교 출입구와 같은 카메라·장소의 반복, 영상 단위/이벤트 구간 라벨의 한계, 인접 프레임·사이트 간 누수, 저작권·개인정보·재배포 제한을 기록한다. 사용자 이미지의 **줄 넘기(4번)**와 **공원 울타리 넘기(7번)**는 서로 다른 드문 유형으로 취급한다. 외부 연구 결과는 **논문 보고치**로 명시하며 SceneGuard 자체 성능으로 표현하지 않는다.

## 포트폴리오 성공 기준
완성된 기능 숫자보다 **문제 정의 → 대안 비교 → 근거 있는 결정 → 재현 가능 실험 → 실패와 수정 → 측정된 결과와 한계**를 증거와 연결해 설명할 수 있어야 한다.
