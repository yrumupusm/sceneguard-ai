## 고정한 범위와 완료 기준

2026-11-01, 로컬 변경 없는 `00dd16a`에서 main `e603288`을 fast-forward했다. 사용자가 지정한 Downloads/CODEX_MVP_FINALIZE.md를 읽고 동일 원문을 docs/CODEX_MVP_FINALIZE.md에 보존했다. 최신 main의 통합 코드와 상충하지 않으며 첨부 작업서를 최종 기준으로 적용한다.

기존 FCOS 검출·ByteTrack·CPU 특징 경로·방향/소실·후속 상태 및 EXP49 문 관측 사건 관리를 단일 영상 분석에 연결한다. 과거 결과는 회귀 비교에만 사용하고 새 결과의 입력으로 복사하지 않는다. 새 모델/학습/영역 조정/알고리즘 탐색은 하지 않는다.

- 007 48–105초와 030 84–100초의 원본 및 검증된 검출에서 현재 판정·근거 영상을 새로 생성한다.
- 실제 정상 구간의 0후보 성공과 보유 자료의 추가 구간을 확인한다. 독립성과 의미 검수 범위를 명시한다.
- 동일 요청 단계 재사용, 변경된 입력 거부, 시간순 상태, 사건별 확인 알림, 관찰 종료와 해제의 분리를 검증한다.
- 기존 웹 기본 보기에서 영상·상태·되감기·폴링·새로고침·재시작과 기존 수동 검토 보존을 실제 확인한다.
- 검증 뒤 기본 시연을 최신 경로에 연결하되 이전 보기를 보존한다. 실제 해제 사례가 없으면 미검증으로 남긴다.

기존 Orca Run의 Sol high 실행, Terra high 최소웹, Astra high 독립 검토를 사용한다. 원본·실험 출력·DB·알림 영수증을 보존하며 코드·문서·비식별 요약만 게시한다.
