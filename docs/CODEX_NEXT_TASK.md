## 다음 순서

1. EXP-0001의 로컬 근거를 사용자와 검토해 작은 사람·가림·감시 범위 실패를 구분한다. 검출이 없는 구간을 tracker로 보간해 관측 사실처럼 만들지 않는다.
2. 다음 소규모 비교는 검출 해상도/검출기 보완을 우선 후보로 둔다. 한 번에 한 요인을 바꾸고 가중치/라이선스/추가 의존성·비용을 확인한 뒤 다음 실험 범위를 정한다. 현재 기준 설정/출력을 덮어쓰거나 결과에 맞춰 기존 경계를 조정하지 않는다.
3. 006의 실제 4006 vs JSON 4011프레임 불일치와 119~132초 비이벤트 후보 상태 유지. 설정한 가까운 출입문 경계와 후기 먼 보행 위치가 다른 점을 확인하고 감시할 경계 범위를 먼저 결정한다.
4. 001/007/030 사람별 첫 등장·넘기 시작, 031 약 33초 접촉·43.600초 공식 시작·미완료 종료를 별도 검수. 공식 라벨 자동 수정·미완료 종료 생성 금지.
5. 006/007 및 013/039/045 같은 카메라 그룹 유지. 모든 현재 표본은 development이며 독립 테스트 아님. 검수된 음성 시간·평가 manifest 확정 전 최종 F1/FP-hour·정밀 지연·새 카메라 일반화 주장 금지.
6. 다음 구현/실험은 사용자와 범위를 정한 뒤 진행한다. 학습·VLM·고급 tracker·UI/API·대규모 수집은 이번 완료 작업에 포함되지 않았다.

코드·문서·공개 가능한 집계만 GitHub에 기록한다. 원본/라벨/영상/이미지/가중치/추론 결과·환경 캐시는 로컬 Git 제외 경로에 보관한다. 이전 데이터 감사와 모든 공식 정답은 보존한다.
