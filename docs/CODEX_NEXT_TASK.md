# Codex 다음 작업 — AI-Hub 침입 CCTV 영상 소량 감사 (Phase 1E)

- 제품 방향: [ADR-0004 — 출입 경계 넘기/통과 이벤트 후보 감지](decisions/ADR-0004-boundary-crossing-cctv-mvp.md) **잠정 채택**
- 공식 후보: https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=71850 (지능형 관제 서비스 CCTV 영상 데이터 / 침입)
- 세부 검증: [AIHUB_INTRUSION_AUDIT_PLAN.md](data/AIHUB_INTRUSION_AUDIT_PLAN.md)
- **기존 Safe and Unsafe Behaviours, iSafetyBench, SteelBench, ACCIDENT 감사 기록·로컬 자료 보존.**

1. **접근성부터 확인:** AI-Hub 공식 영상·JSON 목록, 신청/로그인·이용·공개 조건, 실제 파일 다운로드 가능성을 확인해 줘. 사용자 로컬에 이미 확보한 파일이 있으면 그것부터 이용해. 인증이 필요하면 우회하거나 토큰을 읽지 말고 필요한 사용자 동작을 적어 줘.
2. 허용되고 접근 가능하면 **6~10개 이내** 샘플을 감사해 줘. 유사 학교 철제 출입구 장면뿐 아니라 **4번 줄 넘기, 7번 공원 울타리 넘기** 같은 드문 유형도 별도로 구분해 검수해. 번호는 사용자가 공유한 이미지의 번호로, 공식 파일 ID와 동일하다고 가정하지 마.
3. 영상 길이·FPS·전체 디코딩·JSON 이벤트 시작/종료 시점 매핑, 카메라/장소/구도 중복, 실제 관찰 가능한 경계 통과 행동을 확인해 줘. **이벤트 전후가 무조건 '정상'이라고 가정하지 말고**, 검수 가능한 비이벤트 구간이 있는지 평가해 줘.
4. 목표를 **법적 무단침입 판정이 아닌 '카메라별 지정 경계의 통과/넘기 행동 감지'**로 유지해. 카메라별 경계선/ROI 설정이 가능한지, 새로운 카메라에 대한 평가 분할을 할 수 있는지, 단순 선 통과 vs 울타리 넘기 행동 구분이 필요한지 기록해 줘.
5. `docs/data/AIHUB_INTRUSION_SAMPLE_AUDIT.md` 작성: 검증 사실/미확인, 샘플 목록·동작 근거/라벨 부합, 카메라 중복·정상 구간, Go/Conditional Go/No-Go와 다음 결정. `docs/HANDOFF.md`, `docs/WORK_PLAN.md` 갱신 후 코드·문서만 검토해 커밋·푸시.

**이번 단계는 데이터 감사만.** 대량 다운로드, 모델 학습/추론, VLM·API·대시보드 구현, 원본 영상·프레임·개인정보·정답 원문 GitHub 업로드는 금지. 분석 코드·문서만 보관하고, 메인 데이터와 모델의 최종 채택은 사용자가 검수한 후 결정한다.
