# Codex 다음 작업 — iSafetyBench 데이터 적합성 조사 (Phase 1B)

- 날짜: 2026-10-26
- 상태: 사용자 승인된 **다음 작업**, 실제 다운로드/검증 아직 미실행. 데이터 접근/라이선스 점검부터 수행.
- 반드시 읽을 문서: `AGENTS.md`, `docs/decisions/ADR-0002-reconsider-safety-dataset.md`, `docs/WORK_PLAN.md`, `docs/data/ISAFETYBENCH_AUDIT_PLAN.md`

## 배경
기존 Safe and Unsafe Behaviours의 **패널 열림/닫힘 상태**는 실제 영상에서 식별 가능했지만, 목표인 복합 안전 사건/행동 분석을 보여주기에는 범위가 좁아 **메인 MVP에서 제외**했다. 기존 감사·영상·스크립트 삭제 금지.

**새 데이터셋 iSafetyBench는 조사 후보이지 최종 결정이 아님.** 제품의 1차 활용 목표는 **이미 선택된 사고·이상상황 영상의 행동/사건 분석 및 사람의 검토 지원**이다. [ADR-0003](decisions/ADR-0003-incident-review-product-direction.md), [제품 흐름](PRODUCT_WORKFLOW.md) 참고.

## 우선 실행
1. iSafetyBench 논문 및 공식 데이터/배포 페이지의 최신 실제 링크 확인. 데이터 버전, 사용 조건·라이선스, 원본 영상 권리, 접근 필요사항과 출처 기록.
2. 어노테이션 파일을 먼저 확인하여 영상 ID, 정상/위험, 다중 행동 정답, 설명, 훈련/평가 분할, 원본 출처 ID, 사건 시작·종료와 객체 주석 제공 여부를 **직접 검증**. 제공된 것으로 추정하지 말 것.
3. 데이터가 소량 개별 접근 가능하고 이용 조건이 허용되면, 서로 다른 사건 및 정상 사례 위주로 **6~10개 정도만** 받거나 최소 영상 감사 진행. 대량 다운로드, 모델 학습, 원본 미디어 업로드 금지.
4. 영상 의미가 단일 프레임으로 구분되는지, 시간 흐름이 필요한지, 사고 전 예방인지 사고 후 해석인지 기록. 라벨과 화면의 불일치·모호함을 사용자 검수 항목으로 남길 것.
5. 같은 원본 영상에서 파생된 클립 중복과 데이터 누수 가능성, 사건 정의의 애매함, 추가 라벨 비용 검토.
5-a. **활용 기능 적합성 검증:** 각 샘플에 대해 '다중 행동 태그 / 실제 보이는 사건 설명 / 검토할 근거 프레임 또는 구간'을 마련할 수 있는지 보고, 기존 주석이 제공하지 않는 근거·시점은 **추가 사람 검수 필요**로 표시. 기존 정답 caption, gt_actions 등을 미래 모델 입력으로 사용하지 않도록 데이터 분리 설계도 기술.
6. `docs/data/ISAFETYBENCH_SAMPLE_AUDIT.md`를 작성하되 미확인 값은 미확인으로 표기. Go/Conditional Go/No-Go 의견과 다음 판단 근거 제시.
7. `docs/HANDOFF.md`와 `docs/WORK_PLAN.md`를 업데이트하고 코드/문서만 검토 후 커밋·푸시.

## 이번 단계에서 금지/보류
- 모델 선정이나 VLM·YOLO·추적·대시보드 구현
- '데이터가 있다'는 이유만으로 실시간 위험 조기경보 성능 주장
- 검수 전 공개 이미지·영상 GitHub 업로드
- 승인되지 않은 대량 다운로드·학습
- 문헌 성능·미측정 수치를 SceneGuard 결과처럼 표현
