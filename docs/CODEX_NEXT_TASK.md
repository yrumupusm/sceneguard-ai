# 최신 승인 — EXP-0044 입구 방향 + 소실 자동 판정

2026-11-01. [CODEX_EXP0044.md](CODEX_EXP0044.md)를 실행한다. 사용자는 복잡한 동작 점수보다 **문 안쪽으로 이동하다 선 근처에서 사라지면 침입 확인, 방향 불명/반대쪽이면 침입 의심**을 선택했다. 자동 확인과 사용자 수동 확인은 구분한다. 과거 자동 확인 금지/실험 종료 문구는 당시 범위이며 이번 명시적 승인을 막지 않는다.

준비: `directional_loss.py`, `exp0044_application.py`, CPU 시험43개(핵심36+모의 연결계약7). 실제 CCTV/기존 grouping/UI 통합·성능 검증은 로컬에서 해야 한다.

1. 기존 EXP35 소실14건 + EXP42의 실제 저장 점 경로로007/030을 처리한다. 새 모델/학습/수동 박스/검출/추적/VLM/flow 재계산은 없다.
2. 기존 안쪽/바깥쪽 영역으로 안쪽 화살표를 확인하고 같은 대상에 연결된 동일 점의 평균 이동만 쓴다. 화면 위쪽/변형/가속도 점수와0.55 경보 제외는 사용하지 않는다.
3. 안쪽+선 근처+소실 대기 완료→자동 침입 확인. 방향 애매/바깥쪽→의심 유지. 실제 연속 관측은 번호만 끊긴 경우를 보완하되 가시성 자체로 침입을 부정하지 않는다.
4. 원래 이벤트와 수동 검토는 보존하고 별도 `automatic_status`를 표시한다. 기존 사건 묶음, 첫 통지와 첫 자동 확인 시각을 구분한다. 비교실험 알림을 외부 발송하지 않는다.
5. 원본/입구 방향/대상 이동/소실/판정의 간단한 비교 영상을 기존 담당3에 연결하고 실행 결과·오확인·놓친 사례·실제 화면 확인을 게시한다. 자동 확인 수 증가만으로 개선이라고 쓰지 않는다.
