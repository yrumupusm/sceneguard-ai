# 최신 승인 — EXP-0049 실제 문 관측으로 같은 사건 유지

2026-11-01. [CODEX_EXP0049.md](CODEX_EXP0049.md)를 따른다. 사용자는 030의 같은 침입 상황이 10초 카드 제한 때문에 뒤의 미결 의심으로 갈라지지 않도록 승인했다. 이전 종료 문구는 과거 범위다.

준비: `gate_activity_episodes.py`, `exp0049_application.py`, 합성/순수 함수54시험·문법 검사 통과. 실제 CCTV/기존 PortalGate 전체 연결/웹은 로컬 실행 전이다. 실제 구역 위치 시험은 직사각형 fixture이며 성능 검증이 아니다.

1. 성공한 EXP48 v2의 후보와 **시각별 개별 근거 상태를 그대로 재생**한다. 확인·해제·방향·관측 연결을 재계산하지 않고 모든 프레임의 원래 근거 필드/시각 일치를 검사한다. 변경은 사건 소속·관찰 종료·알림 정리다.
2. 기존 EXP46 문 구역의 현재 실제 검출이 이어지면 같은 사건을 유지한다. 후보 간격/10초 제한으로 나누지 않는다. 실제 문 관측이3초간 없으면 관찰 종료하며, LAST/예측/무관한 보행로 박스는 유지 근거가 아니다.
3. 관찰 종료는 해제가 아니다. 확인 이력은 유지, 방향 불명은 닫힌 의심 이력으로 보존한다. 소스 공백은 관찰 중단이고 영상 종료에 가짜 빈 프레임을 넣지 않는다.
4. 첫 의심/첫 확인은 사건별 한 번이다. 확인 후 새 근거가 붙어도 별도 미결 카드/반복 알림을 만들지 않고, 개별 새 근거는 원래 미결 상태를 유지할 수 있다. 종료 후 새로운 상황은 새 사건이다.
5. 007/030 전체 같은 규칙으로 비교하고 03097초대 같은 상황의 카드 분리와007 일반 통행/재접근 분리를 확인한다. 실제 관측 공백 때문에 갈라지면 원본과 근거를 보여주며 유예시간/영역을 재튜닝하지 않는다.
6. 기존 담당3에 open/closed와 의심/확인/해제를 분리해 연결한다. 재생/되감기/폴링/중복방지는 실제 확인하고 브라우저 실패는 미완료로 남긴다. 기존 MVP/원본/DB/영수증 보존, 새 모델/학습/검출/추적/flow/VLM/영역 변경/외부 발송은 없다.
