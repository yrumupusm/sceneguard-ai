# 최신 승인 — EXP-0047 의심 후속 관찰·해제·확인 알림

2026-11-01. [CODEX_EXP0047.md](CODEX_EXP0047.md)를 따른다. 사용자는 문 주변에서 먼저 의심하고, 문·안쪽과 반대 방향으로 이동하다 사라지면 의심을 해제하며, 안쪽 이동·소실이면 자동 확인하는 상태 갱신을 승인했다. 여러 근거는 사건 카드 하나로 정리하고 첫 확인 때 별도 알림을 낸다. 이전 종료 문구는 과거 실험 범위다.

준비: `incident_lifecycle.py`, `lifecycle_followup.py`, `exp0047_application.py`, 합성54시험. 현재 저장소의 실제 방향/묶음 함수로 합성 좌표를 시험했으며 문 구역 판정은 사각형 fixture를 사용했다. 실제 CCTV·로컬 전체 통합·웹·경보 전달은 아직 전이다.

- EXP46 실제 관측열/후보와 EXP42 점 경로를 재사용한다. ID 변경/점 대응의 후속 관측으로 의심 이력을 이어가되, 같은 사람임을 인증하지 않는다.
- 바깥 이동＋실제1초소실은 연결된 의심만 해제한다. 방향 불명·다른 사람 잔존·영상종료·특징창 만료·소스공백만으로 해제하지 않는다. 이미 확인된 근거나 다른 대상의 미결 의심은 지우지 않는다.
- EXP45 자동 확인은 보존한다. 같은 사건에서 의심→확인 시 별도의 확인 알림 의도를 한 번 만든다. 카드 신규생성 여부나 앞선 첫 경보에 묻히지 않게 한다.
- 자동상태는 원래 이벤트/수동 검토와 별도다. 새 계약 전용 최소 표시와 재생/되감기/폴링/중복방지 확인이 필요하다. 실제 알림은 발송하지 않는다.
- 007/030 전체 실제 비교에서 모든 해제의 원본을 확인하고, 잘못 해제/확인·미결·유효한 개선을 기록한다. 바깥 이탈 실사례가 없다면 그 부분은 미평가다. 최초 오경보 감소와 후속 상태 정리를 혼동하지 않는다.
- 새 모델/학습/수동박스/검출/ByteTrack/flow/VLM/영역조정은 없다. 기존 기본MVP와 DB/영수증은 보존한다. 실제 결과·검토·전달을 게시한다.
