# 최신 승인 — EXP-0048 사건별 상태 연결과 일반 보행 확인

2026-11-01. [CODEX_EXP0048.md](CODEX_EXP0048.md)를 따른다. 사용자는 007에 일반 보행자도 많으니 사건 상태 연결을 정리하고 실제 바깥 이탈의 의심 해제를 확인하라고 승인했다. 과거 종료 문구는 당시 범위다.

준비: `incident_outcome_scope.py`, `passage_audit.py`, `exp0048_application.py`, 상태28/진단14 합계42시험 및 문법 검사. 실제 CCTV/전체 통합/웹은 로컬 실행 전이다.

1. 같은 후속 소실의 확인을 가장 최근 연결 사건 하나에 귀속한다. 이전 접근 카드까지 일괄 확인하지 않고, 다음 프레임에 남은 오래된 후보로 같은 결과가 다시 전파되지 않게 한다. 사건 확인과 개별 근거의 동일인 인증은 다르다.
2. 바깥 이탈은 연결된 의심만 해제한다. 독립 출처가 합류한 하나의 관측으로 모두 해제하지 않는다. 단순1→1 연결/안쪽 사건 확인을 완벽한 개인식별 요구로 다시 막지 않는다.
3. 의심 후보만이 아니라 모든 저장 관측을 감사한다. 007 일반 보행은 의심 없음 / 의심 후 해제 / 의심 유지 / 확인 관련으로 나누며, 처음부터 의심이 없던 보행자를 해제 성공으로 세지 않는다. 약84–104초는 영상 검토 위치일 뿐 알고리즘 시간 예외가 아니다.
4. 기존 EXP45 확인·원래후보·문 구역·수동검토·영수증은 보존한다. 새 모델/학습/검출/추적/flow/VLM/구역튜닝은 없다. 실제 소실/방향 규칙은 그대로이며 박스 이동 진단을 새 자동 판정으로 쓰지 않는다.
5. 실제 해제와 남은 미결 이유, 첫 확인 알림 중복과 과거 카드 상태를 원본/기존화면에서 확인한다. 새 애매한 장면만 영상 확인을 요청한다. 코드·시험 통과와 실제 개선을 분리해 보고한다.
