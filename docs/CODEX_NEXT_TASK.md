# 최신 승인 — EXP-0042 보이는 동안의 침입 의심 후보 생성

2026-11-01. [CODEX_EXP0042.md](CODEX_EXP0042.md)를 실행한다. 사용자는 알림 삭제보다 **대기에서 침입이 의심되는 변화로 전환되는 구간의 의미 있는 검출**을 승인했다. 이전 실험 종료 문구는 이번 명시적 승인을 막지 않는다.

- 새 `gate_transition.py`는 원본 영상 특징으로 경계 통과/경계 근처 변화를 연속 평가한다. ID가 끊기거나 대상이 사라져야만 판단하는 구조가 아니다.
- `exp0042_application.py`는 기존007/030 전체 선택 구간에 CPU 영상 특징 계산을 수행한다. 새 모델/검출/ByteTrack/VLM/학습/수동박스/영역 변경은 하지 않는다.
- 기존 후보, 새 후보만, 기존+새 후보의 세 보기를 구분한다. 폐기한 ‘계속 보이면 경보 제외’와0.55/0.65 연속성 제외 정책은 적용하지 않는다. 기존 의심은 결합 보기에서 전부 보존한다.
- 새 후보만 보기는 독립 진단이며 기존 소실 fallback이 없어 제품 대체물이 아니다. 결합 보기는 기존 오탐까지 보존하므로 오탐 감소를 주장하지 않는다.
- 작성 환경의 합성/계약46시험은 통과했다. 실제 CCTV·기존 모듈 통합·웹·전체 회귀는 아직 실행 전이다. 계약8시험의 묶음 의존성은 모의 함수다.
- 실제 원본에서007 접근·대기와65초대 시작/64–74초 문맥,030 접근 및90–94초를 같은 규칙으로 비교한다. 특정 시각/ID 하드코딩 없이 **새 근거가 더 일찍 나오고 대기에 남발하지 않는가**를 평가한다.
- 이미 받은 사용자 관찰을 재사용한다. 새 후보의 애매한 짧은 구간만 필요시 확인하고 정밀 동일인/바운딩박스를 요구하지 않는다.
- 원본·기존 결과·검토DB·통지 영수증을 보존하고 기존 담당3에서 실제 재생/시각별 후보/카드 표시를 확인한다. 결과·독립 검토·전달 기록을 GitHub에 남긴다. 기본 MVP 자동 교체는 하지 않는다.
