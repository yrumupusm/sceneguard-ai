[실제 결과](experiments/EXP-0034-results.md)와 [독립 검토](reviews/EXP-0034-independent-review.md)를 우선한다. 아래 승인 명세는 구현 전 이력이며 같은 GPU job을 다시 실행하라는 지시가 아니다.

- 기존 2,190프레임 CPU 각1회, Qwen 외형6쌍 각1회 완료. 모델·영역·기존 관측/경보 불변. 가림 보조 주석은 실행 전 고정했고 결과에 맞춰 조정하지 않았다.
- 030 `침입 의심`1,007 가림 소실 의심0. 007 raw8의 두 사람 혼합과 부분 박스/출발 영역 단절 때문에 실제 가림 사건을 포착하지 못했다. 같은 쪽 이탈6행은2segment의 반복이며 독립 정상 성공 건수가 아니다.
- 외형 호환2/비호환4,단일인 연결 제안0. 혼합 크롭을 호환으로 답하고 미관측 부위를 유보하지 못해 기본 적용을 보류한다. 형식 통과6/6은 정확도가 아니다.
- 화면은 `침입 의심 / 침입 확인 / 침입 아님 / 판단 불가`. 방향 ±90°는 보조값,몸·다리 동작은 필수 판정 조건이 아니며 법적 권한/의도는 판단하지 않는다.
- 다음 결정에 필요한 근거: 한 ID 안에서 실제 한 사람을 감싼 관측과 혼합 관측의 구분,가림 전 마지막 관측의 위치/방향/출발 영역 근거. 불명확한 부분은 총괄 초안으로 유지한다. 이번 범위에서 새 모델·학습·재추론·영역/임계값 수정은 진행하지 않는다.

# 최신 사용자 승인 — EXP-0034 접근·이탈·소실 + 외형 비교

이번 대화의 최신 지시는 **기존 영역과 모델을 유지한 채 한 번 실제 적용**하는 것이다. 이전 EXP-0033 종료/후속 대기 문단보다 이 승인이 우선한다. 기존 이력과 결과는 Git 이력 및 각 EXP 보고서에 그대로 보존한다.

[CODEX_EXP0034.md](CODEX_EXP0034.md)를 실행 계약으로 읽고, 추가된 `sceneguard/approach_disappearance.py`, `sceneguard/appearance_support.py`, `tests/test_approach_disappearance.py`를 재사용한다.

핵심은 반대편에서 사람이 다시 안 보여도 **접근 이력 + 방향 + 알려진 가림 위치에서 소실**로 침입 의심을 남기는 것이다. ±90°는 보조값이며 강제 판정 기준이 아니다. VLM은 침입 판정 대신 공통으로 보이는 상의/하의/가방의 비교만 한다. 하의가 가려지면 불일치가 아니라 미관측이다. 예측 박스는 실제 관측과 분리하고 원본 파일 끝은 소실로 세지 않는다.

CPU 분석기와 비교 어댑터/응답 검사 구현, 합성 테스트 32개 통과까지 완료했다. **실제 030/007 실행, 기존 Qwen 큐에 외형 비교 phase 연결, 원본 검수/화면 전달은 아직 남아 있다.** 문서 추가로 종료하지 말고 로컬 CCTV에서 적용하고 결과를 남긴다. 기존 의심 후보/원본/사용자 영역/모델/큐를 보존한다. 화면은 `침입 의심 / 침입 확인 / 침입 아님 / 판단 불가`만 사용한다.
