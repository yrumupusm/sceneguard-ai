## 보존된 실행 지침

# 최신 사용자 승인 — SceneGuard MVP 마무리

[CODEX_MVP_FINISH.md](CODEX_MVP_FINISH.md)를 우선 실행한다.

1. EXP-0035의 넓은 침입 의심 생성은 유지한다. 추가한 `continuation_audit`와 `exp0037_application`으로 명백한 추적 단절의 알림만 줄이는 후처리를007·030에서 각1회 비교한다. 효과가 없거나 핵심 의심을 잃으면 미채택하고 다음 단계로 간다.
2. 기존 모델·설정·큐를 재사용해 영상 입력→분석→사건 카드→근거 영상의 단일 실행 경로를 연결한다. 저장 결과 재생과 새 원본 분석은 구분한다.
3. `review_store`를 기존 화면에 연결해 검토 상태·메모·이력을 별도 저장한다. README와 시연을 실제 구현 상태에 맞게 마무리한다.

원격에서 준비된 것은 핵심 모듈과 합성 테스트다. **실제 영상 비교·웹 연결·최종 시연은 아직 미실행**이므로 소스 추가만으로 완료 처리하지 않는다. 새 모델·학습·완벽한 동일인 복원을 필수로 삼지 않으며 다시 후보 생성 조건을 강화하지 않는다.

이전 작업 안내는 [보존본](CODEX_NEXT_TASK.completed-0036.md), 완료된 사건 카드 기능은 [EXP-0036 결과](experiments/EXP-0036-results.md)를 참고한다. 예전 종료 기록은 이번 명시적 사용자 승인을 막지 않는다.
