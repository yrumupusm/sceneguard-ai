# Codex 다음 작업 — EXP-0002 검수와 평가 범위 확정

2026-10-27: 사용자가 승인한 추가 검출기 1개 비교를 완료했다. [EXP-0002](experiments/EXP-0002-fcos-detector-comparison.md), [ADR-0008](decisions/ADR-0008-fcos-detector-comparison.md), [CLI](design/CV_BASELINE_CLI.md)를 먼저 읽는다. EXP-0001과 ADR-0007 및 원본/기존 출력은 보존했다.

## 완료한 범위

- FCOS ResNet50-FPN COCO_V1 한 모델만 추가, 학습 없이 RTX 3080 실행. 모델과 입력 해상도를 함께 변경했으므로 해상도 단독 효과로 해석하지 않음.
- EXP-0001과 동일한 네 짧은 구간 2,060프레임, 동일 추적/ROI/경계/score 설정. 원본 PTS·영상/config/추적 코드 해시 대조 통과.
- 미리 정한 35개 paired frame에서 실제 사람 복원과 남은 누락 확인. 030/007 중복 bbox 및 031 고정 물체의 person 오검출 의심을 별도로 기록.
- 처리 시간·GPU 메모리·연결 실패·후보 0·한계를 EXP-0002에 기록. 13개 테스트 통과. FCOS는 후속 검증 후보이며 메인 채택 보류.
- 공식 라벨 변경, 재학습, VLM, 고급 tracker, UI, 추가 데이터 수집 없음.

## 다음 순서

1. 로컬 outputs/cv_phase2b/review{030,006,007,031}/의 paired frame 35개와 review031/native_background.jpg를 사용자와 확인한다. 031 고정 의자·흰 물체처럼 보이는 작은 영역은 비사람 오검출 의심이며 최종 판정 유보. 178개 영역 bbox를 확정 FP 정답으로 쓰지 않는다.
2. 실제 사람/중복 bbox/비사람/불확실을 별도 검수 기록으로 분리한다. 모델 출력을 자동 정답으로 사용하지 않는다. 030/031 검출 누락과 007 연결 모호성을 구별하고 메인 모델 여부를 재검토한다.
3. 006 실제 4006 vs JSON 4011 불일치 및 119~132초 비이벤트 후보 상태 유지. 가까운 출입문 ROI와 먼 보행 위치를 구분해 감시 범위를 확정한다. 후보 0을 정상 판별 성공으로 쓰지 않는다.
4. 001/007/030 첫 등장≠넘기 시작, 031 약 33초 접촉≠공식 43.600초 시작·종료까지 모든 사람 완료되지 않음을 유지한다. 미관측 완료 시각 생성 금지.
5. 006/007 및 013/039/045 등 같은 카메라 그룹은 분할을 넘지 않게 한다. 현재 모두 development, 독립 평가 아님. 검수 음성 시간·사람별 시각·평가 manifest·G1E 확정 전 F1/FP-hour·정밀 지연·일반화 주장 금지.
6. 속도 판단이 필요하면 같은 배경 부하에서 교차 반복한다. 해상도 효과는 동일 모델에서 입력만 바꾸는 별도 실험으로 분리한다. 이번 결과를 그 실험의 대체 근거로 쓰지 않는다. 후속 구현 범위는 별도로 정하되 이미 완료한 이번 승인 범위를 다시 승인받을 필요는 없다.
