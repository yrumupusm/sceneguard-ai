# 최신 승인 — 제공된 전체 영상 정확도 검증

사용자는 “주어진 모든 영상에서 다 테스트 된거야?”에 대한 일부 구간만 검증됐다는 설명 뒤 **“응 정확도 한번 검증해보자”**라고 승인했다. [CODEX_MVP_EVALUATE_ALL.md](CODEX_MVP_EVALUATE_ALL.md)를 따른다. 과거 실험 종료/추론 금지 문구는 과거 범위이며, 이번 전체 검증에 필요한 동일 FCOS의 기존 canonical 큐 실행은 허용한다. 새 모델·학습·판정 튜닝은 하지 않는다.

기준 분석 버전은 `548ff7098045f9efc5bd2edfd5ce61431a5e210e`다. 평가 집계기 `sceneguard/accuracy_evaluation.py`와 합성시험 26개·문법 검사를 준비했다. **전체 원본 추론, 로컬 정답/출력 변환, 실제 정확도 계산은 아직 실행 전**이다. 집계기만 실행한 것을 영상 검증으로 표현하지 않는다.

1. 기존 원본과 공식 JSON의 전체 명단을 디스크에서 대조한다. 초기 기록은45쌍이나 실제 수를 다시 확인한다. 모든 원본을 처음부터 끝까지 평가 대상으로 두고, 일부 클립을 여러 영상으로 세지 않는다.
2. 최신 mvp_pipeline으로 지원되는 전체 원본을 실제 실행한다. 맞는 검출 캐시는 재사용하고 없으면 같은 모델을 기존 큐에서 계산한다. 카메라별 정지 배경 설정은 허용하되 정답/출력에 맞춰 튜닝하지 않는다. 미지원 FPS/카메라·실패·미실행은 전체 명단에 이유와 함께 남긴다.
3. 공식 event_frame과 native PTS·프레임 수·0/1기준을 대조한다. 정답을 분석기에 제공하지 않는다. 기존 사용자 검수는 재사용하고 공식/검수 참조 점수는 분리한다. 라벨 밖을 자동 정상으로 만들지 않는다.
4. 의심/확인을 별도 사건 단위로 평가하고 TP/FP/FN·정밀도·재현율·F1·분모를 보고한다. 열린 카드 전체를 검출로 세지 않으며, 이후 TP가 된 사건의 앞선 정상 대기 경보도 별도로 센다. 정상시간 경보수·시간·탐지시점·중복·실패를 함께 보고한다.
5. 개발자료와 같은 카메라 추가자료/미사용 카메라를 분리한다. 모든 프레임/박스는 독립 정답 표본이 아니며, 실행 제외/정답 미확정을 좋은 점수의 분모에서 숨기지 않는다.
6. 전체 실행기/정답 adapter를 로컬 실제 계약에 연결하고 실측 보고서 `docs/MVP_FULL_EVALUATION.md`와 비식별 집계를 게시한다. 기존 시연·DB·원본은 보존한다. 결과를 본 뒤 고친 버전은 별도 평가로 분리한다.

완료 보고는 **전체 N개 중 전구간 성공 M개, 미지원/실패/미실행 수**로 시작한다. 실제 미실행이 남으면 전체 검증 완료가 아니다. 애매한 원본 구간만 모아 확인하고 정밀 개인식별/사람박스/기존 장면 재검수를 요구하지 않는다.
