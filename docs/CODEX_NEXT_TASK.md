# Codex 다음 작업 — 검수 확정과 평가 계약 동결

- 2026-10-27 사용자 최신 지시 반영. [사용자 검수](data/AIHUB_INTRUSION_USER_REVIEW.md), [평가 구성안](data/AIHUB_INTRUSION_EVALUATION_PLAN.md), [CV baseline 설계](design/CV_BASELINE.md), [ADR-0005](decisions/ADR-0005-minimal-boundary-baseline-design.md).
- 완료: 누적 CCTV 10개 디코딩, 사용자 행동 구분 반영, 006 비이벤트 후보 대조, 공식 라벨 무변경, 평가·baseline 설계. **모델 구현·학습·추론은 아직 시작하지 않는다.**

1. 001/007/030에서 사건 주체별 first_visible와 climb_start를 구분해 정밀 PTS 검수 기록을 확정한다. 현재 근거 범위를 확정된 정답 시각으로 바꾸지 않는다.
2. 031 약 33초 접촉과 공식 43.600초 시작을 분리 유지. 완료한 주체와 종료까지 미완료/가려진 주체를 구분하고 미완료 종료 시각은 임의 생성하지 않는다.
3. 006 약 119~132초 후보의 정확한 범위·감시 경계·검수 범위를 사용자와 확정한다. JSON 4011 vs 실제 4006프레임/29.97fps 차이는 별도 조사하며 공식 라벨 자동 수정 금지.
4. 006/007과 013/039/045를 같은 분할 그룹으로 유지. 학교 구도의 동일 장소 가능성 확인 전 새 카메라 독립 성능 주장 금지. 현재 10개는 개발 표본이며 추가 표본/다운로드는 별도 결정.
5. 검수 시간 마스크·camera/site 그룹·평가 manifest·매칭 허용 오차·경계 설정 절차를 동결한다. 이후 검출기 후보의 라이선스·환경·해상도 적합성을 검토하고 사용자가 구현을 승인하면 최소 baseline부터 진행한다.
6. 작업 단위별 기록·HANDOFF/WORK_PLAN 갱신 후 코드·문서만 GitHub에 반영한다. 원본·라벨·프레임·가중치는 로컬 전용, 이전 데이터 감사 보존.

이전 Phase 1E 최초 작업 지시는 Git 이력에 보존되어 있다. 현재 상태는 데이터/평가 설계의 Conditional Go이며 메인 데이터·모델 최종 승인과 별개다.
