# 다음 작업 — 독립 카메라 평가 계획

2026-10-28. 최신 결과는 [EXP-0015 사용자 라벨 revision](experiments/EXP-0015-user-label-revision.md)이다. 기존 EXP-0013 저장 결과에 대한 소규모 CPU 평가와 사용자 확인 반영을 끝냈다. 새 GPU 추론·모델 추가·웹 기능 확장은 수행하지 않았다.

## 완료 상태

- EXP-0014의 사전 고정 12개 5초 창과 B/C 원응답은 보존했다. 사용자가 로컬 원본 전용 클립 q01–q06을 직접 검수해 범위가 한정된 라벨 6개를 제공했다. EXP-0015는 원본 EXP-0014/0013을 덮어쓰지 않고 별도 revision 레코드로 반영했다.
- q01, q02, q03, q05, q06은 해당 5초 구간에서 넘기 시도/진행이 보이지 않는다고 확인했다. q04에는 넘기 시도/진행이 보이지만, 완전히 넘어가기 전에 클립이 끝난다고 확인했다. 완료 여부는 관찰되지 않았다.
- primary 검수는 양성 0/3이다. B는 primary 음성 3개 중 2개, C는 1개에서 후보를 냈다. 진단 창 q03/q04/q06에서 B는 0/3, C는 2/3 후보를 냈으며 q04만 시도/진행 양성이다. 총 6개 중 후보는 B 2개, C 3개다. 이 개발 표본 수는 오탐률이 아니다.
- 확인된 비사건 5개 중 B/C 각각 2개 후보가 남았다. 미확정 5개와 별도 부분 양성 d030_90은 음성으로 취급하지 않았다. 030 약90초는 부분 양성 관찰이며 전체 행동/완료를 확정하지 않는다.
- 독립 검토, 16개 focused CPU tests, completion metrics validator, EXP-0015 완료 등록, GitHub 게시 검증, 기존 로컬 결과 페이지의 담당 카드·보고서·그래프·검토·6개 영상 재생/seek 확인을 마쳤다. GitHub와 로컬 화면 확인은 별도 receipt다.
- 기능/평가 처리 완료와 행동 성능 충족은 다르다. 정확도·precision·recall·F1·FPR·시간당 오탐은 산출하지 않았고, 자동 채택은 보류한다.

## 다음 작업

기존 구현을 바꾸기 전, 독립 카메라/세션을 평가 단위로 하는 사전 고정 검증 계획을 작성한다. 촬영 그룹, 사람 검수 범위, 관측 가능한 사건 정의와 최소 양성·음성 범위를 확인한다. 반복 카메라의 인접 창을 독립 표본처럼 세지 않는다. 이번 개발 창을 튜닝과 최종 테스트에 동시에 사용하지 않는다.

별도 범위 승인 전에는 새 모델 추론, 가중치 다운로드, 경계/후보 규칙 변경, 자동 운영 성능 주장을 시작하지 않는다. 사람 확인이 필요한 새 쟁점은 독립 평가 계획을 세운 뒤 핵심 질문을 한 번에 모은다.
