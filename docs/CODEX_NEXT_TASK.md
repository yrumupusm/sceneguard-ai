## 완료와 제한

사용자 승인으로 한 모델 Qwen3-VL-2B-Instruct를 격리 `.venv-vlm`에서 실행했다. 선택된5초 원본6개,10프레임/약2fps,448×768,동일 중립 질문/greedy384토큰,원본PTS·실제영상토큰1680감사 완료. CV·공식JSON·파일명 정답단서 없이 로컬추론만 수행했다. 기존 `.venv`/CV/추적/경계 코드 불변, VLM 기본 연결 없음, EXP-0006 기본 적용 보류.

생성6개완료/OOM0이나 행동 구분 불안정: 실제 넘기를 문 열기/이동으로 설명, 문 개폐·목적 근거 부족, 가림 유보 미흡,030반복·출력절단. strict JSON은 모두 펜스로 실패. UTF-8 저장 실패 첫 시도까지 기록했고 실패 첫응답본문은 복구못함. 원응답/실패를 성공으로 덮어쓰지 않는다.
