# EXP-0046 실제 실행 완료 — 기본 적용 보류, 전달 확인 진행

2026-11-01. [결과](experiments/EXP-0046-results.md)와 [독립 검토](reviews/EXP-0046-independent-review.md), [전달 확인](experiments/EXP-0046-delivery.md)을 우선 읽는다.

사용자가 문 높이보다 크다고 지적한 두 초안을 직접 제공된 정지 윤곽에 따라 축소한 뒤, 007/030 전체를 각 한 번 실행했다. 새 B는 8/12건이며 일부 작은 박스를 위치상 허용하지만 접근·대기 문맥의 불필요한 의심과 후반 작은 박스 제외가 남는다. A 자동 확인과 원래 이벤트는 보존했지만 결합의 첫 통지 4/5 흡수 때문에 기본 적용을 보류한다.

실제 CPU 실행과 29영상·2미리보기 제작은 완료다. 새 B의 동일인·물리적 출현 정답을 추정하지 않는다. 두 짧은 새 검수 질문의 후속 답변은 별도 관찰 기록으로 반영하되, 답변을 근거로 자동 재실행·구역 확대·임계값 변경을 하지 않는다. 기존 MVP와 수동 검토 DB·영수증은 유지한다. 등록·GitHub·브라우저 확인은 전달 기록의 실제 영수증 상태를 따른다.

아래 승인 원문은 이번 작업의 이력이다. 이번 범위 완료 뒤 후속 성능 실험을 자동 시작하지 않는다.

# 최신 승인 — EXP-0046 문 주변 고정 구역으로 새 출현 검사

2026-11-01. [CODEX_EXP0046.md](CODEX_EXP0046.md)를 진행한다. 사용자는 바닥 경계선과 신체 박스 중심의 거리 대신 **문 높이와 바로 뒤 가시 영역을 포함한 카메라별 고정 구역**을 지정하는 방식을 승인했다. 학습용 사람 박스나 매 프레임 작업이 아니다. 이전 종료 문구는 과거 범위다.

준비: `portal_births.py`, `exp0046_application.py`, 합성/순수 계약55시험 통과와 문법 검사. 실제 문 구역 좌표/원본 적용/전체 통합/웹은 아직 전이다. EXP45 실제 관측열 코드를 그대로 사용해 기하·부분박스·ID변경·짧은누락·첫위치·시간계약을 검사했으며 CCTV 성능으로 확대하지 않는다.

1. 기존 원본 정지 배경으로 C3/C6의 문 주변 구역을 한 번 지정하고 원본 위에 표시한다. 문 전체 높이+바로 뒤 좁은 출현 범위만 포함하며 먼 통로/옆 보행로를 넣지 않는다. 좌표는 원본 기준이고 실제 좌표/미디어는 로컬 전용이다. 정확한 사용자 확정 좌표가 아닌 초안임을 기록한다.
2. 007 승인 inside 수정본과030 기존 scene/바닥선/안밖 방향을 유지한다. 새 다각형은 별도 JSON이며 `make_region`으로 카메라·원본크기·선택 scene·정지프레임 출처를 결속한다.
3. B 첫 박스 중심 또는 절반 이상 면적이 새 구역에 해당하면 위치 근거로 사용한다. 바닥선 거리·박스높이 반경·지면inside를 다시 필수조건으로 붙이지 않는다. 시간 지지/기존 관측열 처리는 EXP45 그대로다. B만으로 자동 확인하지 않는다.
4. A의 문근처이력＋안쪽이동＋소실 확인은 EXP45 출력 그대로 복사하고 손대지 않는다. 새 학습/검출/ByteTrack/flow/VLM/모델은 없다.
5. 두 전체 선택 구간에서 옛 B와 새 B의 후보·첫위치·놓친 사례·오탐을 비교한다. 결합의 원래 첫경보 흡수도 따로 확인한다. 후보 증가만으로 성공 처리하지 않고 원본을 확인한다.
6. 기존 담당3에 구역 미리보기/원본·최초박스/비교를 연결해 실제 재생·되감기·상태를 확인한다. 필요한 새 짧은 영상만 검수 요청하고 이미 확인한 장면은 재질문하지 않는다. 결과·독립 검토·전달을 GitHub에 남기되 기본MVP/수동검토/영수증은 보존한다.
