## 실행 비용·보존·한계

43개 새 FCOS 작업은 각 첫 시도에 성공했다. 새 검출175,327프레임,007/030 재사용8,973프레임이다. 모든45개에서 새 추적·CPU 특징을 생성했다. 새43개 wrapper 시간 합은22615.096초, 원본5,844.366867초 대비3.869555배다. 검출만의 FPS 또는 실시간 탐지 지연으로 해석하지 않는다.

007/030 회귀에서 자동 비교기가 생성 ID와 동일 시각 정렬 차이를 결과 변경으로 오인했다. 원래 실패를 보존하고 독립 검토가 사건 내용/소속/시각의 일대일 대응과 부정 대조를 검사해 의미적 동일성을 판정했다. 이를 실행 실패를 없앤 것처럼 숨기지 않는다.027 전 GPU 자원 부족 중지는 작업 생성 전에 발생했고 사용자 확보 후 동일 계획으로 재개했다.

다섯 출력 흐름의 native PTS와 원본 전체를 대조했다. 기존52개 큐 작업/시도 행은 그대로이며43개가 추가돼95개다. 기본 보기·검토DB·알림 영수증을 보존한다. 실제 해제의 효용과 장면별 인물 동일성은 이 수치로 인증하지 않는다.

## 재현과 전달

실행은 동결 계획과 원본/코드/환경 해시가 일치할 때만 기존 `scripts/mvp_expanded_run.py execute` 경로로 재개한다. 완료45개는 재추론하지 않는다. 공식/검수 manifest는 `scripts/mvp_full_evaluation_adapter.py manifest`, 점수는 `python -m sceneguard.accuracy_evaluation`로 생성했다. 로컬 평가 입력·예측·영상·캐시·원시 로그는 게시하지 않는다.

독립 결과 검토와 웹·GitHub 전달은 별도 확인 대상이다. 실행 성공만으로 화면 재생·게시 완료 또는 MVP 행동성능 충족이라고 표시하지 않는다. 기본 모델과 판정은 그대로 유지하며 본 평가에 맞춘 후속 튜닝을 시작하지 않는다.
