## 재현·로컬 근거·전달

분석 입력은 `outputs/validation/mvp-all-v1/inventory/source-list.json`이며 정답이 없다. 전체 목록/정답은 같은 디렉터리의inventory/truth, 실제 실행은 `outputs/validation/mvp-all-v2/runs/E01_007` 및 `E01_030`, 계획·89개 의존 해시·canonical queue 영수증은 `runtime/MVP-ALL-execution-v2`다. 원본과 원시 결과는 모두 Git 제외다.

실제 실행은 기존 `scripts/mvp_full_run.py`의prepare/execute를 새 LOCAL/RUNS 경로로 호출했다. 재실행은 새 실제Orca배정·새출력경로에서 아래를 사용하며 기존계획/결과를 덮어쓰지 않는다.

```python
import os
from pathlib import Path
from scripts import mvp_full_run as run
run.LOCAL = Path('runtime/MVP-ALL-next').absolute()
run.RUNS = Path('outputs/validation/mvp-all-next/runs').absolute()
run.LOCAL.mkdir(exist_ok=False)
plan = run.LOCAL / 'execution-plan.local.json'
run.prepare(Path('outputs/validation/mvp-all-v1/inventory/source-list.json').absolute(), plan)
run.execute(plan, {k: os.environ['SCENEGUARD_'+k.upper()]
                  for k in ('run_id','task_id','dispatch_id','owner')})
```

기존CV환경 `.venv-cv-batch02/bin/python`으로 실행한다. GPU여유6144MiB보호, 원본/버전/큐/설정해시 검증을 통과해야 한다. 지원확대·판정수정이 있으면 이전점수와 분리된analysisrevision을 사용한다.

```bash

  --inventory outputs/validation/mvp-all-v1/inventory/inventory.json \
  --truth outputs/validation/mvp-all-v1/truth/official-zero-based.json \
```

동일명출력은 이미 있으므로 복제평가는 새 경로를 사용한다. official-one-based 및reviewed도 별도manifest/report로 실행했으며 원본노출은중복합산하지 않는다.
