# Codex 첫 작업 지시 — 데이터 적합성 감사

## 목적
SceneGuard의 모델을 선택하기에 앞서 **실제 공개 영상이 목표 위험행동 분석에 적합한지** 확인하고, 다음 의사결정의 증거를 만든다.

## 순서
1. 저장소의 AGENTS.md, README.md, docs/PROJECT_CHARTER.md, docs/WORK_PLAN.md, docs/data/DATASET_AUDIT_PLAN.md, docs/research/를 읽고 현재 미확정 사항을 파악한다.
2. Safe and Unsafe Behaviours의 원 연구/배포 페이지를 방문하여 파일 구조, 행동 클래스·라벨 메타데이터, 데이터 이용 및 재배포 조건을 URL과 확인일과 함께 기록한다. 웹 접근이 안 되면 실패 사실과 로컬에서 실행할 명령 제시.
3. 우선 정상 3~5개, 위험 3~5개만 골라 다운로드한다. 클래스 편향이 적고 통로 이탈/패널 개방 후보를 비교할 수 있도록 선정 근거를 남긴다.
4. 영상별 재생 여부, FPS, 해상도, 길이, 프레임 수와 라벨 매핑을 검증한다. **파일 이름만 보고 라벨을 짐작하지 않는다.**
5. 이벤트가 실제로 보이는 장면, 필요한 객체, 카메라 시점, 보이는 근거, 단일 프레임과 시간 정보 중 무엇이 필요한지 기록한다. 영상만으로 권한이나 규정 위반을 확정하지 않는다.
6. 불확실한 판단은 사용자에게 영상을 보여주며 확인받을 질문으로 남긴다. 출처 문서 사실/코덱스 관찰/추정/미확인을 구분한다.
7. docs/data/SAMPLE_AUDIT_TEMPLATE.md를 바탕으로 **docs/data/SAMPLE_AUDIT.md** 작성. 데이터 적합성에 대해 Go / Conditional Go / No-Go와 근거·추가 라벨 예상 범위·남은 위험을 보고한다.
8. 로컬 테스트에 필요한 최소 스크립트와 사용법만 추가한다(필요할 때). .gitignore 누락 시 보완. 원본 영상/가중치/개인정보/비밀정보는 공개 저장소에 커밋하지 않는다.
9. 완료 후 docs/HANDOFF.md를 업데이트하고, 변경 파일·실행한 명령·확인된 결과·미완료 항목·커밋을 요약한다.

## 이번 단계에서 하지 않을 일
모델 선택·학습·VLM 서버 구축·대시보드·API·최적화, 전체 데이터셋 다운로드, 요청 없는 대규모 의존성 설치. 사용자 승인 후 다음 단계로 진행한다.
