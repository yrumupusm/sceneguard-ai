# 경계 통과 확인 보완과 관측 연결 비교

## 최종 선택

기존 rc3 관측·소실 판정을 유지하고, 실제 박스의 유효한 경계 통과 후보를 침입 확인에 연결하는 안을 기본 적용한다. 소스 커밋은 `d7e0efe1e2f100082ffd37bfed34377b02560c62`다. 안→밖과 밖→안 모두 데이터셋 기준으로 확인하며, 충분한 실제 경계 통과 근거가 있으면1초 소실을 기다리지 않는다. 다른 사람과의 신원 재연결을 이 통과 확인의 필수 조건으로 삼지 않는다.

동일45개 영상의 공식52개 사건 기준으로 선택안은32/52→39/52(75%), 누락20→13이며 기존 정답 매칭 손실은0건이다. 의심은51/52를 유지한다. 이른 최초 확인은3→8건이어서 추가된5건의 의미 검수가 남는다. 정상 검수 구간에서 확인 오알림0건이 유지된다는 사실을 전체 영상의 오탐0건으로 확대하지 않는다.

전체 관측 보완안은40/52지만009·033을 놓치고 이른 최초 확인이16건이었다. 선택안보다 실제 구간 내 최초 근거가 늦어진 사건도9건이다. 더 많이 구현한 안을 자동으로 채택하지 않고, 기존 사건을 유지하고 확인 지연을 늘리지 않은39건 안을 선택했다. 관측 보완 코드는 재현과 후속 연구용으로 보존하며 기본 경로에서는 활성화하지 않는다.

최종 기본 코드의 관련396개 시험은 실패·오류·skip 없이 통과했다. 과거 동결 소스 동일성 검사1개는 앞선 작업과 같은 이유로 별도 보존했다. 최종 기본 코드 `default-selected-001`의45개 전구간 규칙 재생은182.184초에 오류 없이 완료했다. 선택 비교군과45개 모두의 예측·개별 판정·문 후보·관측 조각 및 전체 수치가 정확히 같으며, 소스90개와 보호 입력218개의 해시가 유지됐다. 원본 영상의 새 모델 추론 결과가 아니라 저장 측정값에 대한 현재 규칙 평가다.

아래 run-002·run-003은 비교 과정의 시험 기록이며 최종 기본 적용 결과와 구분한다.

2026-11-04. 사용자가 제안한 “문에 접근한 대상의 위치·방향·소실을 중심으로 판단하고, 반대편 사람과의 신원 연결을 필수로 두지 않는다”는 방향을 반영한다. [ADR-0027](decisions/ADR-0027-gate-observation-confirmation.md). 이번 범위는 기존 후보 연결과 관측 지속 분기이며, 영역·검출 모델·추적 모델·정답 구간은 바꾸지 않는다.

## 이전 상태와 검수 근거

rc3의 전체 저장 관측값 평가에서 확인32/52, 의심51/52였다. 011·017·019의 기존 경계 통과 후보가 확인에 연결되지 않았다. 다만 기존 `cross_side_observation` 문자열 자체가 통과 증명은 아니었다. 원래 대상에 연결된 점의 실제 유한 경계 교차를 검사하니017·019의 최대 합의 비율은12.9%·3.57%였다.011·019에는 마지막 시점까지 강한 관측 지속 근거도 있었다. 부분 관측을 “넘는 내내 검출이 잘 됐다”로 해석하지 않는다.

원본 감사는 로컬 `outputs/validation/continuation-crossing-v1/continuation-audit.json`, 실제 기존 후보 검사는 `outputs/validation/existing-alert-crossing-v1/E01_011-candidate-inspection.json`에 입력 해시와 함께 저장했다. 작업 시작 웹 pending 답변은0건이며, 이미 받은 채팅 검수는 그대로 재사용했다.

## 구현

- `existing_alert_gate_crossing_v1`: 기존 경계 후보를 실제 박스 하단 중심점으로 재검증한다. 원래 발생 시각까지의 고유 관측 조각, 출발/도착 양쪽의0.2초·3회 관측, 연속성, 유한 문 경계 통과가 필요하다. 실제 발 좌표나 문 넘기 동작 인식은 아니다. 원래 후보의 방출 시각을 유지한다.
- `observed_gate_continuation_v1`: 원래 대상에 묶인 동일 특징점3개 이상·출발 점의60% 이상이 일관되게 움직이고, 카메라 이동 보정 후 방향이 맞아야 한다. 실제 박스도 유한 경계를 지나 반대편에서0.2초·3회 이어져야 한다. 특징점 하나, 정지 박스 내부의 점 흔들림, 선 연장선, 미래 관측은 확인에 쓰지 않는다.
- 출발 쪽 관측 지속, 경계선 위의 확실한 관측, 단지 반대편처럼 보이는 미검증 관측을 실제 소실과 구분한다. 주변 사람이 존재한다는 사실만으로 원래 대상의 소실을 취소하지 않는다.
- 모호한 연결 때문에 임시 보류한 소실은 마지막 실제 연결 관측 이후 대기 시간이 지나면 재검사한다. 겹친 동일 위치 후보만 실제 시각·박스 근거로 사용하고, 서로 다른 위치의 후보를 임의로 같은 사람으로 선택하지 않는다. 마지막 방향도 이후 관측에 맞춰 다시 계산하여, 뒤늦게 돌아간 사람을 이전 접근 방향으로 확인하지 않는다. 모호한 연결을 의심 해제 근거로 쓰지 않는다.
- 관측 조각 연결 전의 실제 근거를 사건별로 보존한다. 처음 조각이 너무 짧으면 상속된 실제 관측 중 첫 반대편 이동 이전의 출발 근거를 보충하며, 기존 출발 참조도 남긴다. 같은 실제 교차는 관측 ID가 바뀌어도 최신 사건의 근거 하나만 확인한다.

MVP 버전은 `MVP-1.0-rc4`다. 과거 EXP 재생 기본값과 원본 결과는 유지한다. 새 이미지 처리나 GPU 추론이 없으며, 검출·추적·특징점 측정값을 재사용하는 CPU 규칙 재생이다.
