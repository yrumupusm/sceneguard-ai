# SceneGuard — CCTV 출입 경계 침범 감지·검토 업무 흐름

- 상태: **1차 MVP 가설/잠정 범위**, 실제 데이터·관제 현장 검증 전
- 현재 결정: [ADR-0004](decisions/ADR-0004-boundary-crossing-cctv-mvp.md)
- 과거 사고 클립 사후 검토 방향은 [ADR-0003](decisions/ADR-0003-incident-review-product-direction.md)에 보존.

## 가정한 사용자 문제
학교·공공시설의 고정형 CCTV에서 경계 근처의 **사람 통행, 머무름, 넘기 행동**을 반복해서 모두 확인하기 어렵다. 자동 탐지는 감시선을 넘는 행동의 후보 시점과 근거를 제공하되, 실제 접근 권한/무단침입 여부는 관리자가 확인한다. 실제 사용자 인터뷰는 아직 없다.

## 제품 흐름 가설
1. 카메라별 감시선/ROI(넘기·통과 판단의 경계)를 지정하고 녹화 CCTV 영상을 입력한다.
2. 공통 CV 모델과 최소 규칙을 적용해 사람 위치 변화와 설정된 경계 통과/넘기 **이벤트 후보**를 찾는다. 기술은 이후 데이터·baseline 실험으로 결정한다.
3. 사건 발생 시점·근거 프레임·추정 행동·신뢰 수준을 제시한다.
4. 관리자가 맞는 경보/오탐/판단 보류를 검토하고, 검수 이력과 함께 저장한다.
5. 기존 CV 방법의 오탐·미탐을 분석해 VLM이 동작 해석/설명 등에 유용한지 **비용·지연 포함 대조 실험**으로 판단한다. VLM은 초기 필수 구성요소가 아니다.

## 반드시 구분할 사례
- **경계선 통과 vs 실제 울타리·줄 넘기**: 2D 사람 중심점이 가상선을 넘었다고 실제 울타리를 넘었다고 결론 내리지 않는다. 대상 경계와 몸의 자세/시간 흐름을 비교 검증해야 한다.
- **법적 무단침입 vs 관찰 행동**: 영상으로 출입 권한을 단정하지 않는다.
- **카메라별 규칙 vs 모델별 재학습**: 우선 **공통 모델 + 카메라별 ROI/선 설정**을 기준선으로 가정. 장소별 모델 파인튜닝은 별도 비교 필요 시 고려한다.
- **같은 카메라 테스트 vs 미경험 카메라 테스트**: 둘을 구분하고 훈련/평가의 같은 영상·세션·구도가 섞인 누수를 방지한다.
- **이벤트 앞뒤 vs 검수된 정상 구간**: 라벨이 없는 시각을 자동으로 안전/비이벤트 gold로 지정하지 않는다.

## 잠정 평가 방법 (데이터 확인 전)
| 질문 | 지표 후보 | 전제 |
| --- | --- | --- |
| 언제 감지했는가 | GT 구간 대비 탐지 지연, 구간 IoU 또는 이벤트 매칭 기준 | 사건 구간·PTS GT 검증 |
| 얼마만큼 놓치거나 오탐이 생기는가 | event precision/recall/F1, 검수 정상 시간당 오경보 건수 | 비이벤트 구간 검수 |
| 처음 보는 카메라에서 되는가 | camera/site held-out vs seen-camera | 충분히 독립적인 그룹 수 |
| 실시간에 가까운가 | 전체 FPS, p50/p95 지연, VRAM | 구현·실측 이후 |
| VLM이 가치 있는가 | CV-only 대비 오탐·미탐/설명 일치·추론시간·비용 차이 | 같은 테스트 영상, 분리 정답, 사람 검수 |
