## 기술 기록

[설계 결정](decisions/) · [실험 보고서](experiments/) · [검토 기록](reviews/) · [선행 기술 조사](research/)

안내 문서와 화면의 상태 이름은 **침입 의심 / 침입 검출 / 의심 해제**로 구분.
침입 검출은 시스템 판단이며 사용자의 검수 완료와 별개.

수치·원문 검증을 위한 실험 보고서, 측정값, 내부 상태값과 키는 보존.
과거 기록을 화면에 표시할 때만 현재 용어로 변환하며, 검수 입력 내용은 변경하지 않음.
