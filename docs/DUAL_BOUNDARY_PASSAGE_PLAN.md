## 사전 고정 범위

- 기존 보라 공통선과 검수한 빨간 안쪽 선을 별도 입력으로 사용한다. C5 안쪽선은 검수 자료의 꺾인 윤곽이다. 원본 registry/scene/portal은 수정하지 않고 새 revision으로 보존한다.
- 문 바로 안쪽이나 두 선 사이에서 관측만 지속되는 경우 의심을 유지한다. 실제 출발 측→문 구간→반대편 이동의 측정 근거로 확인하며, 양방향에 동일 원칙을 적용한다.
- 출발 근거가 최근3초 창 밖으로 밀려나거나 문 구간에서 영역 미분류된다는 이유만으로 잊지 않는다. 유효한 사건 범위·연결의 불확실성을 명시하며 무기한/다른 대상에 이력을 전달하지 않는다.
- 끊김 전후 연결은 실제 박스·시간·위치·방향과 경쟁 후보를 검사한다. ID 같음, 가까운 재등장, 확대 임계값 하나만으로 동일 대상/통과를 확정하지 않는다. 미관측 경로를 실제 관측 경로라고 보고하지 않는다.
- 문 근처 소실은 출발·직전 위치·방향·경로를 함께 본다. 실제 반대편 통과가 없었던 바깥 접근 후 복귀와 안→밖 실제 통과를 구분하고, 확인된 통과를 나중의 복귀/다른 사람 등장으로 취소하지 않는다.
- 0.5초/1초 최적성 주장은 하지 않으며 대기 시간을 임의 탐색하지 않는다. 가려진 발/바닥 복원, 새 검출·추적·flow·GPU·모델 학습은 범위 밖이다.
- 새 규칙이 없는 입력의 기존 동작은 재현 가능하게 보존한다. 새 경계가 활성화된 경우 옛 확인 경로가 새 조건을 우회하지 않아야 한다. 새 구역 자체가 검출/정답을 의미하지 않는다.

저장 측정값을 사용하며 원본·정답·기존 결과·검수 DB·영수증을 보존한다. 실제 신규 모델 추론 결과로 표현하지 않는다. 실행 전에 입력/코드/새 경계 해시와 비교 조건을 고정한다. 구현 오류는 고쳐 재검증하되, 영상별 사건 시각에 맞춰 조건을 반복 탐색하지 않는다.
