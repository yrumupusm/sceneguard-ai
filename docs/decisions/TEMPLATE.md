# ADR-000X — 결정할 기술적 질문

- 날짜:
- 상태: 제안 / 잠정 채택 / 채택 / 보류 / 대체됨

## 문제와 제약
왜 선택이 필요한가? 목표, 데이터 라벨, 장비, 속도, 정확도, 비용, 라이선스.

## 선택과 이유
확정인지 가설인지 명시한다. 선택하지 않은 후보의 이유도 기록한다.

## 검증 방법
어떤 결과가 나오면 선택이 맞거나 틀렸다고 판단할지, 어떤 지표와 데이터를 사용할지.

## 결과와 재검토
실측 결과의 링크; 아직 미실험이면 '미실험'. 결정을 뒤집을 조건과 후속 ADR 링크.

> 이미 내려진 결정을 수정할 때는 과거 기록을 지우지 말고 후속 ADR로 연결한다.
