# ADR-0025 — 연속 관측 경계 통과의 별도 침입 확인 경로

2026-11-04. 사용자 승인: 004처럼 바깥에서 안쪽으로 넘어가는 사람이 계속 보이면 소실 없이 확인하도록 알고리즘 수정.

## 근거와 선택

기존 방향+소실 규칙은 007/030의 가림을 다루기 위한 경로였다. 004 저장 기록에는 60.533초 경계 후보, 61.600초 outside_to_inside 전환이 있지만 검출이 이어져 확인 후보가 없었다. 전체 소실 대기를 없애면 기존 일시 누락 방지가 사라진다. 따라서 1초 대기는 소실 경로에 유지하고, 실제 관측이 연결된 바깥→안쪽 전환을 별도로 확인한다.

기존 observed_side_transition 후보의 실제 관측 prefix에서 바깥/안쪽의 안정된 관측, 유한 문 경계 근접, 관측 연속성을 재검증한다. 기존 안정 관측 기간·개수·간격 정책을 재사용하며 영상/시각별 예외는 없다. 예측 박스와 미래 프레임으로 확인하지 않는다. 기존 후보 원문은 의심으로 보존하고 확인 근거와 시각을 별도 추가한다. 동일 ID만으로 실제 동일인이나 권한 없는 출입을 확정하지 않는다.

005는 내부 출발과 outward 움직임을 기록하며 공식 설명도 밖으로 나가는 사건이다. 양방향 후보 정의는 있지만 침입 확인은 inward만 인정한다. 이번 변경으로 퇴장을 침입으로 승격하거나 원본 정답/과거 점수를 변경하지 않는다. 입장만 감지할지, 퇴장까지 경계 통과로 감지할지는 별도 제품 정의다.

## 검증 및 되돌릴 조건

연속 진입 양성, 역방향/안쪽 최초 등장/순간 흔들림/관측 공백/미래 근거/경계와 먼 이동 음성, 기존 소실 규칙 회귀와 실제 저장 004의 판정 경로를 검증한다. 원본/기존 결과/검수 DB는 보존하고 새 결과는 별도 로컬 출력에 저장한다. 정상 이동·ID 오연결로 잘못 확인되는 사례가 나타나면 해당 경로의 근거 요건을 재검토한다. 한 사례 개선을 전체 성능 향상으로 주장하지 않는다.
