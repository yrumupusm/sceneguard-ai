# ADR-0028 — 안쪽 전용선과 출발 이력을 이용한 양방향 통과 비교

2026-11-04. 사용자가 카메라별 안쪽선 초안을 검토한 뒤 이른 확인 보완과 안→밖 누락 보완을 함께 구현·시험하도록 승인했다. [고정 계획](../DUAL_BOUNDARY_PASSAGE_PLAN.md)을 따른다. 현재 결정은 **별도 프로필에서 후보를 구현하고 비교**하는 것이며, 기존 기본 설정의 일괄 교체를 뜻하지 않는다.

## 문제와 선택

기존 단일 경계에서는 문 바로 안쪽에 지속되는 관측이 실제 통과보다 먼저 확인될 수 있다. 반대로 안쪽 영역과 문 경계 사이의 미분류 구간이나 짧은 박스 단절 때문에 안→밖 출발 근거가 사라진다. 박스 위치·방향·출발 이력 문제를 구분하며 모든 누락을 검출 모델의 원인으로 단정하지 않는다.

새 입력 `inner_line`이 있는 경우 기존 공통선과 별도 안쪽 윤곽을 유한한 문 구간으로 묶는다. 실제 박스 높이65% 지점의 안정된 출발 관측, 순서가 있는 진입·반대편 이탈, 안정된 도착 관측을 함께 확인한다. 문 구간 안에서 관측만 오래 지속되는 것은 통과가 아니다. C5의 꺾인 윤곽과 C8의 반대 정점 순서를 유지한다. 가려진 발이나 바닥을 복원하는 방법이 아니다.

출발 근거는 기존3초 조회창 밖으로 나갔다는 이유만으로 잊지 않는다. 실제 관측의 연속성 및 사건 한계60초를 사용하며, 그 값의 최적성은 검증되지 않았다. 박스 단절은 원래 대상과 함께 움직인 저장 특징점·실제 후속 박스·경쟁 후보 검사를 통과해야 연결한다. 단절 구간을 연속된 실제 박스 관측으로 표기하지 않는다. 양방향에 동일 원칙을 적용한다.

소실 확인은 출발·측정된 진입·반대편에 가까운 마지막 위치·최근 이동·연결된 방향과 기존1초 부재를 모두 요구한다. 반대편 도착이 직접 관측된 통과와 이 소실 추론의 근거를 구분한다. 이미 확인된 실제 안→밖 통과는 이후 복귀로 취소하지 않는다. 이번 후보 경로는 자동 해제를 실행하지 않으므로 해제 개선 실험으로 해석하지 않는다.

## 대안과 선택 이유

- 대기 시간만0.5초 또는1초로 바꾸는 안: 물리적 통과와 정지를 구분하지 못하고 최적 시간 근거가 없어 선택하지 않는다.
- 기존 안쪽 영역을 넓히는 안: 출발 근거와 문 구간은 개선할 수 있으나 단절 연결·이른 확인 우회 경로를 해결하지 못한다.
- 두 경계를 더하고 옛 확인 경로를 그대로 유지하는 안: 기존 조기 확인 경로가 새 조건을 우회하므로 선택하지 않는다.
- 선택안: 새 입력에서만 공통 인과적 사건 판정 경로를 적용하고, 기존 입력의 동작과 과거 결과를 재현 가능하게 보존한다.

## 결과를 보기 전 확인한 보수적 한계

독립 합성 검토에서 선 끝점을 따라 돌아간 경로, 연속 박스의 일대다·다대일 연결, 겹친 경계 입력을 재현해 수정했다. 실제 후보45개 결과를 본 뒤 조건을 맞춘 수정이 아니다.

경쟁 연결을 한 번 가진 관측 계보는 같은 계보의 뒤 사건도 의심으로 유지한다. 이 거절은60초 출발 이력 제한과 별개이고 원본 시간 단절까지 지속될 수 있다. 새 출발 근거만으로 거절을 지우면 오래된 모호한 사건에 새 통과를 잘못 붙일 수 있다. 독립 검토가 이 반례를 확인했으므로 이번 비교는 보수적 거절을 명시한 상태로 고정하며, 새로운 사건으로 안전하게 회복시키는 변경은 별도 근거 소속 설계가 필요하다. 이 제한이 실제 누락에 미치는 영향도 보고한다.

## 판단을 바꿀 근거

전체45개 저장 측정값에서 공식52건의 확인·의심 매칭, 기존 매칭 손실, 남은 누락, 최초 알림 시각을 모두 비교한다. 기준39/52와 이른 최초 확인8건을 함께 유지한다. 안→밖 우선9영상 및010 등반 약63초 검수는 별도로 본다. 더 적은 이른 확인이 단지 확인 자체를 못 하게 된 결과라면 개선 성공으로 부르지 않는다. 회귀나 대리좌표 한계가 남으면 기본 적용을 보류하고 원본·정답·결과를 보존한다. 새로운 모델 추론 또는 전체 행동 정확도는 측정하지 않는다.


## 실제 비교 후 결정

동일45개 저장 측정값에서 확인39/52→0/52, 의심51/52 유지다. 전체 확인 알림49건이0건으로 사라져 이른8건 감소를 성공으로 볼 수 없다. 기존 확인 매칭39건 손실, 새로운 매칭0건, 안→밖 우선9개 기존 누락 회복0건이므로 **현재 조합은 미채택**한다. 기존 운영 프로필을 유지하며 후보 코드와 새 프로필·전체 실패 결과는 재현용으로 보존한다. 이는 두 경계의 위치 효과와 경쟁 연결 거절 효과를 분리한 실험이 아니다. 다음 검토는 모호한 연결이 과도하게 사건 전체를 막는 경로와 근거 소속 회복에 집중하되, 이번 결과에 맞춘 임계값 탐색은 수행하지 않는다.
