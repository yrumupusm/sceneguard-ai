# ADR-0001 — 선행연구·데이터 확인 후 모델 선택

- 날짜: 2026-10-26
- 상태: **채택 (개발 방식에 대한 결정)**
- 모델·아키텍처: **미확정**

## 배경
2023년 우회전 단속 프로젝트에서 YOLO·BoT-SORT를 사용했던 경험 때문에 새 프로젝트에도 같은 기술을 사용하려 했고, VLM 단독 분류를 직접 먼저 실험하자는 대안도 논의했다. 그러나 **관련 연구 결과와 실제 데이터 특성을 먼저 확인한 뒤 필요한 부분만 실험**하는 방식이 중복 작업을 줄이고 합리적인 기술 선택에 적합하다.

## 대안
| 선택 | 장점 | 문제 |
| --- | --- | --- |
| A. YOLO+BoT-SORT부터 구현 | 과거 경험 활용 | 실제 추적이 필요하지 않을 수 있음 |
| B. VLM-only 직접 실험부터 | 빠른 기준선 가능 | 알려진 한계를 처음부터 확인하는 작업 반복 가능 |
| **C. 연구→데이터→선택→필요 실험** | 문제/라벨/환경에 맞는 설계 | 조사 범위가 과도해지지 않도록 통제 필요 |

## 결정
**C를 채택.** Unsafe-Net 등의 시간적 행동 인식 접근, iSafetyBench의 산업안전 VLM 평가와 CV/VLM 역할 분리 사례를 검토한 다음 실제 영상 샘플을 감사한다. 결과에 따라 첫 MVP 행동/평가 단위와 필요한 최소 파이프라인을 정한다.

선행연구 성능은 연구에서 보고된 수치이며 우리 자체 성능이 아니다. 현재 VLM, YOLO, ConvLSTM, BoT-SORT, TensorRT 중 어떤 것을 채택할지도 결정하지 않았다.

## 재검토 조건
- 데이터 라벨/영상/라이선스가 맞지 않으면 데이터와 과제를 변경한다.
- 문헌 결과가 우리 데이터에 적용 가능한지 불확실하면 소규모 직접 실험으로 검증한다.
- 로컬 GPU 제약이나 모델 라이선스가 맞지 않으면 모델·범위를 조정한다.
