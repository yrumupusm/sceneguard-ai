# ADR-0003 — 1차 제품 목표: 산업현장 사고 영상 분석 및 검토 지원

- 결정일: 2026-10-27
- 상태: **제품 문제/활용 방향 채택**, 구현 범위·모델·데이터셋은 검증 전
- 선행 결정: [ADR-0001](ADR-0001-research-first.md), [ADR-0002](ADR-0002-reconsider-safety-dataset.md)

## 왜 이 방향인가
기존 고정형 공장 CCTV 데이터에서 전기함 문 열린/닫힌 상태는 식별했으나, 분류 자체만으로는 실제 안전관리 업무 가치와 포트폴리오의 기술적 문제해결 깊이를 보여주기 어려웠다.

영상에 담긴 복합 행동과 사건을 분석한 뒤 **사람의 검토·수정·재검색에 쓸 수 있는 정보로 구조화**하면, AI 응용 소프트웨어의 사용 목적과 성공 기준이 더 분명해진다.

iSafetyBench는 짧게 추출된 산업현장 클립과 행동 라벨을 제공하는 *후보*이므로, 이 자료로는 사고 후 검토 보조는 검증할 여지가 있지만 **장시간 CCTV 원본에서 사고 구간 자동 발견/사고 전 예방**을 입증하기 어렵다.

## 검토한 제품 대안
| 대안 | 잠재 가치 | 제한 |
| --- | --- | --- |
| 정적 패널 상태 분류 | 구현 간결, 관찰 가능 | 분석·검토 과정 개선과의 직접 연결 약함 |
| 짧은 영상의 정상/위험 이진 분류 | 기술 검증 쉬움 | 관리자가 영상 내용을 다시 읽어야 하는 부담이 남음 |
| **사고/이상상황 클립 분석·검토 보조** | 사건·행동 구조화, 근거 확인, 사람 검수·검색 가능 | 라벨 세밀도·설명 근거·영상 저작권·효용 측정 검증 필요 |
| 연속 CCTV 자동 사고 예방 | 운영 가치 클 수 있음 | 별도 연속 영상·시점 정답·실시간 지연/오탐 평가 필요 |

## 결정
**첫 제품 시나리오는 '이미 선택된 산업현장 영상 클립을 안전 담당자가 검토할 때 분석과 기록을 돕는 시스템'이다.** 기능은 단계별로 조건부 확장한다.

- **입력:** 담당자가 선택한 짧은 영상. 자동 사고 구간 탐지는 초기 범위가 아님.
- **분석 후보:** 영상에 나타난 복수 행동·사건을 구조화. 모델과 입력 방식은 아직 결정하지 않음.
- **근거 후보:** 해당 행동의 근거 프레임 또는 구간 링크. 데이터에 시점 정답이 없다면 추가 사람 검수가 필요함.
- **사람 검토:** 모델의 설명과 행동 태그를 수정/확정. 위험 법규 위반, 책임, 원인, 권한은 근거 없이 단정하지 않음.
- **활용 확장 후보:** 확정 기록의 검색·필터링·검토 기록 축적·보고서 초안. 이것들은 아직 구축/검증되지 않은 목표.
- **후순위:** 실시간 알림, 사고 전 예측, 법규 위반 확정, 대규모 스트리밍·엣지 배포.

## 성공 기준 후보 (실측 전)
1. 영상별 행동 분류: 공개/사람 검수 라벨의 정의와 동일 조건에서 multi-label Precision/Recall/F1 (클래스 희소성 기록).
2. 설명 품질: 장면에 없는 인물·행동·원인을 단정하지 않는지, 근거와 일치하는지 사람 검토 기준으로 평가.
3. 작업 지원: 사람이 영상 사건 기록을 작성하는 작업의 **수정 횟수, 완료 시간, 검색 시간**을 baseline과 비교할 수 있으면 측정. 사용자 연구 없이 실제 효율 개선을 주장하지 않음.
4. 운영 제약: RTX 3080에서 지연, VRAM, 처리 성공/실패, 재시작과 로그 측정 (실험 후).
5. 데이터 편향·누수·라이선스·안전 판단 위험과 남은 한계 명시.

## 데이터 후보 Gate G1B
우선 [iSafetyBench 조사 계획](../data/ISAFETYBENCH_AUDIT_PLAN.md)대로 다음을 확인한다.
- 실제 다운로드 가능한 영상 및 라이선스(원본 YouTube 영상 권리 별도)
- 공식 라벨·caption·gt_actions 등의 실제 컬럼/관계; 추정 금지
- 복수 행동 영상에서 사건 설명에 필요한 시각적 근거가 있는지
- 객체 박스·시작/종료 라벨이 있는지; 없다면 추가 라벨링 범위
- 같은 원본 영상에서 추출된 클립 중복과 평가 누수 가능성
- 모델 입력에 정답 caption/gt_actions를 포함시키지 않는 평가 설계

**iSafetyBench 자체를 최종 메인 데이터셋으로 채택한 것은 아니다.**

## 재검토 조건
다운로드/라이선스/영상-정답 매핑, 영상의 사고 맥락, 사람 근거 검수 가능성 중 하나라도 부적합하면 제품 기능 또는 데이터셋을 조정한다. 새 결정을 내리면 별도 ADR로 기록하고 이 문서를 삭제하지 않는다.
