# ADR-0006 — 제한된 CV baseline 프로토타입 구현 착수

- 날짜: 2026-10-27
- 상태: **사용자가 소규모 구현·진단 실험 착수를 승인**. 메인 데이터 G1E 최종 승인, 모델 채택, 정량 성능 검증은 아직 아님.
- 선행 결정: [ADR-0004](ADR-0004-boundary-crossing-cctv-mvp.md), [ADR-0005](ADR-0005-minimal-boundary-baseline-design.md)
- 구현 계약: [CV_BASELINE](../design/CV_BASELINE.md), [평가 구성안](../data/AIHUB_INTRUSION_EVALUATION_PLAN.md), [사용자 검수](../data/AIHUB_INTRUSION_USER_REVIEW.md)

## 지금 실험을 시작하는 이유
로컬 AI-Hub CCTV 영상 10개와 실제 JSON의 일부 이벤트 구간을 검증했고, 사용자가 처음 등장·단순 접근·울타리 접촉·넘기 시작·관측 중단을 구별해 검수했다. 추가 문서화만 반복하기보다 **사전학습 사람 검출 → 최소 시간적 연결 → 지정된 가상 경계의 양측 이동**을 작은 표본에 실제 적용해, 탐지 실패·시간 지연·가림 문제를 확인할 단계다.

## 이번 승인 범위
- **실행 허용:** 로컬 WSL2/RTX 3080 환경 진단, 의존성/사전학습 가중치의 출처·라이선스 확인 및 필요한 최소 설치·다운로드, 재현 가능한 CLI 코드와 테스트, 로컬 CCTV 2~4개에 대한 짧은 smoke test 후 가능하면 제한된 전체 클립 진단, 최소 PTS 보존 추론 결과·원시 실패 사례·처리 시간 기록.
- **첫 입력 후보:** E01_006(평행 보행, 프레임 수 불일치), E01_007(006과 같은 카메라 후보), E01_030(문 넘기), E01_031(원거리 울타리·불완전 종료). 전부 이미 검토한 **development 데이터**다. 처음 보는 카메라에서의 일반화 성능이 아니다.
- **기술:** 사람 검출기 하나를 작고 재현 가능한 모델로 선정하고, 인접 프레임의 최소 IoU 일대일 연결부터 시작한다. ROI/선은 **카메라별 설정값**; 실제 사람이 울타리를 물리적으로 넘는지의 확정은 하지 않는다.
- **평가:** 우선 **진단 출력**이며, 공식/사용자 정답과 모델 입력을 철저히 분리한다. 사용자 검수된 PTS·비이벤트 범위·카메라 그룹·평가 허용오차가 확정되기 전에는 event F1·FP/hour를 최종 성능으로 표시하지 않는다.
- **수정 금지:** 공식 JSON 및 사용자 검수 원본은 수정하지 않는다. E01_006 원본 실제 4,006프레임 대 JSON 4,011프레임의 차이를 PTS 기반으로 보존하고 임의 보간/프레임 인덱스 치환 금지.

## 보류
- 파인튜닝/재학습/데이터셋 전체 수집, VLM/포즈·복잡한 tracker, 웹 대시보드/API, 24시간 다중 CCTV 관제, 공개 미디어 배포, 모델 성능·무단침입 판정 주장.
- 새로운 의존성·모델은 라이선스, 크기, 적합성, GPU 실행 가능성 확인 후 최소한으로 도입한다. 권리/다운로드 문제가 생기면 우회하지 않고 범위 내 대안 또는 중단 사유를 기록한다.

## 성공 기준 및 재검토
성공은 높은 정확도가 아니라 **같은 환경에서 다시 실행 가능한 파이프라인**과 관찰 가능한 누락/오탐 사례, 영상 PTS의 정확한 보존, 자원 사용량 측정, 재현 명령·코드 SHA와 제한점을 남기는 것이다. 이 결과를 보고 다음 단계(검출/연결/경계/행동 분석 보강)의 필요성을 결정한다.
