# ADR-0002 — 패널 상태 분류를 메인 MVP에서 제외하고 데이터 범위 재검토

- 결정일: 2026-10-26
- 상태: **채택(패널 중심 MVP 제외)** / **조사 예정(iSafetyBench 검증)**
- 관련 근거: [Safe and Unsafe Behaviours 감사](../data/SAMPLE_AUDIT.md), [ADR-0001](ADR-0001-research-first.md), 사용자 이미지 비교 검수
- 새 데이터/모델/아키텍처: **확정하지 않음**

## 기존 문제와 근거
노타 AI Software Engineer 지원을 염두에 둔 SceneGuard는 단순 시각 상태 분류가 아닌, 산업현장 영상에서 **행동·사건의 맥락을 분석하고 판단 근거를 사람이 검토할 수 있게 하는 소프트웨어**를 목표로 한다.

Safe and Unsafe Behaviours 데이터의 초기 8개 영상은 실제 다운로드·디코딩·라벨 매핑을 검증했다. 감사 결과 패널 4개가 열린/닫힌 상태를 시각적으로 구별할 수 있었다. 사용자는 화면의 앞쪽 프레스 기계 흰색 전기함 **왼쪽 문이 닫힌 이미지와 열린 이미지**를 비교 확인했다. 그러나 이는 *문이 열리는 행동*이나 *개방 후 방치 이벤트의 시작/지속 시간*을 검증하는 자료는 아니다.

원 배포는 영상 단위 행동 클래스 정답을 제공하고, 객체 박스·추적 ID·사건 시작/종료 라벨은 제공하지 않았다. 두 대의 카메라/유사 설비가 반복되어 일반화·평가 누수 우려도 있다.

## 고려한 선택
| 대안 | 장점 | 제한 |
| --- | --- | --- |
| A. 패널 열림/닫힘 상태 분류를 메인 MVP로 확정 | 작은 범위로 정량 평가 용이 | 시간적 행동·복합 사건 이해·모델 선택의 필요성 설명이 약할 수 있음 |
| B. 통로 이탈 등 동일 데이터의 다른 행동으로 전환 | 고정형 CCTV, 위치·경로 추적 검토 가능 | 경계·대상 작업자·예외 구역이 불명확하고 추가 주석 필요 |
| C. 사고 영상 이해·검토 지원을 위해 새 데이터셋 조사 | 복합 행동·위험/정상 맥락·근거 설명과 VLM 평가 가능성 | 짧은 클립/상황 편향, 라이선스, 평가 정답, 실시간성 등 검증 필요 |

## 결정
- **A는 SceneGuard의 메인 MVP에서 제외한다.** 이는 실험 실패나 패널 상태 인식의 무가치함 때문이 아니라, 이번 포트폴리오가 보여주려는 문제해결 범위와 기술적 목표에 대한 부적합 판단이다.
- 기존 8개 영상과 코드, 감사 문서, Conditional Go 기록은 **삭제하지 않는다**. 당시 감사 판정은 데이터 접근성과 패널 상태 관찰 가능성에 대한 것이므로 유효하다.
- B는 보류하고, **C의 실현 가능성을 조사한다.**
- **iSafetyBench**(영상별 행동·상황 이해 벤치마크)를 다음 후보 데이터로 우선 검토하되, 라이선스·실제 영상 파일 접근·라벨 스키마·샘플 내용·동일 원본 중복 여부를 검증한 뒤 메인 데이터로 확정한다.
- 장래의 제품명·기능·모델(CV/시계열/VLM/추적/최적화)은 여전히 미확정.

## 다음 검증 질문
1. iSafetyBench에서 실제로 받을 수 있는 영상과 제공 어노테이션은 무엇인가? 공개/재배포 제약은?
2. 영상에서 분류 가능한 행동·사건은 무엇이고, 화면에 보이지 않는 권한·원인 추론은 무엇인가?
3. 사건별 다중 라벨·설명 정답으로 **검증 가능한 지표**와 불가능한 지표는?
4. 기존 연구에서 지적한 VLM 행동 이해 한계를 과장하지 않으면서 어떤 기술 선택/검증을 설계할 수 있는가?
5. 사고 후 분석·검토 기능이 실제 데이터에 적합한가? 실시간 선제 경보는 현재 목표와 분리해야 하는가?

## 결정 번복 조건
새 데이터가 접근 불가하거나 라벨 불충분/라이선스 부적합 또는 프레임 속 행동 해석이 신뢰하기 어려우면 다른 데이터·문제 혹은 기존 데이터의 통로 분석을 다시 검토한다.

> 이번 결정은 **프로젝트 범위 변경 결정**이지 특정 모델의 성능이 입증되었다는 주장이 아니다.
