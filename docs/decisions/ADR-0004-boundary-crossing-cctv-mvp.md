# ADR-0004 — CCTV 출입 경계 침범 감지로 1차 MVP 잠정 전환

- 결정일: 2026-10-27
- 상태: **MVP 문제 방향 잠정 채택 / 데이터 적합성·모델·실제 구현 미확정**
- 연계: [ADR-0001](ADR-0001-research-first.md), [ADR-0002](ADR-0002-reconsider-safety-dataset.md), [ADR-0003](ADR-0003-incident-review-product-direction.md)

## 배경
노타 AI의 영상 관제 솔루션과 가까운 기술 역량을 보여주기 위해, 짧게 편집된 사고 영상의 사후 해석보다 **녹화된 고정형 CCTV에서 사건 전후의 정상 구간과 특정 행동을 연속 분석**하는 문제를 우선 검토한다.

- Safe and Unsafe Behaviours: 산업 CCTV이지만 패널 상태 중심의 단순 문제가 한계.
- iSafetyBench: 복합 행동과 설명은 있으나 비CCTV 일반 촬영·편집 영상이 섞임.
- SteelBench: CCTV 주제는 적합하지만 공식 공개 접근 HTTP 401로 보류.
- ACCIDENT: 실제 교통 CCTV 5개와 공개 정답을 검증했지만 짧은 **사고 포함 클립** 중심. 정상 구간에 대한 실용적인 오탐 평가가 부족.
- **AI-Hub 71850 '지능형 관제 서비스 CCTV 영상 데이터'의 침입 범주:** 사용자가 전체 침입 영상의 장면 구성을 이미지로 검토했고, 학교 출입구·유사 철제 울타리 구도가 반복됨을 확인. 다수 출입구 간 각도 차이는 있으나 실질적인 설치 환경이 얼마나 독립적인지 **영상·메타데이터 검증 전**. 특수 사례는 **4번 줄 넘기**, **7번 공원처럼 보이는 장소의 울타리 넘기**로 구별한다. 둘을 '담벼락 넘기'로 합치지 않는다.

## 문제 정의
**목표:** 고정형 CCTV에서, 카메라별 지정된 출입 경계 근처의 **사람 이동·경계 넘기/통과 이벤트 후보**를 감지하고 영상 시점·근거를 제시하여 관제 담당자가 확인하도록 지원한다.

- **감지 가능한 사실**: 사람 접근, 지정 경계 전후 위치 변화, 넘기/통과 동작, 관찰 시점.
- **판단하지 않는 사실**: 법적 의미의 무단침입, 출입 권한, 사유지 여부. 경계선을 지난 것이 곧 위법·위험이라는 결론이 아님.
- **최초 대상**: 로컬의 녹화된 CCTV 클립. 실시간 스트리밍, 다중 카메라 24시간 운영, 범용 제로샷 침입 검지는 후속 검증.

## 왜 침입/경계 통과인가
1. 사용자가 확인한 AI-Hub 범주는 사고 순간만 편집한 자료보다 상대적으로 긴 **약 1~2분 클립**도 있어 정상 전후 구간의 경보 오탐, 시간 지연 검증을 설계할 가능성이 있다. 실제 전체 길이·정상 구간 유무는 영상 확보 후 확인한다.
2. 상용 침입/경계 통과 감지 자체가 새 기능은 아니다. 포트폴리오의 기술적 가치는 **단순 규칙 baseline, 새로운 CCTV 적용성, 모호한 행동 오탐, 처리 지연·비용**의 근거 있는 비교에 둔다.
3. **공통 모델 + 카메라별 영역/선 설정**을 먼저 비교 대상으로 삼는다. 카메라별 재학습은 꼭 필요하다는 증거가 있을 때만 검토한다.

## 핵심 위험
- 공개 소개상 침입 영상 약 **55개**로 비교적 적고, 유사한 출입구가 반복돼 **카메라/장소 누수**와 학습 데이터 부족 위험.
- 특수 사례(줄 넘기, 공원 울타리 넘기)는 사용자 확인상 각각 1개 수준이므로 독립 클래스 성능을 주장할 수 없음.
- 이벤트 정답이 제공되더라도 실제 대상 사람/경계의 의미, 시간 경계가 시각적으로 일치하는지 검수 필요.
- 실제 '정상/비이벤트' 구간이 충분한지, 비이벤트 구간이 별도로 라벨링되었는지 미확인. 이벤트 클립의 앞뒤를 자동으로 정상 gold로 처리하지 않음.
- 같은 장소/카메라를 학습과 평가에 섞어 새 카메라 일반화를 주장하지 않음.
- AI-Hub 다운로드 자격, 약관, 개인정보 및 공개 영상 사용권 미확인. 실제 미디어는 로컬 전용.

## 조건부 검증 계획
**Gate G1E** — AI-Hub 공식 파일 접근·데이터 유형·실제 길이·라벨 구조 확인 → 6~10개 이내 소량 샘플 다양성 감사(반복 출입구 + 줄 넘기 + 공원 울타리 등 접근 가능 범위) → 카메라/장소/사건별 분할과 비이벤트 평가 구간 정의.

**Gate G2** — 데이터에서 확인된 최소 문제를 대상으로 기존 CV 기반의 가장 단순한 기준 방법(예: 사람 탐지·추적 + 카메라별 ROI/가상 경계)을 연구·실험. **가상 선 통과는 울타리를 물리적으로 넘는 동작과 다를 수 있음**을 측정. VLM은 오류 유형과 비용·지연을 비교한 다음 실효성이 있으면 도입. 모델은 아직 미선정.

## 데이터 전환 기준
사용권·접근 불가, 지나친 카메라 중복, 유효한 이벤트/정상 정답 부족, 검증할 오탐 사례 부족이 확인되면 문제 범위·데이터 보완 여부를 재평가한다. 연구 기록은 보존하고 새 ADR로 변경을 남긴다.

**현 단계에서는 AI-Hub 데이터를 메인으로 확정하거나 모델이 침입을 감지한다고 주장하지 않는다.**
