# ADR-0027 — 경계 후보와 관측 지속의 위치를 침입 확인에 반영

2026-11-04. 사용자 승인: 기존 경계 통과 후보를 실제 관측으로 재검증해 확인하고, 반대편 관측이나 모호한 재연결이 소실 판단 전체를 막지 않도록 보완한 뒤 같은 저장 자료로45개를 비교한다. 새 모델/검출/추적/flow, 영역 및 정답 변경은 범위 밖이다.

기존 rc3는 `observed_side_transition`을 확인에 연결했으나 `existing_alerts`는 의심만 유지했다. 이 후보는 바닥 중앙점과 지연 방출 시각을 쓰므로 .65 높이 영역 규칙에 이름만 바꿔 넣을 수 없다. 실제 관측의 안정된 양쪽 부호, 유한 문 선분 교차, 방출 시각까지의 인과적 연속성을 별도로 재검증한다. 원래 후보 시각을 과거 교차 시각으로 되돌리지 않는다.

기존 특징점 관측 지속은 한 점의 부호 변화도 cross-side로 인정한다.017·019에는 이런 약한 근거가 실제로 존재하며,011·019의 마지막 같은 쪽 관측은 오히려 강하다. 문자열만 확인으로 올리거나 영역None을 사람 소실로 취급하지 않는다.

MVP에서만 다음 관측 판정을 선택한다. 과거 EXP 재생의 기본 동작과 원본 결과는 보존한다.

- 실제 박스/특징점의 유효한 유한 경계 통과는 확인에 사용할 수 있으며 소실을 기다리지 않는다.
- 특징점 경로는 원래 대상 실제 박스에 묶이고, 실제 후속 박스에서 충분한 같은 점이 관측되어야 한다. 한 점, 문 연장선, 원본 프레임 공백, 카메라 이동만의 부호 변화, 상충하는 방향은 확인 근거가 아니다.
- 출발 쪽에서 현재까지 확실히 관측되면 소실이 아니다. 여러 후보/상충 근거는 모호함으로 보존하며, 문 접근·마지막 방향·실제 대기 근거로 하는 사건 판단과 구분한다. 모호한 재연결로 의심을 자동 해제하지 않는다.
- 반대편의 기존 사람이나 단순 새 박스만으로 확인하지 않는다. 사람 신원 재연결은 필수 조건이 아니지만, 서로 다른 사람의 박스를 임의로 이어 통과를 만들어서는 안 된다.
- 한 관측 결과는 기존 최신 사건/근거 하나 소유권 규칙을 유지한다. 반복 적용으로 이전 사건이나 관련 없는 사람에게 확인을 전파하지 않는다.

출발 쪽 접근 후 되돌아감, ID만 바뀐 지속 관측, 문 연장선/미래 관측, 여러 사람의 박스, 카메라 흔들림, 반복 근거 소유권을 회귀 시험한다. 전체 비교는 rc3의32/52 확인을 기준으로 추가 성공·기존 성공 손실·정상 구간 오탐·미검수 예측을 함께 기록한다. 물건/차/가림의 시각적 인과나 사람별 성능을 이 규칙 시험만으로 주장하지 않는다.


## 독립 반례와 재검사 보완

첫 전체 시험 `5909df8` / run-002는 확인32/52→31/52(추가8건·손실9건)로 악화되어 그대로 채택하지 않는다. 배경 특징점만 다른 박스에 포함되어도 관측 지속으로 인정하는 합성 반례와, 원래 소실 후보를 보류한 뒤 다른 짧은 관측 조각으로만 재검사하는 근거 전달 문제를 확인했다. 실제 영상의 모든 누락을 배경점으로 설명하지 않는다.

보완에서 관측 지속/소실 시계 연장/후속 관측 연결은 원래 대상과 함께 이동한 점의 집합과 실제 박스의 연속성을 함께 요구한다. 이동 판단의1px·0.5초와 최소3점 등 기존 정책을 재사용하며, 정지 배경이나 카메라 이동만으로 같은 대상의 관측이 이어졌다고 하지 않는다. 이 검증이 부족하면 연결은 모호함으로 남긴다. 다만 원래 대상이 정지해 있다가 실제로 경계를 통과하는 경우를 막지 않도록, 충분한 유한 경계 통과의 양성 근거는 별도로 검증한다.

잠시 보류된 원래 소실 후보는 해당 사건과 원래 실제 관측 문맥을 보존하여 재검사한다. 마지막 신뢰 가능한 실제 관측에서 대기를 세고 그 시점의 방향을 다시 계산한다. 같은 실제 소실은 원래 후보 경로와 후속 관측 경로가 각각 중복 확인하거나 과거 사건으로 전파하지 못하도록 기존 사건 소유권 검증을 통과해야 한다. 원래 후보의 방향 문맥을 다른 사람의 짧은 관측 조각으로 대체하지 않는다. 경계 시각/프레임/박스는 실제 연결 근거와 대조한다.

수정 후 동일한45개 저장 자료를 다시 비교한다. 실패한 시험 결과와 정답 구간은 보존하며, 개선을 보장하기 위해 정답 구간을 늘리거나 특정 영상에 맞춰 임계값을 낮추지 않는다.


## 최종 적용 — 검증된 경계 후보 확인만 기본 경로에 추가

동일45개 저장 측정값 비교에서 기존 rc3 관측·소실 규칙에 경계 후보 확인만 추가한 안은39/52, 기존 정답 매칭 손실0건이었다. 전체 관측 보완안은40/52지만009·033의 기존 사건을 놓쳤고, 이른 최초 확인이 선택안8건보다 많은16건이며 실제 확인 지연도 있었다. 전체 보완안의 중복 FP0건·미검수 예측8건은 선택안1건·9건보다 적다는 유리한 결과도 기록한다.

기본 `RuleBackend`는 `SavedGateDirection`과 기존 scoped 소실 경로를 유지하고, 검증된 `existing_alert_gate_crossing_v1`을 추가하는 안을 채택한다. 관측 보완 구현과 시험은 재현 가능한 연구 코드로 남기고 기본 경로에서 활성화하지 않는다. 두 방식의 원본·정답·평가기는 같으며 후보 문자열만으로 확인하지 않는다. 선택안의 새 이른 최초 확인5건과 남은13개 공식 사건 누락은 후속 검수 대상으로 남긴다. 이 선택은 현재 개발 자료에서 기존 사건 유지·알림 시각·새 검출의 균형에 따른 것이며 독립 일반화 성능 보장은 아니다.
