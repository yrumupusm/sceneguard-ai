# ADR-0005 — 사용자 검수 분리와 최소 경계 통과 baseline 설계

- 날짜: 2026-10-27. 상태: **설계 제안**, 모델/구현 채택 미확정, 미실험.
- 사용자 요청: 공식 라벨을 유지하면서 사용자 검수·평가 구성·가장 단순한 CV baseline을 설계. [ADR-0004](ADR-0004-boundary-crossing-cctv-mvp.md)의 후속이며 기존 결정을 삭제하지 않는다.

## 근거와 제약

[로컬/사용자 검수](../data/AIHUB_INTRUSION_USER_REVIEW.md): 등장과 넘기 시작은 다르고, 031은 접촉 후 일부 사람의 넘기가 영상 종료까지 미완료다. 006은 경계 가까이 보행하는 음성 후보이며 JSON/영상 프레임 수가 다르다. 같은 카메라 후보가 반복되고 정상 검수 시간이 부족하다. RTX 3080 사용 환경의 실제 모델 속도/VRAM은 미측정이다.

연구 근거: [Bewley et al., SORT](https://arxiv.org/abs/1602.00763)는 검출과 간단한 데이터 연결/상태 추정으로 온라인 추적을 구성하고 검출 품질의 영향을 강조한다. 이는 최소 연결부터 실험하는 설계의 참고이며, 우리 가림·울타리 동작에서의 성능 보증이나 SORT 채택 결정은 아니다. 논문 속도 수치를 본 프로젝트 성능으로 옮기지 않는다.

## 비교 대안

| 대안 | 장점 | 현재 제약/결정 |
| --- | --- | --- |
| ROI 안 사람 존재 | 가장 단순 | 평행 보행·대기·접촉을 통과와 구분 못함. 진단 비교용 |
| **고정 검출기 + 최소 IoU 연결 + 경계 양측 변화** | 입력/출력/실패 원인을 분리하고 학습 없이 시작 가능 | ID 전환·가림·bbox 발점 오차. 첫 baseline 설계 후보 |
| SORT 등 상태 추정 추적 보강 | 짧은 연결 단절 대응 후보 | 추가 설정·의존성·권리 검토 필요. 최소 연결 실패 근거 후 비교 |
| 행동 모델/포즈/VLM | 접촉·시도·완료 구분 가능성 | 정밀 라벨·비용·검증 부담. 필요성 미입증으로 보류 |

## 제안과 뒤집을 조건

공식 원문/사용자 검수/평가 manifest를 분리하고 [평가 계획](../data/AIHUB_INTRUSION_EVALUATION_PLAN.md)과 [입출력·지표 계약](../design/CV_BASELINE.md)을 먼저 고정한다. 모델은 특정하지 않는다. 미검수 구간·미완료 주체·불확실 카메라를 억지 정답/독립 테스트로 만들지 않는다.

006 같은 평행 보행의 오탐, 031의 완료 오판, 가림에서 ID 전환이 주원인인지 분해해 측정할 계획이다. 연결 문제가 주원인이면 tracker 보강, 선/발점 표현이 주원인이면 경계 표현 변경, 물리적 넘기 의미가 필수인데 통과 후보가 이를 설명하지 못하면 행동 정의·모델 대안을 다시 검토한다. 데이터 독립성·검수 시간이 부족하면 모델 복잡도를 늘리기 전에 평가 범위를 축소/보완한다.

**이번에는 설계 문서와 데이터 검수 코드만 작성했다. 모델 구현·추론·학습 결과 없음.**
