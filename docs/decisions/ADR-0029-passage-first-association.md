# ADR-0029 — 실제 통과를 우선하는 박스 연결

2026-11-04. 사용자가 “보수적으로 잡으면 안돼”라고 지시했다. EXP-0050의 일괄 연결 거절은 실제 저장 측정값 비교에서 확인39/52를0/52로 만들었다. 이 실패와 사용자 지시에 따라 ADR-0028의 영구 계보 거절 정책을 대체한다. 기존 실험 기록은 수정하지 않는다.

## 선택

박스 연결의 유일성이나 사람 신원 확인을 출입구 통과 확인의 필수 조건으로 요구하지 않는다. 실제 출발·문 구간·반대편 이동 근거를 우선 사용한다. 복수 인접 박스는 진단 정보이며, 이후 경로 전체를 계속 차단하는 사유로 사용하지 않는다.

끊긴 관측은 기존 저장 이동점과 실제 박스의 지지를 이용한다. 지지되는 대안이 여러 개면 구현 문서에 고정한 순위로 한 경로를 선택하고 대안·신원 미확인을 남긴다. 없는 좌표나 미래 근거를 만들지 않는다. 선택 오류 가능성을 검출 누락만으로 숨기지 않고 알림 시각·미검수 알림·기존 사건 손실을 함께 측정한다.

새 실제 통과 근거를 관계없는 오래된 후보에 붙이지 않는다. 현재 관측 구간의 후보가 없더라도 충분한 실제 통과가 관측되면 그 근거의 새 후보를 만들 수 있다. 원래 후보와 파생 후보의 출처를 구분하고 같은 통과를 반복 소비하지 않는다. 이 원칙은 실제 새45개 결과를 보기 전에 정했다.

## 대안과 한계

기존 영구 거절 유지안은 사용자가 거부했고 실제 확인을 모두 잃었으므로 선택하지 않는다. 모든 박스를 조건 없이 연결하는 안은 관측하지 않은 경로를 만들 수 있어 선택하지 않는다. 대상 연결 모델을 새로 실행하는 안은 이번 저장 측정값 규칙 비교 범위를 벗어난다.

새 안쪽 경계 초안·양방향 통과·출발 이력·소실 위치/방향 조건과 기존 수치 기준을 유지한다. 영상별 정답 시각에 맞춘 기준 탐색은 하지 않는다. 두 경계/연결/후보 생성 효과를 각각 분리한 실험은 아니며 신원 정확도나 가려진 발 복원 성능은 미측정이다.

## 확인할 근거

EXP-0051에서 고정 소스의 전체45개 저장 측정값을 재생하고 원래 기준39/52 확인·51/52 의심·이른 확인8건과 비교한다. 실패한 EXP-0050의0/52는 별도 보존한다. 안→밖 우선9영상·010 사용자 약63초 관찰·006 미확정·008 보류를 구분한다. 결과/회귀를 함께 보고 운영 채택 여부를 판단하며 시험 통과만으로 채택하지 않는다.
