# ADR-0023 — C6 고정 ROI의 YOLO26m-Pose 640→960 비교

2026-10-29. 상태: CPU 준비·독립 검토 대기, GPU 미실행. [BATCH-0006 승인 계획](../experiments/BATCH-0006-c6-pose-960-resolution-plan.md)의 EXP-0025 세 프레임 한정이다.

EXP-0024 사용자 검수에서 기존 640 C6의 84초는 세 사람과 관절이 대체로 양호했지만 90초는 오른쪽 한 행의 관절도 어긋났고 다른 두 명은 누락됐으며 94초의 보이는 두 명도 누락됐다. 이 관찰을 정밀 GT로 바꾸지 않는다. 같은 사전학습 모델·환경·고정 ROI에서 입력 해상도만 높였을 때 누락과 관절 대응이 달라지는지 진단한다. 960 입력에는 보간 확대가 포함되므로 새 영상 정보가 생긴다는 주장은 하지 않는다.

기존 공식 22개 public kwargs를 deepcopy하고 `imgsz` 한 개만 960으로 변경한다. 나머지 21개·FP32·공식 Ultralytics 8.4.192·체크포인트·RGB/BGR 변환은 보존한다. batch04/batch05 소스를 수정하지 않고 crop/좌표 해석을 읽기 전용 재사용한다. 기존 관측기의 640 tensor assertion만 새 batch06 관측기에서 960으로 바꾸며 알고리즘은 대체하지 않는다. 실제 CUDA0 FP32 1×3×960×960 입력을 저장·해시 검증한다.

지정된 EXP-0023 summary와 세 C6 native Results·input·official event artifact SHA를 검증해 640을 재추론 없이 재사용한다. 새 예측은 90→84→94초 각각 1회, 모델 생성 1회와 첫 공식 warmup을 별도 계수한다. 정상 empty도 결과이며 나머지 지정 프레임은 계속 처리한다. 기술 예외는 중단하고 성공한 부분을 재생성하지 않는다. 자동 retry는 차단하며 최대 한 번의 correction도 CPU 회귀·독립 검토·새 freeze·명시 승인 없이는 실행하지 않는다.

CPU의 exact PTS/RGB/crop/hash·공식 API/config/signature·960 전처리·unknown/empty/NaN·다중 행·offset 1회·lease/6144MiB·queue migration 보존 검사를 먼저 통과해야 한다. 총괄의 source commit·독립 사전 PASS·정확한 입력/source authorization 이후에만 기존 canonical queue에서 실행한다. 새 환경·가중치·모델·학습·외부 API·ROI/threshold 변경은 없다.

출력은 로컬 original/640 cached/960 new 세 시점 triptych이며 모든 행의 box/score/관절을 그린다. 출력 행 수·retained 관절 수가 늘어도 실제 손목/무릎/발목·몸 대응 개선을 확정하지 않는다. 960 실제 품질은 사용자 검수 전 unknown이다. 행동 성능·F1/FPR·완료/법적 판단·추적·규칙·전체 영상 처리는 미측정/미실행이며 기본 적용을 보류한다.

AGPL-3.0-only와 ADR-0020/0021의 공식 upstream 출처·조건을 유지한다. raw manifest·source/RGB/native Results/좌표/tensor/미디어/weights/runtime은 로컬만, 공개 manifest는 최소 hash pin만 둔다. 공개 집계와 비용은 CPU builder가 frozen inference source 밖에서 생성하며 이전 cached 비용과 새 비용의 범위를 분리하고 FPS를 주장하지 않는다. 기존 웹·원격 bytes 검증은 총괄이 별도 수행하며 이번 세 예측 종료 후 자동 후속 실험은 없다.
