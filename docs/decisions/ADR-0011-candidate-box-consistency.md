# ADR-0011 — 기존 후보 뒤의 박스 일관성 검토 (실행 전 고정)

2026-10-28. 사용자 승인 개발 비교. 기존 C의 검출·추적·경계 후보는 변경하지 않고 별도 상태를 붙인다. 기본 적용은 하지 않는다. 근거는 EXP-0005 집중 검수의 박스 범위 변화이며, 신체 부위 인식/발 추정이 아니다.

## 한 세트의 조건

- 후보 emission 이전 0.2초부터 emission 이후 0.2초까지 같은 ID의 confirmed 실제 bbox만 사용한다. 첫 관측은 창 시작 시각 이하의 가장 최근 프레임(최대 .1초 이내)으로 잡아 과거 범위를 확보한다. 미래 대기는 정확히 .2초 이상 도달한 첫 원본 PTS에서 종료한다. 프레임 양자화만큼 지연이 더해질 수 있다.
- 창 안 모든 관측 쌍 중 시간 간격 ≤.2초인 쌍을 검사한다. 인접 프레임만 보면 점진적 축소를 놓치므로 짧은 누적 변화도 본다.
- 높이/너비의 배율 H=max(h1,h2)/min(h1,h2), W=max(w1,w2)/min(w1,w2). 상단 이동 T=(top2-top1)/min(h1,h2), 하단 이동 D=(bottom2-bottom1)/min(h1,h2). 원본 정규화 좌표를 사용해 동일 축에서 나눈다.
- 이상 = **(H≥1.5 AND |D−T|≥.3) OR W≥1.5**. 50% 크기 변화는 작은 흔들림보다 큰 변화만 찾으려는 설명 가능한 개발 기준이다. .3은 상하단의 비동일 이동을 명시하는 조건이며 H≥1.5에서는 수학적으로 중복될 수 있다. 독립적인 신체 의미 증거라고 주장하지 않는다. 상하단이 같은 만큼 움직이는 안정적 평행 이동은 이상 아님. 폭만 급변해도 범위 불안정으로 본다.
- .2초 창·대기는 약 6프레임의 국소 변화를 비교하려는 개발 선택이며 최적값 아님. 기존 두 사례를 이미 보았으므로 독립 검증이나 맹검 사전등록이 아니다. 실행 결과를 보고 기준을 바꾸지 않는다. 영상/시각/ID 예외 없음.
- 창 내 원본 프레임에 해당 ID 관측이 하나라도 없거나 PTS 간격>.1초, 과거 범위 미확보, 결정 기한 전 EOF이면 **근거 부족**이 우선한다. 이상이 이미 있어도 수치/증거를 함께 보존한다. 예측으로 채우지 않는다.
- 충분한 관측이고 이상이면 판단 유보, 없으면 검사 통과. 처음은 검토 대기. 통과≠침입 확정, 유보≠정상. 원래 후보 전체와 상태 전이를 보존한다.
- 판단 시각, 실제 사용 마지막 관측, emission 대비 대기, 관측 누락 시각, 이상 관측 쌍을 별도 기록. .2초 뒤 발견을 emission 시점 차단으로 소급 표현하지 않는다. EOF는 도착한 마지막 PTS에서 근거 부족으로 종료하며 대기 미충족 표시.

## 한계와 채택 조건

안정적 부분 신체 박스·잘못된 ID 연결은 통과할 수 있고 실제 넘기/원근 크기 변화도 유보할 수 있다. 두 후보가 모두/전부 막혀도 오탐 해결 아님. 006/031 후보 0은 개선 아님. 이 검토를 알림 앞에 두면 최소 .2초 전달 지연이 생긴다. 기본 교체 전 의미 검수와 유용한 후보의 과도 유보·누락 비용 확인 필요. 새 모델/추적/포즈/VLM/학습 없음.
