# 선행연구 기록

문헌에서 보고된 사실과 SceneGuard의 추론·직접 실험을 **명확히 구별**한다.

- [R-001 산업안전 영상 분석 사례와 초기 가설](0001-literature-and-initial-hypotheses.md): Unsafe-Net, iSafetyBench, 도메인 맞춤 VLM, CV+VLM, LAVAD 등.
- [R-002 iSafetyBench 상세 검토](0002-isafetybench-review.md): VLM 안전 행동 벤치마크의 평가 방식, 수치 해석 한계, 실패 유형.

새 연구를 추가할 때는 서지·원문 URL·해결 문제·데이터·모델·지표 정의·정확한 보고 결과·한계·우리 프로젝트에 대한 해석을 구분한다.

**선행연구만 무기한 확장하지 않는다.** 실제 데이터 감사와 기술 선택에 필요한 범위로 제한한다.
