총괄은 실제 생성 과정에서 원본 SHA·72개 RGB/PTS와 비교영상 프레임 수를 확인했다. 저장 초안 재대조에서 대상 외164개 박스의 좌표를 그대로 유지하고, 지목한15개 중복/부분 박스만 새5개 좌표안으로 바꿨으며, 지정 배경 위치17개만 제거했음을 확인했다. 입력196−제거17−교체15＋신규5=169다.169개를 사람 수나 정답 수로 해석하지 않는다. 수정 집합은18프레임이며 전체 보류1프레임의 원래 후보도 그대로다.

별도 담당의 [수정 감사](EXP-0073-repair-audit.md)는 실제 저장 바이트·숫자·분할·답변 출처를 재검산했다. 현재 웹 답변과 연결 자료, 원본 압축 packet의 native PTS, 기존197프레임의394 이미지/라벨 파일 해시와 보호 분할을 확인했다. 담당은 픽셀을 디코딩하거나 사람/박스 적절성을 시각 인증하지 않았다. 좌표안이 실제 몸을 감싸는지는 새 두 질문의 사용자 확인 대상이다.

R01의 actor/origin1은 정답이 아닌 좌표 제안 참고이며 R02의 같은 사람 관찰을 정확한 새 경계 승인으로 확대하지 않는다. R03 제거는 사용자가 지목한 고정 배경 위치와 기존24프레임 안의 후보에 한정하고 운영 ROI/NMS/점수 규칙을 바꾸지 않는다. 오른쪽 작은 후보가 불확실한23.333초는 프레임 전체를 보류해 미주석 사람을 음성으로 학습하는 것을 막았다.

생성기 단독에는 현재 웹 바인딩/변경된 의미 답변을 다시 검증하는 게이트가 없다. 이번 실제 입력은 총괄의 생성 전후 비교와 별도 감사에서 현재 바인딩까지 일치했으며, 향후 재현에는 같은 사전 확인이 필요하다는 제한을 보고서에 명시했다. 입력이 바뀐 상태에서 같은 수정 규칙을 자동 적용하도록 승인하지 않는다.
