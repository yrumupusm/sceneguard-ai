## 검토 실행 실패와 범위 완료

독립 출력 감사의 첫 실행은 baseline의 `automatic_confirmation=false`까지 불변으로 과도하게 요구해 assertion으로 실패했다. 승인된 자동 overlay만 제외하도록 검토 스크립트를 한 번 수정하고 재시도1회로 통과했다. 최초 실패 `review-output-audit.log`와 성공 `review-output-audit-retry1.log`를 모두 보존했다. 실제 판정 실패나 구현 결함이 아니며 구현/정책/실험을 재실행하지 않았다. 파일 탐색 중 아직 없는 출력 디렉터리를 지정한 조회 오류도 결과 성공으로 꾸미지 않는다.

미디어 원본/native/presentation PTS 매핑과 최종 보고서·공개 지표의 정확한 SHA256 결속까지 완료했다. 로컬근거는 `review-preflight.py/.log`, `review-exp45-integration.log`, `review-output-audit.py/.json`과실패/재시도로그, `review-birth-sites.py/.json`, `review-actual-adapter.json`, 웹시험로그, `review-media-tests.log`, `review-media-audit.py/.json`, `review-final-binding.json`이다. 이파일들은 `runtime/EXP-0045/`에만 보관하며 공개하지 않는다. 구현/수치비교수용과행동성능입증,운영채택,실제브라우저/원격전달완료는별도판정이다.
