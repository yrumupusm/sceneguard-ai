# EXP-0035 독립 검토

상태: **규칙·실제 CPU 출력·보존 수치 및 최종 보고서·지표 감사 완료 / 비교 기록 수용 / 기본 적용 보류**.

검토 범위는 승인된 조건과 구현의 대응, 저장된 관측·이벤트·시간·집계 및 보존이다. 독립 검토자는 CCTV를 시각 검수하지 않았고 새 사람 정체·침입 정답을 만들지 않았다. 기존 사용자 정상 구간 관찰, 이전 총괄 시각 초안, 새 렌더링 자료와 현재 의미 미확정을 구분한다. 신규 추론·실험 재실행·설치·영역/임계값 변경은 하지 않았다.

`docs/CODEX_EXP0035.md`와 새 모듈 및 30개 테스트를 대조했다. 마지막 실제 관측 직전 3초의 관측 박스 높이 중앙값에 기존 0.8배/최소 12px를 적용하고, 유한선 근처 **또는** 기존 가림 주석 겹침인 실제 관측이 2개 이상이면 기존 1초 소실 대기를 확인한다. 출발 영역·방향·±90°·재등장·VLM은 필수조건이 아니다. 같은 쪽 실제 이탈은 마지막 공간 근거 이후에 관측된 경우만 해당 소실의 제외 근거가 되며, 이전 경보를 삭제하지 않는다. 종료 전 1초를 관측할 수 없는 경우와 최근 공간 근거 부족은 제외한다. 새 24개 규칙 테스트와 6개 관측 결속 테스트의 실행 로그가 통과했으며, 이를 실제 행동 성능으로 해석하지 않는다.

저장된 JSON을 읽는 별도 수치 감사에서 28개 소실의 박스/주석 교차와 유한선 거리를 독립 계산해 모든 근거 목록·개수와 일치함을 확인했다. 007의 1,710프레임/3,471관측행, 030의 480프레임/700관측행은 기존 실제 confirmed 관측과 완전히 대응한다. 예측이 포함되지 않았으며 기존 segments·pairs·원래 gap 경보·입력 해시/경로·정책 및 기존 events가 정확히 보존됐다. 새 후보 14행은 모두 마지막 관측 후 1초를 충족하는 첫 실제 프레임에 위치하며 그 대기 중 같은 raw ID의 실제 관측은 없다. `decision_time_pts`는 논리적인 판단 가능 시각이고 `available_after_pts`는 전체 분석 구간 끝이다. 실시간 성능을 측정한 결과가 아니다.

007 raw8은 마지막 관측 71.6초→판단 72.6초, 근거 86행이고 raw13은 71.433333초→72.433333초, 근거 12행이다. 이전 `판단 불가`가 새 `침입 의심`으로 바뀐 것은 확인했지만 실제 사람의 월장·정체 연결 성공을 독립 인증한 것은 아니다. raw13의 출발 영역/신뢰 가능한 방향이 없고 raw8의 경계 쪽 이동 보조값이 false여도 의심이 추가되어 새 필수조건에 과거 veto가 재도입되지 않았다.

사용자가 정상 접근으로 확인한 007 52.5–57.5초에서 끝난 관측에 대응하는 오탐은 raw1 55.0→56.0초, raw5 56.766667→57.766667초, raw2 56.8→57.8초의 **3행**이다. 뒤의 2행은 57.5초 밖의 소실 대기 꼬리에 있고 제외하면 안 된다. 정상 3명이나 독립 정상 사건 3건의 검증은 아니다. raw9의 서로 다른 두 segment에서도 59.666667/62.5초에 각각 새 알림이 발생해 raw ID만으로 사람 수나 독립 사건 수를 산출할 수 없다.

030은 기존 raw3/segment s0003의 91.9초 양측 관측 의심이 그대로 남고 같은 segment의 93.4초 소실 의심이 추가됐다. 이 두 행은 같은 segment에 대한 중복 알림이라는 수치 사실이며, 다른 raw ID 사이의 정체·사건 중복 범위는 미확정이다. 030의 최종 6행을 사람 6명 또는 탐지 성공 6건으로 세지 않는다. 모든 새 행은 `confirmed_intrusion=false`, `identity_verified=false`이고 `침입 확인` 자동 출력은 없다.

보호 목록 **1,358파일**의 현재 SHA-256이 실행 전 목록과 같고 canonical queue의 **47 jobs/47 attempts 모든 행**이 실행 전 스냅샷과 정확히 같다. GPU 신규 작업·검출/추적/VLM 추론·학습·다운로드가 없는 CPU 적용 범위와 일치한다. 로컬 수치 증거는 `runtime/EXP-0035/independent-audit.json`, 읽기 전용 검증 스크립트는 `runtime/EXP-0035/independent_audit.py`에 있다.

전체 저장소 회귀의 최초 `.venv` 실행은 통과로 보고할 수 없다. cv2/transformers/yaml/ultralytics/fastapi가 없는 환경의 import 오류 및 과거 queue 복사본을 44행으로 고정한 테스트의 실제 46행 불일치가 기록되어 있다. 이후 기존 분리 환경에서 data 34개/MVP 167개/VLM 8개가 통과했고 관련 CPU 회귀는 기존 77개+신규 30개=107개가 통과했다. 다른 전체 검사에는 lap/scipy/fastapi 누락 및 과거 43/44행 고정 이력 테스트와 실제 46행의 불일치가 남았다. 실행 receipt와 로그를 읽어 최종 보고서의 전체 회귀 미완료 서술이 맞음을 확인했다. 검토자가 테스트나 실험을 다시 실행한 것은 아니다.

최종 보고서는 후보 증가와 정상 오탐 증가, 같은 segment 중복, 실제 정체/행동 미확정 및 회귀 실패를 함께 명시한다. 검토 중 030 s0004의 설명에서 과거 사용자의 박스 번호를 현재 raw ID 정답으로 바꿔 서술한 부분을 지적했고, 총괄이 박스 중복·ID 단절이라는 사용자 관찰과 현재 raw ID 대응 미확정을 분리했다. 수정 뒤의 정확한 바이트에만 아래 결속을 적용한다.

공개 metrics 13행의 source SHA-256과 JSON pointer 값을 모두 대조했고 정상 007 오탐 3행·raw8/13 새 segment 2개·030 동일 segment 추가 알림 1행을 출력에서 다시 집계했다. `orchestration.complete.public` 및 `metrics(..., 'EXP-0035')` 형식 검사가 통과했다. 총괄의 등록 package와 preflight가 동일 보고서/metrics 해시를 참조하는 것을 확인했다. 원본/관측/상태 렌더와 이전/새 결과 비교 영상은 두 영상 모두 실제 receipt가 있으며, 결과·입력 영상·완성 영상 해시와 1,710/480프레임 결속을 확인했다. 표시용 추가 모듈의 native frame map/PTS 대조와 판단 시각 이후 상태 표시를 읽었으며 영상 의미·실제 브라우저 재생을 독립 인증한 것은 아니다.
