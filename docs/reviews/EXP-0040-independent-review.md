## 코드·시간·원본 보존 계약

3초 내 실제 관측의 자동 seed 후보·영상 특징과 박스 안정성 순위·최대3개 선택, 겹침 영역의 보조 특징 사용, 전후방 LK 점별 탈락, 영구 point ID를 확인했다. 정지·부분 신체·겹침에 일괄 veto를 추가하지 않았고 기본0.70 및 가중치는 유지했다. 경로 사이 충돌은 해당 기준에 도달한 seed끼리 판단한다. 기준 미달의 약한 seed를 새 차단 조건으로 삼지 않는다.

실제0079건·0305건 모두를 감사했다. 35개 seed의2822개 경로 프레임 기록에서 원본 native PTS/time base, 증가하는 frame index/PTS, 점 좌표와 ID 길이, 탈락 ID의 재등장 부재, 원래 decision PTS 종료를 확인했다. 이2822는 겹치는 seed 경로의 기록 수이며 고유 원본 프레임 수가 아니다. 시작점과 관측 이력은 각 소실 판단 이전에 있다. 영상 끝의 미래 재등장이나 표시용 후기0.5초는 점수 입력에 들어가지 않는다.

EXP-0036 원본 bundle의 events/cards/counts/timeline은 재구성과 일치하고 새 baseline 파일도 원본과 같다. 정규화한18행을 한 번 분할하며 event ID·source pointer·판단PTS·원래 payload를 다시 만들거나 바꾸지 않는다. 활성17행과 검토 전용1행의 합집합은 원본18행과 정확히 같고 중복·누락이 없다. 기존 gap3건과 양측 관측1건은 보존됐다. 다른 대상의 알림이나 이미 존재하는 별도 경계 근거를 한 사람의 영상 연속성으로 취소하지 않는다.

원래 카드별 event ID 교집합으로 모든 카드 변화를 대조했고, 재생 snapshot이 미래 행을 미리 포함하지 않음을 확인했다. 기존 판단PTS 보존은 실시간 처리 지연 보장이 아니다. `available_after_pts`는 전체 저장 분석창의 기존 메타로 남으며 실제007/030 실행 walltime10.552859/8.019368초와도 구분해야 한다.

## 시험·공개 수치·보존

공개31지표 중30개 수치는 source SHA256과 JSON 경로의 값이 정확히 같다. 남은 정확도1개는 null로 유지된다. 원본 전체 알림10/8행, 소실 후보9/5건, 개별 점수1건의 표본 단위를 구분했다. 시간 측정은 실행함수 walltime이며 렌더 시간·실시간 경보 지연·전체 영상 추론FPS가 아니다.

독립적으로 보호16937파일 약7.7GB를 재해시해 변경0을 확인했다. 기존 canonical queue50jobs/50attempts, 검토2행/이력5행, 통지 영수증10행은 실행 전 동결과 모든 행이 같다. 별도 read-only DB 논리 해시도 같고 무결성 검사는 정상이다. 기존 사용자 영역·원본·이전 실험을 덮어쓰지 않았다.

최소 웹 adapter는 원본/활성/검토 전용의 완전한 payload 분할과 hash를 검사하고 EXP0040의 실제 통지 claim을 막는다. 기존 EXP0037 등록 기본 경로와 기존 시간 snapshot·검토 저장을 재사용한다. 검토자의 기본 `.venv` 웹 시험은 FastAPI 부재로 실행되지 않았으며 이 실패를 성공으로 세지 않는다. 서비스 환경의7개 통과는 화면 담당이 보고한 별도 실행이고, 이 검토는 웹 코드와 재시작 전후 DB 논리 해시·served JS/source 일치 영수증을 확인한 범위다.

## 남은 판단과 전달 경계

제외1건의 실제 특징이 같은 사람·다른 사람·문에 대응하는지는 사용자 검수 대기다. 기존 관찰과 새 자동 출력을 정답으로 합치지 않았으며 완벽한 개별 정체 정답을 전체 비교의 추가 차단 조건으로 요구하지 않았다. 일부 점의 무늬와 어떤 저장 검출의 지속 대응은 사람 정체를 보장하지 않고, 잔존 점 기준 coverage가 원래 대상 전체의 보존율도 아니다.

새 비교 자료의 실제 브라우저 재생/seek·등록·GitHub 게시는 이 독립 검토에서 인증하지 않는다. 별도 [전달 기록](../experiments/EXP-0040-delivery.md)을 따른다. 이번 결과는 기술 비교로 수용하지만 오탐 감소 목표 미충족·카드 증가·제외 의미 미확정 때문에 기본 적용을 보류하며 추가 튜닝·추론을 자동 시작하지 않는다.

상세14건·35경로·전체 제외 참조·카드별 최초시각·민감도 감사는 로컬 `runtime/EXP-0040/review-output-audit.json`, 보존은 `review-full-preservation.json`, 최종 공개 수치 결속은 `review-final-metrics.json`에 있다. 원본 영상·좌표·특징·원시 결과·DB는 로컬에만 남긴다.
