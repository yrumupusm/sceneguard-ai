2026-11-09. 라벨 보완·사전학습 A 기준선 실제 평가·B/C 비교 준비 범위를 수락한다. 재학습이나 운영 적용은 승인하지 않는다. [독립 검토](EXP-0074-independent-review.md)의 준비 범위 통과, 해결된 P2 세 건, 미측정/미확보 한계를 확인했다.

고정197프레임과 승인5좌표/17배경 제거의 별도 보완본을 구분했다. 개발75프레임/56박스는56TP·0FP·0FN이며 학습122프레임은288TP·9FP·45FN이다. 사람 박스 행과 고유 인원/침입 사건을 구분한다. 개발에는 작은 GT와 A 누락이0이므로 누락 회복 개선을 주장할 수 없다. P01 세 장은 이 부족 조건의 미확정 확인 대상으로만 준비했으며 정답/개발 목록에 추가하지 않았다.

B/C의 동일 초기값·자료·학습량·순서와 BN affine 학습 가능성을 확인했다. 실제 모델 CPU forward 검증과 합성 checkpoint/단위 검증은 학습 성능과 별개다. 현재 코드·자료에서 다시 만든 계획과 plan-v3가 정확히 일치하고 미래 optimizer step은각305다. optimizer/새GPU/실제학습 checkpoint0, 기존 canonical145jobs/145attempts 보존이다. 실험 시작 때 실제 웹 답변 버전을 읽었고 승인된 좌표를 다시 묻지 않았다.
