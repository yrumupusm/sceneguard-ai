# EXP-0064 총괄 검토와 등록 판단

2026-11-07. **accepted_for_comparison / adoption_on_hold**. 첫 이진 행동 모델의 실제 학습·새 시험 참조 평가·기존 45개 별도 점수 계산 결과를 비교 기록으로 수용한다. 모델의 운영 채택이나 사람 검수 기준 행동 정확도를 승인하지 않는다.

실행 담당과 독립 검토 담당을 분리했다. 총괄은 실제 학습 결과·epoch 이력·시험 점수·후보 manifest를 대조한 요약과 모델 해시를 확인했고, 45개 결과를 고정 입력 계획과 연결해 측정값을 생성했다. 독립 검토는 전체 1,431개 시험 점수의 산술, 가중치 선택·유한 상태·실제 갱신 횟수, 기존 45개의 모든 점수·시각·박스·입력 범위·처리 배치와 405개 기준 출력의 바이트 보존을 확인했다. 자세한 근거는 [독립 검토](EXP-0064-independent-review.md)에 남긴다.

첫 전체 학습 실패는 삭제하지 않았다. 무한대 임계값의 기울기 노름 검사에서 종료한 뒤 표준 AMP 건너뛰기·스케일 조정과 실제 AdamW 갱신 기록을 보완했고, 새 코드 검토·소량 실행 뒤 별도 작업으로 학습했다. 10 epoch의 2,250회 갱신 시도 중 실제 적용 2,248회·건너뜀 2회를 확인했다. 검증 손실 최소인 6회차 모델을 선택한 뒤 시험을 한 번 수행했으며, 시험에 맞춘 설정·임계값 변경은 없다. 구현 검사 100개 통과는 행동 성능 검증과 구분한다.

새 시험은 공식 사람별 행동 라벨 참조에서 TP582·FP2·FN0·TN847이다. **별도 장소의 정상 라벨 2개가 모두 FP**이며, 별도 장소의 양성 330개가 많은 구성 때문에 높은 F1만으로 정상 행동 구별 능력을 주장할 수 없다. 검증 음성은 앉기만 있고, 같은 장소 시험은 카메라·배경·사람이 독립인 일반화 평가가 아니다. 사용자 검수 8개는 표본 정렬 관찰 범위로 재사용했고, 두 불일치 장면의 기존 답변을 반복 질문하거나 사람 정답으로 승격하지 않았다.

기존 45개는 학습·검증·시험과 임계값 선택에서 제외했다. 실제 회귀는 184,300 native 프레임을 처리해 3,573개 입력을 계산했고 467개가 임계값 0.5 이상이었다. 이는 겹칠 수 있는 행동 후보이며 침입 사건·인원·TP 수가 아니다. 일부 관측이 부족한 5,057개를 사람 검출 FN으로 확정하지 않는다. 기존 EXP-0062의 405개 판단 출력과 운영 코드 91개 파일은 보존했다. 침입 판단이 그대로인 것은 별도 점수 층의 설계에 따른 결과로서 성능 개선 증거가 아니다.

미세조정 전 95개 큐 작업과 원래 실패를 포함한 기존 시도는 보존됐다. 최종 45개 실행 직전 99개 작업·시도 행도 바뀌지 않았고 새 실행 하나만 추가됐다. 최종 학습과 45개 추론의 실제 종료·성공 영수증을 확인했다. 학습된 모델, 모든 점수, 분할·설정·실행 명령, 대표 불일치 영상은 별도 경로에 보관했다.

사람 검수 기준 정밀도·재현율·F1, 실제 사람 검출 누락 건수, 침입 완료 정확도는 미측정으로 남긴다. 다음 개선에는 별도 장소의 충분한 정상 보행·대기·문 접근 후 돌아가기 사례와 의미 검수가 필요하다. 이번 시험에 맞춘 자동 튜닝이나 운영 기본 모델 교체는 하지 않는다. 등록·게시·실제 화면 확인은 [전달 기록](../experiments/EXP-0064-delivery.md)에서 별도로 검증한다.
